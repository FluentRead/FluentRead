# 译文外观与阅读辅助

调整译文颜色、字号和样式，让原文与译文更容易区分；开启逐句高亮，可以快速找到对应句子。

<GuideVisual kind="appearance" />

## 调整译文外观

1. 打开**设置 → 界面风格 → 译文样式**。
2. 选择样式卡片，在**浅色网页**与**深色网页**预览中比较效果。
3. 展开**自定义外观**微调颜色、字号和字体。

颜色、字号等微调会立即应用到已打开网页的译文，无需重新翻译；切换整个样式后，下一次翻译使用新样式。双语译文样式不适用于仅译文模式，请先切换为双语对照。

网页字体难读时，点击快捷面板翻译卡片右下角的 **Aa**，切换为浏览器默认字体，再点一次恢复原来的字体设置。该选择自动保存，对所有网页已有和后续的译文生效，也适用于仅译文模式；不改变原来的样式或字号。

## 译文样式

样式分为**文字、颜色、线条、标记、卡片、趣味**。可先选朴素文字或配色；需要突出译文时，再试试卡片、便利贴或对话气泡。**模糊遮罩**与**黑幕遮挡**会隐藏译文，指针移上去才看清，适合先读原文再核对。

卡片和大部分趣味样式会根据正文区域的文字明暗，配对调整底色、文字和链接。同一页的不同区域分别适配，网站切换主题时已有译文也会更新，不取决于扩展或系统主题。**终端风格**和**星光夜读**保留各自的深色主题；浏览器不支持自动配色时，使用样式的固定配色。

| 自定义项 | 调整效果 |
| --- | --- |
| 译文颜色、背景色 | 为译文设置独立配色；选择默认沿用样式本身的颜色 |
| 线条颜色 | 改变下划线、波浪线、边框或引用色条 |
| 标记底色 | 改变荧光标记、学习标记和卡片底色 |
| 字号、字重、字体、不透明度 | 调整文字大小和醒目程度；字号范围为原文的 50%–250% |

颜色可用色板、取色器或直接输入 CSS 色值；无效值不会保存。选择颜色卡片会清除与该配色冲突的文字颜色和 CSS，保留字号、字体等其他调整。**恢复默认**回到当前样式的外观。你手动设置的文字、背景、线条和标记颜色优先于自动配色；请在浅色、深色预览中分别检查可读性。

熟悉 CSS 时，可在**直接输入 CSS 样式**填写声明，例如：

```css
color: rebeccapurple;
background: rgb(255, 248, 204);
font-size: 117%;
```

无需选择器。有效声明覆盖对应控件，只允许颜色、字体、边框等外观属性；网址、选择器和定位属性会被忽略。保存为命名样式后，点击“我的样式”卡片即可再次应用。

键盘聚焦译文链接时，模糊遮罩和黑幕遮挡也会揭开内容；不支持悬停的触屏直接显示译文。系统强制颜色模式使用系统的正文、背景和链接颜色；打印时去掉装饰背景和遮罩，保持译文可读。

## 双语逐句高亮

1. 在**设置 → 翻译设置 → 阅读辅助**开启**双语逐句高亮**。
2. 将光标移到原文或译文中的一句话上，两侧对应句子会一起高亮。
3. 点击**调整逐句高亮样式**，或进入**界面风格 → 逐句高亮样式**调整底色和线条。

分句时，浏览器折叠的源码换行按空格处理，网页明确保留的断行按实际换行处理。

可选八种预设，或自定义底色、下划线的颜色、不透明度、线型与粗细。底色不透明度设为 0% 可只留线条；选择**无下划线**可只留底色。修改自动保存并立即作用于已打开网页，**恢复预设外观**清除自定义项。

需要重复使用时，输入名称并点击**保存为新样式**，最多保存 12 套。**更新已选样式**覆盖所选配置；**保存为新样式**另存一套；**删除已选样式**只删除保存项，保留当前可编辑外观。高亮开关独立保存。

也可填写高亮 CSS：

```css
background-color: rgba(255, 220, 100, 0.3);
text-decoration: underline wavy #9d4edd;
text-decoration-thickness: 2px;
```

只支持[浏览器高亮绘制属性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::highlight#allowable_properties)，不支持的声明会提示并忽略。

高亮只在双语模式下生效，不增加翻译请求。句子对应关系按句序和相对长度估计，无法判断翻译是否正确，改写或调序较多时可能对不准。恢复原文、关闭高亮或离开文字会清除高亮，拖选文字时让位给网页选区。浏览器不支持 CSS Custom Highlight API 时仍可正常翻译。
