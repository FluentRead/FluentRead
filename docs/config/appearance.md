# 译文外观与阅读辅助

通过颜色、字号和显示样式区分原文与译文，也可以开启逐句高亮辅助阅读。

<GuideVisual kind="appearance" />

## 调整译文外观

1. 打开 **设置 → 界面风格 → 译文样式**。
2. 点击样式卡片，在预览中比较效果；需要时调整颜色和字号。
3. 外观调整会立即显示在已有译文上。切换整个样式后，下一次翻译使用新样式。

仅译文模式不使用双语译文样式；请先切换为双语对照。

## 译文样式

在 **设置 → 界面风格 → 译文样式** 中选择双语对照时译文的显示效果。样式按 **文字、线条、标记、卡片、趣味** 分类，每张卡片直接展示实际效果；旁边的预览模拟一段网页，可以切换 **浅色网页** 和 **深色网页**，检查译文在不同配色的网站上是否清楚。

**自定义外观** 可以进一步调整：

- **译文颜色**：为译文单独指定文字颜色，选择“默认”则跟随网页。
- **译文背景色**：给普通译文或任何内置样式设置独立背景；选择“默认”则保留该样式原有背景。
- **线条颜色**：修改下划线、波浪线、边框和引用色条的颜色。
- **标记底色**：修改荧光标记、学习标记、底色和卡片的颜色，并按样式自动调整深浅。
- **字号、不透明度、字重和字体**：用滑块或直接输入 50%–250% 的字号，相对原文放大或缩小译文，或让译文更醒目、更柔和。

每种颜色都提供精选色板和取色器，也可直接输入 CSS 颜色名称、`rgb(红, 绿, 蓝)` 或十六进制色值；无效输入不会保存。点“恢复默认”回到样式自带的外观。颜色、字号等外观调整会立即应用到已打开网页上的译文，无需重新翻译；切换样式后，下一次翻译开始使用新样式。仅译文模式不使用这些样式，页面会提示并提供切换到双语对照的按钮。

也可以在 **直接输入 CSS 样式** 中写译文的声明，例如 `color: rebeccapurple; background: rgb(255, 248, 204); font-size: 117%;`。无需写选择器；只接受颜色、字体、边框等外观属性，网址、选择器和定位属性会被忽略。有效声明会覆盖上方控件的对应值，并立即显示在当前预览中。保存为命名样式后，样式卡片也会显示自己的真实效果。

“模糊遮罩”会先模糊显示译文，指针移到译文上再看清，适合先读原文、再核对自己的理解。“黑幕遮挡”用同样的方式，以色块逐行盖住译文。

想让长文更好读，可以试试“批注小字”“宽松行距”“首行缩进”“分隔细线”和“箭头引导”；想换个心情，**趣味** 分类里有渐变文字、彩虹荧光、手绘圈注、便利贴、对话气泡和终端风格等。“自适应底色”“逐行色块”“毛玻璃卡片”等样式的线条和底色跟随网页文字颜色，浅色网页和深色网页上都保持清楚。

## 双语逐句高亮

在 **设置 → 翻译设置 → 阅读辅助** 中开启 **双语逐句高亮** 后，将光标移到原文或译文中的一句话上，即可同时高亮两侧对应的句子。无需点击或按快捷键，适合在长段落中定位难句、核对翻译偏差。阅读辅助依次显示高亮开关与说明、逐句高亮样式入口、实时预览，三行之间用虚线分隔。点击第二行右侧的 **调整逐句高亮样式**，可直接进入外观设置；底部的阅读示例提供多句对照，可以直接试用。

在 **设置 → 界面风格 → 逐句高亮样式** 中选择八种预设。**自定义外观** 与译文样式一样默认折叠，点击标题展开后，可以自定义高亮底色、下划线颜色、两者的不透明度、线型和粗细。底色不透明度设为 0% 时只保留下划线；下划线形态选“无下划线”时只显示底色。支持实线、点线、虚线、双线与波浪线，预览和样式缩略图默认跟随界面的浅色、深色或系统主题，也可手动切换“浅色网页”和“深色网页”来比较效果。修改后立即应用到已打开网页，无需重新翻译；配置会自动保存。“恢复预设外观”清除自定义项，选择其他预设也会恢复该预设的外观。收起面板不影响当前外观，重新打开设置时面板默认收起。高亮开关独立保存。

还可以在 **直接输入 CSS 样式** 中写声明，例如：

```css
background-color: rgba(255, 220, 100, 0.3);
text-decoration: underline wavy #9d4edd;
text-decoration-thickness: 2px;
```

有效 CSS 会覆盖上方控件的对应值，立即应用到预览和已打开网页。支持文字颜色、底色、下划线、文字阴影等[浏览器高亮绘制属性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::highlight#allowable_properties)，无需选择器；不支持的声明会提示并忽略。

输入名称后点击 **保存为新样式**，可以保存最多 12 套逐句高亮配置，每套独立包含基础预设、外观控件和 CSS，并在卡片中展示真实效果。点击卡片切换配置，重新打开设置后仍保留。修改当前外观会即时生效，**更新已选样式** 将修改和新名称写入原配置；**保存为新样式** 保留旧配置，另存一套。**删除已选样式** 只删除保存的配置，当前外观仍可继续调整。内置预设和高亮开关独立于已保存的配置。

原文和译文句数一致时按顺序对应；服务拆句或合句时，根据句序和相对长度组成相邻句组。这是本地近似对齐，不能判断翻译是否正确，改写幅度较大或调整语序的译文可能无法准确对应。高亮不增加翻译请求，也不改变网页文字和排版。

仅双语模式生效。恢复原文、关闭开关或离开文字后清除高亮；拖选文字时让位给网页选区。需要浏览器支持 CSS Custom Highlight API，旧版浏览器缺少该能力时保留正常翻译。
