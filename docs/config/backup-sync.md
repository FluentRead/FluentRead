# 备份与同步

在更换浏览器、多设备切换或重装卸载前，按需要选择合适的备份与同步方式，确保配置、密钥与学习数据不丢失且不越界暴露。

## 1. 本地完整备份（迁移首选） {#本地完整备份}

适合迁移全部配置、词书收藏与模型用量：

1. 打开**设置 → 备份与恢复 → 本地备份**，点击**导出备份**。
2. 按需勾选是否**包含单词上下文**（默认不勾选），确认并保存 JSON 文件。
3. 在新浏览器导入该文件，先核对数据范围摘要（可展开查看逐项差异），再点击确认恢复。

::: warning 妥善保管完整备份文件
本地完整备份为**未加密 JSON**，可能包含 API Key、服务凭据、收藏原文与来源信息。切勿将其上传到公开 Issue 或分享给他人。旧版配置与备份可兼容导入。
:::

只需迁移词书到 Anki 时，可直接在学习中心[导出到 Anki](/guide/vocabulary-book#数据与迁移)。

## 2. 设置历史与 6 小时自动快照 {#最近修改与自动设置快照}

误改某个选项想快速撤回时，无需翻找备份文件：

- **设置历史 → 最近修改**：记录每次改动的设置名、前后值与时间，支持点击并切换**与当前比较**检查恢复影响。
- **自动设置快照**：每 **6 小时**自动保留一份配置快照。两类记录各保留最近 **10 份**，不含词书、模型用量与 API 凭据。

## 3. 云备份范围与敏感配置边界 {#云备份的范围与敏感配置选择}

Google Drive 与 WebDAV 云备份**始终由你手动发起**，不会随设置修改自动上传，两者也各自独立存储、互不转存。

| 同步范围 | 包含内容 | 默认状态 |
| --- | --- | --- |
| **基础配置（v2）** | 语言、译文外观、快捷键、网站规则、界面偏好等普通设置 | **始终开启**（恢复/合并保留本机密钥与连接） |
| **敏感配置（v1）** | API Key、服务凭据、服务与模型选择、地址、鉴权请求头、自定义请求体与私密提示词 | **默认关闭**（需阅读风险并勾选**同意并开启**） |

::: danger 云备份加密边界说明
云备份上传前虽在本机加密，但使用的是**固定公开应用口令**——任何拿到该云端文件的人都可解密。因此建议日常仅同步**基础配置**；若开启敏感配置迁移密钥，请务必保护好云盘账号、目录权限与设备安全，切勿共享备份文件。
:::

- 云备份不包含单词本、聊天记录、用量统计与最近文档；敏感开关仅在当前浏览器持续保存，其他设备需分别确认。
- 关闭敏感开关不会自动擦除旧云端文件中的历史密钥；需主动执行一次基础配置保存/合并更新当前文件，并自行清理网盘历史版本。

## 4. Google Drive 配置同步 {#google-drive-配置同步}

目前仅支持**桌面版 Google Chrome**（其他 Chromium 衍生浏览器请使用 **WebDAV** 或**本地备份**）：

1. 在**云备份**选择 **Google Drive**，确认同步范围。
2. 点击**立即与Google Drive同步**并完成 Google 授权（仅申请管理流畅阅读隐藏应用数据的 `drive.appdata` 权限，不访问普通文件、Gmail 或联系人）。
3. 核对账号，选择**保存本机**、**恢复云端**或**逐项合并**，预览变更后确认。

详细权限与存储说明见[隐私政策 · Google Drive 同步](/guide/privacy#google-drive-配置同步)。

## 5. WebDAV 云备份 {#webdav-云备份}

支持坚果云、Koofr、群晖 NAS、Nextcloud 等标准 WebDAV 服务。在**云备份**选择 **WebDAV**，填入目录地址、用户名和应用密码，点击**测试并保存**（仅保存本机连接，连接参数绝不进入云备份），随后手动点击同步并确认上传。

以坚果云与 NAS 为例的完整步骤见[WebDAV 云备份指南](/guide/webdav)。

## 6. 删除云端备份 {#删除云端备份}

在**云备份**选定对应服务，点击**删除云端备份**，核对实际账号/服务器地址并输入**确定删除**后确认：

- 仅删除云端固定备份文件并清除本机同步记录，**保留本机配置、API Key 与连接设置**。
- 撤销授权、清除连接或卸载扩展不会自动删除云端文件；网盘回收站与历史版本需在服务商处另行清理。

## 缓存和备份有什么区别？ {#缓存和备份有什么不同}

**翻译缓存**仅用于加速重复段落显示，清理缓存不会删除收藏词书，也不能替代配置备份。
