# 备份与同步

更新日期：2026 年 10 月 5 日。

换浏览器、换设备或卸载之前，先保存需要的配置和学习数据。完整备份、设置历史和云端配置同步各自有不同用途。

## 选择合适的方式

| 你想做什么 | 使用什么 |
| --- | --- |
| 保存配置、词书和模型用量，迁移到另一个浏览器 | 本地完整备份 |
| 撤回最近的设置修改 | 设置历史 |
| 在自己的设备间同步设置 | 设置页提供的配置同步 |

## 云备份的范围与本次同意

Google Drive 和 WebDAV 默认**仅同步普通设置**，如语言、外观、快捷键和网站规则。整个敏感连接配置都不参与普通备份，包括 API Key、服务凭据、鉴权请求头、服务地址、翻译服务选择与模型、自定义请求参数；私密提示词及无法识别的字段也不上传。恢复或合并普通设置时，本机密钥、翻译服务、地址和自定义连接保持不变。云备份不包含单词本、聊天记录或用量统计。

需要迁移敏感连接时，打开**本次包含 API Key 等敏感信息**，阅读风险、勾选确认，再点击**同意，仅本次包含**。保存或合并会纳入本机敏感信息；恢复只应用云端文件实际包含的内容，只有普通设置的备份不会补出密钥或覆盖本机连接。该同意只用于此次操作；完成、失败（包括生成预览失败）、取消、离开或重新打开设置、切换备份方式或 Google 账号后，都会恢复默认关闭。

备份在本机加密，但使用公开的应用口令，**拿到文件的人仍可解密**。第三方账号被盗、共享目录被他人访问或备份泄露时，API Key 等敏感信息可能泄露。建议仅同步普通设置；迁移密钥时保护账号和目录权限，避免分享备份文件。

### 旧备份与旧扩展的兼容

- 当前扩展仍能读取旧的完整 v1 云备份。普通模式只恢复或合并普通设置，保留本机敏感连接。
- 本次同意后保存的完整敏感备份继续使用原 v1 格式，旧扩展仍可读取。新的普通设置备份使用 v2 格式，旧扩展会安全拒绝，需升级后读取。
- 升级前尚未确认的同步事务失效，需要重新生成预览并核对范围。
- 关闭敏感开关或仅恢复普通设置不会修改旧云端文件。只有确认保存或合并普通设置后，才会从当前云端文件中移除敏感信息；这不会删除旧文件或服务商保留的历史版本，需另行管理这些副本。

## 删除云端备份

在**配置云备份**中选择 Google Drive 或 WebDAV，点击**删除云端备份**。扩展先读取目标，确认页显示实际账号；WebDAV 同时显示服务器地址。核对后点击**确定删除**，只删除当前服务上的 FluentRead 配置备份文件，包括文件中已有的敏感信息。本机配置、API Key 和连接设置会保留；删除成功后清除此服务在本机的同步时间与比较基线。

取消、关闭页面或切换 Google 账号不会删除文件。文件已不存在时显示**没有云端备份**，点击**完成**清理旧同步记录。确认期间账号、服务器或文件版本变化时，需要重新检查；删除不依赖备份内容解密，因此旧 v1、v2 或无法解密的文件也能清理。缺少强版本信息时会阻止删除并显示服务商页面的手动清理指引。

确认框优先显示目标账号、删除后无法恢复和本机配置保留；**更多说明**默认收起。此操作只清理当前备份文件；服务商保留的回收站、历史版本和其他设备上的副本需要另行管理。之后手动同步或其他设备重新上传仍可创建新备份。清除连接设置、撤销授权和卸载扩展不会自动删除云端文件。

## 本地完整备份

进入 **设置 → 备份与恢复**，导出完整数据备份并保存文件。导入时先查看预览，确认数据范围和影响，再执行恢复。

完整备份可能包含 API 密钥、服务凭据和收藏原文，请妥善保存。旧版备份仍可按导入预览恢复；不要把备份发到公开反馈中。

学习中心还可以单独[导出到 Anki](/guide/vocabulary-book#数据与迁移)。

## 最近修改与自动设置快照

**设置历史** 的 **最近修改** 展示设置名称、修改前后的值和时间。点击记录，默认查看相对于上一次保存的本次修改；切换到 **与当前比较**，确认恢复会影响哪些当前设置。最早的记录没有前一份快照，只能与当前比较。

**自动设置快照** 每 6 小时保留一份设置，列表说明与当前设置有多少项不同。两类记录各保留最多 10 份。

设置历史不包含词书、模型用量或 API 凭据。恢复前会再次确认。

</details>

## Google Drive 配置同步

在 **设置 → 备份与恢复 → 配置云备份** 中选择 Google Drive，再开始操作。

同步是否可用，以所安装版本的设置页为准。默认范围为普通设置；敏感连接需按上文说明单次同意。

1. 确认本次同步范围，点击 **立即与Google Drive同步**，完成本次 Google 授权。
2. 核对账号，查看本地与云端的设置差异。
3. 选择同步方向或逐项合并。
4. 确认后执行，并查看成功结果及上次同步时间。

打开设置不会自动访问 Drive。访问范围仅限 FluentRead 自己的隐藏应用数据；不会读取你的其他文件、Gmail 或联系人。Google 账号授权与本次纳入敏感信息的同意是两个步骤；备份的保护方式及删除流程请阅读[完整同步隐私说明](/guide/privacy#google-drive-配置同步)。

取消预览结束本次操作。撤销授权或卸载扩展不会自动删除云端备份。

</details>

## WebDAV 配置云备份

希望把配置保存在自己的网盘、NAS 或服务器中，可以在 **配置云备份** 中选择 **WebDAV**。填写目录地址和应用密码，测试并保存连接，再查看预览、确认备份操作。

它与 Google Drive 一样，默认仅同步普通设置，本次同意后才可包含敏感连接。用于访问备份服务器的 WebDAV 地址、用户名和应用密码仍只保存在当前设备，不进入云备份。保存、恢复和合并都由你主动发起。

连接要求、保存与恢复步骤、文件保护及删除方法见[WebDAV 云备份指南](/guide/webdav)。

</details>

## 缓存和备份有什么不同

翻译缓存用于复用已经完成的译文。清理缓存不会删除学习收藏，也不能替代完整备份。
