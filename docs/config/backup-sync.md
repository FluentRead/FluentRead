# 备份与同步

换浏览器、换设备或卸载前，先保存需要的配置和学习数据。

<GuideVisual kind="backup" />

## 选择合适的方式

| 你想做什么 | 使用什么 |
| --- | --- |
| 迁移配置、单词本和模型用量 | 本地完整备份 |
| 撤回最近的设置修改 | 设置历史 |
| 在自己的设备间保存和恢复设置 | Google Drive 或 WebDAV 云备份 |

## 本地完整备份

1. 打开**设置 → 备份与恢复 → 本地备份**，点击**导出备份**。
2. 选择是否包含单词上下文，保存下载的文件。
3. 在另一浏览器导入文件，先查看数据范围摘要，需要时展开设置差异，再确认恢复。

完整备份是未加密的 JSON，可能包含 API Key、服务凭据、收藏原文和来源信息，请妥善保存，不要上传到公开反馈。旧版配置 JSON 与备份仍可导入，缺少的新设置会按兼容规则补齐。

导出时可勾选默认关闭的**包含单词上下文**，再点击**导出备份**；**取消**和关闭窗口都不会导出。确认尚未完成时离开该分区会取消本次确认；已经开始生成的文件仍会下载。读取导入文件时离开分区，需要返回后重新选择文件；已经确认的恢复会继续完成。

只需迁移学习卡片时，也可在学习中心[导出到 Anki](/guide/vocabulary-book#数据与迁移)。

## 云备份的范围与敏感配置选择

云备份由你手动发起，不会随设置修改自动上传。Google Drive 与 WebDAV 分别保存备份，不会自动互相转存。

| 同步内容 | 包含什么 |
| --- | --- |
| 基础配置，始终开启 | 语言、外观、快捷键、网站规则等普通设置 |
| 敏感配置，默认关闭 | API Key、服务凭据、服务与模型选择、地址、鉴权请求头、自定义请求参数、私密提示词等 |

基础配置排除整个敏感连接及未知字段；恢复或合并时保留本机密钥、翻译服务、地址与自定义连接。云备份不包含单词本、聊天记录或用量统计。

需要迁移敏感信息时，打开**敏感配置**，阅读风险并勾选确认，点击**同意并开启**。该选择在当前浏览器持续保存，直到手动关闭；取消、失败、重开设置或切换备份方式与账号都不会关闭它，其他设备需分别确认。恢复只应用云端文件实际包含的内容，开启选项无法恢复原本未备份的密钥。

云备份在本机加密，但使用固定公开应用口令，**拿到文件的人仍可解密**。账号被盗、目录共享或文件泄露可能暴露 API Key。建议只备份基础配置；迁移密钥时保护账号、目录权限和设备，避免分享文件。

### 旧备份与旧扩展的兼容

当前扩展可读取旧完整 v1 备份，基础范围只应用普通设置。包含敏感配置的备份仍用 v1；仅基础配置的备份使用 v2，旧扩展需升级后才能读取。升级前未确认的操作需要重新预览。

关闭敏感配置或仅恢复基础配置不会清除旧云端文件中的秘密。确认保存或合并基础配置后，才会从当前文件中移除敏感信息；服务商历史版本与其他副本需另行管理。

## Google Drive 配置同步

目前仅支持**桌面版 Google Chrome**。Aside、Ego Lite、Vivaldi（含移动版）及其他 Chromium 衍生浏览器尚不在支持范围；能安装 Chrome 扩展不代表支持 Google 授权。无法确认浏览器兼容性时不会显示同步按钮，请改用 **WebDAV** 或上方的**本地备份**。

1. 在**云备份**选择 **Google Drive**，确认同步范围。
2. 点击**立即与Google Drive同步**，完成 Google 授权。
3. 核对账号，选择保存本机、恢复云端或逐项合并。
4. 查看变更并确认，完成后检查同步时间。

是否支持以当前安装版本为准。打开设置不会访问 Drive；只有主动操作才读取流畅阅读的隐藏应用数据，不访问普通文件、Gmail 或联系人。Google 授权与敏感配置同意分别确认，详见[同步隐私说明](/guide/privacy#google-drive-配置同步)。

## WebDAV 云备份

在**云备份**选择 **WebDAV**，填写已有目录的完整地址、用户名和应用密码，点击**测试并保存**。这一步只保存本机连接，之后还需手动同步、查看预览并确认。

连接地址、用户名和应用密码不进入云备份。以坚果云为例的操作见[WebDAV 云备份指南](/guide/webdav)。

## 删除云端备份

在**云备份**中选定服务，点击**删除云端备份**。核对实际账号和 WebDAV 服务器地址，输入**确定删除**，再点击**删除备份**。

删除只影响该服务的当前配置备份文件；本机配置、API Key 和连接设置保留，本机同步记录会清除。取消不会删除；文件已不存在时点击**完成**即可清理旧记录。旧格式或无法解密的文件也可删除，因为删除不依赖内容解密。

账号、连接或文件变化时需要重新确认。WebDAV 缺少强版本信息时会再次核对内容，请避免多台设备同时操作；无法安全核验时按页面提示到服务商处手动删除。

服务商回收站、历史版本和其他设备副本需另行清理。撤销授权、清除连接或卸载扩展不会删除云端文件，之后手动同步也可能重新创建备份。

## 最近修改与自动设置快照

**设置历史 → 最近修改**列出设置名称、修改前后值与时间。点击记录查看本次修改，切换**与当前比较**可检查恢复对现有设置的影响；最早的记录只能与当前比较。

**自动设置快照**每 6 小时保留一份，两类记录各最多 10 份。它们不包含单词本、模型用量或 API 凭据，恢复前需确认。

## 缓存和备份有什么不同

缓存复用已有译文，清理它不会删除学习收藏，也不能代替备份。
