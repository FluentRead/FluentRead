# 备份与同步

换浏览器、换设备或卸载之前，先保存需要的配置和学习数据。完整备份、设置历史和云端配置同步各自有不同用途。

## 选择合适的方式

| 你想做什么 | 使用什么 |
| --- | --- |
| 保存配置、词书和模型用量，迁移到另一个浏览器 | 本地完整备份 |
| 撤回最近的设置修改 | 设置历史 |
| 在自己的设备间同步设置 | 设置页提供的配置同步 |

## 本地完整备份

进入 **设置 → 备份与恢复**，导出完整数据备份并保存文件。导入时先查看预览，确认数据范围和影响，再执行恢复。

完整备份可能包含 API 密钥、服务凭据和收藏原文，请妥善保存。旧版备份仍可按导入预览恢复；不要把备份发到公开反馈中。

学习中心还可以单独[导出到 Anki](/guide/vocabulary-book#数据与迁移)。

## 最近修改与自动设置快照

**设置历史** 的 **最近修改** 展示设置名称、修改前后的值和时间。点击记录，默认查看相对于上一次保存的本次修改；切换到 **与当前比较**，确认恢复会影响哪些当前设置。最早的记录没有前一份快照，只能与当前比较。

**自动设置快照** 每 6 小时保留一份设置，列表说明与当前设置有多少项不同。两类记录各保留最多 10 份。

设置历史不包含词书、模型用量或 API 凭据。恢复前会再次确认。

## Google Drive 配置同步

在 **设置 → 备份与恢复 → 配置云备份** 中选择 Google Drive，再开始操作。

同步是否可用，以所安装版本的设置页为准。它只用于配置，不同步词书、聊天记录和用量统计。

1. 点击 **立即与Google Drive同步**，完成本次授权。
2. 核对账号，查看本地与云端的设置差异。
3. 选择同步方向或逐项合并。
4. 确认后执行，并查看成功结果及上次同步时间。

打开设置不会自动访问 Drive。访问范围仅限 FluentRead 自己的隐藏应用数据；不会读取你的其他文件、Gmail 或联系人。配置中包含服务凭据，备份的保护方式及删除流程请阅读[完整同步隐私说明](/guide/privacy#google-drive-配置同步)。

取消预览结束本次操作。撤销授权或卸载扩展不会自动删除云端备份。

## WebDAV 配置云备份

希望把配置保存在自己的网盘、NAS 或服务器中，可以在 **配置云备份** 中选择 **WebDAV**。填写目录地址和应用密码，测试并保存连接，再查看预览、确认备份操作。

它与 Google Drive 一样，保存配置和服务凭据，不包含词书、聊天记录或用量统计。WebDAV 连接凭据只保存在当前设备。保存、恢复和合并都由你主动发起。

连接要求、保存与恢复步骤、文件保护及删除方法见[WebDAV 云备份指南](/guide/webdav)。

## 缓存和备份有什么不同

翻译缓存用于复用已经完成的译文。清理缓存不会删除学习收藏，也不能替代完整备份。
