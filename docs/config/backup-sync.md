# 备份与同步

在更换浏览器、多设备切换或重装卸载前，按需要选择合适的备份与同步方式，确保配置、密钥与学习数据不丢失且不越界暴露。

## 1. 本地完整备份（迁移首选） {#本地完整备份}

适合迁移全部配置、词书收藏与模型用量：

1. 打开**设置 → 备份与恢复 → 本地备份**，点击**导出备份**。
2. 按需勾选是否**包含单词上下文**（默认不勾选），确认并保存 JSON 文件。
3. 在新浏览器导入该文件，先核对数据范围摘要（可展开查看逐项差异），再点击确认恢复。

::: warning 妥善保管完整备份文件
本地完整备份为**未加密 JSON**，可能包含 API Key、服务凭据、收藏原文与来源信息。切勿将其上传到公开 Issue 或分享给他人。旧版配置与备份可兼容导入。
:::

只需迁移词书到 Anki 时，可直接在学习中心[导出到 Anki](/guide/vocabulary-book#数据与迁移)。

## 2. 设置历史与 6 小时自动快照 {#最近修改与自动设置快照}

误改某个选项想快速撤回时，无需翻找备份文件：

- **设置历史 → 最近修改**：记录每次改动的设置名、前后值与时间，支持点击并切换**与当前比较**检查恢复影响。
- **自动设置快照**：每 **6 小时**自动保留一份配置快照。两类记录各保留最近 **10 份**，不含词书、模型用量与 API 凭据。

## 3. 云备份范围、端到端加密与学习资产同步 {#云备份的范围与敏感配置选择}

Google Drive 与 WebDAV 云备份**默认由你手动发起**（WebDAV 还支持可选开启的定时自动同步），两者各自独立存储、互不转存。

| 同步范围 | 包含内容 | 默认状态 |
| --- | --- | --- |
| **基础配置（v2）** | 语言、译文外观、快捷键、网站规则、界面偏好等普通设置 | **始终开启**（恢复/合并保留本机密钥与连接） |
| **敏感配置（v1）** | API Key、服务凭据、服务与模型选择、地址、鉴权请求头、自定义请求体与私密提示词 | **默认关闭**（需阅读风险并勾选**同意并开启**） |
| **单词本** | 收藏词条、复习调度、掌握度与笔记（来源网页上下文另有独立开关，默认关闭） | **默认关闭**（同步预览确认后应用） |
| **个人校订** | 已确认的译文校订规则与项目归属，按身份和最新版本确定性合并 | **默认关闭**（同步预览确认后应用） |
| **阅读材料元数据** | 标题、来源地址、阅读进度、主题与个人笔记（不含本地大型文件） | **默认关闭**（同步预览确认后应用） |

所有学习资产开关默认关闭，开启后在同步预览弹窗中会展示各类别的本机与云端条目数及新增/更新摘要，经你确认后才应用。

### 端到端加密口令（零知识保护）

云备份均在本机通过 `PBKDF2-SHA256`（600,000 次迭代）派生 `AES-256-GCM` 密钥并绑定认证数据（AAD）防降级，支持两种口令模式：

- **兼容模式（默认应用口令）**：使用固定公开应用口令（v1 信封），无需记忆额外密码；但**拿到文件的人仍可解密**，主要依赖云盘账号、目录权限与设备安全。
- **自定义端到端口令（零知识）**：由你设置至少 12 个字符的自定义口令（v2 信封，AAD 强制绑定 `keyMode: "custom"`）。自定义口令绝不会写入 `browser.storage.sync`、配置导出、日志或云端文件；你可以选择仅本次同步使用、在当前浏览器会话内保持（退出清除），或在本机扩展后台加密存储中留存（WebDAV 用于支持定时自动同步），并可随时一键清除。
  - **本机留存安全边界**：选择“在本机留存”时，口令与本地 API 凭据（`local:credentials`）同样保存在扩展后台的本机加密 IndexedDB 中，可防止泄露到浏览器同步存储、配置导出、日志或网页脚本；但若他人或本地恶意程序已获得当前浏览器配置文件的完全访问权限，仍可能访问本机扩展存储。需要最高隔离级别时，请使用“仅本次同步”或“当前会话保持”。

::: danger 零知识口令与加密边界说明
- 兼容模式下使用**固定公开应用口令**，任何拿到该云端文件的人都可解密，建议同步敏感配置时开启**自定义端到端口令**。
- 零知识模式下，一旦遗忘自定义口令，任何人都无法恢复云端备份内容，请妥善保存。
:::

- 云备份不包含聊天记录、用量统计与最近文档；敏感配置与学习资产开关仅在当前浏览器持续保存，其他设备需分别确认。
- 关闭敏感开关不会自动擦除旧云端文件中的历史密钥；需主动执行一次基础配置保存/合并更新当前文件，并自行清理网盘历史版本。
- 当前扩展可无缝读取旧版兼容模式（v1）备份：启用自定义端到端口令后，读取旧版备份时会自动以兼容模式解密，并在确认保存或合并时重新加密升级为自定义口令（v2）。若云端备份已使用自定义口令而本机未输入或口令错误，系统会提示输入口令且不会修改任何本机数据。

### 可选定时自动同步（WebDAV）

WebDAV 备份支持可选的**定时自动同步**，默认关闭。你可以按需开启并选择同步周期（30 分钟、1 小时、6 小时或 24 小时）：

- 仅执行**安全三方合并**，不会在缺少共同基线或存在字段冲突时盲目覆盖本机或云端数据；检测到冲突时会暂停自动写入并提示手动审阅。
- 若自定义端到端口令未解锁，自动同步会安全暂停并标记为待解锁状态，不修改任何数据。
- 自动同步与手动同步共享互斥队列，离线时跳过并在网络错误时按指数退避重试。

## 4. Google Drive 配置同步 {#google-drive-配置同步}

目前仅支持**桌面版 Google Chrome**（其他 Chromium 衍生浏览器请使用 **WebDAV** 或**本地备份**）：

1. 在**云备份**选择 **Google Drive**，确认同步范围。
2. 点击**立即与Google Drive同步**并完成 Google 授权（仅申请管理流畅阅读隐藏应用数据的 `drive.appdata` 权限，不访问普通文件、Gmail 或联系人）。
3. 核对账号，选择**保存本机**、**恢复云端**或**逐项合并**，预览变更后确认。

详细权限与存储说明见[隐私政策 · Google Drive 同步](/guide/privacy#google-drive-配置同步)。

## 5. WebDAV 云备份 {#webdav-云备份}

支持坚果云、Koofr、群晖 NAS、Nextcloud 等标准 WebDAV 服务。在**云备份**选择 **WebDAV**，填入目录地址、用户名和应用密码，点击**测试并保存**（仅保存本机连接，连接参数绝不进入云备份），随后手动点击同步并确认上传。

以坚果云与 NAS 为例的完整步骤见[WebDAV 云备份指南](/guide/webdav)。

## 6. 删除云端备份 {#删除云端备份}

在**云备份**选定对应服务，点击**删除云端备份**，核对实际账号/服务器地址并输入**确定删除**后确认：

- 仅删除云端固定备份文件并清除本机同步记录，**保留本机配置、API Key 与连接设置**。
- 撤销授权、清除连接或卸载扩展不会自动删除云端文件；网盘回收站与历史版本需在服务商处另行清理。

## 缓存和备份有什么区别？ {#缓存和备份有什么不同}

**翻译缓存**仅用于加速重复段落显示，清理缓存不会删除收藏词书，也不能替代配置备份。
