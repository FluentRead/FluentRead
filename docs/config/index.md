# 设置

打开 FluentRead 弹窗，点击设置图标即可进入完整设置。大多数选择会自动保存，不需要登录账号。

## 先调整这几项

- **默认目标语言**：选择网页、划词和悬浮翻译要使用的语言。
- **默认翻译服务**：选择网页翻译默认使用的服务。
- **翻译模式**：选择保留原文的双语对照，或只显示译文。
- **译文样式**：调整颜色、字号和译文显示方式。
- **界面主题**：选择跟随系统、亮色或暗色主题。
- **界面布局**：在“基础配置 → 界面风格”中，通过“界面与弹窗”选择风格，通过“菜单栏布局”编排模块和快捷功能卡片。

## 界面布局

界面布局包含“界面与弹窗”“动画与加载效果”和“菜单栏布局”三个分组。14 套皮肤分为“效率与可读性”和“氛围风格”两组：前者包含默认、简约、紧凑和高对比，后者包含奶酪、海盐、抹茶、樱花、Emoji 乐园、夜幕、纸张护眼、极光舷窗、像素街机和落日公路。菜单栏顶部品牌与设置入口固定保留；翻译控制、当前网站、快捷功能栏和底部信息栏可以编排，快捷功能栏默认以两列三行展示悬停、划词、图片、圈选、视频翻译与文档翻译六个入口，统一线条图标位于左侧，名称与简短提示左对齐，状态点位于右侧；每个入口通过浅色边框和悬停反馈区分点击范围，不再叠加外层大边框。「译文显示」默认隐藏，可在菜单栏布局中重新添加；已保存的显隐选择仍会保留。每个入口都可以逐张编排。两级顺序和显隐都会自动保存。风格和布局只改变界面呈现，不会关闭对应功能；隐藏后的入口仍可在设置中恢复。所有皮肤（包括完整默认布局）的菜单栏都按实际内容自适应高度；隐藏栏目或卡片后同步收缩，不在底部保留多余空白。

十套氛围风格分别搭配轻量背景纹理与图案。海盐采用晴空蓝与水波，抹茶采用鲜绿叶片与奶油白，樱花采用明亮花粉与轻柔花瓣；Emoji 乐园以奶油纸、彩色贴纸和小表情增添趣味。奶酪、夜幕与纸张护眼保留各自的暖色、夜色与纸张氛围；极光舷窗用青绿光带表现远方感，像素街机用方格、霓虹和街机轮廓强化节奏，落日公路则以夕阳、路面和暮蓝表达慢读氛围。图案位于内容背后，控件保留清晰的文字、边界和焦点。完成翻译后，恢复原文按钮切换为浅强调底色，便于识别当前状态。所有风格兼容深浅模式，风格和布局预览会同步变化。

菜单栏重新打开时会先读取已保存配置，再直接呈现对应的皮肤、主题与栏目布局，减少默认界面短暂闪现。

## 让网站按你的习惯工作

在“网站规则”中可以：

- 让常用网站打开后自动翻译；
- 对某个网站暂时或长期关闭 FluentRead；
- 管理已经保存的网站名单。

规则按网站保存，不会影响其他网站。

## 更多功能

“翻译设置”可以调整悬浮、划词、输入框和全文翻译；“图片翻译”和“圈选翻译”分别管理整图与局部阅读，共享本地 OCR 语言包；“视频字幕翻译”管理 YouTube 字幕；“备份与恢复”用于迁移或找回 FluentRead 数据。

如果只是想连接一个翻译服务，请继续阅读[翻译服务](/config/translation-engines)。

## 网站适配

在网站规则中管理正文范围、保护区域和自定义 JSON。第一次调整网站时，跟随[自定义网站适配教程](/guide/custom-site-rules)操作；需要查询字段和合并规则时，参见[网站适配 JSON 参考](./site-adaptation)。
