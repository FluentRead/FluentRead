# 设置

点击扩展菜单中的齿轮进入完整设置。不知道某项在哪里时，可以直接搜索，例如“目标语言”“快捷键”“菜单栏布局”。修改通常会自动保存。

## 常用设置

| 设置 | 什么时候需要 |
| --- | --- |
| 目标语言 | 想读另一种语言，或切换简体、繁体中文 |
| 翻译服务 | 免费服务不稳定，或想使用已有的 AI / DeepL 服务 |
| 译文样式 | 希望原文与译文更容易区分 |
| 悬浮和划词触发方式 | 想减少误触，或让查词更快 |
| 自动翻译与网站规则 | 某些网站总要翻译，另一些希望保持原样 |

## 界面与菜单栏布局

在 **界面风格** 中选择浅色、深色与不同皮肤。进入 **菜单栏布局**，拖动预览里的区域或快捷卡片调整顺序；不常用的点“隐藏”，需要时再“添加”回来。也可以在列表中用方向按钮调整。

隐藏入口只改变菜单显示，不会关闭对应功能。要停用图片、圈选、字幕或翻译卡，请在各功能自己的设置中关闭。

## 各功能的翻译服务

网页、文档、字幕和翻译卡的服务选择可以不同。某个功能结果不符合预期时，先检查这个功能当前使用的服务和模型，详见[翻译服务](/config/translation-engines)。

## 网站与快捷键

- [网站阅读范围](/config/site-adaptation)：处理漏译、自动翻译或希望保持原文的网站。
- [快捷键与触发方式](/guide/custom-hotkey)：设置全文、悬浮、划词和圈选的操作方式。
- [术语库](/guide/glossary)：为 AI 翻译指定统一译法。

## 备份、缓存和用量

更换浏览器或卸载之前，在 **备份与恢复** 中保存需要的配置和学习数据。备份可能包含密钥和收藏原文，请妥善保存。

翻译变慢、磁盘空间紧张或想清除旧结果时，可以在 **翻译缓存** 查看和清理。清理翻译缓存不会删除学习收藏。AI 使用情况见[模型用量](/guide/model-usage)。
