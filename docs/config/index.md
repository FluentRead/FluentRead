# 设置

点击扩展菜单中的齿轮进入完整设置。找不到某一项时，可以搜索“目标语言”“快捷键”或“菜单栏布局”。大部分修改会自动保存。

桌面设置页的左侧菜单默认展开全部分组。窗口较矮时，可以在侧栏内滚动；窄屏可通过顶部的分类下拉框切换。

## 常用设置

| 你想做什么 | 从这里开始 |
| --- | --- |
| 更换目标语言或默认服务 | 通用设置 |
| 翻译前隐藏敏感文字或阻止发送 | [翻译隐私防护](/config/privacy-protection) |
| 调整原文与译文的颜色、字号和显示效果 | [界面风格](/config/appearance) |
| 减少悬浮或划词误触 | 翻译设置中的对应功能 |
| 每次翻译某网站，或保持原文 | [网站规则](/config/site-adaptation) |
| 更换浏览器、备份或撤回设置修改 | [备份与恢复](/config/backup-sync) |

**通用设置 → 启动插件**是总开关。关闭后，网页、视频、文档、翻译中心和写作助手停止发起新请求，正在执行的请求会被取消；已完成的文档译文仍可校订、复制和导出。再次开启后，原有偏好保留，未完成任务需要手动继续。

## 各功能的翻译服务

在扩展菜单中点击**翻译服务**，可查看网页默认服务，以及悬浮、划词、文档、字幕和翻译卡片等功能的选择。支持的功能可选择**跟随默认**，也可独立指定服务；修改自动保存。

完整设置中的**通用设置**也提供功能服务分配。**翻译服务**页用于填写密钥、地址和模型；点击目录只打开连接设置，需点击**设为默认翻译服务**，才会更换网页默认服务。详见[翻译服务与连接](/config/translation-engines)。

## 不翻译的语言

在**翻译设置 → 不翻译的语言**中点选语言，再点一次即可取消。简体与繁体中文可分别设置；**更多语言**展开完整列表，**清空选择**取消额外排除。

这项设置按文字判断，适用于自动与手动全文翻译、悬浮翻译和页面标题。混合页面中的其他语言仍可翻译；短文本或无法可靠识别的内容可能继续翻译。划词、输入框、文档、图片和字幕翻译不受此项控制。修改后请先恢复原文，再重新翻译。

## 界面与菜单栏布局

在**界面风格**中选择浅色、深色或其他皮肤，调整[译文样式](/config/appearance)，或进入**菜单栏布局**拖动区域与快捷卡片。也可用列表中的方向按钮排序，隐藏不常用的入口，再通过**添加**恢复。

隐藏入口只改变菜单，不会停用对应功能。要停止图片、圈选、字幕或翻译卡片，请关闭各功能自己的开关。

**界面字体**默认跟随系统。选择未下载的字体时会先下载，之后可离线使用，无需安装到系统；下载失败可重试。字体卡片上的**清除**只移除该字体可释放的资源；清除正在使用的字体后会切回系统字体。

## 阅读辅助

在**翻译设置 → 阅读辅助**开启双语逐句高亮，阅读时将光标移到句子上即可对照原文与译文。点击**调整逐句高亮样式**修改外观，详见[译文外观与阅读辅助](/config/appearance)。

## 备份、缓存和用量

换浏览器或卸载前，先[导出备份](/config/backup-sync)。备份可能包含密钥与收藏原文，请妥善保存。

**翻译缓存**用于复用已有译文，清理它不会删除学习收藏。清理后若提示尚未确认结果，请稍后刷新用量；离开页面不会取消已经开始的后台清理。请求耗时与各服务表现见[翻译统计](/guide/translation-stats)，AI 用量见[模型用量](/guide/model-usage)。

## 请求限制

服务提示请求过于频繁时，在**高级选项 → 请求限制**降低并发与请求频率。

| 项目 | 默认值 |
| --- | --- |
| 同时翻译的请求数 | 10 |
| 每秒最多请求数 | 10 |
| 每分钟最多请求数 | 250 |
| AI 翻译请求超时 | 120 秒 |

每秒或每分钟设为 **0** 表示不限制该项。超过上限的请求会排队；取消或超时后，尚未结束的请求仍占用名额，等待其结束才会放行下一项。

需要单独限制某项服务时，进入**翻译服务 → 请求限制**：

- **整个服务 → 自定义**：限制该服务下所有模型的总量，适合共用额度的账号。
- **当前模型 → 自定义**：为实际请求使用的模型设置上限；若自定义 JSON 覆盖了模型，限制对应覆盖后的模型。模型仍受服务总上限约束。
- 切回**跟随全局设置**或**跟随服务设置**恢复继承，之前填写的数值会保留。

**AI 翻译请求超时**可设为 10–600 秒，对新发起的 AI 文本、批量、输入框、字幕和翻译中心请求生效。慢模型可适当增加时间；图片识别、圈选和连接检查仍受各自时限约束。重试次数与间隔在全局高级选项中设置。
