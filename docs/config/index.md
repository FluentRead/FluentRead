# 设置中心概览

点击扩展菜单右上角齿轮即可打开完整设置。左上角支持**全局搜索**（例如搜索「目标语言」「快捷键」「菜单栏布局」直达控件），绝大多数修改会自动保存。

## 按任务快速定位设置

| 你想做什么 | 前往入口 |
| --- | --- |
| 更换目标语言、默认服务或总开关 | **通用设置** |
| 为网页、划词、文档、字幕分别选服务 | **通用设置 → 按功能选择服务** 或 [翻译服务](/config/translation-engines) |
| 翻译前自动脱敏或阻止敏感文字外发 | **高级选项 →** [翻译隐私防护](/config/privacy-protection) |
| 调整界面皮肤、字体、译文样式与逐句高亮 | **界面风格 →** [译文外观与阅读辅助](/config/appearance) |
| 调整菜单卡片顺序或隐藏不常用入口 | **界面风格 → 菜单栏布局** |
| 设置常用网站自动翻译、仅译文或禁用 | **工具与学习 →** [网站规则](/config/site-adaptation) |
| 导出本地备份、查看快照或配置云同步 | [备份与同步](/config/backup-sync) |

## 全局总开关与按功能分配服务

- **启动插件（总开关）**：位于**通用设置**。关闭后，网页、视频、文档、翻译中心与写作助手停止发起新请求并取消进行中的任务；已完成的文档译文仍可校订与导出。重新开启后原有偏好完整保留。
- **连接配置 ≠ 默认服务**：在**翻译服务**目录点击某项服务仅用于填写密钥、地址和模型，需点击**设为默认翻译服务**才会更换网页默认引擎；其他场景可在**按功能选择服务**中设为**跟随默认**或独立指定。

## 不翻译的语言

在**翻译设置 → 不翻译的语言**点选要跳过的语种（简体与繁体中文可分别设置；**更多语言**展开完整列表）。

- 适用于自动与手动全文翻译、悬浮翻译和页面标题（混合语言页面中其余语种照常翻译）。
- 不影响划词、输入框、文档、图片与字幕翻译；修改后需先恢复原文再重新翻译生效。

## 界面皮肤、字体与菜单栏布局

- **界面皮肤与明暗主题**：在**界面风格**可切换浅色/深色主题，并选用涵盖「经典与效率 / 现代工作台 / 纸感与自然」三大系列的 12 套专属 Popup 皮肤。
- **菜单栏布局**：可拖拽或用方向按钮调整弹窗卡片顺序，隐藏不常用入口（仅隐藏菜单项，不关闭对应功能开关）。
- **界面字体**：默认跟随系统；选择在线字体包时会下载并离线缓存（无需安装到系统），随时可点击**清除**释放字体资源。

## 翻译缓存、统计与请求限制 {#请求限制}

- **翻译缓存**：复用已翻译段落节省额度，清理缓存不影响学习收藏；清理为后台异步执行，离开页面不会中断。
- **翻译统计与模型用量**：分别查看[请求耗时与缓存复用](/guide/translation-stats)及[AI Token 用量](/guide/model-usage)。

当翻译服务提示请求过于频繁或限流时，可在**高级选项 → 请求限制**下调并发与速率：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| **同时翻译的请求数** | `10` | 并发上限；超出的请求自动排队 |
| **每秒最多请求数** | `10` | 设为 `0` 表示不限制 |
| **每分钟最多请求数** | `250` | 设为 `0` 表示不限制 |
| **AI 翻译请求超时** | `120 秒` | 可设 `10–600` 秒，慢推理模型可适当调大 |

也可在**翻译服务 → 请求限制**为**整个服务**（共用额度的账号）或**当前模型**设置独立限速（模型上限仍受所属服务总上限约束），随时可切回**跟随全局设置**恢复继承。
