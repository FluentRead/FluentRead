# 翻译隐私防护

在**高级选项 → 翻译隐私防护**开启。默认关闭；开启后，对新发起的文字翻译先在本机识别敏感信息，再发送给翻译服务。无需下载模型或部署代理。

## 两种处理方式

- **脱敏后翻译，返回后本地还原**：将命中的内容替换为本次请求的随机标记，服务返回后在本机恢复。重复值使用一致标记，批量翻译逐条校验；标记缺失、重复、损坏或串到其他条目时，停止展示，不会改发明文。
- **发现敏感内容时阻止发送**：只要在待发正文、上下文或自定义提示词中命中规则，就停止该请求。

可分别选择邮箱、电话号码、身份证件、银行卡与 IBAN、密码与密钥，以及 IPv4 地址。IPv4 默认不选。卡号与部分证件号使用格式和校验位验证；普通年份、日期或无标签的短数字不会直接当作验证码。

## 自定义词与本地预览

点击自定义敏感词旁的**管理**，每行填写一个需要保护的姓名、详细地址或内部名称，再点击**保存**。精确区分大小写，最多 128 条，每条 256 字符，不接受正则表达式。自定义词使用本机的凭据存储区，不向网页广播，不进入设置历史或不含敏感配置的备份；明确导出敏感配置时可能包含，分享前请检查。

页面底部的**脱敏预览**只展示固定示例，随处理方式和保护类别自动更新，不提供测试输入框，也不发送网络请求。示例效果不能证明其他内容都能被完整识别。

## 覆盖范围与限制

保护统一翻译链路中的网页、悬浮、划词、输入框、文档、字幕和识别后的图片文字，包括正文、网页摘要、篇章/字幕上下文、自定义提示词与请求体。重试、免费服务换线及批量处理继续使用防护策略；认证所需的服务密钥和请求头照常用于认证。

这是文字翻译防护，不是浏览器级流量防火墙。阅读助手、AI 写作、音频识别、云端 OCR 等独立请求不受此开关保护。无法对原始图片直接做文字脱敏，因此开启后会阻止统一翻译接口发送原图；可改用本地 OCR 后翻译文字。

规则识别不能覆盖所有语言、姓名、地址、编码或改写后的敏感信息；请用自定义词补充。上下文中剩余内容也可能透露身份，不适合发送给服务的材料应使用本地翻译或不发送。

开启后，新请求跳过持久翻译缓存的读取与写入。既有缓存、最近文档、学习记录及主动导出的文件仍按各自功能的规则保留，可到对应入口清理；本开关不会自动删除它们。会话映射仅在内存中使用，结束后释放引用，不写入日志或备份。

## 参考实现

参考 [OneAIFW](https://github.com/funstory-ai/aifw) 的本地脱敏与恢复思路、[Microsoft Presidio](https://github.com/microsoft/presidio) 的识别校验思路，以及 [Gitleaks](https://github.com/gitleaks/gitleaks) 的快速匹配设计，在 FluentRead 的 TypeScript 架构内独立实现。没有引入这些仓库的运行依赖。规则识别与模型识别的覆盖范围不同，不宣称未经同条件测量的性能或识别率排名。
