# 网站阅读范围

网页漏译或翻译范围不合适时，先检查识别范围；需要长期记住某个网站的选择时，再设置网站偏好。

## 正文漏译

1. 安装或更新后先刷新网页。
2. 向下滚动查看后续段落，默认会随阅读位置逐步翻译。
3. 希望连菜单、按钮也翻译时，在**高级选项 → 页面识别**开启**识别全部节点**，恢复原文后重新翻译。
4. 图片、图表中无法选中的文字，使用[圈选翻译](/guide/area-translation)。

部分网站会保留作者、时间、投票和导航等辅助信息，优先翻译正文、评论或产品介绍。若目标区域仍漏译，可调整正文适配，或反馈具体网址与区域。

网站明确标记的话题标签和 Discourse 分类徽标默认保留原文，例如论坛的 `chatgpt`、`rate-limit`、`API`，以及博客的标准标签链接。全文翻译与悬浮翻译遵循同一规则，开启**识别全部节点**也会保留这些标签；帖子标题和正文继续正常翻译。

在 OpenAI 开发者社区，导航、筛选器和活动日期也保留原文。双语译文显示在帖子标题和摘要下方，讨论正文仍可翻译。

Llamaperf 的 Mac 基准测试页面会翻译标题下的介绍、配置与报告数量，以及热门模型的统计说明。数据卡片沿用原有识别范围；导航是否翻译仍由侧边栏识别设置决定。

## 每次都翻译，或始终保持原样

进入**设置 → 工具与学习 → 网站规则 → 网站偏好**，按网站设置：

| 偏好 | 生效方式 |
| --- | --- |
| 始终翻译 | 打开该网站的新页面时自动翻译 |
| 禁用扩展 | 恢复原文并停止该网站上的扩展功能，优先于自动翻译 |
| 隐藏悬浮球 | 只隐藏入口，快捷键和其他功能仍可使用 |
| 仅显示译文 | 此网站不显示双语对照，其他网站仍沿用全局显示模式 |

网站偏好按主域名保存，也覆盖子域名，不区分路径和端口。重新启用被禁用的网站会恢复原有偏好；移除偏好则恢复全局默认。**所有网站自动翻译**适用于未被禁用的网站，并保留已存名单。

**仅显示译文**可作为初始偏好添加，也可在已有网站行中勾选；它本身不会开启自动翻译。修改后，已有网页译文直接切换显示，无需重新请求。取消后恢复全局模式，**恢复原文**仍可正常使用。显式指定显示方式的快捷翻译方案保留本次选择。Google 翻译仅支持双语；需要该网站仅显示译文时，请选择其他翻译服务。

扩展菜单中也可切换**始终翻译此网站**与**在此网站禁用扩展**。当前文章恢复原文后会保持原文，页内目录跳转不重新翻译；进入下一篇文章后，始终翻译重新生效。关闭始终翻译只影响以后的自动触发，不会恢复当前译文。

## 仍然识别不对

**正文适配**可按域名、路径和 CSS 选择器指定正文及保护区域。**生效预览**检查已保存规则的匹配和优先级，不会访问网站，保存后仍需在真实网页检查。

熟悉网页结构时，可按[自定义网站规则](/guide/custom-site-rules)操作，修改前先导出备份。也可到 [GitHub Issues](https://github.com/FluentRead/FluentRead/issues)提供可公开的网址、浏览器版本和去除隐私信息的截图，说明希望翻译与保留的区域。

完整字段见[规则参考文档](https://github.com/FluentRead/FluentRead/blob/main/docs/maintainers/product-reference/site-adaptation-20260906.md)。

## 指定区域被禁译标记阻挡

在正文适配的高级 JSON 中添加 `forceTranslate`，选择**携带禁译标记的元素本身**。例如 itch.io 评论外壳：

```json
{
  "version": 1,
  "rules": [{
    "id": "itch-comments",
    "name": "itch.io 评论",
    "match": {"hosts": ["*.itch.io"]},
    "forceTranslate": ["div[id^='game_comments_react_'][id*='_Game-Comments_']"],
    "content": [{"css": [".post_body", ".post_body p", ".post_body li"], "atomic": false}]
  }]
}
```

`forceTranslate` 只覆盖匹配元素自身的 `translate="no"`、`.notranslate` 和 `data-notranslate="true"`，不修改网页属性。嵌套区域若有自己的禁译标记，仍保留原文；编辑区、代码、隐藏内容，以及规则中的 `protect`、`exclude` 继续受保护。需要穿过多层禁译容器时，应分别匹配每一层。

保存规则后，全文、悬浮和局部翻译使用相同边界。此字段也可写入模板，复制、导出及停用规则时一同处理；默认遵循正文范围，需要适用于全部节点时显式设置 `allScopes: true`。itch.io 内置规则已包含上述评论外壳例外。
