# 选择翻译服务

流畅阅读把待译内容交给你选择的服务。可以直接使用免费翻译，也可以连接已有的机器翻译账号、AI 服务或本地模型。

<GuideVisual kind="provider" />

## 怎么选？

| 你的需要 | 可以选择 |
| --- | --- |
| 安装后直接翻译，不填密钥 | 免费翻译服务 |
| 使用已有翻译账号 | 对应的 DeepL、微软、谷歌等服务 |
| 使用云厂商的官方接口 | 谷歌云、Azure、阿里云、腾讯云、百度或火山引擎 |
| 翻译复杂表达，或配合 AI 讲解 | 已配置密钥与模型的 AI 服务 |
| 在本机处理翻译文字 | 本地模型翻译、Ollama，或 [Chrome 本地翻译](/guide/chrome-translator) |
| 在多个服务之间轮换或失败回退 | 组合翻译 |

流畅阅读免费开源，第三方服务可能单独收费。聊天会员不一定包含 API 额度，免费额度、地区限制和超额处理请以服务商账号为准。

## 配置并开始使用

1. 打开**设置 → 翻译服务**，搜索或选择需要配置的服务。
2. 按服务商提供的信息填写密钥、地址；AI 服务还需选择模型。
3. 点击**检查连接**。它会发送一条短请求，可能消耗少量额度；通过只表示本次检查成功。
4. 点击**设为默认翻译服务**，再回网页试译。文档、字幕和翻译卡片可独立选服务，请分别检查。

点击目录只打开连接配置，不会更换默认服务。可以从扩展菜单的**翻译服务**或通用设置的**按功能选择服务**为各功能分配服务。**按功能选择服务**默认展开，点击标题即可收起。

## 移除和添加回服务

在**设置 → 翻译服务**中，点击服务行右侧的 **×**。弹窗打开后，点击**确认**或直接按 Enter，服务会从目录移除并停止接收新请求。移除当前默认服务时，确认框会显示接替它的服务。目录至少保留一项可用服务。

需要恢复时，打开**自定义服务**，选择**恢复已移除服务**，搜索并选中服务，再点击**添加服务**。服务的密钥、模型和各功能原有选择会保留。移除期间，其他选择面板会将该服务标为不可用或从候选中隐藏。组合翻译和免费翻译会跳过该服务，并保留已有的成员设置。

## 免费翻译如何工作？

默认使用**自动均衡**，根据可用性和响应速度在已启用服务间分配请求；失败时可能把同一段原文发给另一家服务。也可选择**优先顺序**，按列表依次尝试，至少保留一项。只想使用一家时，停用其他项或选择独立服务。

在**参与翻译的服务**中调整候选。免费网页接口可能限流、改动或停止服务，没有持续可用保证；冷却后会再试，相关健康记录保存在本机。豆包网页翻译与 Reverso 为实验接口；豆包、Yandex 的繁体中文目标及 Apertium 的中文语言对等支持限制，以界面与请求结果为准。

豆包网页翻译使用匿名网页参数，不读取个人 Cookie 或“字节豆包”服务中配置的 API Key。匿名访问不代表永久免费；各候选的数据政策分别适用。

B 站翻译会合并同一个正文块内预算内的多行文本，并保留原来的换行。这条规则独立于 **AI 多段翻译**设置。译文行数不匹配、为空或被截断时，会改为逐行翻译。

## 谷歌翻译的速度与失败回退

谷歌翻译无需密钥，全文翻译会自动合并短段、减少零散请求，并在接口失败时尝试其他可用线路。限流时等待后恢复，不能因此提高服务商额度。

免费谷歌翻译、Google Cloud Translation、Chrome 自带整页翻译与 Chrome 本地翻译是不同服务，请按需要选择。

## 多段请求与翻译可靠性

谷歌、微软、DeepL、Azure 和谷歌云的**请求限制 → 合并翻译请求**默认开启，全文翻译会合并同配置的短段，并分别对应译文。关闭后逐段请求；免费服务调用谷歌或微软也遵循这一开关。

这与默认关闭的**AI 多段翻译**不同。合批减少请求次数，不减少按字符计费的用量；结果缺失或损坏时会尝试逐段恢复，失败则保留原文并显示失败，不缓存异常结果。

## Claude 与 DeepSeek Responses 翻译

使用这两种接口翻译时，流畅阅读等待完整的非流式响应；即使自定义请求体设置了 `stream: true`，翻译请求也会使用非流式方式。服务明确返回截断、拒绝或未完成的工具调用时，会显示失败，不把部分输出当作完整译文。

DeepSeek Responses 返回已完成的服务端搜索和最终译文时，可以正常使用译文；搜索能力取决于所选模型和服务。需要客户端执行的工具调用不会由翻译功能自动运行。

## 组合翻译服务

1. 点击**自定义服务 → 组合翻译**，填写名称。
2. 选择至少两个已有服务，按需要排序；组合不能嵌套。
3. 选择策略、设置等待时间，点击**保存**，再检查连接。
4. 像其他服务一样设为默认或分配给某项功能。

| 策略 | 行为 |
| --- | --- |
| 轮流 | 按列表轮换首选服务，失败再试其他成员 |
| 随机 | 每次打乱顺序，失败再试其余成员 |
| 智能 | 优先近期成功率高、响应快的成员，失败再试下一项 |

每次取首个成功译文，不合并多份译文；智能排序不评判翻译质量。成员使用各自的模型、密钥、提示词和请求限制，请先配置好它们。

每个成员默认等待 12 秒，可设 1–45 秒，整次请求仍受总超时限制。取消后不再回退。回退可能向多家发送相同原文并消耗各家额度，请考虑数据政策与费用。删除组合不会删除成员服务；成员为空的导入组合需补齐后才能使用。

## 使用多个 API Key

在服务的**密钥管理**启用轮换，点击**添加 Key**，每行填写一个。所有密钥共用该服务的地址、模型、区域和请求头；配置不同请分别建服务。

请求会分担到各密钥，失败后尝试其他项，鉴权失败、限流或额度用尽的密钥会暂停或降低使用频率。轮换不绕过服务的频率或总超时限制。

**检查连接**会逐项检测有效且不重复的密钥，也可用行末按钮单独重测。空白与重复项不会多发请求；检查可停止，并可能消耗少量额度。

## 使用 MyMemory

联系邮箱可留空，直接检查连接即可。日常翻译使用所选语言；短文本无法自动识别时，手动指定源语言再试。

## 使用 DeepL

选择 **DeepL API Free** 或 **API Pro**，填写对应套餐的密钥。DeepL 网页订阅和 API 套餐不能互换。

## 使用 DeepLX

API Key 为空，且地址留空或使用默认地址时，先尝试 DeepL 匿名接口，失败后使用默认公共 DeepLX。填写自定义地址、代理或密钥后，只使用指定线路；代理优先。

自定义地址需要完整接口路径，如 `https://deeplx.example.com/translate`，只填域名不补全路径。无鉴权接口可留空 Key；需要 Token 时只填值，不加 `Bearer`。默认放入请求头，需要网址鉴权时可用服务商支持的占位符：

- 查询参数：<code v-pre>https://deeplx.example.com/translate?token={{apiKey}}</code>
- 路径：<code v-pre>https://deeplx.example.com/{{apiKey}}/translate</code>

保留占位符原样，不要把真实 Token 写进地址。占位符需要的 Key 缺失时，不会转用公共接口。

## 使用云服务厂商

官方云接口需要在对应控制台开通并创建凭据。选择服务后，展开**开通指南**可查看控制台和接口说明。

| 服务 | 需要填写 |
| --- | --- |
| 谷歌云翻译 | API Key |
| Azure 翻译 | 密钥、区域 |
| 阿里云机器翻译 | AccessKey ID、AccessKey Secret、地域 |
| 腾讯云翻译 | SecretId、SecretKey |
| 百度翻译 | APP ID、密钥 |
| 火山引擎翻译 | Access Key ID、Secret Access Key、地域 |

区域必须与控制台资源一致。鉴权失败时核对密钥是否成对、已启用、具备翻译权限，以及服务开通与账号状态；时间签名错误还需校准设备时间。反馈服务错误码即可，不要发送密钥或完整请求。

这些凭据保存在本机，不进入公开分享配置或设置历史；完整备份与明确开启敏感配置的云备份可以包含它们。

## 本地模型翻译

在**翻译服务 → 本地模型翻译**选择并下载模型，显示**可离线使用**后先试译，再设为使用服务。无需密钥或另启服务器，翻译文字在本机处理。

| 模型 | 下载大小 | 适合用途 |
| --- | --- | --- |
| 中英轻量语言包 | 约 239 MB | 简单中英句子 |
| 混元 Hy-MT2 1.8B | 约 1.13 GB | 多语言与复杂表达，需要更多内存 |
| 日英轻量语言包 | 约 214 MB | 日译英，英译日质量有限 |

下载可暂停、继续或重试，切换设置不会停止后台下载；文件校验完成前不能使用。来源不可用时自动换备用来源，下载的是同一固定版本并进行校验。

模型保存在当前浏览器，不进入配置备份；删除需确认且只影响所选模型。下载大小不等于运行内存，加载时可能明显增加 CPU、内存或显存，空闲后会释放运行资源。详见[本地模型常见问题](/guide/faq#本地模型会每次重新加载吗-会一直占用内存吗)。

本功能仅浏览器扩展支持，油猴版不提供。模型卡片的信息入口提供来源与许可；浏览器不兼容时请选择其他模型或服务。

## 使用 AI 服务

填写服务密钥，选择账号支持的模型，再检查连接。内置列表没有模型时可填**自定义模型**，名称应复制服务商提供的 API 模型 ID。Azure 填写实际**部署名称**。

默认模型适合日常翻译，也可自行选择更大模型。型号停用或连接返回模型错误时，检查服务商当前列表；恢复旧备份后也应检查模型与自定义请求参数。费用和可用额度以服务商为准。

### AI 精翻与多段翻译

两项默认关闭，可独立开启：

- **AI 精翻**发送网页标题、描述、部分正文、章节定义和已有译文作为参考，帮助保持术语与指代一致，可能增加用量与等待时间。参考只保留在当前会话，不保证覆盖远处内容，也不能保证翻译正确。
- **AI 多段翻译**把同一父元素下直接相邻的正文一起交给 AI，可能减少请求次数。仅适用于支持通用提示词的 AI 服务，组合服务不适用；悬浮翻译仍只处理当前段落。

批量请求回退到逐段翻译时，每段在译好后就会显示。其他段落可以继续等待，失败后也可单独重试。

开启后可调整**每批上限**：默认最多 **8 个文本片段、2,000 个原文字符**，可分别设为 **2–32** 和 **500–12,000**。达到任一上限就拆批；单个超长段落保持完整，不会截断。一个富文本段落可能包含多个片段，因此片段数不等同于网页段落数。收集窗口固定为 **32 ms**，后续片段不会延长窗口，也不保证凑满批次。

关闭开关会保留参数，**恢复默认**只重置两项上限。批次越大不一定越快，也更依赖模型完整返回每段译文。标记完整且只有部分段落为空或仍是原文时，仅补译异常段落，保留其余结果；补译仍失败时显示失败，不缓存不完整结果。段落标记缺失、重复或整包回显时，整批回退逐段翻译；当前页面会话中，同一请求配置的后续段落也逐段请求。

术语、emoji 与文档保护标记在本地严格校验和回填，提示词不再重复发送它们的恒等词表。固定规则位于动态材料之前；这有利于保持前缀稳定，但不会为了凑缓存门槛填充内容，也不保证服务商的提示缓存一定命中。可在用量统计中核对实际请求和服务返回的 token 用量。

修改后先恢复原文，再重新启动全文翻译生效。需要固定术语时，配合[术语库](/guide/glossary)。

### 自定义服务的 Base URL

**自定义服务 → 兼容接口**使用 OpenAI Chat Completions 协议：

| 地址形式 | 请求位置 |
| --- | --- |
| `https://api.example.com` | 自动补 `/v1/chat/completions` |
| `https://api.example.com/v1` | 自动补 `/chat/completions` |
| 完整接口路径 | 按填写地址请求 |

其他非标准路径按完整接口处理。代理地址优先，必须填写完整路径，不自动补全；查询参数会保留。只支持 `/responses`、`/messages` 或 Gemini 原生协议的模型不能直接用于这个兼容接口。

例如 [OpenCode Zen](https://opencode.ai/docs/zen/) 使用 `https://opencode.ai/zen/v1`。请先核对所选模型支持 Chat Completions，再填 API 模型 ID，不带客户端的 `opencode/` 前缀；Go 的接入限制见其[官方说明](https://opencode.ai/docs/go/)。

### 自定义请求头

展开**接口兼容 → 自定义请求头**，按服务商要求填写 JSON：

```json
{"X-Title": "My translation client"}
```

名称和值均为字符串，同名头覆盖默认值。需要稳定会话标识时可在此保存。自定义鉴权无需默认 Bearer Token 时，可关闭对应模型的 API Key 要求。

请求头只用于这项服务，按凭据保存，不进入公开分享或设置历史，完整备份会保留。更换接口或代理地址后需重新填写；浏览器禁止修改的头不能靠此字段覆盖。

### 按域名移除 Origin / Referer

自建接口拒绝扩展来源时，可在**接口兼容 → 移除来源请求头**添加实际请求域名；使用代理时填代理域名。

只填精确域名，不含协议、端口、路径或通配符，也不覆盖子域。默认只移除 Origin，Referer 需另选；名单在服务间共用，仅影响扩展请求，删除规则即恢复。油猴版和不支持相关浏览器 API 的环境不提供此项。

### Gemini 代理地址

代理需填写完整接口，支持以下模板：

```text
https://myproxy.example/v1beta/models/{model}:generateContent?key={key}
```

占位符按当前模型与保存的密钥替换。含 `{key}` 的地址会收到密钥，导入或更换代理仍会保留原密钥，请确认代理可信；没有该占位符则不自动附加。留空代理使用官方接口。

### 腾讯混元连接失败

**腾讯混元**使用混元控制台 API Key；**腾讯混元翻译**需要 SecretId 和 SecretKey，两者不同。自建代理或网关需填写对应完整接口与配套密钥，参考[官方接入说明](https://cloud.tencent.com/document/product/1729/116755)。

### 使用本机 Agent 的 ACP 桥接

这是一项需要自行运行本机程序的实验功能。先安装并登录 GitHub Copilot CLI 或 OpenCode，再从源码目录运行[桥接程序](https://github.com/FluentRead/FluentRead/blob/main/scripts/agent-bridge/bridge.mjs)：

```sh
node scripts/agent-bridge/bridge.mjs --agent=copilot
```

OpenCode 改用 `--agent=opencode`。保持终端运行，在兼容接口中填写终端显示的回环地址与令牌，模型填 `default` 或 Agent 提供的 ID；重启令牌改变后需更新。按 Ctrl+C 停止。

桥接仅支持文本、非流式请求，禁用 Agent 工具与文件、终端和权限操作。原文仍会交给 Agent 使用的模型服务，可能消耗订阅额度并留下本机会话记录；本机持有令牌的其他进程也可调用。请勿公开令牌。真实 CLI 账号兼容性需要自行验证；已有可用 API 时可直接配置，无需桥接。

## 使用本地模型

Ollama 需先安装、启动并下载模型。在**聚合平台与接口 → Ollama（本地）**填写已下载模型名，默认连接 `http://127.0.0.1:11434`，无需 Key。其他电脑或端口需填完整 `/v1/chat/completions` 地址，并按 Ollama 设置允许扩展来源。

电脑处理较慢时，将该服务的**请求限制 → 整个服务 → 自定义**并发设为 **1**。只有对应翻译请求在本机处理；词典、朗读等其他功能仍可能联网，详见[隐私政策](/guide/privacy)。

## ChatGPT 套餐接入状态

当前公开版本未开放 ChatGPT 登录接入。请选用可用服务，详见[接入状态](/config/chatgpt-plan)。

## 连接失败

核对地址、密钥、模型、区域与账号额度。短句可用但长文失败时，降低并发或缩小任务；HTTP 404 且返回网页时，先检查接口路径和协议，不能仅据此判断密钥无效。

服务返回原文或错误语言时会重试或回退，持续失败则保留原文并提示。仍有问题见[常见问题](/guide/faq)，反馈错误码与去除隐私的截图，不要发送真实密钥。
