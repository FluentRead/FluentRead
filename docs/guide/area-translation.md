# 圈选翻译

框住网页中的截图、图表或暂停的视频画面，识别并翻译选区内的文字。

<GuideVisual kind="area" />

## 开始圈选

1. 在**图片翻译 → 圈选翻译**中开启功能，选择识别方式和翻译服务。
2. 在网页按一次 **Shift+Z**，拖动框住需要的区域，再松开鼠标。
3. 等待识别和翻译，在卡片中阅读结果。可以拖动卡片、复制译文、展开原文或查看截图。

缺少本地识别语言包时，点击**下载语言包并重试**，下载完成后继续使用同一张截图。需要换区域时点**重新圈选**；换服务后点**重新翻译**，无需重新截图。按 **Esc** 退出。

截图完成后，滚动或调整窗口会保留结果；截图尚未完成时，页面位置变化会取消旧选区。切换标签页会关闭结果并释放截图。

## 选择文字识别方式

| 方式 | 如何处理选区 | 需要准备什么 |
| --- | --- | --- |
| 优先使用模型识图（默认） | 模型支持图片时，把裁剪后的选区交给模型识别；不支持或能力未确认时改用本地识别 | 支持图片的服务与模型，或本地语言包 |
| 本地 OCR | 在设备上识别截图，再把识别文字交给翻译服务 | 对应原语言的语言包，与[图片翻译](/guide/image-translation)共用 |

圈选可单独选择服务，留空时跟随网页默认服务。在翻译服务页编辑某项连接，不等于已经选择它。结果卡片会显示本次实际使用的识别方式、服务和模型。

模型识别可能误读模糊或手写文字，请展开截图核对。网络、密钥、配额等错误会直接提示，不会因请求失败悄悄切换为本地识别。

## 选择译文处理方式

**标准翻译**直接翻译识别出的文字，适合清晰、排版简单的内容。

**AI 文本增强**用支持通用提示词的 AI 服务整理断行并翻译。它只处理识别文字，不能补回漏识别的字；可搭配任一种识别方式。

## 使用范围与数据

圈选截图支持具备区域截图能力的 Chrome、Edge 和 Firefox 扩展版。浏览器内部页、受限制的视频或无法读取的区域可能无法截图，其他版本会按实际能力提示。

本地 OCR 不上传截图，只发送识别文字。使用模型识图时，只上传裁剪后的选区，再由同一服务翻译文字；不会上传整屏截图。识图请求不进入翻译缓存，关闭圈选后释放临时截图。

想直接在整张图片上查看译文，可以使用[图片翻译](/guide/image-translation)。

## 换一个快捷键

在**图片翻译 → 圈选翻译 → 圈选快捷键**中选择预设，或录制自定义组合键。单个字母需搭配 Ctrl、Alt/Option 或 Shift；与其他功能冲突时需更换后再保存。取消录制会保留原设置。

快捷键不会在输入框或可编辑区域触发。

</details>

<details class="guide-details">
<summary>检测模型识图能力和调整提示词</summary>

未知模型第一次使用时，会先发送一张本机生成的随机字符小图检查识图能力；不会使用网页截图做测试。也可在**翻译服务 → 模型偏好 → 模型识图能力**中选择**检测**，或手动指定“支持识图”“仅文本”。测试可能产生模型调用费用，可以取消。

只有准确读出测试文字才确认支持识图。文字连接测试成功或 HTTP 200 不代表支持图片。测试结论在本机保存 7 天，修改服务、模型或连接信息后会重新判断；不保存测试图片、答案或密钥，也不进入配置备份。手动指定的能力优先于测试结果。

开启优先模型识图后，可以**编辑识图提示词**，要求保留表格、公式或特殊符号，也可恢复默认。它只影响文字识别，不影响网页翻译；后续文字翻译仍使用服务已有设置。

</details>

## 遇到失败时

卡片会给出当前最合适的操作：缺少识别语言包时可 **下载语言包并重试**；没有识别到文字时可 **重新圈选**；服务配置或连接需要检查时可进入 **圈选设置**。一般失败可直接 **重试**，复用刚才的选区。

**其他操作** 保留重新圈选、设置或重试入口，具体异常可展开 **查看详细原因**。关闭卡片会取消未完成的请求。
