# 快捷键与触发方式

快捷键与鼠标动作可以直接触发网页、划词和悬浮翻译。

## 常用操作

| 操作 | 默认方式 |
| --- | --- |
| 翻译当前段落 | 鼠标放在段落上，按 **Control** |
| 翻译页面 / 恢复原文 | **Alt + T**；Mac 键盘上的 Alt 通常标为 Option |
| 圈选画面文字 | 按一次 **Shift+Z**（可修改），再拖动区域 |
| 复制鼠标所在段落 | 鼠标放在段落上，按 **Alt+C**（Mac 为 Option+C） |
| 只翻译网页中的一块区域 | 点击扩展菜单的 **局部** 按钮；也可开启快捷键 **Alt+R**（Mac 为 Option+R） |
| 划词翻译 | 先开启划词翻译，再选中文字并点击附近图标 |

## 在哪里修改？

打开扩展菜单里的 **鼠标悬停翻译** 或 **划词翻译**，点击面板底部的对应设置入口，再修改触发方式；需要组合键时，使用完整设置中的自定义快捷键入口。快捷面板会展示当前的使用方式。

圈选快捷键在 **图片翻译 → 圈选翻译** 设置中修改：可以选择预设组合键，也可以录制自定义组合键，详见[圈选翻译](/guide/area-translation)。

段落复制在 **设置 → 翻译设置 → 段落复制** 中修改：可以更换预设或录制自定义组合键，并选择复制内容。复制内容有四种口径：

- **跟随页面显示**（默认）：段落已翻译就按当前显示形态复制，双语复制原文和译文，仅译文复制译文；未翻译时复制原文。
- **原文**：始终复制网页原文。
- **译文**：始终复制译文；该段落尚未翻译时复制原文，并在提示中说明。
- **原文和译文**：两段一起复制，顺序跟随 **译文显示位置** 设置。

复制成功后网页右上角会提示复制了什么、共多少字。在输入框、可编辑区域中按下时不会触发，浏览器的 **Ctrl+C** 仍然用于复制选中文字。

局部翻译快捷键默认关闭，在 **设置 → 翻译设置 → 局部翻译** 中开启，可选择预设或录制自定义组合键。进入选择模式后按 **↑/↓** 调整范围，按 **Esc** 或再按一次快捷键退出，详见[局部翻译](/guide/features#局部翻译)。

划词可以改成直接弹出、小点入口、按键触发或 **仅右键菜单**。选“仅右键菜单”后，选中文字不会显示划词图标或小点，也不会占用划词快捷键；右键选择“翻译选中文本”才会打开卡片。保持 **设置 → 右键菜单** 中的总开关和选区入口开启。卡片模式共用划词翻译的触发方式，不再显示独立的选区浮条。

划词选择可以包含正文中的行内代码：只翻译周围文字，代码内容和空白保持原样，在原文与译文卡片中以等宽代码样式显示。单独选中代码、包含代码块的选区，以及输入框和交互控件仍不触发划词翻译。

浏览器扩展管理页中能配置的是浏览器列出的扩展命令；它与 FluentRead 内部的段落、划词触发设置不同。

## 没反应或与网页冲突

先用扩展菜单确认翻译功能能正常工作。避开浏览器、输入法和常用网页已经占用的快捷键；输入框中部分快捷键不会触发。

自定义组合键按录制时键盘实际输入的字符匹配，Dvorak、AZERTY 等布局也以键帽字符为准；Mac 上 Option 把按键变成特殊符号时，按对应的物理按键匹配。

浏览器内部页面和扩展商店通常不允许内容翻译，请在普通网页尝试。
