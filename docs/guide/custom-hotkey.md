# 快捷键与触发方式

用顺手的组合键瞬间翻译整页、单段或框选画面，减少来回点击菜单的打断。Mac 键盘上的 `Alt` 对应 `Option`。

<GuideVisual kind="shortcuts" />

## 修改与录制快捷键 {#在哪里修改}

- **悬浮 / 划词触发**：在扩展菜单打开**鼠标悬停翻译**或**划词翻译**进入对应设置。
- **圈选快捷键**：在**设置 → 图片/漫画翻译 → 圈选翻译**中修改。
- **独立浏览器命令**（如打开独立翻译小窗口）：在浏览器的扩展快捷键管理页分配。

录制组合键时，按住 `Ctrl`、`Alt/Option` 或 `Shift` 再按下字母或功能键后确认保存（仅按修饰键不会完成录制）；若与其他已启用功能冲突，界面会提示更换。

## 局部翻译与独立方案 {#局部翻译与独立方案}

局部翻译快捷键默认关闭，可在**设置 → 翻译设置 → 局部翻译**中开启（默认 `Alt+R` / `Option+R`）：

1. 按快捷键移动鼠标预览区块，单击或拖拽多个段落锁定。
2. 用 `↑ / ↓` 或工具条调整范围，按 `Enter` 确认翻译；选中已翻译区域再确认即可恢复原文；`Esc`、右键或再按快捷键退出。

### 最多 8 套独立方案

悬浮、全文与局部翻译各自支持添加最多 **8 个独立方案**，每个方案可独立绑定专属快捷键、翻译服务、模型、目标语言与显示方式（即使主快捷键关闭，已开启的独立方案仍可触发）。

<details class="guide-details">
<summary>独立方案的服务与模型继承规则</summary>

方案默认跟随网页默认服务；为其指定独立模型时会同步固定当前服务。清空模型将恢复该服务的默认模型；想重新跟随网页默认服务，请选择**跟随默认**。更换服务时自动清空旧模型。

</details>

## 两点选取（免长按跨行选词） {#两点选取}

在**设置 → 划词翻译 → 触发与显示**开启**两点选取**后：

1. 按 `Alt+Shift+S`（Mac 为 `Option+Shift+S`）进入选取模式。
2. 依次单击正文的**起点**与**终点**，即可轻松跨行或反向选中文字，无需全程按住鼠标左键。
3. 第二次点击后生成浏览器原生选区，并按你原有的划词触发方式弹出翻译入口。

- 按 `Esc`、再次按快捷键或离开页面取消；点击链接、按钮或输入框会退出并保留网页原交互。
- 单次上限 **4,096 字符**；两点选取、局部翻译与圈选同一时间只激活一种选择模式。

<summary>段落复制内容与划词触发方式</summary>

### 段落复制（`Alt+C` / `Option+C`）

在**设置 → 翻译设置 → 段落复制**中选择复制策略（输入框内不触发，`Ctrl+C` 始终保留原生复制）：

| 复制内容 | 实际行为 |
| --- | --- |
| **跟随页面显示（默认）** | 已翻译时按当前双语/仅译文复制，未翻译时复制原文 |
| **原文** | 始终复制段落原文 |
| **译文** | 尚未翻译时复制原文并给出提示 |
| **原文和译文** | 同时复制两段，顺序跟随页面双语上下设置 |

### 划词入口样式

可选**图标（默认）**、**小点**、**直接弹出**、**悬停图标**、**快捷键**或**仅右键菜单**（选择仅右键菜单时请保持**设置 → 右键菜单**中对应开关开启）。

</details>

## 快捷键没反应或冲突怎么办？ {#没反应或与网页冲突}

1. 先从扩展菜单确认该功能已开启且在普通网页上可用（浏览器设置页与扩展商店不支持注入）。
2. 检查是否处于输入框或输入法组词状态——为了不打断打字，绝大多数翻译快捷键会在编辑区自动让行。
3. 检查是否与浏览器、系统输入法或当前网站快捷键冲突；Mac 上 `Option` 产生特殊字符时会按物理键位匹配。
