# 调整某个网站的正文范围

大多数网站直接翻译即可。如果某个网站总是漏掉正文，或你希望作者信息、导航保持原文，可以先按[网站阅读范围](/config/site-adaptation)检查。

下面的自定义功能适合熟悉网页结构的用户。不想研究规则时，也可以向项目反馈具体网址与希望调整的区域。

## 从已有规则开始

进入网站适配设置，找到相似的网站规则，复制后再修改。先导出备份，避免丢失原来好用的配置。

规则主要告诉 FluentRead 三件事：对哪个网站生效、在哪里找正文、哪些地方保持原样。填写错误可能造成漏译或多译，不会自动帮你判断正文含义。

## 保存后怎么检查？

1. 打开对应网站，恢复原文后重新翻译。
2. 查看标题、正文是否齐全，作者、按钮和不希望翻译的位置是否保持原样。
3. 向下滚动、展开评论或切换文章，再检查后续内容。
4. 若效果不对，关闭这条自定义规则，或导入备份恢复。

## 需要具体字段和示例

[仓库里的完整规则教程](https://github.com/FluentRead/FluentRead/blob/main/docs/contributing/site-adaptation.md)包含选择器、规则格式与验证方法。验证过的规则也可以按该指南分享给社区。
