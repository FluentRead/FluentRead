# 调整某个网站的正文范围

大多数网站直接翻译即可。如果某个网站总是漏掉正文，或你希望作者信息、导航保持原文，可以先按[网站阅读范围](/config/site-adaptation)检查。

入口位于 **系统与数据 → 网站规则**，分为“网站偏好”“正文适配”“生效预览”。大多数用户只需要调整网站偏好，不必编写 JSON。正文适配提供可视化表单，仍需要知道要处理区域的 CSS 选择器。不想研究网页结构时，也可以向项目反馈具体网址与希望调整的区域。

## 从已有规则开始

进入“正文适配”，搜索网站名、域名或规则标识。点开规则可以查看匹配路径、正文与保护区域，再选择“基于此规则自定义”。也可以直接新建规则。先导出备份，避免丢失原来好用的配置。

可视化表单每行填写一个域名、路径或 CSS 选择器。CSS 中的逗号不会拆成多条。补充识别在通用正文上增加目标；限定范围只处理规则声明的正文。先“暂存规则”，再“保存并应用”；暂存目录不等于网页已生效。切换设置分类会保留草稿。未保存修改会请求浏览器在关闭或刷新时提醒，但草稿不会自动保存；确认离开仍会丢失，请先保存或导出。

“高级 JSON 编辑”保留模板和全部高级字段。导入默认合并，同 ID 规则会整条替换；不会删除其他规则。模板重名而内容不同时会拒绝合并，需要先重命名。确实需要完整替换时可选择“替换整个草稿”，保存前可撤销。

同 ID 自定义规则完整覆盖内置版本；从草稿移除后保存即可恢复内置版本，停用状态仍按 ID 保留。若其他设置页更新了规则，正在编辑的草稿不会被覆盖，也不会静默覆盖新配置；可导出草稿后恢复最新配置，再合并自己的修改。

规则主要告诉 FluentRead 三件事：对哪个网站生效、在哪里找正文、哪些地方保持原样。填写错误可能造成漏译或多译，不会自动帮你判断正文含义。

## 保存后怎么检查？

先到“生效预览”输入完整 HTTP(S) 网址，查看自动翻译、网站禁用、悬浮球与正文规则的组合结果，并可直接打开命中规则。预览使用已保存配置、不访问网站；它不能代替真实网页检查。开启“识别全部节点”时，只有显式声明 `allScopes` 的适配规则参与。

1. 打开对应网站，恢复原文后重新翻译。
2. 查看标题、正文是否齐全，作者、按钮和不希望翻译的位置是否保持原样。
3. 向下滚动、展开评论或切换文章，再检查后续内容。
4. 若效果不对，关闭这条自定义规则，或导入备份恢复。
