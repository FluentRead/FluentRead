# 划词翻译

选中网页中的单词或句子，在同一张卡片内完成译文对照、英汉词典查词、多源语音朗读、AI 深入讲解与收藏。

<GuideVisual kind="selection" />

## 快速上手

1. 打开**设置 → 专项翻译 → 划词翻译**并开启功能。
2. 在网页中拖动选中文字，点击选区旁出现的流畅阅读图标。
3. 卡片默认打开**翻译**标签：上方为原文、下方为译文，均支持单独复制与朗读；查英文单词无需配置 AI 即可显示词典释义。

### 卡片交互与排障

- **自由移动与缩放**：卡片遮挡正文时，可拖动标题栏空白处或原文/译文空白处移动，拖选文字仍可正常复制；拖动边缘可调整尺寸，长内容在卡片内滚动，下次划词恢复默认大小并靠近新选区。
- **快速收藏与分享**：点击右上角图标可一键收藏到[学习中心](/guide/vocabulary-book)或制作[双语分享卡片](/guide/share-cards)。
- **遇到「密钥或权限无效」**：点击卡片中的**配置服务**，在**通用设置 → 翻译服务选择 → 划词翻译 → 配置连接**核对密钥与权限，再返回手动重试。

## 按需使用 AI 深入讲解

在划词设置中开启**AI 深入讲解**并选好服务与模型后，可在卡片顶部按需点击学习动作（打开卡片本身不会自动发起 AI 请求）：

| 学习动作 | 适用目的 | 免费 B 站服务支持 | 通用 AI 服务支持 |
| --- | --- | --- | --- |
| **读懂** | 提炼大意、语气与上下文指代 | ✓ 基础支持 | ✓ 完整支持 |
| **词性与句法** | 拆解句子主干、成分与词性作用 | — | ✓ 完整支持 |
| **用法** | 常见搭配、惯用表达与替换说法 | ✓ 基础支持 | ✓ 完整支持 |
| **练习** | 根据当前原句生成一道巩固练习 | — | ✓ 完整支持 |

- **免密钥试用**：**B站翻译 · 免费**无需 API Key，点击卡片上的**免费 AI 讲解**即可为当前选文试用「读懂」与「用法」，且不覆盖你原有的服务偏好。
- **交互浏览与依据核对**：在句法视图中点击片段或按 `← / →` 键查看解释；回答句末的小引号可悬停查看原文依据，点击或按 `Enter / Space` 跳回原句（页面变化或离开后仅保留查看）。
- **更多操作（⋯）**：支持查看原文、重新生成、扩展为整句、朗读或打开历史记录。同卡切换动作会复用已完成回答；更换原文、模型或语言后重新发起。

## 多源朗读与播放控制 {#朗读设置}

在划词朗读设置中，可灵活组合多种发音方式与语速（`0.5×–2.0×`，提供常用倍速档位）：

| 朗读来源 | 特点说明 |
| --- | --- |
| **在线多源自动回退** | 支持 **Edge 神经语音**（默认免费自然音色）、**有道发音**（英/日/韩/法/中短句极速）、**Google 朗读**（语种最全兜底），以及 **OpenAI / 兼容 TTS**（复用已配置密钥与代理，支持 `gpt-4o-mini-tts`、`tts-1`、`tts-1-hd`） |
| **本机离线朗读（仅本地）** | 下载本地语音模型到当前浏览器后离线发声，勾选**仅本地**时绝不回退在线语音 |
| **浏览器系统语音** | 调用操作系统自带 TTS 引擎（不支持 5 秒进度跳转） |

点击朗读后，底栏可随时停止、查看播放时间或前后跳转 **5 秒**，并伴随跟读高亮（无逐词时间戳的音频采用估算进度，可能略有偏差）。关闭卡片或更换选区会自动停止播放。

### 统一触发方式

在**触发与显示**中可选择：**显示图标（默认）**、**小点**、**直接弹出**、**悬停图标**、**快捷键**或**仅右键菜单**，并调整等待延迟。

- **不按住鼠标跨行选词**：可开启[两点选取](/guide/custom-hotkey#两点选取)（默认 `Alt+Shift+S`）。

### 英文查词与词典来源

在**划词翻译 → 翻译卡片 → 词典来源**中默认为**自动选择**（优先本地词库，未命中再查在线词典），也可指定 ECDICT 本地词库、有道词典、Free Dictionary API、Wiktionary、WiktApi、Datamuse 或自行导入的[离线/自定义词典](/guide/dictionaries)。

- **ECDICT 本地词库（扩展版）**：内置 3,000 个常用英文词条免下载；遇到未收录词条时在后台静默下载并校验约 **3.9 MB** 完整词库供后续离线查词（下载地址不含所查单词）。
- **中英双向划词**：目标语言为中文或英文时，开启后可根据选文语种自动反向翻译。

</details>

<summary>上下文范围、学习记录与隐私边界</summary>

### 上下文、记录与隐私

- **参考原文**：可设为**仅当前选区**或允许有限长度的**当前段落**，绝不读取整页。
- **收藏与笔记**：**收藏原文**存入[学习中心](/guide/vocabulary-book)的「单词与句子」；**保存学习笔记**存入「学习笔记」。**回答时参考学习笔记**默认关闭，开启后讲解和写作才参考相关笔记。
- **30 天本地历史**：阅读问答在普通窗口保留 30 天（查看不请求 AI），无痕/隐私窗口不读写历史。仅主动点击讲解、重新生成或追问时才发送选区与允许的上下文，详见[隐私政策](/guide/privacy)。

</details>

<details class="guide-details">
<summary>高级：Chat Completions 参数与输出上限兼容说明</summary>

### Chat Completions 参数兼容

「读懂」与共用模型网关的写作功能会继承所选 Chat Completions 服务的自定义请求体参数（如 `service_tier`、`reasoning_effort`）。参数在顶层覆盖默认值，但模型、会话消息、工具调用、响应格式和流式协议由功能自身管理，不可通过自定义请求体替换；非法 JSON 会在发送前报错。

翻译、阅读和写作根据请求端点与 Azure 部署名称自动选择输出上限字段：

- 官方 `https://api.openai.com/v1/chat/completions`（含直连官方端点的自定义服务）使用 `max_completion_tokens`。
- Azure 的 GPT-5 / GPT-6 / o1 / o3 / o4 系列部署使用 `max_completion_tokens`；未知部署别名默认保留 `max_tokens`。
- 第三方兼容端点默认保留 `max_tokens`；若要求新字段，在自定义请求体显式提供 `max_completion_tokens` 会自动移除旧字段。同时提供两者时前者优先，不会同时发送两个字段。
- Responses 接口的 `max_output_tokens` 属另一协议，不能仅通过改字段切换协议。推理强度与 Fast 等级按用户配置原样传递，不自动降级或重发付费请求。

</details>
