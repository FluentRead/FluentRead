# 划词翻译

选中文字，在原文旁查看译文。原来的“翻译卡片”已整合到划词翻译中，共用入口、开关和触发方式。

## 普通翻译与卡片模式

进入 **设置 → 专项翻译 → 划词翻译**，开启功能并选择默认呈现：

| 呈现 | 适合什么时候 |
| --- | --- |
| 普通翻译 | 快速看懂意思，复制或朗读原文和译文 |
| 卡片模式 | 查单词的音标和词性，或围绕句子继续学习 |

网页中的弹窗可以随时切换两种呈现，只影响当前选区，并复用已有译文。下一次划词仍使用保存的默认设置。设置页提供单词和句子的交互预览，示例不会发送请求。

普通翻译把语言切换与模式切换放在同一条工具栏中，复制和朗读贴近原文与译文；减少重复标题与空白，把空间留给阅读内容。

普通翻译使用默认翻译服务。卡片中的英文查词使用词典，不要求配置 AI；词典没有结果时仍保留译文。词典按词性归类释义，例如冠词、名词、动词和形容词。词典列出的是常见用法，不代表该词在当前句子中的唯一词性。

## 统一触发方式

在 **触发与显示** 中选择图标、小点、直接弹出、悬停图标、快捷键或仅右键菜单，并调整显示延迟。两种呈现使用相同设置。

选择悬停图标后，把鼠标停在图标上等待才打开；移开会取消等待。选择快捷键或仅右键菜单时，选中文字不会额外显示浮条。

如果划词经常打断阅读，推荐保留默认的**显示图标**，需要时再点击；想完全隐藏浮动入口，可以选择**自定义快捷键**或**仅右键菜单**。直接弹出更适合连续查阅，不适合习惯用选区标记阅读进度的用户。已有触发偏好不会在升级时被替换。

**继续阅读时自动收起**默认开启：滚动正文或复制原文后收起浮层；鼠标远离未点击的入口后，它会在短暂等待后消失。原生选区和复制不受影响，卡片内部的滚动、复制也不会关闭结果。需要边滚动页面边对照译文时，可以关闭这项设置。

按 Escape 或点击网页其他按钮会关闭弹窗。旧选区不会自行重新打开；重新选中文字或主动按快捷键可以再次打开。关闭划词翻译总开关后，普通翻译和卡片都会停用，已有学习偏好继续保留。

## 英文查词与卡片操作

划词词卡内置 3,000 个常用英文词条，首次查词无需下载额外资源。查询其他单词时，在线词典可以继续提供结果；扩展同时在后台下载并校验完整词库，供后续本地查词使用。完整词库约 3.9 MB，下载后保存在浏览器缓存中。下载不可用时，常用词库与在线词典仍可使用。词库下载地址不包含正在查询的单词。

卡片挡住原文时，按住顶部或周围空白处拖动；拖动边缘或四角可调整大小，长内容在卡片内部滚动。下一次划词会恢复默认大小，靠近新的选区显示。

目标语言设为中文或英文时，可在卡片的语言按钮中临时切换本次翻译方向，不会修改网页翻译设置。选区的触发方式和语言偏好在 **划词翻译** 设置中调整。

## 按需使用 AI 深入讲解

在 **AI 深入讲解** 中启用讲解，并展开 **服务与学习偏好**，选择已配置的 AI 服务和模型。连接信息在[翻译服务](/config/translation-engines)中填写。打开卡片本身不会请求 AI，点击学习动作后才开始：

| 动作 | 用途 |
| --- | --- |
| 读懂 | 解释大意、语气和指代 |
| 词性与句法 | 分析主干，区分词性与句中作用 |
| 用法 | 学习搭配和自然表达 |
| 练习 | 根据原文做一道练习 |

读懂、句法、用法和练习都把完整原句保留在滚动区顶部。进入时默认向下滚过原句，直接查看回答；向上滚动即可核对原句，无需展开，也可从“更多操作”选择“查看原文”。回答生成时不会改变用户的阅读位置；重复点击当前标签会保留位置和未发送的追问。

学习面板中的“句法”对应词性与句法分析。原文按顺序分成紧凑的双行片段：上行是原文，下行常驻显示句中作用和词性，例如“主语 · 短语”“谓语 · 动词”，不必逐个点击才能看清结构。作用摘要取自回答的首个短分句，不额外猜测语法。点击或用左右方向键切换片段，再查看详细含义和完整作用说明；通用词性说明按需展开。例如 `reader` 的词性是名词，在某句话里可以作主语，也可以作宾语。

标注由 AI 根据原文生成。相同单词在不同句子中可能有不同词性。FluentRead 只把能够按顺序对应原文的分析呈现为交互标注；无法对应、格式不完整或使用了不同的自定义提示词时，保留普通文字回答。标注不代表语法分析绝对正确。

同一张卡片内切换学习动作会复用已完成的回答，需要新答案时在“更多操作”中点击“重新生成”。朗读原文、理解整句、收藏、阅读记录与设置也集中在“更多操作”中。可以返回译文，或在下方继续追问。更换原文、模型、语言或讲解偏好后，相关旧结果不再复用。

## 上下文、记录与隐私

在 **上下文、学习记忆与自定义指令** 中选择仅发送选中文字，或允许参考当前段落。不会因此读取整页。学习记忆默认关闭，需要时可以启用；自定义提示词保留原样，默认提示词随界面语言切换。

收藏的单词、短语和句子进入[学习中心](/guide/vocabulary-book)。阅读问答在本机保留 30 天；查看记录本身不会请求模型。隐私窗口不读取也不保存阅读记录。

只有主动选择学习动作、重新生成或追问时，才将选区、允许参考的原文和必要问答发送到所选 AI 服务。详情见[数据与隐私](/guide/privacy)。

## 兼容已有设置

升级时保留已配置的服务、自定义模型、学习动作、上下文和提示词。旧翻译卡片单独开启时会迁移到统一划词入口；只有旧卡片在用的快捷键或悬停方式也会迁移。旧设置链接仍可打开新的划词翻译页面。

学习会话沿用 DeepSeek Harness 的浏览器适配，不绑定 DeepSeek 模型。[来源与许可](https://github.com/FluentRead/FluentRead/blob/main/public/third-party-notices/deepseek-harness-MIT.txt)
