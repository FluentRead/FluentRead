# 划词翻译

选中单词或句子，在同一张卡片中查看译文、查词、朗读，或按需使用 AI 讲解。

<GuideVisual kind="selection" />

## 翻译卡片

1. 打开**设置 → 专项翻译 → 划词翻译**并开启功能。
2. 在网页上选中文字，点击选区旁的图标。
3. 卡片默认打开**翻译**标签。查英文单词时可直接查看词典解释，无需配置 AI。

点击右上方的分享或收藏按钮可保留结果。卡片挡住正文时，拖动顶部或周围空白处移动，拖动边缘调整大小；长内容在卡片内滚动，下次划词会恢复默认大小并靠近新选区。

提示“密钥或权限无效”时，点击**配置服务**，在**通用设置 → 翻译服务选择 → 划词翻译 → 配置连接**检查服务密钥与权限，再返回手动重试。

## 按需使用 AI 深入讲解

在划词设置中开启**AI 深入讲解**，选择服务和模型，再在卡片中选择学习动作。打开卡片本身不会发起 AI 讲解。

| 动作 | 可以了解什么 |
| --- | --- |
| 读懂 | 大意、语气和指代 |
| 词性与句法 | 句子主干、词性和句中作用 |
| 用法 | 常用搭配和自然表达 |
| 练习 | 根据原文完成一道练习 |

<GrammarDemo />

**B站翻译 · 免费**无需 API Key，提供基础的“读懂”和“用法”。卡片上的**免费 AI 讲解**可为当前选文开启它；句法、练习和连续追问需要通用 AI 服务，连接信息见[翻译服务](/config/translation-engines)。原有服务和动作偏好仍会保留。

点击句法片段或使用左右方向键可查看解释；上行是原文，下行是句中作用和词性。AI 无法与原文对应的分析会保留为普通文字回答。讲解可能出错，请结合原文判断。

## 核对解释的原文依据

回答句末的小引号可查看原文依据：悬停查看，点击或按 **Enter / Space** 回到原句。页面内容变化或离开后，旧引用只能查看，不再定位当前网页。

“更多操作”（⋯）中可查看原文、重新生成、扩展整句、朗读或打开记录。同一张卡片切换学习动作会复用已完成的回答；更换原文、模型、语言或讲解偏好后，旧回答不再复用，需要时重新发起讲解。

## 朗读设置

在划词设置中选择在线声音或本地朗读，声音留空时按语言自动选择。**仅本地**不会使用在线备用声音；本地模型需要先下载到当前浏览器。

点击朗读后，可在底栏停止、查看播放时间，或前后跳转 5 秒。使用浏览器系统语音时，跳转不可用。跟读高亮随播放推进；没有逐词时间的音频使用估算，可能与发音有偏差。停止、关闭卡片或更换选区会结束播放。

## 统一触发方式

在**触发与显示**中选择图标、小点、直接弹出、悬停图标、快捷键或仅右键菜单，并调整等待时间。悬停图标需要停留后才打开；快捷键和仅右键菜单不会额外显示浮动入口。

默认**显示图标**适合需要时再点击。**继续阅读时自动收起**默认开启：滚动正文、复制原文或移开未点击的入口后会收起；卡片内的滚动和复制不会关闭结果。需要一边滚动一边对照时，可以关闭此项。

按 **Escape** 或点击网页其他按钮关闭卡片。旧选区不会自行重开，重新划词或按快捷键可再次使用。关闭划词翻译会同时停用卡片和学习功能，保留原有偏好。

</details>

## 英文查词与卡片操作

内置的 3,000 个常用英文词条无需额外下载。其他单词可使用在线词典；同时会在后台下载并校验约 3.9 MB 的完整词库，供之后本地查词。下载失败时，常用词库和在线词典仍可使用，词库下载地址不包含查询的单词。

词典中的词性列出单词的可能用法，不一定是它在当前句子的作用。目标语言是中文或英文时，可在划词设置中开启**中英双向划词**，按选文语言自动反向翻译。

</details>

## 上下文、记录与隐私

**参考原文**可选择只发送选区，或允许有限长度的当前段落，不会因此读取整页。**自定义指令**只影响 AI 讲解，不改变翻译和词典查词。

**收藏原文**存入[学习中心](/guide/vocabulary-book)的“单词与句子”；**保存学习笔记**存入“学习笔记”，可长期保留、编辑或删除。**回答时参考学习笔记**默认关闭，开启后讲解和写作才会参考相关笔记，关闭不会删除笔记。

阅读问答在本机保留 30 天，查看记录不会请求模型。隐私窗口不读写阅读记录。主动选择学习动作、重新生成或追问时，选区、允许的上下文和必要问答才会发送给所选 AI 服务，详见[数据与隐私](/guide/privacy)。

</details>

## OpenAI 生成参数兼容

使用内置 OpenAI 服务时，「读懂」与共用模型网关的写作功能会继承该服务的自定义请求体参数，例如 `service_tier` 和 `reasoning_effort`。参数在顶层覆盖默认值，但模型、会话消息、工具调用和流式响应协议仍由功能自身管理，不能通过自定义请求体替换。非法 JSON 会在发送前报错。具体参数是否可用由所选模型、端点和账户决定。

对于 `gpt-6-luna`、`gpt-6.1-terra` 及其日期快照，输出上限使用 `max_completion_tokens`，最终请求不会包含 `max_tokens`。显式的非空 `max_completion_tokens` 优先，其次是非空自定义 `max_tokens`，最后使用功能默认上限；把旧字段设置为 `null` 不会让它出现在请求中。其他型号和其他 OpenAI-compatible 服务不执行此自动转换。
