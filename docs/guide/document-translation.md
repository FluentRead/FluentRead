# 文档翻译

在浏览器内直接导入 PDF、EPUB、Word、PowerPoint、Excel、LaTeX、Markdown、表格与字幕等 17 种格式，双语对照阅读、校订译文、添加批注并导出保留排版的双语或纯译文文件。

## 支持格式与打开方式

从扩展菜单点击**文档翻译**，拖入本地文件或点击选择；还没有素材时，可展开**没有文件？先用范例试试**（导入范例后仍需手动点击开始翻译）。

| 类别 | 支持格式 | 大小限制与说明 |
| --- | --- | --- |
| **PDF 论文与书籍** | `.pdf` | 最大 **50 MB**；支持菜单直接**打开 PDF 阅读器**或粘贴公开 PDF 链接（需登录的链接请先下载） |
| **电子书与办公文档** | `.epub`、`.docx`、`.pptx`、`.xlsx` | PPTX 最大 **50 MB**，其余最大 **10 MB**；旧版 `.doc`、`.ppt`、`.xls` 请先另存为 `.docx`、`.pptx`、`.xlsx` |
| **学术与网页纯文本** | `.tex`、`.html`、`.md`、`.txt` | 最大 **10 MB**；支持 UTF-8 与带 BOM 的 UTF-16（导出统一为 UTF-8） |
| **结构化数据表** | `.json`、`.csv`、`.tsv` | 最大 **10 MB**；CSV/TSV 支持按列勾选翻译范围 |
| **字幕文件** | `.srt`、`.vtt`、`.ass`、`.ssa`、`.lrc` | 最大 **10 MB**；完整保留时间轴与格式标签 |

从文档历史中还可重新打开**已保存的网页正文**，自动回到上次阅读位置并保留已有译文与校订；点击标题下的**查看原网页**可跳回来源网址。

## 翻译、对照阅读与断点控制

1. 在顶部选择**翻译服务**、**目标语言**（AI 服务同时选择模型）；**源语言与术语库**位于侧栏（窄屏点**翻译设置**）。
2. 检查正文内容后，点击**开始翻译**。翻译优先从当前阅读位置开始，译好一段立即显示一段。
3. 随时切换**原文 / 双语 / 译文**视图：
   - 左侧**文件**用于切换文档，**目录**用于跳转章节。
   - 点击**专注阅读**隐藏周边工具条（按 `Esc` 退出）；支持工具栏、触控板捏合、`Ctrl`+滚轮及 `Ctrl/Cmd + / − / 0` 缩放预览。
   - **CSV / TSV 按列选择**：打开后在**要翻译的列**勾选目标列（首行同步翻译，数字/公式/链接原样保留）；下载按当前勾选列写回，双语在同一单元格换行展示。

### 暂停、失败重试与更换服务

- **暂停与续译**：点击**暂停翻译**保留已完成译文与校订；点击**继续翻译**或**重试**只处理剩余段落。
- **限流等待与换服务**：服务限频时自动等待重试（期间可暂停）；需要更换服务/模型时先暂停再继续，已译内容保留、剩余段落使用新服务。
- **修改语言/术语**：更改语言、术语或关键连接参数后，页面会提示是否**重新翻译**（确认后才会替换现有译文与校订；如需保留旧版请先下载）。

## PDF 双模式阅读与批注 {#pdf-有哪些限制}

### 原版排版 vs 重排阅读

| 特性 | 原版排版（默认） | 重排阅读 |
| --- | --- | --- |
| **布局方式** | 双语左右并排对照，严格对应原页位置；公式、插图、作者署名与纯数字单元格保持原样 | 单栏流式逐段对照原文与译文，也支持直接阅读未翻译原文 |
| **适用场景** | 学术论文、图表密集材料、需要精确保留版式与页码对照 | 窄屏、分屏阅读或长时间沉浸式长读 |
| **长译文与外观** | 悬停展开或点击书本按钮查看**完整段落**；支持纸张/薄荷/深色/自定义配色与**智能反色** | 自定义字号、字体、行距、段距与配色主题，插图保留原色 |
| **划词与搜索** | 原页文字支持直接复制、搜索与划词翻译（划词使用独立划词服务） | 支持全文搜索与段落级批注 |

::: info 浏览器内置 PDF 查看器划词
在 Chrome/Edge 自带 PDF 查看器中，也可开启划词翻译与右键菜单后选中文字右键**翻译选中文本**（单次最多 4,096 字符，独立窗口展示）。
:::

### 本地批注与导出带注释 PDF

- 在原页同一页或重排同一段选中文字后，可直接高亮、加下划线或点击**备注**填写内容并保存（每份文档最多 **1,000 条**，随本地历史保存）。
- 点击工具栏**批注**可浏览列表并一键跳转，通过**更多操作**查看全文、编辑或删除。
- 点击**导出 PDF** 可生成包含标准 PDF 注释的原文件副本（保留原页与既有注释；加密或损坏文件可能无法导出）。

### Hypothesis 协作批注

在 PDF 阅读器中选择**批注 → Hypothesis 协作批注**可打开官方侧栏（连接中可取消）：

- 开启后向 Hypothesis 官方服务发送标准 PDF 指纹、标题、选中文本和批注（不上传 PDF 文件，不发送本地路径、局域网地址或带查询参数的下载链接，流畅阅读不接触你的登录令牌）。
- 翻译进行中暂缓协作侧栏，完成后恢复；连接受阻时提供[官方代理入口](https://web.hypothes.is/help/what-is-the-via-proxy/)与[本地文件指引](https://web.hypothes.is/help/annotating-locally-saved-pdfs/)。

## 扫描版 PDF 识别（OCR）与校对

无文字层的扫描 PDF 或混入的扫描页同样可以翻译：

1. 确认源语言后点击**开始翻译**，系统从当前页开始自动识别文字并翻译（缺少识别语言包时自动下载）。
2. 逐页保留识别结果，暂停或失败后继续只处理剩余扫描页；识别完成后可在原图上直接选择与复制文字。
3. 发现识别偏差时，在文档设置点击**校正识别原文**对照原图逐行修改（仅使改动段落译文失效，旧译文保留备查），或点击**重新识别当前页**单独重读当前页。

<details class="guide-details">
<summary>查看扫描 PDF 复核与特殊版式处理细节</summary>

- **上下标与数值复核**：扫描论文的数字上下标会结合原页局部放大复核，确认的科学计数法与下标原样保留，无法确认时标虚线框提示**核对原文**；低置信度但逐字有据的数字保留原读数并提示核对。
- **低置信度汉字与列表**：低置信度汉字结合上下文双倍率复核，仅两次高分一致时自动修正；扫描列表圆点经形状与缩进复核后按条目翻译。
- **图示与表格**：确认边界的扫描图示保留原图并翻译题注；有线表及列对齐清晰的无边框数值表按单元格复核，纯数字原样保留。
- **原生 PDF 排版细节**：加粗/阴影重描字只计一次；公式上方说明文字与积分/求和符号分开归行；含原生文字的图文卡片按底框独立排版；异常提取字符会主动提示人工核对。

</details>

## 校订译文与导出下载 {#校订与下载}

1. 点击**校订译文**，按关键词搜索或筛选未翻译片段并直接修改（校订结果会写入导出文件）。
2. 点击工具栏**下载**，选择**双语对照**或**仅译文**，再点击底部下载按钮；**下载原文**可随时保存原始文件。
3. 若文档尚未全部译完，需确认**下载当前结果**（未译段落保留原文）；导出中可随时取消，失败时译文与校订均完整保留。

| 格式 | 导出保留特性 |
| --- | --- |
| **PDF** | 展开**PDF 排版**可选**保留原版**（左右并排、长译文附可跳回续页、同步翻译书签目录）或**重新排版**（固定字号流式续页，首次需联网缓存约 5 MB 字体） |
| **EPUB** | 保留章节、图片、链接与样式，并将已翻译/校订的章节标题同步写入阅读器目录 |
| **DOCX（Word）** | 保留普通段落中的超链接、加粗、斜体与表格结构；校订时请保留 `<g1>…</g1>` 格式标记 |
| **PPTX（PowerPoint）** | 按幻灯片顺序提取正文与演讲者备注，保留形状、表格、图片、动画与字体样式；双语在原段后追加译文段落，仅译文原位替换 |
| **XLSX（Excel）** | 按工作簿顺序读取多张工作表（支持共享字符串与行内字符串），公式、数字、日期与样式原样保留，双语在单元格内换行附加译文 |
| **LaTeX（`.tex`）** | 保留导言区、注释、数学公式及 `verbatim`/`lstlisting`/`minted`/`tikzpicture` 等环境，用编号占位符保护行内公式、引用与格式命令，导出源码可直接编译 |
| **Markdown / HTML** | 保留 GFM 表格对齐、链接与代码块（代码块与标识不翻译）；普通折行单换行送翻时自动合并 |
| **字幕 / CSV / JSON** | 字幕保留序号与时间轴；CSV/TSV 写回所选列；JSON 保留结构与非文本值（嵌套上限 1,000 层） |

::: tip 本地历史与数据安全
文档、译文与校订保存在本机浏览器的 IndexedDB（最多 20 份、原文件合计 80 MiB），刷新或从首页**最近翻译**即可继续。多标签页并发修改同一历史时不会互相静默覆盖；清理浏览器数据可能移除历史，重要文档请及时下载备份。
:::

<details class="guide-details">
<summary>PDF 长段续页、跨页上下文与旧校订恢复</summary>

- 原版排版导出时，原框放不下的长译文会在对应原页后插入完整译文续页（末页按正文高度缩短，页脚可跳回原页），译文全程可搜索与复制。
- 原文件自带书签或自动识别的章节标题在导出时同步更新跳转位置与译文。
- PDF 重新解析后，能确认位置的校订自动恢复，无法安全匹配的校订保留在**校订译文 → 保留的旧校订**中供复制；跨页接续段落可通过**跨页上下文**对照查看。

</details>

<details class="guide-details">
<summary>多段合并、字幕相邻参考与 AI 篇章参考</summary>

- **多段合并翻译**默认开启以减少小请求，可在当前文档设置中独立关闭。
- **字幕相邻参考**：使用支持通用提示词的 AI 服务翻译 SRT/VTT/ASS 时，自动选取前后各 6 条字幕（总计不超过 1,200 字符）辅助理解断句与语序，同时保留每条独立时间戳。
- **AI 篇章参考**：开启**AI 精翻**时逐段参考当前章节定义、邻近原文与已完成译文（人工确认译法优先于机器参考，术语库优先级最高；不跨文档保存）。

</details>

<details class="guide-details">
<summary>加入学习材料、批量翻译与 Obsidian 集成</summary>

### 保存材料并继续阅读 {#保存材料并继续阅读}

点击**加入学习材料**（或**更新学习位置**），即可在[学习中心](/guide/vocabulary-book)统一管理文档收藏、笔记与进度；原文件被清理后重新选择同一文件即可无缝恢复定位。

### 批量翻译 {#批量翻译}

一次拖入多个文件或在侧栏**文件 → 添加文件**批量导入，点击**翻译剩余文件**依次处理。单份失败不影响队列，完成后可通过**下载已完成文件（ZIP）**打包下载（批量 PDF 使用原版排版）。

### 在 Obsidian 中翻译 {#在-obsidian-中翻译}

可按[实验性 Obsidian 桌面插件](https://github.com/FluentRead/FluentRead/tree/main/integrations/obsidian)说明自行构建安装，右键翻译 Markdown 与带文字层 PDF 并生成相邻双语 Markdown 笔记（当前使用微软翻译，不覆盖原文件）。

</details>

## 文件会上传吗？

原始文件完全在你的浏览器内解析与生成，只有待译文本会被发送给你选择的翻译服务；使用本地模型时连文本也不会离开设备。详见[隐私政策](/guide/privacy)。
