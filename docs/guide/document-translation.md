# 文档翻译

导入文件后，可以双语对照阅读、校订译文，再下载结果。

<GuideVisual kind="document" />

## 打开文件

从扩展菜单进入 **文档翻译**，拖入文件或点击选择文件。没有文件时，展开 **没有文件？先用范例试试**；范例导入后也需要手动开始翻译。

在线 PDF 可以在扩展菜单中选择 **打开 PDF 阅读器**，也可以在文档首页粘贴 PDF 链接。流畅阅读会在自己的阅读器打开原文件。需要登录的链接无法打开时，请先下载再导入。

支持 PDF、ePub、Word（DOCX）、HTML、TXT、Markdown、JSON，以及 SRT、VTT、ASS、SSA、LRC 字幕。PDF 最大 **50 MB**，其他格式最大 **10 MB**；旧版 `.doc` 请先另存为 `.docx`。

## 翻译与对照阅读

1. 在顶部选择 **翻译服务**、**目标语言**，使用 AI 服务时再选择模型。源语言与术语库在侧栏的 **源语言与术语库** 中设置；窄窗口可打开 **翻译设置**。
2. 检查文件内容，点击 **开始翻译**。
3. 切换 **原文 / 双语 / 译文** 阅读。翻译优先从当前阅读位置开始，完成的段落会陆续显示，无需等全文结束。

左侧 **文件** 用于切换文档，**目录** 用于跳转章节。点击 **专注阅读** 可隐藏周边工具，按 Esc 退出。缩放可用工具栏、触控板捏合或 Ctrl 加滚轮；点击正文后也可用 **Ctrl/Cmd +、−、0**。缩放只影响阅读预览。

### 暂停、失败与换服务

点击 **暂停翻译** 后，已有译文和校订会保留。选择 **继续翻译** 或失败后的 **重试**，只处理未完成部分。

服务暂时不可用或限频时，会显示原因并自动等待重试，期间仍可暂停。需要换服务或模型时，先暂停，调整后继续；从其他页面更换当前服务或模型也会自动暂停旧任务。已有结果保留，剩余段落使用新服务。

修改语言、术语或部分连接参数后，页面会提示按新设置重新翻译。确认 **重新翻译** 会替换现有译文和人工校订；需要保留旧版本时先下载。查看详细错误可展开 **详情**。

## 校订与下载

1. 点击 **校订译文**，搜索句子或筛选未翻译片段，直接编辑译文。
2. 点击 **下载文件**，选择双语或仅译文，核对文件名和预览后下载。校订会写入下载文件。

下载默认跟随当前双语或译文阅读方式，也可在弹窗修改。尚未完成时，需要确认下载当前结果；缺少译文或已清空译文的位置保留原文。更改设置不会自动重译，下载仍使用当前保留的结果。

**下载原文** 可直接保存已打开的原文件，无需先翻译。ePub、DOCX、PDF 和批量 ZIP 的生成可以取消后重试，译文与校订会保留。

::: tip 刷新后继续
文档、译文和校订保存在本机浏览器里。刷新后可继续阅读，也可从首页 **最近翻译** 恢复；记录按最近保存顺序排列，显示的日期取自本机系统时间。清理浏览器数据可能删除这些内容，需要长期保留或分享时请下载。

如果本机历史暂时无法读取，页面仍可打开文件，但该任务不会自动保存，以免覆盖可能存在的旧校订。请先下载本次修改；点击 **重试读取历史** 会保留当前任务，并将重新读取的文件作为独立任务打开。

如果其他页面已修改或清除同一文件的历史，当前页面不会覆盖较新的记录，也会提示下载本次修改。重试后可在两个独立任务中分别查看和下载两份结果。

历史列表暂时无法读取时，已显示的记录会保留，并可重试读取。删除或清空未能确认时，请重试读取后检查实际结果。删除单条记录前会检查列表显示时的版本；如果其他页面已经修改或移除该记录，请重新读取后再决定是否删除。清空会删除执行时的全部历史。

更新后的历史记录不能被旧版本读取；如需降级，请先下载需要保留的文件。
:::

## PDF 有哪些限制？

PDF 默认使用 **原版排版**：双语视图左右对照，译文按原段落位置显示，公式、插图和纯数字单元格保持原样。长译文可悬停展开，或点击段落展开按钮查看 **完整段落**；也可切换 **重排阅读**，按完整段落阅读。工具栏可搜索原文与译文，并调整译文样式。

没有文字层的扫描 PDF、文档里混入的扫描页也可翻译：点击开始后，先从当前页识别文字，再翻译。缺少的识别语言包会自动下载，请先确认源语言。扫描页文字不能直接划选；识别、公式和专业术语仍可能有误，关键内容需要核对。

原页文字可以选择、复制和划词翻译；划词使用独立的划词服务，整篇翻译使用文档服务。浏览器自带 PDF 查看器中，也可选中文字后右键 **翻译选中文本**，在独立窗口查看结果；需要先开启划词翻译及对应右键菜单，一次最多 4096 个字符。

<details class="guide-details">
<summary>PDF 下载、长段落与校订恢复</summary>

原版排版下载保留原页顺序。双语版将同一原页的原文与译文左右并排；仅译文版保留译文页。放不下的长译文会保留完整批注，并在对应原页后添加完整译文续页，因此下载页数可能增加。译文文字可搜索、选择和复制。

单份文档在 **重排阅读** 下下载时，译文按固定字号自动续页，双语版在原页后接译文。公式和插图尽量整块保留；需要精确保留原稿字形时选择原版排版。首次重排导出需联网准备约 5 MB 字体，成功缓存后可复用；字体请求不含文档、译文或密钥。少见字符的外观可能取决于本机字体。批量下载使用原版排版。

PDF 重新解析后，只有原文及位置能够确认时才恢复已有校订；无法安全恢复的内容保留在 **校订译文 → 保留的旧校订** 中，可查阅和复制。相邻页有明确接续关系时，可用 **跨页上下文** 对照阅读，原文和校订不会自动合并。

</details>

<details class="guide-details">
<summary>其他格式、术语与 AI 篇章参考</summary>

Markdown、HTML、ePub 的链接、强调和行内代码尽量保留；网址、邮箱、代码块和程序标识不翻译。格式无法保留时会提示重试或换服务。JSON 保留结构和非文本值；嵌套超过 1000 层时无法处理。Word 表格仍按表格阅读，ePub 下载保留章节、图片、链接和样式。

字幕下载保留序号、时间轴与格式标签：仅译文替换字幕文字，双语在同一时间段保留两种文字。普通文本中按固定宽度折行的段落会合并翻译，标题和列表尽量分开。

**多段合并翻译** 默认开启，可减少小请求；可在当前文档的翻译设置中关闭，不影响网页设置。格式保护不能保证译意完整或术语一致，请用术语库统一译法，并校订关键段落。

### 篇章参考

使用支持通用提示词的 AI 服务并开启 **AI 精翻** 时，会参考当前章节定义、邻近原文和已完成译文。当前阅读会话中手动确认的译法优先于机器参考，术语库优先级最高。

此模式逐段执行，可能更慢；参考范围有限，不保证消除所有歧义。篇章参考本身不额外调用模型，也不跨文档保存。

</details>

## 保存材料并继续阅读

点击 **加入学习材料**，把文档与收藏、提问和笔记放在一起；已加入时点击 **更新学习位置**。在学习中心选择继续阅读，可回到保存的段落。材料与位置都保存在本机浏览器中。

原文件被清理后，重新选择同一文件即可继续；同名但内容不同的文件不会覆盖旧材料。若无法确认原段落，页面会保留旧定位并提示重新保存；较早的材料可能只能恢复页码或章节，请核对位置。主动滚动会停止自动定位。

</details>

## 批量翻译

一次拖入多个文件，或在侧栏 **文件 → 添加文件** 中添加。确认服务和语言后，点击 **翻译剩余文件**，依次处理未完成文档。单份失败不影响其他文件；**暂停全部** 保留已有进度。

队列停止后，可逐份阅读、校订或下载。**下载已完成文件（ZIP）** 只打包已完成文档；同名文件放进不同编号目录。改变设置后，部分完成的文件需要逐份确认重译，避免覆盖校订。未下载的结果被移除前也会提示。

</details>

## 在 Obsidian 中翻译

可按[实验性 Obsidian 桌面插件](https://github.com/FluentRead/FluentRead/tree/main/integrations/obsidian)目录的说明构建安装，从命令面板或文件右键菜单翻译 Markdown 和带文字层的 PDF。结果保存为相邻的双语 Markdown 笔记，原文件不被覆盖。该插件目前使用微软翻译，待译文字会发送给该服务；PDF 不保留原版式。

</details>

## 文件会上传吗？

文件在浏览器中解析，待译文字会发送给所选翻译服务。使用云端服务时，相关文字会离开本机。详见[数据与隐私](/guide/privacy)。
