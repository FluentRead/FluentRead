# 常见问题与排查

排查前请先做两项快速核对：① 确认扩展总开关已开启；② 安装或更新扩展后刷新当前普通网页。以下按场景分类汇总高频问题。

## 一、基础使用与网页翻译

### 点击「翻译页面」后没有变化

1. 确认总开关已开启且**目标语言**设置正确（与原文语言不同）。
2. 浏览器设置页（`chrome://`、`edge://`）与扩展商店受系统保护不允许翻译，请换一篇普通文章测试。
3. 在**设置 → 翻译服务**点击**检查连接**；若免费服务繁忙，稍后重试或[切换其他服务](/config/translation-engines)。

### 页面只翻译了一部分

默认随阅读位置逐步翻译，先向下滚动即可继续。如果菜单、按钮或特定正文区域漏译，检查[网站阅读范围与偏好](/config/site-adaptation)；图片与图表里的文字请使用[图片翻译](/guide/image-translation)或[圈选翻译](/guide/area-translation)。

### 为什么选区翻译可用，整页翻译却不行？

先用悬浮段落翻译试译一段，再检查[网站阅读范围](/config/site-adaptation)（正文识别范围不匹配或整页并发请求触发限流都可能引发此现象），同时确认服务额度与[请求限制](/config/#请求限制)。

### 如何恢复原文？更换语言或服务后如何生效？

打开扩展菜单点击**还原**（或按 `Alt+T` / `Option+T`）。更换目标语言、翻译服务或基础译文样式后，需**先恢复原文，再重新翻译**。

### 为什么中文译文里偶尔出现日文？

先核对目标语言并恢复重译。服务若整段返回错误语种，流畅阅读会自动重试或切换免费候选，连续异常会报错且不写入缓存；中文译文中的少量专名、术语或引用可能会保留原语种。

### 网页邮箱的正文可以翻译吗？

支持 **QQ 邮箱旧版阅读页**以及**网易 163 / 126 / yeah 的 JS6 阅读页**的正文识别（写信编辑器不按正文处理）。打开具体邮件后使用全文或划词翻译，必要时刷新。反馈漏译请提供邮箱域名、去掉 `sid` 等参数的路径与去敏截图。

## 二、划词翻译、AI 讲解与特定站点

### DeepSeek 网页选中文字没有反应怎么办？

确认已开启**划词翻译**，更新扩展后刷新 DeepSeek 页面并选中回答中的普通文字重试。流畅阅读已允许穿透 DeepSeek 页面根节点的整页禁译标记以及同一编辑器宿主内的主动选区；原生输入控件、局部禁译区与隐藏内容仍受保护。

### 为什么划词卡片里没有 AI 讲解？

普通划词卡片默认仅展示译文与词典，不会自动请求 AI。如需讲解，请先在[划词翻译设置](/guide/deepseek-harness)中开启**AI 深入讲解**并选好服务/模型，或点击卡片中的**免费 AI 讲解**试用 B 站免费服务。

## 三、图片、视频与本地模型

### 图片翻译一直在准备中

本地 OCR 首次使用需要下载识别模型或语言包（默认 PaddleOCR 约 30 MB），请按提示确认下载并核对源语言。若网络受限或图片模糊，也可在[圈选翻译](/guide/area-translation)开启**优先模型识图**，或打开清晰原图重试。

### 视频字幕没有出现

先确认**视频字幕翻译**已开启且视频本身带有原生字幕轨。X、B 站普通视频及普通 HTML 音视频在无字幕时，可在播放器菜单手动启动本地 AI 转写（详见[视频与会议字幕](/guide/video-subtitles)）。

### 本地翻译模型保存在哪里？卸载扩展会清理吗？

- 默认保存在当前浏览器的扩展缓存中，可在模型管理页单独删除。
- 若启用了**跨浏览器共享模型**，文件保存在你授权的本地目录里，卸载扩展或断开授权**不会**自动删除这些文件。
- 浏览器内置翻译语言包由 Chrome/Edge 自身管理；手动离线安装的解压目录需自行清理。

### 本地模型会每次重新加载吗？会一直占用内存吗？ {#本地模型会每次重新加载吗-会一直占用内存吗}

模型文件存于磁盘，不等同于常驻内存。本地翻译、朗读、语音识别与 OCR 会复用已加载实例，**空闲后自动释放内存**（低内存设备约 1 分钟、常规设备约 3 分钟、未知内存环境约 2 分钟；运行中的任务不会被打断）。释放内存不会删除磁盘文件，下次直接从缓存重新加载。浏览器内置模型与 Ollama 的内存驻留由各自服务管理。

## 四、服务密钥与连接失败

### API Key 填在哪里？为什么连接失败？

在**设置 → 翻译服务**选中对应服务，填写接口地址、密钥和模型，再点击**检查连接**：

- 网页聊天会员通常不含 API 额度，请核对开发者后台余额。
- HTTP 404 且返回网页 HTML 通常是接口路径错误，而非密钥无效。
- Ollama 需先在本机启动服务、拉取模型并允许扩展来源。详见[翻译服务与模型配置](/config/translation-engines)。

## 五、排版冲突与备份迁移

### 译文重复或页面排版异常

先恢复原文，关闭浏览器自带整页翻译或其他翻译插件，仅保留流畅阅读后重试。

### 与 Font Rendering 字体渲染脚本冲突导致译文消失

更新流畅阅读并刷新网页后重试；若仍有冲突，可暂时关闭字体脚本的粗体修正功能，并在 Issue 中附上双方版本与可公开复现网址。

### 旧版备份还能导入吗？

在**设置 → 备份与恢复 → 本地备份**直接导入旧版配置 JSON 或备份，先核对预览再确认（完整备份未加密且可能含密钥，请勿公开分享）。遇到校验报错请保留原文件、更新扩展后重试，详见[备份与同步](/config/backup-sync)。

## 仍然无法解决？

前往 [GitHub Issues](https://github.com/FluentRead/FluentRead/issues) 反馈，请附上：

1. 浏览器与流畅阅读版本号；
2. 可公开访问的复现网址与操作步骤；
3. 隐藏了私人内容、Cookie 与 API Key 的报错截图或错误码。
