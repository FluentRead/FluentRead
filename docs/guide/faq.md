# 常见问题

先确认流畅阅读已开启，安装或更新后刷新网页，再按遇到的问题排查。

## 点击“翻译页面”后没有变化

1. 确认总开关已开启，目标语言正确。
2. 浏览器设置页、扩展商店等受保护页面不能翻译，换一篇普通文章试试。
3. 在**设置 → 翻译服务**检查当前服务连接。服务繁忙时稍后重试或换一个服务。

## 页面只翻译了一部分

默认随阅读位置逐步翻译，先向下滚动。菜单、按钮或特殊正文漏译时，检查[网站阅读范围](/config/site-adaptation)；图片与图表中的文字使用[图片](/guide/image-translation)或[圈选翻译](/guide/area-translation)。

## 为什么选区翻译可以用，整页翻译却不行？

先试译一个段落，再检查[网站阅读范围](/config/site-adaptation)。正文识别不合适或整页请求较多都可能造成此现象；同时确认当前服务连接与请求额度。

## 如何恢复原文？

打开扩展菜单，点击恢复当前网页的按钮。更换语言、服务或基础样式后，先恢复原文，再重新翻译。

## 为什么中文译文里出现日文？

确认目标语言，恢复原文后重试。服务明确返回整段错误语言时，流畅阅读会重试或切换免费候选；连续错误会显示失败，不把结果写入缓存。中文译文中的短名称、术语或引用可能保留原语言。

## 网页邮箱的正文能翻译吗？

QQ 邮箱旧版阅读页与网易 163、126、yeah 的 JS6 阅读页支持邮件正文识别。打开具体邮件后尝试全文或划词翻译，必要时刷新；写信编辑器不按邮件正文处理。

仍有漏译时，反馈邮箱域名、去掉 `sid` 等参数的页面路径、浏览器版本和去除隐私的截图，不要提交邮件全文或登录信息。

## DeepSeek 网页选中文字没有反应怎么办？

先确认已开启划词翻译，并按设置使用翻译图标、直接翻译或快捷键。更新扩展后刷新 DeepSeek 页面，再选中回答中的普通文字重试。

DeepSeek 页面根节点的整页禁译标记不应阻止主动划词翻译；流畅阅读允许这类选区，也允许完整落在同一编辑器宿主内的用户选区。原生输入控件、局部禁译区域、隐藏内容和扩展 UI 仍受保护。

## 为什么没有 AI 讲解？

普通划词翻译只给出译文。要获得讲解，先开启[翻译卡片](/guide/deepseek-harness)并选择已配置的 AI 服务，选中文字后点击“读懂”等动作。

## 图片翻译一直在准备

本地 OCR 首次使用需要下载识别语言包，按图片提示下载，并确认源语言正确。圈选可开启**优先模型识图**，模型支持时直接识别选区图片。图片模糊或无法读取时，换清晰原图或缩小选区。

## 字幕没有出现

确认字幕功能已开启，视频本身有字幕。X 无字幕视频可尝试本地 AI 识别，需先下载模型，且部分视频无法读取。详见[视频字幕](/guide/video-subtitles)。

## API Key 填在哪里？为什么连接失败？

在**设置 → 翻译服务**选择服务，填写地址、密钥和模型，再点击**检查连接**。检查账号额度，网页聊天会员不一定包含 API 用量。Ollama 还需在电脑上启动服务、下载模型并允许扩展连接，详见[翻译服务](/config/translation-engines)。

## 译文重复或排版异常

先恢复原文，关闭浏览器自带翻译或其他翻译扩展，只保留一种翻译后重试。仍异常时记录网址、步骤和去除隐私的截图。

## 与 Font Rendering 字体渲染脚本一起使用时，译文为什么会消失？

更新流畅阅读并刷新网页后重试。仍有冲突时，可暂时关闭字体脚本的粗体修正功能，并反馈两者版本与可公开的复现网址。

## 本地翻译模型保存在哪里？卸载扩展会清理吗？

下载的模型保存在当前浏览器的扩展缓存中。正常卸载会清理所属存储，停用则保留；也可在模型设置中单独删除。Chrome 内置翻译语言包由 Chrome 管理，手动下载的扩展安装包或解压目录需自行清理。

## 本地模型会每次重新加载吗？会一直占用内存吗？

模型文件保存在磁盘，与运行时内存不同。本地翻译、朗读、语音识别与 OCR 会复用已加载资源，空闲后自动释放。已知低内存设备通常等待 1 分钟，其他已知设备 3 分钟，无法获取内存信息时 2 分钟；运行中的任务不会因空闲计时被中断。

释放内存不会删除下载文件，下次仍可从缓存加载。多功能同时运行的内存可能叠加，这些时间不是硬性内存上限；Chrome 内置模型与 Ollama 的驻留由各自服务管理。

## 旧版备份还能导入吗？

在**设置 → 备份与恢复 → 本地备份**导入旧配置 JSON 或备份，检查预览再确认。完整备份可能含 API Key，且未加密，不要公开分享。

出现备份校验错误时，保留原文件，更新扩展再试；仍失败只需反馈版本与报错文字，无需提交完整备份。操作见[备份与同步](/config/backup-sync)。

## 仍然无法解决

到 [GitHub Issues](https://github.com/FluentRead/FluentRead/issues)附上浏览器与扩展版本、可公开的网址、复现步骤，以及隐藏私人内容的截图。请勿提供密钥、Cookie 或账号资料。
