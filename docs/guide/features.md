# 功能概览

按你正在做的事找操作指南。第一次使用，请先看[安装与第一次翻译](/guide/getting-started)。

## 页面翻译

在原网页中按段落显示译文，双语对照、仅译文随时切换，也能恢复原文。

[查看操作指南](/guide/webpage-translation)

## 翻译中心：多服务对比

在 **设置中心 → 工具与学习 → 翻译中心** 中输入或粘贴原文，选择语言后点击 **开始翻译**，也可以按 Mac 的 **⌘ + Enter** 或其他系统的 **Ctrl + Enter**。

[查看操作指南](/guide/translation-center)

## 局部翻译

只想读网页中的一部分时，例如 GitHub 项目的 README、文章正文或某个评论区，不必翻译整页。

[查看操作指南](/guide/webpage-translation)

## 英文单词查词

划词词卡内置 3,000 个常用英文词条，首次查词无需下载额外资源。

[查看操作指南](/guide/deepseek-harness)

## 译文样式

在 **设置 → 界面风格 → 译文样式** 中选择双语对照时译文的显示效果。

[查看操作指南](/config/appearance)

## 双语逐句高亮

开启逐句高亮后，指向原文或译文的一句话，同步强调另一侧的对应句子。适合定位长段落中的难句。

[查看操作指南](/config/appearance)

## 选中即译

先在扩展菜单的 **划词翻译** 中开启双语显示，再选中词语、句子或段落，点击附近的 FluentRead 图标查看译文。

[查看操作指南](/guide/deepseek-harness)

## 双语分享卡片

把喜欢的句子、译文和来源排成高清图片，保存或分享自己的阅读发现。

[查看操作指南](/guide/share-cards)

## 悬浮翻译

将鼠标停在想读的段落上，按 **Control** 翻译当前段落。

[查看操作指南](/guide/hover-translation)

## 输入框翻译

在 **设置 → 翻译设置 → 输入框翻译** 中选择触发方式、目标语言和输出方式，顶部会说明当前操作及输出结果。

[查看操作指南](/guide/input-translation)

## 划词学习与学习中心

划词翻译的卡片模式提供词典、词性分类与句法学习。

[查看操作指南](/guide/vocabulary-book)

## 图片、文件与字幕

- [图片与圈选](/guide/image-translation)：识别图片或网页截图中的文字。
- [文档翻译](/guide/document-translation)：导入文件，翻译、校订并下载。
- [视频与会议字幕](/guide/video-subtitles)：查看支持平台、字幕来源与显示方式。

## 多种翻译服务

免费翻译可以直接开始。

[查看操作指南](/config/translation-engines)

## 自动翻译与网站规则

经常阅读同一个网站，可以让它自动翻译；希望某个网站保持原样，也可以单独关闭。

[查看操作指南](/guide/webpage-translation)

## 恢复、样式和主题

在设置中选择译文样式、界面主题和菜单栏布局。

[查看操作指南](/config/)

### 请求限制

服务提示请求过于频繁时，降低并发或请求速率。具体操作见[请求限制](/config/#请求限制)。

## 更多翻译语言

源语言和目标语言现在提供 52 个语言选项，包括简体中文、繁体中文、德语、葡萄牙语、意大利语、阿拉伯语、印地语、越南语、泰语、乌克兰语和斯瓦希里语等。

[查看操作指南](/guide/webpage-translation)
