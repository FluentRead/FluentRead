# 网页与划词翻译

FluentRead 支持网页全文双语对照、划词翻译和悬浮翻译，译文在当前网页中显示。

## 页面翻译

扩展菜单顶部的“流畅阅读”下方显示当前安装版本号。

打开扩展菜单，点击“翻译页面”。默认将原文与译文按段落排列，方便随时核对；原文保留标题、链接和正文结构不变。带链接、加粗、斜体或脚注标记的段落会整段作为一次翻译单元，译文以通顺的整段文本呈现，避免句子被行内格式拆成碎片后逐片翻译，机器翻译服务的这类段落也只发一次请求；含行内代码、公式或图片的段落仍按片段翻译，以便在译文中原样保留这些内容。阅读论文或 Codeforces 题面时，文字周围的常见公式也会尽量保留原来的显示。Codeforces 比赛卡片中的状态、名称和注册链接分别翻译，实时倒计时仅保留原站点的一份，秒数变化不会反复重建译文。

直接打开原始 XML、RSS 或 SVG 文件时，FluentRead 不会向文档注入翻译内容或样式，以保留浏览器原生的文件展示；正常 HTML 与 XHTML 网页仍可翻译。

默认按阅读位置逐步翻译；如果需要一次处理整页，可在全文翻译设置中调整范围。点击“恢复原文”即可移除译文，之后可以换语言或服务再次翻译。

全文翻译中，快速完成或命中缓存的段落直接显示译文；等待稍久的段落才显示加载图标，减少图标闪烁。GitHub 文件和对比页中的代码行保持原样，提交说明和代码审查评论仍可翻译。

“按阅读进度”会优先处理当前屏幕，再预翻译上下约 600 像素内的内容。连续滚动时暂停派发新段落，停顿约 220 毫秒后按当前位置继续；快速划过并离开附近范围的待翻译段落，会等到再次读到时再处理，已经发出的请求会继续完成。高级选项中的“免滚动预翻译字符数”默认是 0；需要提前翻译页面开头的一部分内容时，可以自行调大。

网页中的固定高度内容卡片会在译文溢出时自动增高，避免压住相邻内容。带行数截断的卡片摘要也会临时展开，让双语译文完整显示；恢复原文后还原原有高度与截断样式。独立滚动区域仍保留原来的滚动方式。

OpenRouter 的模型列表、供应商列表和模型详情页会保留模型名称原文，模型介绍继续翻译。

页面出现需要先处理的公告或模态弹窗时，全文翻译会优先处理当前弹窗，等你关闭后自动继续原页面。翻译途中出现公告也会暂停尚未完成的正文任务，保留已经显示的译文。开启翻译进度提示时，等待期间会显示“关闭弹窗后自动继续翻译”；点击“恢复原文”会同时取消自动续译。普通提示条和非阻塞面板不会让全文翻译一直等待。

将 FluentRead 固定到浏览器工具栏后，图标右下角会显示浏览器原生角标：蓝底省略号（…）表示正在翻译，绿底白色对勾（✓）表示当前已进入翻译的内容完成，橙底白色感叹号（!）表示有内容翻译失败，可以在页面中点击“重试”。默认随阅读位置翻译时，尚未滚动到的内容会稍后处理。恢复原文、关闭翻译或刷新页面后，图标恢复原样。

### 页面悬浮球

在 **设置 → 常规 → 网页辅助** 中开启 **全文翻译悬浮球**，网页边缘会出现一个快捷入口：点击即可翻译整页，再次点击恢复原文；按住可以上下拖动，松手后自动停靠到离得更近的一侧，并与页面滚动条保持间距。拖动后的停靠侧和高度会自动保存，在其他网页和刷新后继续使用；窗口大小改变时，悬浮球会保持在可见区域内。

也可以在设置页搜索“全文翻译悬浮球”，直接定位开关；搜索“悬浮球进阶设置”则会定位到显示方式、位置和网站名单等详细选项。

下方的 **悬浮球进阶设置** 可以进一步调整：

- **按钮显示方式**：翻译与设置按钮可以悬停时展开、始终显示，或完全隐藏只保留悬浮球本体。
- **展开延迟**：鼠标停留多久后展开按钮，默认立即展开；调大可以避免划过页面边缘时误展开。键盘聚焦始终立即展开。
- **点击行为**：点击悬浮球本体可以切换翻译、打开设置页，或设为仅拖动。无论选择哪一项，按住都可以拖动调整位置。
- **缩小悬浮球**：以更小的尺寸显示，减少对网页内容的遮挡。
- **显示设置入口**：关闭后悬浮球不再显示打开设置页的按钮。
- **收起时不透明度**：数值越小越透明；鼠标悬停、展开和拖动时始终完全清晰。
- **不显示悬浮球的网站**：按主域名添加，该网站及其子域不再显示悬浮球，快捷键、右键菜单和其他功能仍然可用。

关闭悬浮球不会影响全文翻译快捷键（默认 Alt+T）和右键菜单入口。

### 按钮和操作文字只显示译文

按钮、标签页、表单标签和工具栏里的操作文字是界面控件，宽高由网站样式固定。双语模式下这类文字**只显示译文、替换原文**，不再叠加一行原文，避免按钮被撑高、文字溢出或整排工具栏错位。原生按钮、`role` 声明的控件、按钮样式的链接，以及用输入框实现的按钮都按同一规则处理。恢复原文会把按钮文字还原为原始内容。

正文段落、标题和折叠区域里的完整句子仍按所选的显示模式呈现，双语对照不受影响。

会随表单一起提交的按钮（带 `name` 的提交按钮）和输入框中的内容保持原文，避免翻译后网站收到无法识别的操作或改动你输入的文字。

### 补充翻译菜单和动态界面

某些网站的菜单、按钮或导航文字没有被翻译时，可在 **设置 → 高级选项 → 页面识别** 中开启 **识别全部节点**。先恢复原文，再重新翻译。此选项会保存，也会处理翻译期间新展开的可见菜单。

识别范围更大时，页面里的操作文字也可能发生变化。不需要时关闭，下一次翻译恢复默认范围。图片、图表里无法选中的文字，请使用[图片翻译](/guide/image-translation)或[圈选翻译](/guide/area-translation)。

### 时间、数字与持续变化的内容

独立的日期、时钟、时长（如 `12:34 PM`、`5 minutes`、`1小时2分3秒`）和纯数值保持原文，不发送翻译请求。包含这些信息的正常句子仍可翻译。网页用 `<time>` 或 `role="timer"` 标记的时间展示也保持原文。

翻译期间来源文字变化后，全文翻译会等它稳定约 1.8 秒，再处理最新内容，减少反复撤下和插入译文。短时间内连续只改变数字的短标签（如访问计数、进度）会保持原文；同一位置换成其他内容后可重新翻译。这些规则同样用于悬浮翻译；悬浮时遇到仍在变化的内容，待其稳定后再次触发即可。

### 调整段落处理方式

**设置 → 高级选项** 还提供几项网页翻译的细节控制，修改后在下一次翻译生效：

- **侧边栏翻译**：正文范围下一并翻译侧边栏和导航区域，页眉页脚仍保持原文。
- **翻译段落最少字符数**：短于该长度的段落不再翻译，可以减少零碎短句带来的请求。这里的长度按字符计算，例如 `hello` 是 5 个字符。
- **免滚动预翻译字符数**：默认为 0，完全按视口触发。调大后，启动全文翻译时会提前翻译页面开头的这部分内容；为保持段落完整，最后一段可能略超出额度。其余内容仍按阅读进度翻译。已保存的自定义数值会保留。
- **长段落自动换行**：在长段落译文的每句话结束处插入换行，便于阅读。
- **译文在原文之前**：双语模式下把译文放在每段原文前面，默认排在原文之后。

## 翻译中心：多服务对比

在 **设置中心 → 工具与学习 → 翻译中心** 中输入或粘贴原文，选择语言后点击 **开始翻译**，也可以按 Mac 的 **⌘ + Enter** 或其他系统的 **Ctrl + Enter**。首次只展示少量免密钥服务与已配置的默认服务；原有的服务选择和顺序会保留。

**管理服务** 可以多选，并按服务或模型名称搜索。目录区分免密钥/凭据已配置与需要配置的服务；“已配置”不等于连接已验证。添加服务不会自动翻译；点击 **配置服务** 可编辑连接与模型，返回后原文及完成结果仍在。本中心的选择不会更改网页默认服务，服务连接配置仍与其他功能共享。

结果可切换为 **列表** 或 **并排**，窄屏自动改为单列。可以拖动卡片，或聚焦拖动按钮后按 **Alt + ↑ / ↓** 排序；语言、服务顺序和排列方式自动保存。翻译过程中可以停止全部或某一项，已完成的结果保留；失败或停止后可只重试未完成项。

原文、语言或模型变化后，旧结果会标记出来，并显示当时的语言。**复制本次结果** 只包括与当前输入匹配的成功结果，不混入旧译文；单项复制仍可复制供参考的旧结果。

原文和译文不写入翻译中心配置，仅保留在当前设置页面；关闭或刷新后清空。点击翻译后，原文会发送给所选服务，并遵循扩展已有的请求记录和统计设置。

## 局部翻译

只想读网页中的一部分时，例如 GitHub 项目的 README、文章正文或某个评论区，不必翻译整页。点击扩展菜单里 **翻译当前网页** 旁的 **局部** 按钮，网页进入选择模式：

- 鼠标所指的区域会被高亮框标出，旁边的标签说明点击后会发生什么：翻译多少段、恢复原文，或这里没有可翻译的文字。
- 点击即可只翻译这块区域。视口内的段落先翻译，其余随后完成；显示方式、翻译服务和目标语言与全文翻译相同。
- 按 **↑** 扩大到外层区域，按 **↓** 缩小回来。扩大后只要鼠标还在高亮范围内，选择就不会跳回小段落。
- 再次选择已经翻译的区域即可恢复这块区域的原文；区域里有翻译失败的段落时，再次选择会重新翻译它们。
- 按 **Esc**、点击右键或点击底部提示条上的 **×** 退出。选择期间点击网页不会打开链接或触发按钮。

经常使用时，可以在 **设置 → 翻译设置 → 局部翻译** 中开启快捷键（默认 **Alt+R**，Mac 为 Option+R），选择模式中再按一次即可退出。页眉、导航和侧栏在全文翻译中通常保持原文；主动选择这类区域时，其中的文字也会翻译，并像按钮、菜单等界面文字一样直接替换原文显示，避免撑乱版面。恢复全文翻译时，局部翻译的内容会一并恢复原文。

## 英文单词查词

划词词卡内置 3,000 个常用英文词条，首次查词无需下载额外资源。查询不在常用词库中的单词时，在线词典可立即继续提供结果；扩展同时在后台下载并校验完整词库，供后续查词在本地使用。完整词库约 3.9 MB，只下载一次并保存在浏览器缓存中；下载不可用时，常用词库及在线词典仍可使用。词库文件的下载地址固定，不包含正在查询的单词。

## 译文样式

在 **设置 → 界面风格 → 译文样式** 中选择双语对照时译文的显示效果。样式按 **文字、线条、标记、卡片** 分类，每张卡片直接展示实际效果；旁边的预览模拟一段网页，可以切换 **浅色网页** 和 **深色网页**，检查译文在不同配色的网站上是否清楚。

**自定义外观** 可以进一步调整：

- **译文颜色**：为译文单独指定文字颜色，选择“默认”则跟随网页。
- **译文背景色**：给普通译文或任何内置样式设置独立背景；选择“默认”则保留该样式原有背景。
- **线条颜色**：修改下划线、波浪线、边框和引用色条的颜色。
- **标记底色**：修改荧光标记、学习标记、底色和卡片的颜色，并按样式自动调整深浅。
- **字号、不透明度、字重和字体**：用滑块或直接输入 50%–250% 的字号，相对原文放大或缩小译文，或让译文更醒目、更柔和。

每种颜色都提供精选色板和取色器，也可直接输入 CSS 颜色名称、`rgb(红, 绿, 蓝)` 或十六进制色值；无效输入不会保存。点“恢复默认”回到样式自带的外观。颜色、字号等外观调整会立即应用到已打开网页上的译文，无需重新翻译；切换样式后，下一次翻译开始使用新样式。仅译文模式不使用这些样式，页面会提示并提供切换到双语对照的按钮。

也可以在 **直接输入 CSS 样式** 中写译文的声明，例如 `color: rebeccapurple; background: rgb(255, 248, 204); font-size: 117%;`。无需写选择器；只接受颜色、字体、边框等外观属性，网址、选择器和定位属性会被忽略。有效声明会覆盖上方控件的对应值，并立即显示在当前预览中。保存为命名样式后，样式卡片也会显示自己的真实效果。

“模糊遮罩”会先模糊显示译文，指针移到译文上再看清，适合先读原文、再核对自己的理解。

## 双语逐句高亮

在 **设置 → 翻译设置 → 阅读辅助** 中开启 **双语逐句高亮** 后，将光标移到原文或译文中的一句话上，即可同时高亮两侧对应的句子。无需点击或按快捷键，适合在长段落中定位难句、核对翻译偏差。旁边的阅读示例提供多句对照，可以直接试用。

在 **设置 → 界面风格 → 逐句高亮样式** 中选择八种预设，也可以自定义高亮底色、下划线颜色、两者的不透明度、线型和粗细。底色不透明度设为 0% 时只保留下划线；下划线形态选“无下划线”时只显示底色。支持实线、点线、虚线、双线与波浪线，并可在浅色、深色网页预览中实时体验。修改后立即应用到已打开网页，无需重新翻译；配置会自动保存。“恢复预设外观”清除自定义项，选择其他预设也会恢复该预设的外观。高亮开关独立保存。

还可以在 **直接输入 CSS 样式** 中写声明，例如：

```css
background-color: rgba(255, 220, 100, 0.3);
text-decoration: underline wavy #9d4edd;
text-decoration-thickness: 2px;
```

有效 CSS 会覆盖上方控件的对应值，立即应用到预览和已打开网页。支持文字颜色、底色、下划线、文字阴影等[浏览器高亮绘制属性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::highlight#allowable_properties)，无需选择器；不支持的声明会提示并忽略。

输入名称后点击 **保存为新样式**，可以保存最多 12 套逐句高亮配置，每套独立包含基础预设、外观控件和 CSS，并在卡片中展示真实效果。点击卡片切换配置，重新打开设置后仍保留。修改当前外观会即时生效，**更新已选样式** 将修改和新名称写入原配置；**保存为新样式** 保留旧配置，另存一套。**删除已选样式** 只删除保存的配置，当前外观仍可继续调整。内置预设和高亮开关独立于已保存的配置。

原文和译文句数一致时按顺序对应；服务拆句或合句时，根据句序和相对长度组成相邻句组。这是本地近似对齐，不能判断翻译是否正确，改写幅度较大或调整语序的译文可能无法准确对应。高亮不增加翻译请求，也不改变网页文字和排版。

仅双语模式生效。恢复原文、关闭开关或离开文字后清除高亮；拖选文字时让位给网页选区。需要浏览器支持 CSS Custom Highlight API，旧版浏览器缺少该能力时保留正常翻译。

## 选中即译

先在扩展菜单的 **划词翻译** 中开启双语显示，再选中词语、句子或段落，点击附近的 FluentRead 图标查看译文。若只是选中文字阅读或复制，滚动页面或正文滚动容器后，尚未打开的划词图标或小点会消失；已打开的卡片仍可继续使用。含行内公式的句子也可以选中翻译，卡片原文会将公式整理为一份文本表示。卡片可以复制结果和朗读原文。放大或缩小网页时，扩展版划词卡片会保持原本的屏幕尺寸。窗口挡住原文时，可以按住顶部或内容周围的空白处拖动；拖动任意边缘或四角可以调整宽高，文字会随宽度自动换行，长内容可在卡片内滚动。调整会保留到本次卡片关闭，重新划词时恢复默认大小并靠近新选区显示。读完后关闭即可。点击网页其他按钮或按 Escape 会关闭卡片；网页保留旧选区时也不会再次弹出。

目标语言设为中文或英文时，划词卡片可点“译为”里的语言按钮，临时切换这次翻译的方向，不会修改网页翻译设置。默认仍跳过已经是目标语言的选区；如需直接对中文和英文都使用划词翻译，可在 **设置 → 专项翻译 → 划词翻译** 开启“中英双向划词”。开启后，同语言选区也会显示入口，卡片自动选择另一种语言。未开启时，仍可用选中文字后的右键菜单打开卡片并反向翻译。

喜欢更直接的操作，可以在划词设置中改成直接弹出、按键触发或其他手势，并调整出现前的等待时间。只需要查意思时，使用普通翻译服务即可。

## 双语分享卡片

遇到喜欢的句子，可以把原文和译文排成一张图片：

1. 选中文字并完成划词翻译，在翻译结果内点击 **制作卡片**。入口只在划词结果中显示，正常浏览、悬浮段落翻译和全文翻译时不会在网页上出现。
2. 默认使用红白分区的 **珊瑚** 风格，另有 **晴空、流光、月白、抹茶、书页、落日、蓝图**，共八套样式。风格按钮展示缩略图；在 **更多设置** 中用分段按钮选择自适应或方形、字号，用开关调整双语顺序、来源和 FluentRead 署名。工作台统一使用 FluentRead 品牌色，不随图片样式改变控件颜色。
3. 在 **编辑摘录** 中修改这张卡片的文字，不会改变网页或翻译结果。来源默认只显示网站域名，可以填写作者或直接隐藏。
4. 点击 **保存图片** 下载高清 PNG，或 **复制图片** 后粘贴分享。

预览就是导出的图片。方形放不下时会提示改用自适应长图；超长内容需要精简，不会自动截掉文字。关闭预览后可继续阅读。外观偏好会沿用到下次，摘录文字和生成的图片不会存入插件配置。

图片在本地生成，不额外请求翻译或上传内容。部分页面不支持图片剪贴板，仍可保存 PNG 后自行分享。划词翻译的双语和仅译文模式均可制作卡片。公式等富文本以文字形式排版，不保留网页原有的数学布局。

复制和保存后的结果会显示在固定底栏中：绿色表示操作成功，红色表示失败并提供下一步建议。保存提示只表示已发起下载，请以浏览器下载记录为准。复制等待期间显示加载标记并防止重复操作。

## 悬浮翻译

将鼠标停在想读的段落上，按 **Control** 翻译当前段落。鼠标位于输入框或可编辑区域时，不会触发悬浮翻译。不必拖动选择，也不必翻译整页。快捷键和触发方式都能修改，详见[快捷键与触发方式](/guide/custom-hotkey)。

同一个段落还可以直接取走文字：按 **Alt+C** 把鼠标所指段落复制到剪贴板，段落已翻译时默认按当前显示形态复制原文和译文。开关、快捷键和复制内容在 **设置 → 翻译设置 → 段落复制** 中调整。

## 输入框翻译

在 **设置 → 翻译设置 → 输入框翻译** 中选择触发方式、目标语言和输出方式，顶部会说明当前操作及输出结果。在普通输入框或社交平台、聊天工具、邮件等网页的富文本编辑器里写好内容后，连续按三下空格、等号或短横线，将内容翻译成指定语言；原有 **Ctrl+Enter** 设置继续生效。富文本编辑器中的译文通过编辑器自己的粘贴与输入流程写入，可以用编辑器的撤销找回原来的格式。

**输出方式** 默认是“替换原文”。需要双语回复时，选择 **原文在前，译文在后**，例如目标语言设为英语，输入中文后触发翻译，中文保持不变，英文追加到下一行。也可以选择 **译文在前，原文在后**，让英文在前、中文在后，两段之间换行。原文中的空白和段落会保留，富文本原有的加粗、链接等结构也会保留。追加模式适用于支持换行的多行输入框和富文本编辑器；单行输入框会提示不支持换行，并保留原文。

选择连按触发后，点击 **连按速度** 打开调整弹层。三击间隔指相邻两次按键之间最多可以等待多久，默认 **1000 毫秒**，可在 **200～2000 毫秒**之间调整，并随时恢复默认。容易误触时调短，连按不容易成功时调长。长按按键或使用输入法选词不会作为三击触发。

在输入框翻译设置中选择翻译服务、AI 模型并按需展开提示词，连接参数沿用该服务已保存的设置。模型可从列表中选择；留空使用服务默认模型。选择支持提示词的 AI 服务后，可调整语气和翻译要求；`{{origin}}` 表示输入框原文，`{{to}}` 表示目标语言。留空使用内置提示词，也可点击“从默认提示词开始编辑”进行修改；恢复默认只影响当前提示词。

修改自动保存。输入框翻译关闭时也可预先配置，修改目标语言或翻译配置不会自动启用翻译。升级后保留原有触发方式、目标语言及独立服务选择；未设置独立服务时，输入框默认跟随网页翻译服务。

翻译期间可以按 **Esc** 取消本次写回；继续编辑时，迟到的译文不会覆盖新的内容。翻译成功后的提示提供 **恢复原文**，再次编辑后不会用旧原文覆盖新内容；富文本编辑器恢复的是原来的文字，链接、@提及等格式可用编辑器的撤销找回。密码框和代码编辑器不参与翻译。

## 划词学习与学习中心

[划词翻译的卡片模式](/guide/deepseek-harness)提供词典、词性分类与句法学习。查词无需 AI；讲解语气、分析句法、学习用法和练习需要配置 AI 服务，并在点击后才发起请求。

遇到想记住的单词、短语或句子，可以收藏到[学习中心](/guide/vocabulary-book)，结合原句练习和复习。

本地朗读需要先在设置中下载语音模型，支持中文和英语。合成时优先使用可用的 GPU；加速不可用或输出异常时自动改用 CPU，在线与本地的优先顺序仍按你的朗读设置执行。

经常阅读同一个网站，可以让它自动翻译；希望某个网站保持原样，也可以单独关闭。正文漏译时先看[网站阅读范围](/config/site-adaptation)，无需从编写规则开始。

## 恢复、样式和主题

在[设置](/config/)中选择[译文样式](#译文样式)、界面主题和菜单栏布局。不常用的入口可以隐藏，常用的放在手边。隐藏入口不会删除收藏或停用对应功能。


### 请求限制

在「高级选项 → 请求限制」中调整翻译并发数、每秒和每分钟最多请求数。默认值分别为 **10**、**10** 和 **250**；已有设置会保留。每秒或每分钟的数值设为 **0** 表示不限制该项。

未单独配置的服务和模型共用全局限制。需要适配某个 API 的额度时，进入「翻译服务」，展开页面底部的「高级设置」，关闭「跟随全局设置」即可为当前模型填写限制。切换模型后可以分别设置。

如果一个服务的所有模型共用额度，点击「服务请求限制」设置服务总上限。单独配置的模型同时受该服务总上限约束；未配置的模型直接使用服务限制。重新开启「跟随」会恢复继承，并保留之前填写的数值，方便以后再次使用。

达到上限的请求会排队等待。失败后的重试次数与重试间隔在全局高级选项中统一设置。

## 更多翻译语言

源语言和目标语言现在提供 52 个语言选项，包括简体中文、繁体中文、德语、葡萄牙语、意大利语、阿拉伯语、印地语、越南语、泰语、乌克兰语和斯瓦希里语等。输入框翻译与写作助手也使用同一份语言列表；源语言仍可选择自动检测。原有语言设置会保留。

选择语言后，使用支持该语言对的翻译服务。不同机器翻译服务、AI 模型和 Chrome 内置翻译的语言范围不同；语言出现在列表中不代表每项服务都支持。图片文字识别和视频语音识别仍取决于各自的识别语言包或模型。

DeepL 当前不支持卡纳达语和僧伽罗语，选择这些语言时会提示切换服务。谷歌、小牛的挪威语以及微软的塞尔维亚语会自动转换为对应接口的语言代码；无需手动修改。

### 右键翻译

选中文字后右键，选择“翻译选中文本”打开划词翻译。右键网页普通位置可翻译全文，翻译后同一入口变为“显示页面原文”；右键图片可翻译图片。菜单使用扩展图标和操作名称，不再显示品牌名称、目标语言或快捷键。每个场景优先显示一个操作，不再创建分组子菜单。全文翻译也可以从工具栏的扩展面板发起。

如果选中文字只是为了复制或阅读，不希望旁边出现划词入口，可在 **设置 → 专项翻译 → 划词翻译 → 划词触发方式** 选择 **仅右键菜单**。此时划词图标和小点都不显示；需要翻译时，选中文字后右键选择“翻译选中文本”。请保持右键菜单及该入口开启。翻译卡片的选区提示由其独立设置控制。
