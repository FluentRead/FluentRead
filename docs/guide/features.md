# 功能介绍

FluentRead 的功能都围绕一个目标：让你在当前页面完成理解，不必在网页、翻译器和词典之间来回切换。

## 页面翻译

点击“翻译页面”，译文会放在原文附近，形成可以对照阅读的双语页面。原文不会被覆盖，随时可以恢复。

阅读论文时，双语译文会保留原文中的行内公式，包括原生 MathML、KaTeX、MathJax 和 Wikipedia 公式图片。公式沿用网页的渲染结构，周围文字正常翻译；恢复原文和再次翻译不会改写原始公式。

### 补充翻译菜单和动态界面

如果菜单、按钮或节点标签未被识别，在 **设置 → 高级选项 → 页面识别** 中开启 **“识别全部节点”**，然后使用原有的悬浮或全文翻译方式。该选项默认关闭，设置会保存并在下次翻译时生效；已翻译的页面请先恢复原文，再重新翻译。全文翻译期间，随后打开的新菜单或加载的界面文字也会自动翻译，结束后仍用原有恢复原文操作统一恢复。

适合尝试的场景包括：

- [Epoch AI 数据中心页面](https://epoch.ai/data/ai-data-centers)：页面导航、页脚链接、图表页签和已展开的筛选控件。
- n8n 工作流编辑器：节点面板、操作菜单和节点配置说明。
- 文档或项目管理应用：展开后的导航树、页签和动态操作菜单。

关闭开关后，下次翻译会恢复默认识别范围。恢复原文或重新加载页面不会清除这个设置。识别对象是页面中已经挂载、可见的文本 DOM。尚未打开的菜单会在显示后处理；不会预先加载未渲染的内容，也不会读取输入框中的用户内容、代码或纯数字。Canvas 绘制文字和图片中文字不属于这次文本扫描范围，可使用图片翻译或圈选翻译。

## 选中即译

选中句子、段落或术语，就能打开聚焦的翻译卡片。它适合快速确认意思、查一个单词或核对专有名词，不需要等待整页处理。

还可以根据习惯使用悬浮、双击、长按、中键和触屏手势等方式触发翻译。具体触发方式可以在[设置](/config/)中调整。

## 图片、文件与字幕

### 圈选翻译

按 Shift+Z 后拖拽网页区域，以可复制的文字卡片阅读原文与译文。圈选支持标准翻译与 AI 文本增强，具有独立开关和服务选择。详情见[圈选翻译](/guide/area-translation)。

### 图片翻译

图片翻译适合截图、漫画、扫描资料和网页图片。FluentRead 会先识别图片中的文字，再使用你选择的翻译服务生成译文。图片越清晰、背景越简单，结果通常越稳定。详情见[图片翻译](/guide/image-translation)。

### 文档翻译

文档翻译适合不想复制粘贴的本地文件。当前支持 PDF、ePub、HTML、JSON、TXT、DOCX、Markdown，以及 SRT、VTT、ASS、SSA、LRC 等字幕文件。文件在浏览器中解析，待译文字发送至所选翻译服务。

打开文件后，在左侧确认语言、服务与模型，在右侧预览原文，再开始翻译。窄屏下翻译设置可展开和收起，正文、校订和下载保持独立。翻译可以随时暂停；失败或暂停时已完成的片段仍保留，继续翻译只处理剩余内容。更改语言、服务、模型或术语后，会提示按新设置重新翻译。

- **阅读**：切换原文、双语与译文。PDF 连续展示页面，ePub 按章节阅读，字幕和 JSON 保留时间轴或路径。
- **校订译文**：搜索整份文档的原文、译文与位置，筛选未翻译片段，分页编辑任意段落。修改会用于预览和下载。
- **下载**：独立选择双语或仅译文，保留原文件格式。未完成时可确认下载当前结果，缺失译文的位置保留原文。

翻译和校订结果只保留在当前页面，请下载后再离开。打开新文件或覆盖已有译文前会提醒；刷新或关闭页面时，浏览器也会提示尚未下载的结果。扫描版 PDF 暂不支持 OCR，PDF 译页以图像呈现，适合版面阅读，暂不支持复制译文。

### YouTube 字幕翻译

开启视频字幕功能后，FluentRead 会翻译 YouTube 已提供的字幕文本，并显示原文与译文。它不上传音频，也不会凭空生成没有字幕的视频内容；视频字幕功能目前仍属于 Beta。

## 多种翻译服务

你可以根据阅读场景选择服务：

| 需求 | 可以先尝试 |
| --- | --- |
| 想马上开始 | 免费翻译服务 |
| 想要稳定的通用翻译 | Microsoft、Google 或 DeepL |
| 需要上下文和风格 | OpenAI 兼容 API 或其他 AI 服务 |
| 希望内容留在本机 | Ollama 本地模型 |

服务的价格、额度和数据政策由服务提供方决定，配置方法见[翻译服务](/config/translation-engines)。

## 自动翻译与网站规则

可以让常用网站自动翻译，也可以对某个网站关闭 FluentRead。规则按网站保存，适合固定阅读新闻、文档或社区网站。需要时可以在[设置](/config/)中修改。

## 术语库

在“工具与学习 → 术语库”中创建自己的固定译名，例如把 `large language model` 统一译为“大语言模型”，或让产品名保留原文。词库可以按语言和网站启用，支持 CSV、TSV、JSON 导入导出，并提供本地匹配预览。

术语库默认关闭，适用于 AI 翻译服务；通义 qwen-mt 使用原生术语参数。Microsoft、Google、DeepL 等机器翻译暂不应用术语。详细规则和使用方法见[术语库](/guide/glossary)。

## 恢复、样式和主题

译文不会永久覆盖原文。你可以恢复当前页面，换目标语言或服务后再次翻译；也可以选择译文样式、浅色或深色主题，让页面更适合长时间阅读。

### YouTube / X 视频字幕翻译（Beta 测试）
X 字幕默认靠近视频底边显示，只在播放控件可见时上移避让；缩放或全屏时会重新计算位置。外观高级设置中的“X 字幕自动贴底”可切回手动控制，直接拖动底部偏移也会保留手动值。原生字幕中的逐词时间标记会在显示、翻译和导出前移除，仅保留字幕正文。

视频字幕翻译默认开启，可在设置中单独关闭。在 YouTube 播放器或 X status 视频播放器旁会显示 FluentRead 图标入口。YouTube / X 已提供原生字幕时，FluentRead 会复用字幕轨道或页面已经渲染的字幕文本，在播放器中显示双语译文；不改变视频时间轴。字幕菜单支持“双语 / 仅译文 / 仅原文”、独立的“显示字幕”和“下载字幕”。

X 没有原生字幕时，可以在播放器菜单中点击“生成 AI 字幕”。生成入口与字幕显示控制分组排列，生成时会在图标旁直接显示百分比，并可停止，就绪后可关闭 AI 字幕；底部并排提供原文和译文字幕下载。菜单右上角显示当前翻译服务，点击可打开视频设置。

完整识别后的 X 字幕会按视频、模型和原语言缓存最多 32 个视频、7 天，只保存字幕文字与时间；刷新、再次开启或拖动进度不会重新识别。播放器菜单展开“X 本地 AI 字幕”后可明确选择“重新识别字幕”。视频设置中的“已识别视频缓存”可以查看数量并一键清除，适合在需要重新识别或修正结果时使用。

弹窗视频设置中的“X 视频 · 本地 AI”独立分组提供模型选择和下载入口，与通用翻译服务和字号设置分隔。视频设置直接展示 Tiny 和 Base 模型卡片、下载状态及下载按钮，无需展开；已识别视频缓存的数量和清除操作也常驻显示。先下载 Tiny 或 Base 本地模型；推荐先用速度更快、占用较低的 Tiny。下载完成后回到播放器即可生成，无需刷新页面；如果模型状态暂时读取失败，菜单会提示重试。模型首次下载需要联网，下载完成后识别音频留在浏览器本地；字幕文字仍会交给你选择的翻译服务生成译文，不需要 Python、Docker 或额外本地服务。

只有点击后才会读取音频。扩展优先读取当前视频的独立音轨，完成识别和译文准备后，按当前播放位置显示字幕。生成过程保留你的视频播放或暂停状态、播放位置、倍速与音量；跳转时不会把之前那句字幕移到新位置。明显停顿会用于校准字幕边界；持续低背景音与语音可明确区分时，也会估计底噪后再定位停顿。完整识别结束后会统一重叠窗口的时间边界，播放和导出的 SRT 使用同一条时间轴。再次点击可停止生成，离开当前视频会取消相关请求。

本地 AI 识别目前需要桌面 Chrome/Edge 的扩展离屏能力。独立音轨无法读取时会尝试单独的扫描副本，因此可能需要更久；不支持的媒体格式会显示失败状态，可重试或使用原生字幕。单次完整识别支持最长 20 分钟的视频，耗时与视频长度、电脑性能、模型和翻译服务有关。

视频翻译服务与网页文本翻译服务独立配置，可以在“通用设置”或弹窗的视频字幕卡片中选择字幕译文服务、本地 Whisper 模型和视频原语言。视频原语言默认是自动检测，与网页翻译的源语言设置分开保存；韩语、英语、中文、日语等语言都可以明确选择。完整设置的“视频字幕外观”分组提供 8 套可扩展皮肤，以及字号、颜色、位置、底部偏移、背景透明度、行距和最大宽度调整；预览会即时反映设置，恢复默认可以回到当前字幕样式。原生字幕的完整 cue 会提前预取并缓存；如果站点只给出逐词或局部文本，则回退到稳定后实时翻译。完整设置中的“视频字幕翻译”页面可以关闭该功能；支持 YouTube 的 `/watch`、`/shorts`，以及 X / Twitter 的帖子、个人主页和信息流视频。X 原生字幕会直接用于翻译；播放器展开或全屏后继续跟随当前视频。关闭插件时不会向播放器嵌入入口。

在“基础配置 → 界面风格”中，“界面与弹窗”提供 14 套皮肤：默认、简约、紧凑、高对比、奶酪、海盐、抹茶、樱花、Emoji 乐园、夜幕、纸张护眼、极光舷窗、像素街机和落日公路。海盐、抹茶与樱花使用更明亮的色彩和水波、叶片、花瓣背景，Emoji 乐园带来奶油纸与彩色贴纸；极光舷窗、像素街机与落日公路分别加入光带、像素网格和夕阳公路图案，并兼容深浅模式。

同页的“菜单栏布局”提供“整体区域”和“快捷入口”两个视图。直接拖动左侧预览中的区域或快捷卡片即可调整顺序，也可以在右侧“已显示”列表中拖动整张卡片或使用方向键；不常用的入口用“隐藏”移到下方，之后可从“已隐藏”区域点“添加”恢复。布局会自动保存；所有皮肤（包括完整默认布局）的菜单栏都会随实际内容自适应高度，隐藏栏目或卡片后自动收缩，底部不保留多余空白。菜单栏默认宽度为 360 CSS 像素，极简和紧凑皮肤分别为 350 和 340 CSS 像素。翻译区域使用单行“网页翻译”主标题，移除宣传语。翻译服务菜单直接展示搜索框与分组列表，省去重复标题和说明。默认布局收紧了语言区、服务区和快捷卡片的纵向间距；内容较多时，菜单栏最多显示 560 CSS 像素高，超出部分在内部滚动，长文案仍可换行。这些设置只影响入口展示，不会停用对应能力。

## 单词本 Beta

选中一个英文单词后，可以把它收藏到本地单词本，之后再复习。单词本不需要账号，也不会上传学习记录；它目前只支持单个英文单词，更多说明见[单词本 Beta](/guide/vocabulary-book)。


### 界面操作与本地模型

界面语言选错时，可以在设置搜索中输入 `language`、`语言`、`言語`、`언어`、`langue`、`idioma` 等关键词，点击“界面语言 / Language”直接定位修改；搜索不受当前界面语言限制。“柔和圆环”位于加载样式列表首位，已保存的选择会保留。

图片、圈选和视频翻译默认开启，可分别关闭并保存选择。翻译卡的服务和模型并排显示在启用开关下方，可独立选择，切换服务会清除旧模型选择。翻译卡、图片、圈选、视频和术语库的总开关显示启停状态与启用操作。文档翻译、翻译中心、术语库和学习中心等页面使用统一下拉菜单；文档页仅在左侧选择翻译语言，右上角通过“设置”进入软件偏好。

在图片翻译的 OCR 语言包或视频翻译的本地模型卡片上，可点击“清除模型”释放已经下载的资源，之后可以重新下载。清除只影响对应模型，不删除文档、术语或已识别字幕结果；正在使用的字幕模型需要先停止任务。X 视频翻译入口等待原生控制栏出现后再显示，避免首次悬浮时从右下角跳到播放进度左侧。

本地视频模型卡片会在下载前显示预计大小：Whisper Tiny 约 100 MB，Whisper Base 约 150 MB。这是首次下载文件的估算，不代表运行内存；后续运行可能补充兼容文件。估算基于上游 [Tiny 文件清单](https://huggingface.co/onnx-community/whisper-tiny/tree/main/onnx)和 [Base 文件清单](https://huggingface.co/onnx-community/whisper-base/tree/main/onnx)，包括分词配置文件并向上取整。

功能总开关使用带淡边框、柔和背景和轻阴影的独立设置卡：左侧保留一句说明，右侧显示启停状态与开关。开启时以主题色开关和细微边缘强调状态，不使用整块强色背景或重复启用提示。


### 翻译卡提示词

在「设置 → 翻译卡」最底部的「提示词」中点击“编辑提示词”展开编辑器（默认折叠），分别编辑通用指令与“读懂、拆句、用法、练习”的动作提示词。这里只支持大模型服务，使用你已配置的服务与密钥。提示词会自动保存；清空时使用默认内容，“恢复默认”只重置当前模板。默认提示词支持中文、英语、日语、韩语、法语、俄语和西班牙语，随界面语言切换；“恢复默认”和留空时也使用当前界面语言的模板。旧版本保存的内置默认内容会自动适配，自己修改的内容保持原样。回答语言由目标语言 `{{to}}` 决定，与提示词的显示语言独立。每个模板最多 4000 字符，修改对下一次分析或追问生效，进行中的请求保留启动时的提示词。

可点击插入以下占位符：

| 占位符 | 替换内容 |
| --- | --- |
| `{{to}}` | 目标语言代码，例如 `zh-Hans` 或 `en` |
| `{{learningLevel}}` | 学习程度：`beginner`、`intermediate` 或 `advanced` |
| `{{explanationDepth}}` | 回答长度：`concise` 或 `detailed` |

例如：`请用 {{to}} 对应的语言，为 {{learningLevel}} 水平的读者解释原文。` 只替换列出的变量，其他占位符按原文保留。选中文本和追问自动作为独立消息提供，段落仍受“结合哪些原文”的设置控制。无需把原文或 API Key 写进提示词；提示词不会扩大页面读取范围。学习中心的词汇练习保留其专用任务指令。
