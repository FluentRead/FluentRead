# 快速开始

安装流畅阅读，选择目标语言，就可以在原网页中对照阅读原文和译文。

## 安装

从当前浏览器的扩展商店安装：

<BrowserInstall />

商店打不开时，按[离线安装说明](/guide/offline-install)下载并安装正式版。手机和 Safari 见[其他设备与版本](/guide/mobile-safari)，另有[油猴脚本](/guide/userscript)和 [Thunderbird](/guide/thunderbird) 安装说明。安装前已经打开的网页，刷新后再使用。

## 固定扩展图标

在 Chrome 地址栏右侧点击拼图形状的**扩展程序**按钮，找到**流畅阅读**，点击固定图标。以后点击工具栏中的流畅阅读图标，即可打开菜单。

## 翻译网页

1. 打开一篇外语文章，例如新闻或博客。
2. 点击流畅阅读图标。首次使用时，直接选好界面语言并**确认**。
3. 在菜单中选择**目标语言**。原语言可保留**自动检测**，翻译服务可保留默认的**免费翻译服务**。
4. 点击**翻译**按钮。译文会显示在原文下方，向下滚动继续阅读。
5. 想回到原文时，再打开菜单，点击**还原**。

<GuideVisual kind="first-translation" />

**界面语言**决定按钮和设置使用什么语言，**目标语言**决定网页翻译成什么语言。免费翻译服务可直接使用，无需填写密钥。

## 一键翻译

在**完整设置 → 通用设置 → 网页辅助**中，将**工具栏图标点击行为**改为**翻译 / 显示原文**。之后点击工具栏图标即可翻译当前网页，再点一次恢复原文。默认仍为打开快捷面板。

启用后，右键工具栏图标选择**打开快捷面板**，仍可调整语言、服务或进入完整设置。网页右键菜单关闭时，该入口仍保留。

网页悬浮球默认也支持点击翻译和恢复；在**翻译设置 → 悬浮球 → 点击行为**中可调整，悬停后点击设置按钮可打开快捷面板。

## 划词翻译

在扩展菜单的**划词翻译**卡片中开启开关，选中一个单词或句子，再点击附近的流畅阅读图标。卡片中可查看译文、查词或朗读，详见[划词翻译](/guide/deepseek-harness)。

## 悬浮段落翻译

把鼠标停在一段文字上，按 **Control** 翻译这一段，再按一次恢复原文。如果没有反应，在菜单的**鼠标悬停翻译**中检查**默认悬浮快捷键**是否开启，详见[悬浮段落翻译](/guide/hover-translation)。

## 常见问题

- 点击翻译后没有变化：确认扩展已开启，刷新普通网页后重试。浏览器设置页和扩展商店不允许翻译。
- 翻译服务繁忙：稍后重试，或[更换翻译服务](/config/translation-engines)。
- 更换语言或服务：先恢复原文，再重新翻译。

仍有问题时，查看[常见问题与排查](/guide/faq)。
