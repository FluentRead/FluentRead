# 快速开始

安装流畅阅读、固定扩展图标并选好目标语言，无需注册账号，3 分钟即可在原网页对照阅读原文与译文。

## 安装 {#安装}

从当前浏览器的官方扩展商店安装：

<BrowserInstall />

- **商店无法访问**：按[离线下载与安装](/guide/offline-install)获取官方 ZIP 包手动安装。
- **手机与其他环境**：支持[移动端与 Safari](/guide/mobile-safari)、[油猴脚本](/guide/userscript)、[Thunderbird](/guide/thunderbird) 与 [Zotero](/guide/zotero)。

::: tip 首次安装后请刷新页面
安装扩展前已经打开的标签页需要先刷新，才能正常注入翻译入口。浏览器内部设置页和扩展商店页面受系统保护，不允许翻译。
:::

## 固定扩展图标

在 Chrome 地址栏右侧点击拼图形状的**扩展程序**按钮，找到**流畅阅读**并点击图钉固定。固定后点击工具栏图标即可随时打开快捷菜单。

悬停工具栏图标可查看网页翻译和划词翻译的功能提示（文字随浏览器语言显示）。

## 翻译第一篇网页

1. 打开任意外语文章，例如新闻、技术文档或博客。
2. 点击工具栏中的流畅阅读图标；首次打开时先选好**界面语言**并点击**确认**。
3. 选择**目标语言**；源语言保留**自动检测**，翻译服务保留默认的**免费翻译服务**（免填密钥）。
4. 点击**翻译**按钮，译文会随滚动逐段出现在原文下方。
5. 想回到纯原文时，再次打开菜单点击**还原**即可。

<GuideVisual kind="first-translation" />

::: info 区分「界面语言」与「目标语言」
**界面语言**决定按钮与设置页文字；**目标语言**决定网页被翻译成哪种语言。默认菜单为常用控件预留了固定位置，悬停省略文字可查看完整名称；站点规则以绿点表示开启、灰点表示关闭，点击整行即可切换。
:::

## 一键翻译与快捷入口

- **点击工具栏图标直接翻译**：在**完整设置 → 通用设置 → 网页辅助**中，将**工具栏图标点击行为**改为**翻译 / 显示原文**。此后单击图标直接翻译或恢复原文，悬停图标会提示右键可打开快捷面板和菜单栏，右键图标选择**打开快捷面板**仍可切换语言、服务或进入完整设置（即使关闭网页右键菜单该入口仍保留）。
- **边缘悬浮球**：在**翻译设置 → 悬浮球**开启后，点击悬浮球即可一键翻译与恢复；悬停后点击齿轮打开当前网页快捷面板。
- **快捷键触发**：整页翻译/恢复默认 `Alt+T`（Mac 为 `Option+T`），悬浮单段默认按 `Control`，完整快捷键见[快捷键与触发方式](/guide/custom-hotkey)。

## 新手常见问题

| 现象 | 快速排查 |
| --- | --- |
| 点击翻译后无变化 | 确认总开关已开启，刷新普通 HTTP(S) 网页重试；浏览器内置页与商店页不支持翻译 |
| 提示服务繁忙或超时 | 稍后重试，或按[翻译服务指南](/config/translation-engines)切换其他免费线路 / 自有 API |
| 更换语言或服务未生效 | 先点击**还原**回到原文，再重新发起翻译 |

更多排查见[常见问题与排查](/guide/faq)。
