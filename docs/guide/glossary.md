# 术语库

为人名、产品名和专业术语指定译法，让机器翻译和 AI 翻译保持一致。术语库控制翻译用词；想收藏表达用于学习，请使用 [学习中心](/guide/vocabulary-book)。

## 网页常用术语

网页和普通文本翻译默认保留 `API`、`SDK`、`JSON`、`HTML`、`ChatGPT` 等常用技术术语的原有写法。单独的术语标签直接显示原文，句子里的术语保留在译文中。规则适用于不同网站，按完整词和大小写匹配，并把 `myAPI` 这类名称视为单独的标识符。开启术语库后，命中的自定义词条优先。

## 添加第一个词条

1. 打开 **工具与学习 → 术语库**，点击 **添加词条**；没有术语库时会自动创建。
2. 填写原文和译文，点击 **保存**。译文留空表示保留原文拼写。
3. 开启顶部总开关，再发起翻译。已翻译的网页需先恢复原文，再翻译一次。

也可添加 **内置术语库**，得到一份可编辑的副本。添加不会自动开启总开关，也不会覆盖已有修改；已有副本不会随内置词表自动更新。

内置词库包括 **AI 与机器学习、软件开发、金融与财报、学术论文、计算机硬件、网络与云计算、数学**，以及 **产品名保留原文**。领域词库适用于英语到简体中文；产品名词库不限语言。它们提供可调整的起步译法，可先预览再添加。

只想让某些单词不被翻译时，添加对应词条并将译文留空即可，无需自己再填一次原词。例如原文填写 `FluentRead`、译文留空；开启总开关后，句中其他内容照常翻译，该词保留原文。可按需要区分大小写或限定网站。

术语库设置自动保存，词条编辑需要点击 **保存**。切换术语库会保留当前页内的草稿，关闭页面前仍需保存。

## 限定适用范围

在 **术语库设置** 中修改名称、语言和网站范围。网站范围留空表示不限网站；限定网站的术语库不适用于没有网址的本地文档。文档和视频也可单独选择术语库。

多个词条重叠时，较长的短语优先；多个术语库定义同一原文时，**术语库优先级** 中靠前的优先。需要区分大小写时，在词条中开启对应选项。

## 检查匹配结果

保存词条后，点击 **匹配预览**，粘贴一段原文。查看命中的术语、译法和次数；没有命中时，检查语言、网站条件和冲突提示。

预览在本机完成，即使总开关关闭也能检查；实际翻译仍遵循总开关。固定译法可能影响周围语句的自然度，适合用于名称和稳定术语。关闭术语库后，流畅阅读仍会保护原文中的表情符号。服务未完整保留受保护内容时，请重试或换用其他服务。

## 导入、导出与备份

点击 **导入术语库**，先选择 **选择文件** 或 **粘贴内容**。文件支持 CSV、TSV、JSON；展开 **文件格式** 可调整格式。预览先展示三条词条和导入数量，更多内容可展开 **查看全部词条**；检查提示后点击 **确认导入**。切换导入方式会保留各自的草稿；保存失败时，提示会显示在弹窗内，输入保留供重试。导入会新建术语库，不替换已有内容。文件支持 UTF-8、带 BOM 的 UTF-16 和常见 GB18030 编码。

在 **术语库设置** 中导出：JSON 保留完整设置，CSV、TSV 便于用表格编辑。配置备份也包含术语库。

## 数据会怎么用？

编辑和匹配在本机完成。翻译时发送受术语保护的原文和必要指令，不发送整本术语库。周围文字、已允许的页面上下文和自定义请求内容仍可能发送给所选服务，术语保护不等于完整匿名化。
