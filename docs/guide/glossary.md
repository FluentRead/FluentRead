# 术语库

术语库让你指定专业词汇的译法，并在翻译中保持一致。它与单词本不同：单词本用于收藏和复习，术语库用于影响实际译文。

## 开始使用

1. 打开设置 → 工具与学习 → 术语库，开启“启用术语库”。
2. 在“内置词库”中预览并添加所需主题，或点击“新建术语库”建立自己的词库。
3. 按需编辑原词和译词。例如 `large language model` → `大语言模型`；译词留空表示保留原文。
4. 按需选择目标语言与适用网站。在“匹配预览”中输入原文，检查哪些译法会生效。

更改自动保存在当前浏览器，名称和网站范围在离开输入框时保存。保存失败时界面会显示提示并回读已保存的数据；保存期间继续输入的内容会保留，请检查后重试。启用或修改词库后，下一次翻译使用新规则；已经显示的译文需要恢复原文后再次翻译。

## 内置词库

扩展离线内嵌 5 套、共 240 条起步词条，无需注册或下载。默认不添加、不启用，按阅读领域选择即可。

| 词库 | 词条 | 语言与示例 |
| --- | ---: | --- |
| AI 与机器学习 | 60 | 英语 → 简体中文；`context window` → `上下文窗口` |
| 软件开发 | 60 | 英语 → 简体中文；`race condition` → `竞态条件` |
| 金融与财报 | 50 | 英语 → 简体中文；`free cash flow` → `自由现金流` |
| 学术论文 | 40 | 英语 → 简体中文；`confidence interval` → `置信区间` |
| 产品名保留原文 | 30 | 所有语言；`GitHub`、`FluentRead` 等保持原文，区分大小写 |

“预览”支持搜索完整原始词表；“添加词库”会在“我的术语库”中建立可编辑副本，不会改变顶部总开关。添加后可修改译法、删除词条、限制网站或在文档/字幕/快捷方案中指定使用。主题名不会自动判断网页属于哪个领域，建议只启用当前需要的词库。英中词库不会把简体译法应用到繁体中文或其他目标语言。

重命名或停用不会导致重复添加。已添加的词库显示“查看我的词库”；内置版本更新不会覆盖你的修改。删除副本后可以重新添加当时扩展内嵌的原始版本；自定义修改需从事先导出的备份恢复。来源与版本信息随配置备份和词库 JSON 保留，CSV/TSV 不保留来源标记，因此重新导入 CSV/TSV 会被视为普通自定义词库。

本批词条由 FluentRead 独立整理，按项目许可证分发，不是从第三方词库复制的数据，也不是专业标准词典。可以根据上下文修改首选译法。引入第三方词表前需逐项确认授权。

## 哪些服务支持？

支持提示词的 AI 翻译服务会在请求中收到实际命中的术语约束；通义 `qwen-mt` 模型使用原生术语参数。模型仍可能不完全遵守约束，匹配预览只证明词条将被采用，不承诺模型输出一定相同。

Microsoft、Google、DeepL、DeepLX、Chrome 内置翻译等机器翻译暂不应用术语库。切换到支持术语的 AI 服务后，保存的词库继续可用。

腾讯混元翻译的专用接口也暂不应用术语库；这不影响支持提示词的腾讯混元通用模型。高级用户如果在自定义请求体中覆盖 `messages` 或 `translation_options`，可能覆盖自动加入的术语约束；请移除相应覆盖字段后再检查效果。

## 语言、网站和选择范围

- 词库的源语言、目标语言留空表示不限。已指定源语言时按语言筛选；自动检测源语言时按实际原词匹配，不额外识别同形异义词。例如英语和法语都有 `chat`，自动模式下按词库顺序取译法，需要区分时应明确选择语言或词库。
- 网站范围留空表示全局。`example.com` 包含本域与子域；`*.example.com` 仅匹配子域。每行一个域名，不填写 `https://`、路径或端口。
- 没有网页网址的本地文档，不会匹配限定网站的词库；用于文档的词库可保留全局网站范围。
- 快捷翻译方案、文档和字幕可以跟随全局词库、指定词库或完全不使用。指定词库仍需满足词库开关、语言和网站范围；总开关关闭时所有翻译都不应用术语。

词条采用字面匹配，不执行正则表达式。默认忽略大小写，可对产品名称等词条开启“区分大小写”。英文等词语会检查词边界，避免 `AI` 命中其他单词内部；中文等连续文字按实际字符匹配。

## 多个译法与优先级

同一原词在多个适用词库中有不同译法时，优先使用列表中靠前的词库；同库内优先使用靠前的词条。可以用上下箭头调整词库顺序。较长词组会优先提供给翻译模型。

匹配预览会列出命中词对，并显示冲突中采用和忽略的译法。建议用更明确的词组、网站范围或独立方案减少冲突。术语库名称仅用于管理，不会让 AI 自动推断词库语境。

## 导入、导出与备份

支持本地文件或粘贴 CSV、TSV、JSON。每次导入会新增词库，不覆盖已有数据；确认前可查看所有识别出的词条。格式错误、非法范围或超出容量会阻止导入；涉及清理、重复或多语言分组的提示需要检查并确认。

CSV/TSV 支持 `source`、`target` 表头及对应中文列名。可选 `tgt_lng`（目标语言）、`src_lng`（源语言）、`caseSensitive`（`true` 或 `false`）。支持 `source,target,tgt_lng` 格式，多语言内容会按语言分成词库。

```csv
source,target,tgt_lng,caseSensitive
large language model,大语言模型,zh-Hans,false
FluentRead,,zh-Hans,true
```

CSV 的引号、逗号和多行内容会按表格格式解析。JSON 导出保留词库设置；CSV/TSV 适合表格编辑，并保留语言与大小写选项，网站范围和启停等管理信息请用 JSON 保存。下载格式可在当前词库的“导出格式”中选择。

最多 20 个词库、每库 500 条、合计 5000 条；文件上限 2 MB。术语库也包含在 FluentRead 的配置备份中，可通过“备份与恢复”迁移。导出文件可能包含个人或业务术语，分享前请检查。

## 数据与隐私

编辑、导入和匹配预览在本地运行。实际翻译只发送当前文本命中的原词与译词，不附加整份词库、词库名称或未命中的词条；接收方是你选择的翻译服务。详见[数据与隐私](/guide/privacy)。
