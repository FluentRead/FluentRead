# 悬浮段落翻译

把鼠标停在段落上，按 **Control**，即可在原文下方查看译文。再次按下可恢复原文。

<GuideVisual kind="hover" />

## 翻译一个段落

1. 在扩展菜单中打开**鼠标悬停翻译**，确认**默认悬浮快捷键**已开启。
2. 把鼠标停在正文段落上，按 **Control**。
3. 按住快捷键移动鼠标，可以接着翻译其他段落。松开按键后，已有译文仍会保留。

在输入框、可编辑区域中打字或使用输入法组词时，悬浮快捷键会让行，包括波浪号键；即使鼠标停在正文上，也不会拦截输入。焦点变化或开始组词会取消尚未执行的悬浮翻译，离开编辑区后可重新按快捷键使用。需要更换按键或调整触发延迟，见[快捷键与触发方式](/guide/custom-hotkey)。延迟从鼠标进入段落时开始计时；在同一段内移动不会重新等待，设为 0 则立即触发。

## 翻译失败或没有开始

点击段落旁的错误提示可重试，也可以聚焦提示后按 **Enter**。连续移动鼠标不会反复重试同一个失败段落。

切到后台、跳转页面或滚动时，尚未开始的翻译会取消。返回后重新移动鼠标并按快捷键即可继续。

<details class="guide-details">
<summary>段落复制与触发设置</summary>

按 **Alt+C**（Mac 为 Option+C）可复制鼠标所指段落。默认按当前显示方式复制：已翻译时跟随双语或仅译文显示，未翻译时复制原文。

在**设置 → 翻译设置 → 段落复制**中可更换快捷键和复制内容。

</details>
