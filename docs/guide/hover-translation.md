# 悬浮段落翻译

将鼠标停在段落上，按 **Control** 即可翻译当前段落。

<GuideVisual kind="hover" />

## 翻译一个段落

1. 点击扩展菜单中的 **鼠标悬停翻译** 卡片并确认 **默认悬浮快捷键** 已开启。
2. 把鼠标停在想读的段落上，按 **Control**。
3. 原文下方出现译文；再次按下可恢复。输入框和可编辑区域不触发。

按住快捷键并移动鼠标可连续翻译；移回已经翻译的段落会保留译文，松开后再次按键才切换原文。悬浮延迟用于减少移动途中的误触，设为 0 时无需停留等待。

切换页面、章节或标签页会取消尚在等待的悬浮手势。返回后重新移动鼠标并按快捷键即可继续；旧按键状态不会在新页面发起翻译。默认快捷键和额外悬浮方案采用相同规则。

<details class="guide-details">
<summary>段落复制与触发设置</summary>

将鼠标停在需要翻译的段落上并按下 **Control** 即可翻译。鼠标位于输入框或可编辑区域时，不会触发悬浮翻译。不必拖动选择，也不必翻译整页。快捷键和触发方式都能修改，详见[快捷键与触发方式](/guide/custom-hotkey)。

也可以复制鼠标所指段落的文字：按 **Alt+C** 把鼠标所指段落复制到剪贴板，段落已翻译时默认按当前显示形态复制原文和译文。开关、快捷键和复制内容在 **设置 → 翻译设置 → 段落复制** 中调整。

</details>
