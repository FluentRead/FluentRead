# 图片翻译

FluentRead 在浏览器本地识别图片文字，再使用当前翻译服务生成译文，并在原图上显示译图。网页图片的地址、链接和排版保持原样。

## 如何使用

1. 在弹窗的「图片翻译」或完整设置中启用图片翻译。
2. 将鼠标移到网页图片上，点击左下角的半透明 FluentRead 图标，或右键图片选择「翻译图片／还原图片」。
3. 首次缺少识别语言时，图片中央会显示准备提示，点击卡片内的「下载语言包并翻译」，准备完成后自动继续当前图片；也可以提前在设置中下载语言包。
4. 图片中央会显示轻量加载状态，依次提示读取、识别、翻译和生成译图；识别阶段显示 OCR 引擎返回的实际百分比。处理中点击「取消」即可退出当前图片任务。
5. 完成后点击「原图」恢复，点击「翻译」再次显示译图；点击「文字」查看、选择和复制完整译文。

已开始下载的共享语言包会继续缓存在本地；取消图片任务后不会自动翻译或覆盖图片。缺少模型或翻译失败时，提示会保留，方便下载、重试或关闭；普通悬浮入口会在移开鼠标后收起。

在「设置 → 图片翻译 → 操作入口」中，「图片悬浮按钮」和「图片右键菜单」默认都开启，可分别关闭并自动保存。关闭悬浮按钮后，仍可通过右键翻译；关闭右键菜单不影响悬浮按钮。图片翻译总开关控制两个入口，右键全文翻译开关不影响图片菜单。手动开始翻译后仍会显示进度、取消和重试操作。

## 语言与翻译服务

- 源语言为 English 时只需英语包；简体中文使用简体与英语组合，繁体中文使用繁体与英语组合；日本語使用日英组合；西班牙语使用西班牙语与英语组合。
- 「下载推荐语言」一次准备简体、繁体、英语和日语四个语言包，自动检测也使用这四种语言。已经下载的语言包会复用，只补齐缺少的包；西班牙语图片请先选择西班牙语并下载 Español。
- 翻译使用当前选中的服务和目标语言。重复文字只请求一次；不支持批量请求的服务最多同时处理三段，仍遵循共享翻译限流。
- 识别结果和近期译图只在当前运行环境内有界缓存。恢复原图后可快速重显；换图、修改翻译配置或移除图片时旧结果不会覆盖新图。

## 图片与识别质量

清晰截图、横排印刷文字通常更适合识别。竖排漫画、艺术字体、模糊照片和复杂表格仍需核对人名、数字及专有名词。OCR 会过滤低置信度噪声，并限制大图识别尺寸；译文根据原文字区域自动换行和调整字号，不截断为固定三行。过长译文可能较小，可通过「文字」阅读完整内容。

图片不能读取、过大或识别结果为空时会显示具体原因。可尝试清晰原图或使用[圈选翻译](/guide/area-translation)处理局部。页面允许 CORS 时会在页面权限内重读图片；不允许读取的跨域来源仍受浏览器及扩展的安全边界限制。

文字背景采用局部像素修补，复杂纹理可能留下痕迹。原图始终保留，可随时恢复。OCR 在本地执行；识别出的文字会按当前翻译服务的请求规则发送，图片像素不会作为文本翻译请求上传。

网页用透明图片节点配合背景层显示图片时（例如 X），入口、进度和译图会跟随实际显示的图片区域；还原时恢复背景层原有样式。

悬浮图标、操作提示与语言准备卡片使用 FluentRead 标识，提示文字跟随界面语言；将鼠标移到图标上或使用键盘聚焦时会提高对比度。整页滚动和局部容器裁切后，操作入口与进度仍跟随图片的可见区域。
