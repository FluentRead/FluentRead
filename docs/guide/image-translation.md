# 图片翻译

图片翻译识别网页图片中的文字，并在原图上显示译文。将鼠标移到图片上，点击 FluentRead 图标即可开始。

## 翻译一张图片

1. 确认 **图片翻译** 已开启，鼠标移到图片上，点击左下角的图标；也可以右键选择翻译图片。
2. 第一次使用某种语言时，按提示点击 **下载语言包并翻译**。
3. 等待识别与翻译完成。想中途退出，点击 **取消**。
4. 完成后切换 **原图 / 翻译** 对照，也可以点击 **文字** 复制完整译文。

取消翻译不会删除已下载的语言包。下一张同语言图片可以继续使用。

## 源语言设置

图片中的原语言应与语言包匹配。自动检测默认准备简体中文、繁体中文、英文和日文；其他支持的语言需要先明确选择原语言，再下载对应语言包。

翻译服务与目标语言沿用当前设置。悬浮图标和右键入口可以在图片翻译设置中分别关闭。

## 太小、太糊，怎么办？

优先打开清晰原图。竖排文字、艺术字、复杂背景和表格更容易识别出错，注意核对人名、数字和单位。

译文太长时，在图片里可能显示得较小，点击 **文字** 看完整结果。背景修补可能留下痕迹，原图始终可以恢复。

只想看图里的一小块，试试[圈选翻译](/guide/area-translation)。无法读取的图片或受限制的页面可能不能处理。

## 图片会发送出去吗？

文字识别在浏览器本地完成，识别出的文字交给所选翻译服务。图片像素不会作为文本翻译请求上传。语言包首次下载需要网络，详见[数据与隐私](/guide/privacy)。
