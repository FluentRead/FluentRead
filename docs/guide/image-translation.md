# 图片与漫画翻译

在浏览器本地识别图片与漫画中的文字，自动修补背景并在原图上排版显示译文；同时提供文字面板，方便核对原文与一键复制。

## 翻译单张图片

1. 打开**设置 → 图片/漫画翻译**，开启**网页图片翻译**，确认源语言、目标语言与图片专用翻译服务。
2. 将鼠标停在网页图片上约 0.6 秒，点击左下角翻译图标（或右键图片选择**翻译图片**）。
3. 首次使用按提示准备本地识别资源；完成后可随时切换**原图 / 翻译**，或点击**文字 → 原文对照**阅读和复制完整译文。

### 实用交互

- **大图直接复用**：点击已翻译图片进入网页大图查看器时，若打开的是同一张图，直接复用已有译图，无需再次识别或翻译。
- **随时取消与对照**：处理中点击**取消**仍保留已下载模型；图片较小或译文较长时，打开文字面板阅读更清晰。在文字面板按 `Esc` 关闭并返回原入口。
- **动图与原图恢复**：动图会生成静态译图，切回**原图**即可继续观看动画；任何时候原图都可无损恢复。

## 漫画连续翻译

1. 在同一设置页开启**漫画连续翻译**，打开支持的漫画阅读页，例如 **MANGA Plus**、**Pixiv** 或局域网/本机自建阅读器（支持带端口的 `localhost` 与私有网段自定义规则）。
2. 点击页面上的漫画按钮；缺少资源时先确认**准备资源并开始**（点稍后或关闭不会触发下载）。
3. 当前可见页优先翻译，继续滚动即可自动连续翻译后续页面：
   - **实时进度指示**：漫画入口与悬浮球会实时显示已完成页数、预译进度和失败数量。
   - **快速对照原图**：按住入口旁的**按住对照原图**可临时查看原图且不中断后台预译；悬停在已翻译单页左下角可切换**原图 / 重新翻译**；再次点击漫画按钮则暂停整章并显示原图。
   - **预译页数控制**：默认提前处理网站已加载的后续 **3 张**图片（可在设置中调为 **0–5 张**，`0` 表示仅翻译可见页）。

### 查看漫画文字面板

展开漫画按钮旁的**查看漫画文字**，可阅读、搜索和复制当前可见页面或长图片段的完整译文：

- 仅存在单个可见候选时自动展开，支持页内搜索、上下页切换与单条复制；图片、画布和背景图混排时按页面顺序排列。
- 面板仅读取已有结果，不会重新触发识别或翻译。
- 若部分译文因保护原文/数值而未直接绘在图上，面板会显示**未绘制译文**徽标与数量，点击即可单独筛选阅读；**复制当前部分**仅复制当前筛选，**复制全文**复制该页全部文字。

::: tip 支持站点与圈选漫画
在**支持的网站**中可搜索名称或域名并查看入口类型：部分站点支持连续翻译，部分站点提供**圈选漫画翻译**（需启用圈选后拖选可见区域）。未收录站点可尝试单图翻译或[圈选翻译](/guide/area-translation)。
:::

## 识别引擎与本机后端

| 组件 / 选项 | 体积与说明 | 适用场景 |
| --- | --- | --- |
| **PaddleOCR（默认标准模型）** | 约 **30 MB**，单图与漫画共用 | 绝大多数横排、漫画气泡与高对比彩字识别 |
| **Tesseract（轻量模型）** | 按语种按需下载语言包 | 明确指定**俄语、韩语、阿拉伯语或希伯来语**时单图自动切换使用，也支持日文横竖排 |
| **LaMa 背景修补模型** | 约 **197 MB**（仅漫画复杂底图加载） | 漫画网点、渐变与复杂插画背景擦字；单图模式不额外加载 |
| **本地处理后端（自动 / CPU WASM）** | 默认**自动**（按算子调度 WebGPU / WASM） | 浏览器卡顿时切至 **CPU（WASM）** 跳过 WebGPU；可在**识别资源 → 运行信息**查看当前后端 |

## 图片会发送出去吗？

**不会。** 文字识别（OCR）与背景修补全部在你的本机浏览器完成，只有识别出来的文字会被发送给你选择的翻译服务；原始图片像素不会随文本翻译请求上传。首次准备识别模型需要联网下载资源文件，详见[隐私政策](/guide/privacy)。

## 常见问题与排查

| 现象 | 处理建议 |
| --- | --- |
| 图片上没有翻译图标 | 头像、小图标、表情与视频封面默认跳过；可尝试右键翻译、打开清晰原图或使用[圈选翻译](/guide/area-translation) |
| 识别不准或漏字 | 确认源语言设置正确，优先打开清晰原图；小字、艺术字和复杂表格易误识别，请对照原图或文字面板核对 |
| 漫画单页失败 | 失败页自动保留原图，不影响其余页面；切回原图再开启或悬停该页点击**重新翻译** |
| 本地模型失败 | 按提示点击**调整本地模型**或**切换图片翻译服务**，不会在未确认时悄悄把本地任务改发在线服务 |
| 扩展更新后无响应 | 刷新当前网页后重试 |

<details class="guide-details">
<summary>排版、原文保护、背景修补与识别优化细节</summary>

### 原文保护与安全补绘

- 已识别且保持不变的品牌名、目标语言文字、独立时间/日期/金额/百分数等数值，以及漫画透明镂空区域均会受到保护；若绘字会覆盖受保护内容，自动保留原图并在文字面板提供完整译文。
- 横排漫画发生原文冲突时，会复用本次结果在同一封闭气泡的纯白空处补绘完整译文（不低于原文字号），不重复识别或翻译。

### 字体、换行与排版均衡

- 优先调用设备字体并按目标语言选择对应字形；设备缺失部分扩展汉字时，自动使用内置字体补绘（含 305 个扩展汉字与 485 条异体字映射，覆盖 JIS X 0213 增补汉字）。
- 自动避开句末标点孤行、保留完整词语与组合字符/表情、按实际字形边界避免描边和附标裁切；短对白自动均衡末行行宽；阿拉伯语/希伯来语按段落自身 RTL 方向排版。
- 日文正文上方或右侧的清晰小字注音（Furigana）会随正文合并归组，避免拆成孤立译文；倾斜横排拍照文字在角度可确认时跟随原倾角排版；旋转 90° 的书脊/栏侧短标签在可确认时沿原方向放回。

### 背景擦除与修补策略

- 纯色与平滑渐变背景优先恢复原底色与原文字色，减少模型修补色差；细线纸面、斜边与纯色小装饰在原图证据充分时保留背景特征。
- 纯色底原字笔画超出擦除框时，已导入可选文字分割模型会清理完整笔画；导入后只需切回原图重译即可应用。复杂纹理或半透明底图仍可能有修补痕迹，可随时切回原图核对。

### 识别、空格修复与上下文

- 自动增强浅底彩字与深底亮字对比度，结合字形空隙补回英文紧裁文字漏掉的词间空格（如 `ROUTEC4` → `ROUTE C4`），减少将高光或纹理误判为文字。
- 居中相邻小字、同纸面相邻横排文字按字形间距智能合段，明显字号/色差标题保持独立。
- 开启**AI 上下文**并选用支持提示词的 AI 服务时，每个文字区域参考同图前后各两段原文（不额外生成摘要）；Google 原生合批模式允许最多四条同栏句子共享语境。
- 网页中带旋转、缩放、镜像或透视变换的图片会沿用页面原生变换；无法安全定位覆盖层的特殊布局自动保留原图并提示在文字面板查看。

<summary>漫画资源下载、离线导入与缓存管理</summary>

### 漫画资源下载

在**图片/漫画翻译 → 识别资源**可查看下载状态、清理资源或离线导入匹配校验值的模型文件（仅存本机）。下载中断会自动重试并保留完整文件，仅补齐缺失项；清理模型不影响翻译配置。

模型齐全后，识别与背景修补可完全离线运行（文本翻译仍取决于所选服务）。附近已完成页优先复用缓存；切换标签页暂停启动新任务，切回后继续。连续漫画依赖扩展本地模型，油猴版能力有限。

</details>

<details class="guide-details">
<summary>源语言与 Tesseract 语言包</summary>

### 源语言设置

源语言和目标语言与网页、圈选翻译共用；图片与漫画共用图片翻译服务。Tesseract 在**自动检测**下默认准备简中、繁中、英文与日文语言包；其他语种需先明确指定源语言再下载。离开设置页不会中断后台下载。

</details>

<details class="guide-details">
<summary>跨域图片与受限图片说明</summary>

### 跨域图片

公开 HTTPS 图片通常可直接处理；网页受跨域限制无法直接读取时，扩展会核对当前图片并以不带登录凭据的方式读取（Pixiv 仅临时附加所需站点来源，不发送 Cookie）。需登录、内网、超过 **16 MiB** 或服务器拒绝的图片会提示具体原因，建议改用[圈选翻译](/guide/area-translation)。

</details>
