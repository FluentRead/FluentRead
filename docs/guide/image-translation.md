# 图片翻译

识别网页图片中的文字，在原图上阅读译文，也可以打开文字面板对照、复制。

<GuideVisual kind="image" />


已识别且保持不变的品牌名、目标语言文字或缺译原文也参与保护。相邻译文的清字或绘字范围会影响这些原文时，保留对应原文，并在文字面板提供未绘制的译文；若整张普通图片都不适合绘制，继续显示网页原图。此保护不覆盖未识别的文字或未知画面。

横排漫画段落发生原文冲突时，可在同一封闭气泡的纯白空处补绘完整译文，保留原文和图案，字号不低于识别到的原文字号。超长图片分段只补绘能完整显示的段落；空间不足、跨过分段边界或位置无法确认时，继续在文字面板提供完整译文。这个补绘过程复用本次结果，不重新识别、翻译或下载模型。

## 翻译一张图片

1. 打开 **设置 → 图片/漫画翻译**，开启 **网页图片翻译**，确认原语言、目标语言和翻译服务。
2. 鼠标停在图片上约 0.6 秒，点击左下角翻译图标；也可以右键选择翻译图片。
3. 首次使用按提示准备识别资源。完成后切换 **原图 / 翻译**，或点击 **文字 → 原文对照** 核对识别结果、阅读完整译文并复制。

点击已翻译的图片放大时，如果网页查看器打开的是同一张图，大图会直接显示已有译图，无需再次识别或翻译。

处理中可点击 **取消**，下载好的资源会保留。译文太长、图片太小时，文字面板更便于阅读。鼠标离开后操作条会收起，回到图片即可再次使用。

在文字面板内按 **Escape** 可关闭并返回可用入口；焦点已移到网页其他位置时不会抢回。复制提示只对应当前展示和最新操作；复制失败时可选中文字手动复制。

已识别的韩文分解字母、扩展汉字及其变体选择符会保留原始文字形式。排版避免拆开组合字符和表情；较旧浏览器中的复杂连续词仍可能需要缩小字号，可在文字面板阅读。

普通图片自动换行时，句末标点和闭括号尽量随前字，开括号随后文，避免句号单独占一行；日文小假名和长音也保持连贯。原文或译文中明确指定的换行仍会保留。

短段落的末行明显过短时，会适当均衡行宽，保留当前字号、行数和完整单词，让对白与短说明更便于阅读。

普通图片按设备实际字体的字形边界安排译文，减少变音符号和上下伸展笔画被裁切。Tesseract 竖排合段保留每列的清字范围，避免擦掉列间图案；不透明文字区域的完整边界确认为平滑渐变时，普通图片和漫画都会延续渐变底色修补。复杂纹理或半透明背景仍可能留下修补痕迹，建议切回原图核对。

横排文字会优先结合原图中可确认的逐行字形宽高估计字号，并在已有区域内对齐译文，减少识别框留白导致的放大。复杂字体、背景和透视仍可能影响效果；字号估计不代表能准确恢复原图的字体族或装饰样式。

拍照图片中的轻微倾斜横排文字，在方向和字号都能确认时，译文会跟随原字的倾角与位置；行数相同时还会参考原行距。旋转后的完整字形须放进原区域，信息不足时沿用原布局。强透视、弯曲文字和复杂纹理仍可能无法准确还原。

纯色背景上，能够确认且对比清晰的原文字色会尽量保留。单行横排文字周围确认为连续同色空白时，可适当增加绘字高度，让译文更接近原字号；邻近文字、图案和透明边界会限制这项扩展。复杂背景或颜色关系不明确时，仍使用清晰的深色或白色文字。

能够确认同一字色的平滑渐变区域也会保留原色，并加上较细的对比描边，减少白色或彩色标题被统一改成黑字的情况。无法确认的混色或纹理仍沿用原有处理。

漫画译文按整段文字自身的方向排版，阿拉伯语、希伯来语中的数字、括号和标点随正文处理，减少被画布默认方向打乱的情况。

漫画自动换行会尽量保留完整词语和字素，减少“看懂”被拆到两行的情况。词界依赖浏览器的语言处理能力，真正过长的词仍会按完整字素适配。

日文正文上方或右侧的小字注音，在大小、位置和归属明确时随正文一起处理，避免将读音另翻译成一块译文。正文和注音分别保留原始清字框，注音周围的清字余量按自身大小保留；归属不明确、独立的小字或已合并的识别区域仍保持原有处理方式。

大型曲边气泡上方的注音也会核对与正文的关系：只有底色可信、正文归属唯一且小字不属于其他气泡或独立卡片时，才随正文归组。

逐段翻译时会提供同图相邻文字作为有限参考，帮助支持上下文的服务理解短标签和句子；批量翻译继续一起处理原有段落。译图会跟随网页原图的形状裁切和像素缩放设置。

部分带编号的全大写多词说明会交给当前翻译服务处理，减少被当成型号而整段漏译的情况。原文和编号保持完整；服务原样返回的名称仍保留在原图中。

使用支持提示词的 AI 服务（或包含此类成员的组合）并开启 **AI 上下文** 时，每个文字区域会参考同图前后各两段识别原文，不额外生成摘要。相同短句出现在不同位置时会分别结合邻文翻译，改变邻文后不会沿用另一种语境的缓存；关闭该开关后沿用原有翻译方式。上下文能帮助消歧，但识别错误和模型误译仍需对照原图核查。

Google 开启原生合批时，图片中的完整句子会结合最多四条相邻原文翻译，标题保持独立。系统会检查文字框编号和句末语气，出现缺句、串位或把独立句子接成逗号连句时自动回退；相同短句也保留各自位置和整组语境缓存。这个过程只提交本次识别出的文字，不上传原图，仍需对照原图判断具体词义。

网页中的普通旋转、缩放、镜像和透视图片会沿用页面的原生变换，调整样式不需要重新识别和翻译。无法确认覆盖位置或共用祖先裁切的特殊布局（例如同时固定定位并旋转，或旋转图片位于不承担定位的溢出裁切容器内）会保留原图，提示通过文字面板查看译文；布局恢复后可直接显示已有译图。

居中的相邻小字会结合原图中的空白和渐变判断续行，减少一句话被拆成几段翻译；可靠的空格修正仍保留原有位置关系。跨栏、其他文字或图案阻挡时继续分别处理。

纯色底的小字、带轻微灰度变化的白底黑字在缩放后，可能把英文单词和编号连成一串。模型和原字形间隙都支持时，会补回缺失的空格，例如把 `ROUTEC4` 识别为 `ROUTE C4`，或把 `ISAVED` 识别为 `I SAVED`；原字符与位置保持不变。

图片翻译也会结合文字检测与识别结果，减少把高光、纹理和装饰线条当作文字翻译。

部分被背景干扰而漏掉的横排文字会进一步识别。复杂透视、很小或较淡的文字仍可能遗漏，建议核对原图。

连续渐变背景上的两行，如果字号和可确认的字色都有明显差异，会保留各自文字区域，减少大标题与副标题被合并成同一种样式。同图上下文仍按原有服务和设置提供参考。

同一背景上的独立标签会结合实际字形间距保持分开，减少识别框留白过多时把不同提示合成一段。

漫画中，相邻渐变标题有明确共同左边线或右边线时，单行译文会尽量沿用该边线，避免短译文被分别居中而打乱层次。居中、换行、透明避让或字形无法完整放下时，继续沿用原排版。

图片翻译默认使用 **PaddleOCR（标准模型）**，首次翻译准备约 **30 MB** 资源，与漫画共用。也可选择 **Tesseract（轻量模型）**，按原文语言准备语言包。切换识别方式后，下次翻译会重新识别；选择方式本身不会开始下载。

**本地处理后端** 默认选择 **自动**。若浏览器在处理图片时卡顿，可选择 **CPU（WASM）**：后续 PaddleOCR、LaMa 和已导入的可选文字分割从首次初始化就跳过 WebGPU，使用单线程 WASM 和 CPU 超时预算。切换不会下载模型，正在执行的推理会先完成或超时，再在任务边界重建 Worker；取消仍可立即结束页面等待。此选项不改变 Tesseract 的识别方式。

在 **识别资源 → 运行信息** 可查看当前处理阶段及最近成功初始化会话的执行后端。`wasm` 表示该会话仅配置 CPU；`webgpu / wasm` 表示 ONNX Runtime 可以按算子分配到两个后端，不代表全部算子都在 GPU 上运行。自动模式失败时会显示 CPU 回退信息。

PaddleOCR 会为部分浅底彩字和深底亮字自动增强识别对比，无需额外下载模型。很浅的细字和复杂背景仍可能漏识别，可在原图或文字面板中核对。

## 漫画连续翻译

1. 在同一设置页开启 **漫画连续翻译**，进入支持的漫画阅读页，例如 MANGA Plus 或 Pixiv 的作品阅读器。
2. 点击页面上的漫画按钮。缺少资源时，先确认 **准备资源并开始**；选择稍后或关闭说明不会下载。
3. 当前可见页优先翻译，继续滚动即可翻译新页面。再次点击漫画按钮显示原图并暂停，再点恢复。

开启后，展开漫画按钮旁的 **查看漫画文字**，选择当前可见的页面或长图片段，即可阅读、对照和复制已完成的文字；再次点击该入口可关闭。图片、画布和背景图混用时按网页内容顺序列出。列表序号表示当前可见候选顺序，不是章节页码。

文字面板只读取已有结果，不会为了打开面板重新识别或翻译。页面仍在处理、结果已释放或内容过大时会提示暂不可用；可返回漫画页面后手动重新查看。长图片段可能包含相邻片段的文字；画布文字来自最近完成的翻译快照，后续画面变化可能尚未同步。

已有译文因保护原文而未绘制时，面板显示 **未绘制译文** 和数量。点击可直接阅读这些完整译文，再次点击返回原顺序的全文；切换只复用当前快照，不重新识别或翻译。**复制当前部分** 复制当前筛选页，筛选时的 **复制全文** 仍复制所选图片或片段的全部文字，包括筛选隐藏的条目。原图对应位置仍保留原文（例如英文），该入口不会重新擦字或绘图，也不代表已修复 OCR 漏识别。

默认提前处理网站已加载的后续 **3 张图片**，可在设置中改为 **0–5 张**；0 只处理可见页。提前页越多，设备处理量和翻译请求越多。流畅阅读不会主动加载整章或下一章。

失败页保留原图，其他页继续；切回原图再开启可重试。切换章节、离开页面或关闭漫画功能会停止旧任务。普通图片开关和悬浮球开关不会关闭漫画功能；独立入口可在 **独立漫画按钮** 中调整。

漫画和普通图片中，独立识别且符合支持格式的时间、日期、金额、百分数等数值保留原文，不单独发送给翻译服务或重绘。附近译文可能覆盖这些数值且没有安全位置可绘制时，该译文只在文字面板中显示，并提示未绘制。保护取决于识别结果及格式：未识别、识别错误、某些低置信结果或与文字混在同一行的数值可能无法保护，请对照原图核对。数值区域的坐标无法可靠对应时，处理会报错并保留原图。

漫画中的透明镂空在能确认其背景透明度时会受到保护，译文在原文字框内绕开镂空，尽量保留字号和完整词语。可用空间不足时字号仍可能变小，可打开文字面板阅读完整译文；透明图案过于复杂或遮满排字区域时，这一页保留原图并提示失败。

在 **支持的网站** 中搜索名称或域名，并查看入口类型：有些阅读器支持连续翻译，有些只提供 **圈选漫画翻译**，需要启用圈选后拖选可见区域。清单登记不代表所有章节都已验证；登录、付费或受保护内容仍取决于网站能否正常显示。其他网站可尝试单图或[圈选翻译](/guide/area-translation)。

### 漫画资源下载

漫画通常使用本地 PaddleOCR，复杂背景还会用 LaMa 修补原字。识别模型约 **30 MB**，修补模型约 **197 MB**；单图选择 PaddleOCR 不会额外加载漫画修补模型。俄文或韩文漫画请明确选择原语言，以使用对应语言包；自动检测的漫画模型不包含这两种文字。

在 **图片/漫画翻译 → 识别资源** 查看下载状态，展开下载与管理选项可清理资源或导入已有文件。连接或校验失败会自动重试；完整文件会保留，只补齐缺失项，未下载完整的单个文件需要重下。导入文件需匹配要求的名称、容量和校验值，仅保存在本机。

模型齐全后，文字识别和背景修补可离线运行；文字翻译仍取决于所选服务。清理模型不会删除翻译设置或其他语言包。

附近已完成页面会尽量复用缓存，远处页面或缓存被释放后可能重新处理。修改图片、语言、服务或识别方式后不复用旧结果。切走标签页会暂停启动新页面任务，回来后继续；复杂图片和首次准备仍可能需要等待。

小字、艺术字、人名、倾斜文字和背景修补都可能有误，随时切回原图核对。连续漫画使用浏览器扩展的本地模型，油猴版能力有限。

</details>

## 没有入口或翻译失败

- **没有图标**：头像、图标、表情、视频封面和小图通常跳过。尝试右键翻译，或打开清晰原图；被查看器或菜单遮挡的图片会暂时隐藏入口。
- **识别不准**：确认原语言，优先使用清晰原图。复杂表格、艺术字和日文以外的竖排文字较易出错，请核对人名、数字与单位。
- **识别失败**：按提示重试。漫画失败页会保留原图，切回原图再开启可重试。
- **翻译失败**：按提示重试，或调整图片专用翻译服务。扩展更新或重新加载后，先刷新网页。
- **本地模型失败**：点击 **调整本地模型** 检查模型和语言方向，或点击 **切换图片翻译服务**。修改后返回图片重试，不会自动把本地任务改送在线服务。

不需要翻译的部分数字、网址和版本号等内容会保留；只识别到这些内容时，仍可在文字面板查看和复制。动图生成静态译图，切回原图即可继续看动画。背景修补可能留下痕迹，原图始终可恢复。

## 源语言设置

原语言和目标语言与网页、圈选翻译共用；图片和漫画共用此处选择的翻译服务。设置页的固定示例只预览效果，不识别图片或发送翻译请求。

Tesseract 的 **自动检测** 默认准备简体中文、繁体中文、英文和日文。其他语言需先明确选择原语言，再下载对应包；纯英文图片选择 English 可减少等待。日文同时支持横排和竖排。

下载按语言包分别显示进度。离开设置页不会中断下载，部分失败时保留已完成项，只需重试缺失项。移除的语言包下次使用需重新下载。

</details>

<summary>跨域图片</summary>

## 跨域图片

公开 HTTPS 图片通常可以处理。网页无法读取图片时，扩展会核对当前图片，再读取不带登录凭据的图片数据；Pixiv 仅对当前图片的读取临时附加所需站点来源，不发送登录 Cookie。

需要登录、重定向、本地或内网图片可能无法读取；超过 16 MiB、被服务器拒绝或不是图片时会显示具体原因。可尝试对可见文字使用圈选翻译。

</details>

## 图片会发送出去吗？

文字识别和背景修补在本机进行，识别出的文字交给所选翻译服务；图片像素不会随文本翻译请求上传。首次下载识别资源需要联网。详见[数据与隐私](/guide/privacy)。
