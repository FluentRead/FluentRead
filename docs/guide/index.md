# 从你想读的内容开始

**外语？照样读。**

FluentRead 流畅阅读是一款开源浏览器翻译扩展。它把译文放在你正在阅读的地方：一整篇文章可以双语对照，一句不明白的话可以随手查，想记住的表达可以留下来慢慢学。

第一次使用？先跟着[安装与第一次翻译](/guide/getting-started)读完一个段落，无需提前了解各种翻译服务。

## 今天想做什么？

| 想留下来学习的词句 | [学习中心](/guide/vocabulary-book) |

## 用得更顺手

在[设置](/config/)中调整语言、译文样式、自动翻译和菜单栏布局。需要固定某些人名或专业词的译法，可以使用[术语库](/guide/glossary)。

免费翻译服务可以直接开始；需要 AI 讲解或已有付费服务时，再按[翻译服务指南](/config/translation-engines)连接。服务商可能单独收费。

遇到问题请看[常见问题](/guide/faq)。想了解哪些内容会发送给服务商，请看[数据与隐私](/guide/privacy)。
