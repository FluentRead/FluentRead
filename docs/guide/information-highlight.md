# 智能高亮

自动突出正文中的词语，让阅读更有侧重。启用后，智能高亮把部分词语变成视觉线索，帮助扫读长段落、定位和回看内容。原文仍完整可读，选取、复制和排版保持原样。

这是独立的阅读辅助功能。双语逐句高亮用于对应原文和译文句子；智能高亮在正文中标记词语，两者各自配置。

## 使用

1. 在想要高亮的网页上按 **Alt+H**（macOS 为 Option+H）。智能高亮只在这个页面开启，再按一次关闭；其他页面不受影响，刷新或离开后恢复关闭。页面上方会短暂提示已开启或已关闭；如果选择了本地模型但还没有下载，会提示先去设置中下载。
2. 打开 **设置 → 翻译设置 → 智能高亮**，可以更换或关闭快捷键，选择分析方式、密度、配色、颜色浓度和绘制方式，左侧预览会即时显示效果。
3. 希望每个页面都自动高亮时，打开 **所有页面自动高亮**。已打开的网页会立即开始高亮，之后访问的网页和在 FluentRead PDF 阅读器中打开的文档也会自动高亮；关闭开关即可清除。这个选项默认关闭。

在 FluentRead PDF 阅读器中，同一个快捷键或工具栏的 **智能高亮** 按钮可以单独开关当前文档，不改变设置中的开关。

预览右上角可以在 **高亮** 和 **原文** 之间切换，方便对比有无高亮的阅读感受。

标题旁提供 **关键词**、**预测意外度** 和 **辅助阅读** 三个小标签。鼠标悬停、键盘聚焦或触屏点击即可查看原理与用途；按 Escape 或点击外部可收起说明。

选择本地模型模式时，Qwen2.5 0.5B（基础模型）和 Qwen3 0.6B（进阶模型）两张卡片同时显示：宽屏并排，窄屏上下排列。点击卡片标题旁的单选项选择分析模型，默认使用 Qwen2.5 0.5B。每张卡片右下角各有一个操作按钮：尚未下载时显示 **下载模型（大小）**，下载完成后变为 **删除模型**。点击下载或继续下载会先打开确认框，确认后才开始下载；取消、关闭或按 Escape 不会下载。删除也需确认，且只删除对应卡片的模型文件。模型不可用时，可以在分析方式中选择 **关键词**。设置内的预览是外观示例，不是模型分析结果。

PDF 高亮使用现有可选文字层，原页图像和布局保持原样；没有文字层的扫描页不参与分析。

## 两种模式

| 模式 | 适合什么 | 处理方式 |
| --- | --- | --- |
| 关键词 | 快速浏览主题词语 | 轻量本地算法，按词长、数字、专名与缩写以及段内首次出现排序；中文和日文另按用字的常见程度、英文另按常用词表区分，常见词浅、少见词深。无需下载模型 |
| 预测意外度 | 留意上下文中不容易预测的词语 | FluentRead 按需下载 Qwen，在设备上计算预测概率 |

两种模式都在本机处理正文。下载模型会访问模型托管站点；评分不会向其发送网页文字。

预测意外度使用 `−log₂ P(词语 | 前文)`。分数高表示模型较难预测该词，不代表它更重要、更正确，也不验证文章事实。名称、罕见词、错字等都可能获得高分；阅读时仍需留意未高亮的否定和条件。

## 外观与性能

默认使用 **深浅渐层**：词语按分数分成八档，颜色越深越值得停留，浅色部分可以略读。也可以改为统一的柔和底色或细下划线。

提供少、适中、多三档密度（默认为多）：少只标出最关键的词，适中加上次一级的词，多会给所有有信息量的词上色；蔷薇、琥珀、薄荷、晴蓝、藤紫、青灰六套配色，以及浅、适中、深三档颜色浓度。调整密度和外观会复用已有评分，无需重新分析；只改配色或浓度时页面上的标记不会重绘。

这里的“本地模型”由 FluentRead 下载并运行，不依赖 Edge、Firefox 或其他浏览器内置的 AI。可选 Qwen2.5 0.5B（约 490 MB，默认）和 Qwen3 0.6B（约 579 MB）；两者使用各自固定版本的 q4f16 ONNX 文件，选择模型不会自动下载，已下载的文件分别保存。扩展通过 ONNX Runtime Web 在独立 Worker 中调用设备的 WebGPU 计算，下载完成后可离线分析。

首次使用需点击卡片的下载按钮，并在确认框中确认模型和大小。模型模式需要浏览器和设备支持 WebGPU 及 shader-f16 半精度计算能力；模型尚未下载或设备无法运行时，按快捷键开启的页面会自动改用关键词方式并提示原因，设置中的选择不变。正文不会自动上传到云端。

下载暂停或中断后，已保存的部分会保留，点击 **继续下载** 并确认即可续传。切换分析模型不会下载或删除文件；未选用的卡片也可以单独下载和管理。文件校验、存储空间或模型启动错误会显示对应恢复提示；已有完整模型文件时不会重复下载。两个模型的高亮效果、速度和内存消耗会因设备和正文而异，较新模型不保证选词更符合阅读重点。

按下快捷键后立即开始，屏幕上看得见的段落最先上色，再向上下延伸。滚动和页面自身变化时已有标记保持不动，只补充新进入阅读区域的段落，持续滚动时也会边滚边补；关闭后取消当前任务并丢弃迟到结果。页面正文更新后重新分析对应内容。深色页面上底色会自动加浓，保持深浅层次。使用本地模型时，开启提示会说明正在分析，首次加载模型需要几秒。代码、编辑器、表单和公式等区域不参与正文高亮；日期、计数这类短片段以及标签、导航等链接列表也不上色。

需要浏览器支持 CSS Custom Highlight API；没有该能力时会保留正常页面并显示不支持状态。
