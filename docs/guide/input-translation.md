# 输入框翻译

把输入框里的文字翻成另一种语言。可以替换原文，也可以保留原文追加译文。

<TranslationDemo variant="input" />

## 开启与设置

进入 **设置 → 翻译设置 → 输入框翻译**，开启功能，选择目标语言、触发方式和输出方式。未单独选择服务时，默认跟随网页翻译服务；连接参数沿用已有配置。

设置会自动保存。关闭功能时也可以预先配置，修改语言或服务不会自动开启翻译。

## 翻译输入内容

在普通输入框，或聊天、邮件等网页的富文本编辑器中写好内容，再使用选定的触发方式：连续按三下 **空格、等号或短横线**。原有 **Ctrl+Enter** 设置也继续生效。

选择连按触发后，可在 **连按速度** 中调整相邻两次按键之间的最长间隔。默认 **1000 毫秒**，范围为 **200～2000 毫秒**。容易误触时调短，连按不容易成功时调长；长按或输入法选词不会当作三击。

## 保留双语回复

| 输出方式 | 翻译后显示 |
| --- | --- |
| 替换原文（默认） | 用译文替换输入内容 |
| 原文在前，译文在后 | 保留原文，下一行追加译文 |
| 译文在前，原文在后 | 先显示译文，再换行显示原文 |

追加模式需要支持换行的多行输入框或富文本编辑器。单行输入框会提示不支持换行，并保留原文。支持的富文本编辑器会通过自己的输入流程写入结果，保留原有段落、加粗和链接等格式。

## 取消与恢复

翻译期间按 **Esc** 可取消本次写回。继续编辑时，迟到的译文不会覆盖新内容。

翻译成功后的提示提供 **恢复原文**，请在再次编辑之前使用。再次编辑后不会用旧原文覆盖新内容。富文本恢复会找回原来的文字；链接、@提及等格式可用编辑器的撤销恢复。

密码框和代码编辑器不参与翻译。翻译不会自动发送回复。

## 调整 AI 提示词

选择支持提示词的 AI 服务，可调整语气和翻译要求。模型留空时使用服务默认模型；`{{origin}}` 表示原文，`{{to}}` 表示目标语言。

提示词留空使用内置默认值，也可点击 **从默认提示词开始编辑** 再修改。恢复默认只影响当前提示词。
