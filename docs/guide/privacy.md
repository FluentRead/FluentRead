# 隐私政策

更新日期：2026 年 10 月 25 日。

本政策说明流畅阅读浏览器扩展如何处理翻译内容、本地记录、服务凭据及可选的 Google Drive、WebDAV 备份。流畅阅读由开源项目维护者开发，官网与本政策无需登录即可查看，翻译也不要求连接 Google 账号。

流畅阅读没有自建翻译服务器。哪些内容离开浏览器，取决于你启用的功能和选择的第三方服务。

## 可选的翻译隐私防护

可在高级设置开启[翻译隐私防护](/config/privacy-protection)，在本机识别并替换文字翻译中的敏感值，响应后本地恢复，或选择检测到敏感内容就阻止发送。自定义词使用本机凭据存储；防护开启时跳过持久翻译缓存。规则识别有覆盖限制，也不替代阅读助手、云端 OCR 等独立功能各自的数据处理说明。

## 使用功能时，会发送什么？

| 功能 | 发送内容与去向 |
| --- | --- |
| 网页、悬浮、划词、输入框翻译 | 待译文字与语言信息，发送给所选翻译服务 |
| 免费翻译 | 发送给已启用的候选服务，按成功率、响应时间和近期错误分配；失败可能把相同原文发送给另一候选 |
| AI 精翻 | 网页标题、描述、部分正文、章节定义及已有译文，发送给所选 AI 服务；默认关闭，篇章参考只留在当前会话内存 |
| 翻译卡片与学习讲解 | 主动提交的词句、允许参考的原文、必要问答，以及已开启且本次使用的学习记忆，发送给所选 AI 服务 |
| 术语库 | 只把原文实际命中的词语与指定译法附在支持术语的 AI 请求中，不发送整份词库 |
| 图片、本地 OCR 圈选 | 在本地识别图片，识别文字发送给翻译服务 |
| 优先模型识图的圈选 | 开启且模型支持时，裁剪的选区图片发送给圈选服务识别，再翻译文字；不上传整屏截图 |
| 文档翻译 | 文件在浏览器解析，待译文字发送给所选服务 |
| 视频字幕 | 字幕文字发送给字幕翻译服务；X 本地 AI 音频识别在本机完成 |
| 查词与朗读 | 主动查询或朗读的文字，发送给对应词典或语音服务 |
| Google Drive 云备份 | 主动操作并确认后，按所选范围读写自己的隐藏应用数据，详见下文 |
| WebDAV 云备份 | 向所选服务器发送连接凭据并读写备份，详见下文；不经过开发者服务器 |

输入框翻译默认关闭，只处理你主动触发的普通输入内容，不读取密码框。配置自动翻译的网站可自动发起翻译请求。本地翻译只改变对应请求的去向，词典、朗读和资源下载仍可能联网。

首次准备 OCR 语言包与本地模型需要下载文件。英文词卡查询未收录的词时，可从 JSDMirror、GitHub Raw 或 jsDelivr 下载并缓存约 3.9 MB 的固定版本完整词库；静态文件请求不包含所查单词，在线词典仍可能收到单词。

首次导出 PDF 译文时，会从 JSDMirror、onmicrosoft 镜像、jsDelivr 或 GitHub Raw 下载约 5 MB 的固定版本字体，校验后缓存，失败自动尝试备用来源。该请求只获取字体，不发送文档、译文、API Key 或其他服务凭据。

## 哪些内容留在浏览器里？

| 本地数据 | 保存与清理 |
| --- | --- |
| 设置、网站规则、术语、收藏与复习记录 | 保存在当前浏览器的扩展存储，各自页面提供管理入口 |
| 免费服务健康、错误与性能统计 | 保存在本机，用于自动分配、暂停与恢复候选服务 |
| API Key 等服务凭据 | 默认保存在本机，用于所选服务连接；访问浏览器配置或备份的人仍可能读取 |
| 翻译卡片问答 | 普通窗口保留 30 天，可查看和删除；隐私窗口不读取、不保存该历史，也不提供持久学习收藏 |
| 翻译缓存 | 默认最多 5 MiB 或 2,000 条，最长 24 小时，可调整或清空 |
| 英文词库与 PDF 字体 | 校验后存入浏览器 CacheStorage，供后续或离线复用，不进入配置云备份；清理浏览器数据或卸载可能移除，下次使用需再下载 |
| X 识别字幕 | 最多 32 个视频、7 天的字幕文字与时间，不保存识别音频；可在视频设置清理 |
| 最近文档 | 本机 IndexedDB 保存原始文件、解析内容、译文、校订、进度与翻译设置指纹；最多 20 份、原始文件合计 80 MiB，超限淘汰最久未更新记录，无按天自动过期 |

最近文档可在文档首页逐份删除或全部清空，不进入配置云备份。需长期保留的文件请下载；卸载或清理浏览器数据可能移除本地记录。清理翻译缓存不会删除学习收藏。

## 云备份的范围与保护

Google Drive 与 WebDAV 默认只备份语言、外观、快捷键、网站规则等**基础配置**。它们排除整个敏感连接配置，包括 API Key、配置中的服务 OAuth Token、鉴权请求头、服务地址、翻译服务与模型、自定义请求体、URL 鉴权参数，以及私密提示词和未知字段。恢复或合并基础配置会保留本机密钥、服务、地址与自定义连接。

只有主动开启**敏感配置**、阅读风险并勾选确认后，后续保存或合并才纳入敏感连接与私密提示词。恢复只应用备份实际包含的内容。选项默认关闭，确认后在当前浏览器持续保存，直到手动关闭；完成、失败、取消、重开设置或更换备份方式与账号不会关闭，其他设备需分别确认。

云备份不包含单词本、聊天记录、用量统计或最近文档，也不会为备份扫描网页。本次 Google 同步令牌与 WebDAV 连接地址、用户名、应用密码、连接鉴权头始终不进入备份。可选备份里的 OAuth Token 指你配置的服务凭据。

上传前在本机使用固定公开应用口令加密，无需另输密码。**得到文件的人可以按公开口令解密**，不能将其视为只有你能解密的备份。第三方账号被盗、共享目录被访问或文件泄露时，备份中的 API Key 等可能泄露。建议只备份基础配置；迁移密钥时保护账号、目录、浏览器配置与设备，避免分享文件或公开完整配置。

当前版本可读取完整 v1 与基础 v2 备份。敏感备份仍用 v1，旧扩展可读；基础 v2 需升级后的扩展读取。升级前未确认的预览需重新生成。关闭敏感开关或读取、恢复旧备份不会清除旧文件中的敏感信息；只有确认保存或合并基础配置，才从当前文件移除它们。服务商历史版本、旧文件与其他副本需另行管理。

## Google Drive 配置同步

该功能目前在 Chrome 扩展测试，是否可用以安装版本为准，用于自己的设备间备份与恢复，不需要持续连接账号。

### 何时访问，访问哪些数据？

点击**立即与Google Drive同步**才为本次操作请求授权并读取备份生成预览；确认方向与变更后才上传或应用到本机。打开设置不会访问 Drive。Google 授权与敏感配置同意分别进行。

| 数据 | 用途 |
| --- | --- |
| 所选范围的配置备份，读到的旧文件可能含敏感信息 | 上传、比较差异，并按确认范围恢复或合并 |
| Drive 账号标识与 Google 返回时的邮箱 | 防止混用账号，显示当前账号及本机上次成功同步记录；不另申请邮箱身份权限，未返回邮箱仍可同步 |
| 文件 ID、名称、版本、修改时间与版本校验信息 | 查找备份、检测同步期间变更，避免覆盖新配置 |
| Chrome 身份接口管理的临时 Google 访问令牌 | 仅认证本次 Google API 请求，不上传为配置，也不交给翻译服务 |

只请求管理流畅阅读隐藏应用数据的 `drive.appdata` 权限，不访问普通 Drive 文件、Gmail 或联系人，参见 [Google 官方说明](https://developers.google.com/workspace/drive/api/guides/appdata)。

### 保存在哪里，如何保护？

文件以 `fluentread-config.encrypted.json` 经 HTTPS 直接保存到你自己的 Drive 隐藏应用数据区，不显示为普通“我的云端硬盘”文件，不经过开发者配置服务器。加密限制见上文。

| 位置 | 保存期限 |
| --- | --- |
| 你的 Google Drive | 当前配置文件保留至删除，后续成功上传更新它 |
| 本机扩展存储 | 账号标识、Google 返回时的邮箱、成功同步时间与加密比较副本，保留至成功删除云备份、清理相关浏览器数据或卸载；换账号重建比较基线，取消或失败保留上次成功记录 |
| 本次临时状态 | 账号与文件信息、预览及加密快照；预览有效 10 分钟，完成、失败、取消或离开设置会清理待确认状态与身份缓存 |

清理身份缓存不会撤销 Google 账号中的许可，也不会删除备份。

### 如何停止访问和删除？

停止手动同步即可停止新操作。撤销许可可在 [Google 第三方连接](https://myaccount.google.com/connections)移除 FluentRead，之后需重新授权。

预览中**更换 Google 账号**会取消当前预览、清理身份缓存并重新请求授权；**取消**只结束此次操作。两者都不退出浏览器 Google 登录、不删备份，也不清除上次成功同步记录。

通过**云备份 → Google Drive → 删除云端备份**核对实际账号并确认，或在 Drive 网页**设置 → 管理应用 → FluentRead → 选项 → 删除隐藏应用数据**手动清理。扩展只条件删除确认版本，账号或文件变化需重新检查，取消不删除。删除不依赖内容解密，成功后清除本机同步记录和比较副本，保留本机配置及 API Key。

撤销许可、卸载或清理本机记录不会删除 Drive 备份。其他设备副本需另行管理，后续同步可能重新上传。

### Google 数据用于什么？

Google 账号标识与备份只用于账号核对、配置比较、同步和恢复，同步过程不把账号标识或整份备份发给 Google 以外的第三方。不出售数据，不用于广告、画像或无关内容生成，不用 Google Workspace API 数据开发、改进或训练非个性化 AI 或机器学习模型。开发者不通过同步服务查看备份；反馈内容由你自愿提供，请先移除凭据与私人内容。恢复后的凭据会用于你选择的翻译服务，发送范围见第一节。

信息使用遵守 [Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy)，包括适用的 Limited Use 要求；Google API 用于配置备份与恢复，不用于生成未经同意的私密影像。Google 自身的数据处理适用 [Google 隐私政策](https://policies.google.com/privacy)。

## WebDAV 云备份

仅主动测试连接、保存连接或开始备份操作时访问指定服务器。打开设置只读本机连接摘要，不轮询、不自动备份，与 Google Drive 分别记录。

- **请求与去向**：用户名和应用密码通过 Basic 鉴权发送给指定网盘、NAS 或服务器。测试与保存连接只读检查目录，开始同步读取固定备份；确认保存或合并后才创建目录、写入配置。不经过开发者服务器或 Google，不携带浏览器 Cookie，不跟随重定向转发密码。服务器日志、保存期限等适用服务商政策；运营者及能访问文件的人可读取备份。
- **范围与同意**：沿用上文基础与敏感范围、持续保存的选择、v1/v2 兼容及旧文件规则。连接凭据始终不进入备份或配置导出，不回显给设置页。
- **存储与期限**：固定文件为所填目录下 `FluentRead/fluentread-config.encrypted.json`，保留到删除。连接和密码存于本机后台专属加密配置仓库；成功账号、时间与加密比较副本保留到成功删除云备份、清除连接、相关浏览器数据或卸载。预览有效 10 分钟，完成、失败、取消、离开或过期时清理待确认快照。
- **保护**：使用上文公开口令加密，文件持有者仍可解密。HTTPS 保护传输；HTTP 不保护用户名、密码和文件，需要明确确认。主要访问保护依赖服务器账号、目录权限与设备安全。
- **停止与删除**：停止主动操作即可停止新请求。**删除云端备份**先显示账号和服务器，确认后只删除固定文件，清除同步记录与比较副本，保留本机配置、API Key、连接及其他文件。缺少强 ETag 时，删除前再次核对内容并使用可用版本或存在性条件；多设备不要同时操作。版本变化或 HTTP 412 会中止，不降级重试。无法安全核验时在服务商处手动删除。**清除连接设置**只清理本机连接、应用密码和同步记录，不删服务器文件。

卸载或撤销应用密码不会删除云端文件；服务商回收站、历史版本与其他设备副本需另行清理，后续同步可重建备份。WebDAV 数据只用于请求的备份、恢复与比较，不出售、不用于广告、画像或模型训练。恢复后的凭据继续用于所选服务。操作见[WebDAV 指南](/guide/webdav)。

## 怎么控制其他数据？

关闭不需要的自动翻译、AI 精翻、学习记忆或收藏入口。将翻译卡片的原文范围设为**当前选区**可减少上下文发送。收藏、阅读记录与学习记忆在各自页面管理，清理翻译缓存不删除它们。

本地完整备份未加密，可能包含密钥、原句与来源；导出前确认范围，分享前检查内容。第三方翻译服务对请求内容的保存和使用适用其各自政策。

## 官网与外部链接

官网由 GitHub Pages 托管，无需注册。中英文使用不同网址，由你主动切换，首页不自动跳转语言。外观等网站偏好存在浏览器，清除该网站数据可移除。官网不读取扩展配置备份或凭据。

托管服务处理访问请求适用 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。访问扩展商店、Google 或翻译服务的网站时，也适用对方政策。

## 政策更新与联系

政策随功能和数据处理方式更新，日期见页首。Google 数据用途或访问范围变化时，会在新的访问或使用前更新说明并请求同意。

隐私或删除问题可通过 [GitHub Issues](https://github.com/FluentRead/FluentRead/issues)或[邮件](mailto:a1914493943@gmail.com)联系维护者。公开反馈前请移除凭据、账号信息与私人文本。
