# 隐私政策

更新日期：2026 年 10 月 3 日。

本政策说明 FluentRead（流畅阅读）浏览器扩展如何处理翻译内容、本地记录、服务凭据和可选的 Google Drive、Dropbox 配置备份。FluentRead 是由开源项目维护者开发的双语翻译与阅读辅助工具。官网与本政策无需登录即可查看；使用翻译功能不要求连接 Google 账号。

你选择的功能和服务，决定哪些内容会发送出去。FluentRead 没有自建翻译服务器；云端翻译由对应的第三方服务处理。

## 使用功能时，会发送什么？

| 功能 | 发送的内容与去向 |
| --- | --- |
| 网页、悬浮、划词、输入框翻译 | 待译文字和语言信息，发送给所选翻译服务 |
| 免费翻译服务 | 待译文字；自动均衡会由后台根据成功率、响应耗时和近期错误分配给已启用的服务，失败后可能发送给其他候选 |
| AI 精翻 | 额外参考的网页标题、描述和部分正文，发送给当前 AI 服务；默认关闭 |
| 翻译卡片与学习讲解 | 主动提交的词句、允许参考的原文、必要问答，以及启用且被使用的学习记忆，发送给所选 AI 服务 |
| 术语库 | 本次原文实际命中的词语与指定译法，随支持术语的 AI 请求发送；不会发送整份词库 |
| 图片翻译、本地 OCR 圈选 | 图片在本地识别，识别出的文字发送给所选翻译服务 |
| 优先模型识图的圈选 | 开启且模型支持时，将裁剪后的选区图片发送给圈选服务识别，再发送识别文字进行翻译；不上传整屏截图 |
| 文档翻译 | 文件在浏览器中解析，待译文字发送给所选翻译服务 |
| 视频字幕 | 字幕文字发送给字幕翻译服务；X 本地 AI 的音频识别在本机完成 |
| 查词与朗读 | 主动查询或朗读的文字，发送给对应词典或语音服务 |
| Google Drive 配置同步（Chrome 测试功能） | 用户主动确认后，将完整配置的加密备份保存到用户自己的 Google Drive；详细范围见下文 |

图片语言包和本地 AI 模型首次准备需要联网下载。输入框翻译默认关闭，只处理你主动触发翻译的输入内容，不读取密码框。

英文词卡随扩展提供常用词库。查询未收录的单词时，扩展可从 JSDMirror、GitHub Raw 或 jsDelivr 下载约 3.9 MB 的固定版本完整词库并缓存；该静态文件请求不包含所查单词。在线词典仍可能按上表向对应服务发送单词。

开启自动翻译的网站，会在符合设置的页面自动发起翻译请求。仅选择本地翻译模型，并不意味着词典、朗读、模型下载等独立功能也全部离线。

## 哪些内容留在浏览器里？

- 设置、网站规则、术语、收藏与复习记录保存在当前浏览器的扩展存储中。
- 免费翻译的健康、错误和性能统计保存在当前浏览器的本地存储中，仅用于后台自动分配和冷却恢复。
- API 密钥等凭据默认保存在扩展本地凭据存储中，用于连接对应服务。主动使用 Google Drive 同步时，也会包含在下文所述的配置备份中。能访问浏览器配置或备份文件的人仍可能读取相关内容。
- 普通模式的翻译卡片问答保留 30 天，可以查看和删除。隐私窗口不保存也不读取该历史，也不提供持久学习收藏。
- 翻译缓存暂存已完成的结果，默认最多 5 MiB 或 2,000 条，记录最长保留 24 小时；可在设置中调整或清空。
- 按需下载的完整英文词库保存在浏览器的 CacheStorage 中；清除浏览器站点数据或卸载扩展会移除它。
- X 已识别视频的字幕文字与时间可缓存最多 32 个视频、7 天，不保存识别音频；可在视频设置中清除。
- 文档翻译与校订结果留在当前页面，关闭前请下载需要的文件。

## Google Drive 配置同步

Google Drive 配置同步目前处于 Chrome 扩展测试阶段，是否可用以所安装版本的设置页为准。它用于在你自己的设备间备份和恢复 FluentRead 设置，不是翻译服务，也不要求持续连接账号。

设置页的同步卡片右侧显示上次同步账号和时间。将鼠标移到“隐私保护”或用键盘聚焦该徽标，可查看本机加密、云盘访问范围、临时授权缓存清理和不参与同步的数据说明。

### 何时访问，访问哪些数据？

只有你点击“立即与Google Drive同步”时，扩展才为本次操作请求 Google 授权并读取备份以生成预览。确认同步方向与变更后，才上传配置或将下载的配置应用到本机。打开设置页不会自动访问 Google Drive。

- **配置范围**：包含API Key、OAuth Token、鉴权请求头、自定义请求体及URL中的鉴权参数，不包含单词本、聊天记录和用量统计。这里的 OAuth Token 是你配置的服务凭据；本次 Google 同步的访问令牌不放进备份。
- **Google 权限**：只申请管理 FluentRead 自己隐藏应用数据的 `drive.appdata` 权限，不请求读取你的其他 Drive 文件、Gmail 邮件或联系人。该权限的说明见 [Google 官方文档](https://developers.google.com/workspace/drive/api/guides/appdata)。
- **账号信息**：通过 Drive 读取本次同步账号的标识，防止把不同账号的配置混用；Google 返回邮箱时，用于展示本次账号，并在成功同步后与时间一起保存在本机，显示为“上次同步账号”。不另行申请邮箱身份权限，未返回邮箱也可同步。
- **授权令牌**：由 Chrome 身份接口管理，仅用于本次 Google API 请求。操作完成、失败、取消预览或离开设置后，扩展清除身份缓存。清除缓存不会撤销你在 Google 账号中授予的许可，也不会删除备份。

本次同步处理的数据和用途如下；读取备份只限于 FluentRead 自己的隐藏应用数据区。

| 数据类别 | 具体内容 | 用途 |
| --- | --- | --- |
| 配置备份内容 | 翻译服务与模型、语言与外观、快捷键、网站规则、术语、自定义提示词，以及上述服务凭据和请求参数 | 上传以备份配置，下载以预览差异，并按你确认的方向恢复或合并设置 |
| Google 账号信息 | Drive 账号标识，以及 Google 返回时的邮箱地址 | 标识用于防止混用不同账号的备份；邮箱用于展示本次账号和保存在本机的上次成功同步记录 |
| FluentRead 备份文件信息 | 文件 ID、名称、版本、修改时间，以及可用的版本校验信息 | 找到配置文件，检查同步期间的变更，避免覆盖其他设备的新配置 |
| 本次 Google 访问令牌 | Chrome 身份接口取得的短期授权令牌 | 向 Google 证明本次请求已获授权；不作为用户配置上传或交给翻译服务 |

你在提示词、自定义请求体或 URL 中自行填写的内容，也属于配置备份的一部分。仅同步设置，不会扫描网页、下载文档或读取学习、聊天与用量记录作为备份内容。

### 保存在哪里，如何保护？

备份通过 HTTPS 直接发送到你自己的 Google Drive 隐藏应用数据区，文件名为 `fluentread-config.encrypted.json`，不经过 FluentRead 开发者的配置服务器，也不会显示为普通的“我的云端硬盘”文件。账号标识、Google 返回时的上次成功同步账号邮箱、上次同步时间和用于比较变更的加密副本保存在当前浏览器中。

上传前在本机加密，使用固定公开的应用口令，无需你输入密码。**持有备份密文的人可以根据公开口令解密**，因此文件的访问保护主要依赖 Google 账号、应用授权和设备安全。请保护账号、浏览器配置与导出的备份，不要把文件或完整配置发到公开反馈中。

| 保存位置 | 保存内容与期限 |
| --- | --- |
| 你的 Google Drive | 加密配置文件，保留至你删除隐藏应用数据；成功上传会更新该配置文件 |
| 当前浏览器的扩展存储 | 账号标识、Google 返回时的上次成功同步账号邮箱、上次同步时间、用于比较变更的加密配置副本，保留至清除相关浏览器数据或卸载扩展；切换账号会重建比较基线，取消或失败不会覆盖上次成功同步记录 |
| 本次操作的临时状态 | 账号与文件信息、待确认预览及其加密快照；预览有效期为 10 分钟，完成、失败、取消或离开设置时清理待确认状态和授权缓存 |

### 如何停止访问和删除？

每次同步都需要你主动触发。停止点击同步即可停止新的同步操作。若要撤销许可，可在 [Google 账号的第三方连接](https://myaccount.google.com/connections)中选择 FluentRead 并移除访问权限；之后再次使用同步需要重新授权。

在预览中选择“更换 Google 账号”，会取消当前预览、清除扩展身份缓存并重新发起账号授权；选择“取消”只结束这次操作。两者都不会退出浏览器中的 Google 登录、删除云端备份或清除上次成功同步记录。

云端备份保留到你删除它为止。可在 Google Drive 网页的**设置 → 管理应用 → FluentRead → 选项 → 删除隐藏应用数据**中删除备份。撤销授权、卸载浏览器扩展或清除本机记录，不等于删除 Drive 中的备份；删除云端备份也不会删除其他设备已下载的配置。

### Google 数据用于什么？

Google 账号标识和配置备份仅用于账号核对、配置同步与恢复。同步过程中不会将账号标识或整份备份发送给 Google 以外的第三方。FluentRead 不出售这些数据，不将其用于广告、用户画像或与同步无关的内容生成，也不使用 Google Workspace API 数据开发、改进或训练非个性化 AI 或机器学习模型。开发者不会通过同步服务查看你的备份；问题反馈由你自愿提供，反馈前请删除凭据与私人内容。恢复后的服务凭据会继续用于你选择的翻译服务，翻译请求的数据范围见本政策第一节。

FluentRead 使用 Google API 收到的信息遵守 [Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy)，包括适用的 Limited Use（有限使用）要求。Google API 用于配置备份与恢复，不用于生成未经同意的私密影像。Google 自身对云端存储与账号数据的处理还适用 [Google 隐私政策](https://policies.google.com/privacy)。

## Dropbox 配置同步

Dropbox 是另一种可选配置备份方式，是否启用以所安装版本为准。只有主动点击“立即与Dropbox同步”时才进行授权并读取备份生成预览；确认后才保存、恢复或合并，打开设置不会访问 Dropbox。

- **范围**：与 Google Drive 配置同步相同，包含API Key、OAuth Token、鉴权请求头、自定义请求体及URL中的鉴权参数，不包含单词本、聊天记录和用量统计。本次 Dropbox 访问令牌不进入备份。
- **权限和用途**：只申请 `account_info.read`、`files.metadata.read`、`files.content.read`、`files.content.write`。账号标识及邮箱用于核对和展示同步账号；文件元数据、修订号和配置内容用于预览、恢复及避免覆盖其他设备的修改。文件访问限制在 FluentRead 自己的 App folder，不访问其他文件、分享或团队数据。
- **保存与保护**：配置通过 HTTPS 直接存入你自己的 Dropbox 的 Apps / 应用名文件夹，文件名为 `fluentread-config.encrypted.json`，不经过开发者的配置服务器。上传前本机加密，使用源码公开的固定应用口令；持有密文的人可以据此解密，访问保护依赖账号、授权和设备安全。该文件夹可在 Dropbox 中看到。
- **本机保留**：成功账号标识、邮箱、时间与加密比较基线保留至清除扩展数据或卸载；与 Google Drive 记录分开。切换账号不混用基线，取消不会覆盖成功记录。待确认预览有效期十分钟，完成、失败、取消或离开页面清理。短期访问令牌只暂存于扩展会话存储，清理时删除；不请求 refresh token，不持续后台同步。
- **使用与披露**：Dropbox 账号信息和备份只用于配置同步，不出售、不用于广告或模型训练，也不发送给其他翻译服务。恢复后的服务凭据只按你选择的翻译服务使用，范围见本政策第一节。
- **控制与删除**：取消结束当前操作；更换账号重新登录。它们不会退出 Dropbox 网站或删除云端文件。可以在 [Dropbox 已连接应用](https://www.dropbox.com/account/connected_apps) 撤销访问，在 Apps 文件夹删除上述备份。云端文件保留至你删除；撤销授权、卸载扩展或清除本机记录不会自动删除云端备份，也不清除其他设备已恢复的配置。

Dropbox 自身的存储与账号处理适用 [Dropbox 隐私政策](https://www.dropbox.com/privacy)。维护者接入和用户流程见 [Dropbox 同步指南](/config/dropbox-sync)。

## 怎么控制其他数据？

不需要的自动翻译、AI 精翻、学习记忆和收藏入口可以关闭。翻译卡片的原文范围可改为“当前选区”，减少发送的上下文。

清除翻译缓存不会删除学习收藏。收藏、阅读记录和学习记忆请在各自页面管理。卸载扩展或清除浏览器数据可能删除这些本地记录。

备份可能包含密钥、原句和来源信息；导出前确认范围，分享前检查内容。使用云端服务时，请按服务商自己的政策了解其数据保存方式。

## 官网与外部链接

官网由 GitHub Pages 托管，无需注册或登录。中文和英文内容通过不同网址提供，语言切换由你主动选择，首页不会自动跳到其他语言网址。外观选择等网站偏好保存在浏览器中，清除该网站的浏览器数据即可移除；官网不会读取扩展中的配置备份或服务凭据。网站托管服务处理访问请求还适用 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。访问扩展商店、Google 或翻译服务的网站时，相关服务各自的隐私政策也适用。

## 政策更新与联系

本政策随功能和数据处理方式更新，并在页首标明日期。若 Google 数据的使用范围或目的发生变化，会更新说明并在新的访问或使用前请求你的同意。

有隐私疑问或数据删除问题，可通过 [GitHub Issues](https://github.com/FluentRead/FluentRead/issues) 或 [邮件](mailto:a1914493943@gmail.com) 联系项目维护者。公开反馈时请隐藏密钥、账号信息和私密正文。
