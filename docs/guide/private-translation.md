# 无痕专用翻译模型

在 **设置 → 通用 → 无痕专用翻译模型** 中开启，选择连接并填写明确的模型编号。默认关闭；关闭后保留选择，普通窗口始终沿用原有功能配置。

当前最小兼容范围是 **OpenAI 与已配置的自定义 OpenAI-compatible 连接**。连接、API Key、请求头和限额来自所选服务；若需要独立的凭据或地址，请先新建一个自定义 AI 服务。不会复制普通窗口的服务身份到专用连接，也不会自动选择或调用模型来测试。

## 失败时不使用普通模型

- 服务被删除、模型未填、凭据缺失、模型不可用时，明确报错，不退回普通模型。
- 目前只支持标准请求体。所选连接配置了非空自定义请求体时会拒绝翻译，不会悄悄忽略必需参数；请使用单独的标准连接。
- 模型编号须为实际编号，不含展示后缀。若已有兼容规则会改写编号（如官方 MiMo 端点的退役别名），请填写最终模型编号。
- 所有已识别的无痕翻译都不读取或保存共享译文及页面摘要缓存（不受专用模型开关影响）；重复请求可能再次调用模型。配置就绪并取得快照后，请求、调度和统计使用该快照的服务、模型、凭据与可信隐私身份，不会因之后的设置页编辑而换用新模型；等待配置就绪期间的编辑仍可能影响随后取得的快照。

## 范围和隐私边界

仅浏览器发送者元数据明确标记为无痕的请求启用此选择。消息中的 `privateContext`、`incognito` 等自报字段不生效；启用专用模型后，未知身份明确报错且不调用普通或专用连接；关闭专用模型后，未知身份沿用普通路由，但不能据此宣称具有无痕保障。扩展仍需浏览器授予在无痕窗口运行的权限。

覆盖汇入共享翻译 broker 且保留可信身份的文本翻译，例如网页全文、悬浮、划词正文、输入框、字幕和文档文本，以及识别后的图片/圈选文字。离线验证覆盖普通数组逐项翻译、网页/文档 AI 多段合批、错语种单槽恢复及文档坏槽拆批恢复，逐次核对专用连接身份与共享缓存零读写；真实浏览器文档入口仍未验收。**不是全模态隐私开关**：独立阅读讲解、写作、词典查询与辅助释义、语音、OCR/图像识别等服务不在此承诺内；识别前的图像仍可能使用原配置。直接集成和油猴版不具备这条浏览器可信身份；若导入配置开启专用模型，共享翻译会明确拒绝未知来源，需要关闭该开关才能继续。内部视觉能力探测也缺少标签页身份，开启此模式时不能执行；词典辅助释义的共享翻译会被拒绝，并沿用词典原文。不会伪造普通身份绕过检查。

浏览器无痕模式和本地缓存隔离并不保证供应商不留存数据。请确认所选供应商的隐私政策与连接设置。

## 验证范围

`privateTranslation`、`privateTranslationIntegration` 和 `privateTranslationSettingsLifecycle` 使用真实配置、后台 fallback、broker、锁定 AI SDK、Vue 模板与离线 HTTP 夹具，检查出站模型/地址/凭据、普通数组逐项翻译、并发缓存隔离、错误无回退、取消、配置快照以及设置关闭/重开和迟到事件。

这不代表真实无痕窗口、Firefox 实机、外部模型质量或所有多模态入口均已验收。未访问用户设备、用户凭据或外部模型。

输入框翻译会先确定本次可信窗口对应的有效连接与模型，再为该连接应用输入框专用系统提示词和用户提示词。普通输入服务为机器翻译时，无痕请求仍会为专用 AI 模型应用输入提示词；配置就绪并取得快照后，配置变更不影响该次请求；等待配置就绪期间尚未取得快照的请求除外。

开启专用模型时，扩展页面不再按普通连接的凭据提前拒绝请求，而由后台根据可信窗口身份校验最终连接；普通窗口缺少凭据仍会被后台拒绝。
