# 双语分享卡片



遇到喜欢的句子，可以把原文和译文排成一张图片：

1. 选中文字并完成划词翻译，在翻译结果内点击 **制作卡片**。入口只在划词结果中显示，正常浏览、悬浮段落翻译和全文翻译时不会在网页上出现。
2. 默认使用红白分区的 **珊瑚** 风格，另有 **晴空、流光、月白、抹茶、书页、落日、蓝图**，共八套样式。风格按钮展示缩略图；在 **更多设置** 中用分段按钮选择自适应或方形、字号，用开关调整双语顺序、来源和 FluentRead 署名。工作台统一使用 FluentRead 品牌色，不随图片样式改变控件颜色。
3. 在 **编辑摘录** 中修改这张卡片的文字，不会改变网页或翻译结果。来源默认只显示网站域名，可以填写作者或直接隐藏。
4. 点击 **保存图片** 下载高清 PNG，或 **复制图片** 后粘贴分享。

预览就是导出的图片。方形放不下时会提示改用自适应长图；超长内容需要精简，不会自动截掉文字。关闭预览后可继续阅读。外观偏好会沿用到下次，摘录文字和生成的图片不会存入插件配置。

图片在本地生成，不额外请求翻译或上传内容。部分页面不支持图片剪贴板，仍可保存 PNG 后自行分享。划词翻译的双语和仅译文模式均可制作卡片。公式等富文本以文字形式排版，不保留网页原有的数学布局。

复制和保存后的结果会显示在固定底栏中：绿色表示操作成功，红色表示失败并提供下一步建议。保存提示只表示已发起下载，请以浏览器下载记录为准。复制等待期间显示加载标记并防止重复操作。
