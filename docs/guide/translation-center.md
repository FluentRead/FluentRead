# 翻译中心

让多个服务翻译同一段文字，方便对照措辞并复制合适的结果。

<GuideVisual kind="compare" />

## 对比一次翻译

1. 打开 **设置 → 工具与学习 → 翻译中心**。
2. 输入文字，选择原文和目标语言，在 **管理服务** 中添加要对比的服务或模型。
3. 点击 **翻译**，或按 Mac 的 **⌘ + Enter**、其他系统的 **Ctrl + Enter**。
4. 以列表或并排方式查看结果，复制需要的译文。

文字会发送给所选服务。输入和结果只保留在当前面板，关闭或刷新前请复制需要的内容。

## 侧边栏翻译

Chrome、Edge 和桌面 Firefox 可点击插件弹窗顶部的**侧边栏翻译图标**，直接粘贴复制的文本并翻译，无需另开设置页。也可以从浏览器的侧边栏菜单中选择 FluentRead。

在侧边栏输入文字后按 **Enter** 翻译，按 **Shift + Enter** 换行；也可以继续使用 **⌘ + Enter** 或 **Ctrl + Enter**。侧边栏右上角的按钮会打开设置页中的翻译中心。

打开的就是翻译中心的侧边栏形态，语言、服务选择和首次默认项与设置页共用。服务按钮显示当前服务或已选数量，点开可搜索并多选；服务较多时，列表在菜单内滚动。选择多个服务时，每个服务的名称、模型、译文或翻译状态都显示在各自的卡片中，可以逐份复制译文。切换网页时面板中的输入与结果保持，关闭面板会停止未完成的翻译。侧边栏不会自动读取剪贴板，也不会把原文或译文写入配置。

## 管理服务和结果

**管理服务** 可搜索并同时选择多个服务或模型。已保存密钥不代表连接可用；需要时点击 **配置** 检查连接和模型，返回后输入与已完成结果仍在。添加服务本身不会翻译。对比列表不改变网页默认服务，但连接配置与其他功能共用。

拖动卡片可排序；也可聚焦拖动柄，按 **Alt + ↑ / ↓**。语言、顺序和布局会自动保存，窄屏使用单列。

点击停止可中止全部或某个服务的未完成请求，已完成结果会保留，之后可重试未完成项。修改原文、语言或模型后，旧结果会标记为之前的结果；**复制当前结果** 只包含本次条件下成功完成的译文，旧结果仍可单独复制。
