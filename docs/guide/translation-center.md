# 翻译中心



在 **设置中心 → 工具与学习 → 翻译中心** 中输入或粘贴原文，选择语言后点击 **开始翻译**，也可以按 Mac 的 **⌘ + Enter** 或其他系统的 **Ctrl + Enter**。首次只展示少量免密钥服务与已配置的默认服务；原有的服务选择和顺序会保留。

**管理服务** 可以多选，并按服务或模型名称搜索。目录区分免密钥/凭据已配置与需要配置的服务；“已配置”不等于连接已验证。添加服务不会自动翻译；点击 **配置服务** 可编辑连接与模型，返回后原文及完成结果仍在。本中心的选择不会更改网页默认服务，服务连接配置仍与其他功能共享。

结果可切换为 **列表** 或 **并排**，窄屏自动改为单列。可以拖动卡片，或聚焦拖动按钮后按 **Alt + ↑ / ↓** 排序；语言、服务顺序和排列方式自动保存。翻译过程中可以停止全部或某一项，已完成的结果保留；失败或停止后可只重试未完成项。

原文、语言或模型变化后，旧结果会标记出来，并显示当时的语言。**复制本次结果** 只包括与当前输入匹配的成功结果，不混入旧译文；单项复制仍可复制供参考的旧结果。

原文和译文不写入翻译中心配置，仅保留在当前设置页面；关闭或刷新后清空。点击翻译后，原文会发送给所选服务，并遵循扩展已有的请求记录和统计设置。
