# 视频与会议翻译

在 YouTube、X 视频或 Google Meet、Teams、Zoom 网页会议中对照阅读原字幕与译文，使用时需开启平台提供的可读取字幕。

<summary>会议字幕与人工字幕</summary>

## 会议字幕与人工字幕

**视频翻译设置 → 通用** 中新增两个默认开启的选项，关闭后会自动保存：

- **会议平台自动开启双语字幕**：在 Google Meet、Teams 和 Zoom 网页会议中尝试开启平台可用的字幕，并使用视频翻译服务显示译文。关闭此选项后仍可手动开启平台字幕并翻译；关闭视频字幕翻译或隐藏 FluentRead 字幕时会恢复原生字幕显示。
- **优先使用人工字幕**：YouTube、Udemy、Disney+ 有可读取的目标语言人工字幕时，优先显示这份字幕，无需为对应句子调用翻译服务；不可读取、轨道缺失或该时段没有字幕时，继续翻译原字幕。原语言字幕保持原样，不会切换成目标语言轨道。

会议支持浏览器中的网页版本，Zoom 使用 `/wc/` 网页客户端；桌面客户端不受浏览器扩展控制。平台、主持人或账号需允许字幕，FluentRead 无法代替平台生成未提供的会议字幕，也不会开启录制或转录。Teams 会沿会议的更多操作及语言菜单寻找明确的字幕开启项；若平台改版或控件不可用，请先手动开启原生字幕。

Udemy 与 Disney+ 读取网站显示的字幕和可用字幕轨道，原文与译文在播放器画面内显示，全屏时随画面移动。字幕下方可以切换双语、仅译文、仅原文或关闭；翻译失败时可以重试。受版权、地区、账号或播放器限制而未向页面提供字幕轨道时，人工字幕优先会回退到原生字幕文字翻译。此功能不绕过媒体访问限制，也不为没有字幕的视频生成音频字幕。

扩展菜单中的 **视频字幕** 面板可以快速开关翻译、切换 **双语 / 仅译文 / 仅原文**。翻译服务、字幕外观和本地 AI 模型集中在底部的 **视频翻译设置** 中，修改后自动保存。

播放器内的字幕菜单用一行 **双语 / 译文 / 原文 / 关闭** 选择当前看哪种字幕；选择 **关闭** 会停用 FluentRead 字幕并保留网站自带字幕，再选择任一显示方式即可恢复。观看首页保持紧凑单列，字幕来源以简短状态显示。识别模型、校时、下载与重新识别放在 **字幕选项** 中，点左上角返回或按 Esc 回到显示方式。

X 播放器自动收起控制栏时，已打开的字幕菜单会保持显示；显示方式和 AI 字幕状态会随操作更新，方便连续调整。点击菜单外部、右上角关闭按钮或按 Esc 可关闭菜单。方向键可在菜单中移动焦点，不会触发播放器快进。

X 菜单会显示字幕来源：原生字幕、已恢复的本地字幕或 AI 字幕，以及已读取的字幕条数。暂未检测到字幕时会说明下一步；没有时间轴时，下载按钮暂不可用。原生字幕优先于自动恢复的 AI 缓存；手动生成 AI 字幕后则使用这一份时间轴，避免两种来源来回切换。

## 已有字幕的视频

1. 确认 FluentRead 的 **视频字幕翻译** 已开启。
2. 打开 YouTube 或 X 视频，找到播放器控制栏全屏按钮前的 FluentRead 图标；在 X 中，它位于画中画和全屏按钮之间，控制栏重新显示或切换全屏后会保持这个位置。
3. 打开字幕菜单，选择 **双语 / 译文 / 原文**。

字幕来自视频已有的字幕轨道或网页显示的字幕。没有可用字幕时，不能保证直接生成译文。字幕翻译服务默认跟随网页服务，也可以在视频设置中单独选择。

<details class="guide-details">
<summary>字幕校时与提前翻译</summary>

字幕本身已经是目标语言时（例如目标为简体中文，字幕是简体或繁体中文），FluentRead 不再请求翻译，只显示原文一行；选择 **译文** 时这句会显示在译文位置。

读取到 YouTube 或 X 的字幕时间轴后，FluentRead 会优先翻译当前句，并提前翻译最多八条不同的后续原文；机器翻译通常预取未来 10 秒，AI 服务预取未来 30 秒，倍速播放时相应扩大时间范围。原生轨道加载后立即开始预取，重复条目和已结束字幕不会挤占后续句子的名额；拖动进度后会更新预取窗口。

YouTube 全屏时也可以打开播放器字幕菜单。已预翻译的原文与译文会在同一次更新中一起显示；换句、字幕空档或拖动进度时会清除上一句译文。刚打开视频、跳到尚未翻译的位置或服务未及时返回时，先保留原文，译文完成后仅在对应句子仍有效时补上。

X 的双语字幕始终成对更新：尚未翻译的句子等待译文就绪后一起显示，不先单独出现原文；等待期间视频继续播放，已经过期的结果不会补到下一句。仅原文模式立即显示原字幕；翻译失败时保留当前原文，并在菜单中提供重试。

X 已有可读取的原生字幕轨道时，后台字幕分片陆续加载会保留当前字幕和已完成的翻译，避免开头几秒因反复切换来源而闪烁。

YouTube 逐词滚动字幕会根据当前播放时间和新出现的句子匹配预取译文，不必等上一行滚走。没有可用字幕时间轴时，也会在连续输出期间提交当前文字；实际译文出现速度仍取决于所选翻译服务。

如果字幕比声音慢或快，可以直接在**播放页面的 FluentRead 字幕菜单 → 字幕时间**中点击 **−** 或 **+**，每次提前或延后 0.5 秒。负数表示提前，正数表示延后，最多调整 ±10 秒；有偏移时左侧会出现重置按钮，点一下恢复为 0。设置自动保存并用于之后打开的视频，原文与译文一起调整，视频播放进度和下载字幕的时间戳保持原样。当前字幕没有可用时间轴时，这一行会暂时收起。

</details>

## X 视频没有字幕时

桌面 Chrome / Edge 扩展可以尝试本地 AI 字幕：

1. 在 X 播放器的字幕菜单中点击 **生成 AI 字幕**。
2. 首次使用时，菜单内会列出 **Tiny**（约 100 MB）、**Base**（约 150 MB）和默认推荐的 **Small**（约 590 MB，多语种质量更好）；确认后开始下载模型，完成后自动生成字幕。也可以提前在视频设置的本地 AI 模型卡片中下载。下载期间，菜单按钮显示进度条和百分比，设置里的模型卡片显示进度条、百分比和已下载体积。
3. 读取与识别进度显示在按钮上，生成过程中可以停止。前段已识别的稳定句会先显示，并按播放位置翻译附近字幕，无须等整段识别和翻译完成。完整识别成功后才保存字幕缓存并允许导出 SRT；后续识别失败会清除未完成的预览。只看原文时不请求翻译服务。

Tiny、Base 和 Small 均为多语言模型。默认模型为 **Small · 高质量**，约 590 MB；新配置、旧配置缺少模型选择或选择无效时都使用 Small。Tiny 约 100 MB，Base 约 150 MB，适合下载和内存受限的设备；明确保存过的 Tiny/Base 选择和已下载模型继续保留。

需要换模型时，打开播放器内的 **字幕选项 → 识别模型**。选择页默认保留当前模型；取消或按 Esc 会返回原操作，当前字幕继续显示。确认后才保存新选择并重新识别，已下载的模型无需再次下载。识别或下载进行中暂不能换模型，可以先停止识别再选择。

模型状态会核对本机缓存中的完整文件清单。浏览器清理了部分文件时，该模型会重新提供下载入口；确认下载后复用仍在缓存中的文件，只补齐缺失部分。无法读取缓存时会显示读取失败，重新进入设置或回到该页面可再次检查。

**视频原语言 → 自动检测** 会重新检测每个有人声的音频窗口，不需要预先知道整段视频的语言，也不会用开头的语言锁住后面的对白。已知单一语言时仍可手动指定。Base 和 Small 保留更多正文与时间戳的解码容量；Tiny 保留较短预算以限制低质量长输出。出现长串重复文字时只自动重试一次，仍异常则报错，不展示或缓存损坏字幕。质量模型仍可能误识别口音、配乐、专业名词和部分语言，不能保证所有多语种视频都准确。

本地识别会优先使用可用的 GPU 加速；浏览器不支持或加速失败时自动改用 CPU，无需手动切换。

在 **视频翻译设置 → 本地 AI 字幕 → 下载来源** 中选择 **自动选择 / 国内优先 / 官方优先**，仅影响后续下载。国内优先依次尝试魔搭、HF Mirror 和 Hugging Face 官方；官方优先先尝试 Hugging Face，再尝试 HF Mirror 和魔搭。自动选择使用浏览器语言作为初始顺序提示，不判断实际所在地。设置中提供这三个模型页面的链接。

下载卡片显示正在连接的来源、失败后切换的来源和真实接收字节。连接等待超过 10 秒、连续 20 秒没有收到数据时会尝试下一来源；所有文件与来源共用十分钟总下载预算，持续接收期间进度正常更新。失败后可以改变优先来源并点击 **重试下载**，已经完整缓存的文件直接复用。模型不随扩展安装包一起下载。

HF Mirror 为第三方镜像，在部分网络中可能重定向到官方站点；它不是所有地区的独立备用通道。可达性仍取决于所在网络、来源服务和浏览器，本轮来源核验与验证范围见[下载验证记录](https://github.com/FluentRead/FluentRead/blob/main/docs/reports/x-model-download-sources-20261009/verification.md)。

音频识别在本机进行，识别出的字幕文字仍交给所选翻译服务。首次下载需要网络，生成时间取决于视频长度和电脑性能。目前单段视频最长支持 20 分钟；部分媒体格式或受限制的视频无法读取。

鼠标移出、移回、播放控件重建、视频暂时隐藏或缩略图信息补全时，保留当前 AI 字幕时间轴和模型请求；同一视频补全媒体信息后，模型下载完成仍会启动识别。确认切换到不同媒体后才清理上一视频状态。首页缩略图位于播放器旁边时也会用于定位当前音轨。

读取时优先从主清单选择音轨，先检查初始化段是否包含音频，避免下载纯画面的高清分片。读取或解码失败会尝试同一主清单声明的备用音轨，以及当前视频对应的低码率完整 MP4。候选来自页面已加载的媒体及视频元数据，扩展只提取媒体地址和码率；媒体身份不明确时不会使用时间线中的其他视频候选。没有兼容音轨时仍可能失败。

识别会跳过数字静音，保留低音量人声和片尾短句；视频中的长停顿不会让整段人声被跳过。完整识别会保留已识别的短句和跨窗口延续词，长静音边缘裁剪后仍保持原有字幕时间。长视频逐窗准备音频，同时只保留一个识别窗口和一个待处理窗口；停止后会释放待处理音频。此处理不能过滤所有配乐和噪声。

Home 信息流也可以直接生成字幕。FluentRead 按当前视频的媒体标识重新读取已加载音轨，避免混入其他帖子的预加载视频。若仍无法读取音频，菜单会提示“暂时无法生成 AI 字幕，可尝试打开帖子或刷新页面后重试”。切换到其他视频时，上一视频的错误、进度和模型确认会被清理。

## 调整显示和保存字幕

在视频字幕外观设置中修改字号、背景、位置和显示宽度。字号支持 80–500%，也可输入整数百分比；大字号或长双语字幕超出实际画面时，会临时缩小以完整显示，保存的字号不变。X 字幕按视频实际画面定位，竖屏视频中的长字幕会在画面内换行；调整播放器大小或切换全屏时会同步更新位置，播放控件出现时会尽量避让。

**字幕选项 → 下载字幕** 中的 **原文 / 译文 / 双语** 可下载 SRT 字幕，结果提示显示在按钮下方。双语文件在同一条字幕里先放原文、后放译文；译文与原文相同时只保留一行。X 已完整识别的字幕会在本机缓存一段时间，重复打开同一视频通常无需重新识别。缓存命中后立即恢复字幕时间轴，双语随当前句译文一起显示；返回视频设置时会刷新缓存数量。需要重新识别时，打开 **字幕选项 → 重新识别此视频**，无需清除其他视频的缓存或重新下载已有模型。模型确认前保留当前字幕，取消仍可继续观看。

下载译文或双语字幕前，菜单会列出完整时间轴的条目数、可复用的人工字幕与缓存译文、待补译条目及时间跨度，以及去重后的最多新增文本请求数。选择 **补译并导出完整字幕** 才会请求缺失内容；也可选择 **仅导出已有结果**，保留原始时间戳并跳过未翻译条目，文件名带 `partial`，完成提示明确显示跳过数量。界面不估算服务商费用，实际用量以所选服务为准。

确认期间切换视频、目标语言、模型、术语或请求参数会取消旧预览；请重新点击下载生成当前预览。补译时关闭菜单或按 Esc 可取消，不会下载错配或失败的完整文件；已经成功的当前视频译文缓存仍可复用。


AI 识别期间可以提前观看已完成的句子，完整识别结束前导出按钮暂不可用。

识别与翻译分别处理：翻译服务失败不会丢失已识别的原文和时间轴。菜单会显示“这句翻译失败”，并提供 **重试**；也可以切换到原文，或在设置中更换翻译服务。

<summary>没有字幕或时间不准</summary>

## 没有字幕或时间不准

先确认视频本身有字幕，再尝试打开原生字幕。若使用 X 本地 AI 识别，检查模型是否下载完成；原语言未知或会切换时，保留自动检测。

“未识别出可读字幕”表示音频识别没有得到文字，并非翻译服务失败。使用 Tiny 或 Base 时可以尝试 Small；已经使用 Small 时，请检查视频是否有清晰人声，再重试。语言无法预先确定时使用自动检测。没有人声时通常无法生成可读字幕。

识别可能听错人名、专有名词或背景音，译文也可能有误。重要细节请结合音频和原字幕核对。

</details>
