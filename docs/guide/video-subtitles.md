# 视频与会议字幕

在主流视频网站、在线课程、网页会议以及普通网页音视频播放器中对照阅读双语字幕，支持快捷键切换、时间轴校准、读音标注、完整句学习与字幕导出；无字幕视频还可在浏览器本地运行 AI 语音转写。

## 已有字幕的视频平台 {#已有字幕的视频}

1. 在扩展菜单或设置中确认**视频字幕翻译**已开启，并在播放器打开原生字幕。
2. 在播放器控制栏（通常紧邻原生字幕或全屏按钮）点击**流畅阅读图标**。
3. 在菜单中选择**双语 / 译文 / 原文**，或选择**关闭**暂时隐藏（图标仍保留，随时可重新开启；如需隐藏图标本身，请在设置中心关闭总开关）。

### 快捷键与听力练习

- **模式切换快捷键**：在**视频翻译设置 → 通用 → 字幕显示模式快捷键**开启（默认 `Alt+M` / `Option+M`，支持自定义），可选**双语 ↔ 原文**或**循环切换**，在评论/搜索输入框内自动让行。
- **不重复扣费的听力练习**：在 YouTube 等平台按**关闭 → 原文 → 双语 → 关闭**切换练习听力时，已完成译文保留缓存，再次打开双语无需重复请求；接管期间持续隐藏平台原生字幕，关闭总开关后恢复原生显示。

### 主要视频与课程站点说明

| 平台 | 字幕来源与特性 |
| --- | --- |
| **YouTube** | **优先使用人工字幕**（默认开启），有目标语言人工轨时直接使用；原文模式按完整时间轴显示，避免逐词跳动 |
| **哔哩哔哩（普通/分 P）** | 优先读取 UP 主人工字幕，其次平台 AI 字幕（需登录）；支持无字幕时生成本地 AI 字幕；默认需手动点击开启（可在设置设为自动），番剧暂不支持 |
| **X (Twitter)** | 支持原生字幕翻译，无字幕视频支持浏览器内 Whisper 或本机 Qwen3 ASR 转写 |
| **Udemy / Udemy Business** | 优先讲师上传的原始语言字幕，默认自动开启，切换下一节自动绑定新播放器 |
| **edX / Coursera** | 支持可读取原生字幕轨的 HTML5 播放器；完整字幕加载后均支持完整句学习与导出（不含嵌入式 YouTube 播放器） |
| **Disney+** | 支持可读取字幕轨翻译，实际可用性取决于账号、地区与播放器限制 |

## 网页会议实时字幕 {#会议字幕与人工字幕}

支持 **Google Meet**、**Microsoft Teams** 与 **Zoom 网页版（`/wc/`）**（桌面会议客户端不受浏览器扩展控制）：

- **视频翻译设置 → 通用**中的**会议平台自动开启双语字幕**默认开启，会尝试启用平台自带字幕（前提是平台、主持人与账号允许字幕）；未自动开启时请手动打开平台原生字幕。
- 流畅阅读**不会**开启会议录制或云端转录，也无法为平台未提供字幕的会议生成字幕。

## 无字幕视频与普通网页音视频（本地 AI 转写） {#普通网页音频与视频}

当 **X 视频**、**B 站普通/分 P 视频**或普通网页中的 `<audio>` / `<video>` 没有可用原生字幕时，可在播放器流畅阅读菜单点击**生成 AI 字幕**（绝不自动采集音频）：

- **短媒体独立解码（最长 20 分钟）**：常见 MP3、M4A、WAV、OGG、MP4、WebM 与 B 站 AAC DASH 音轨在本机直接解码并逐窗转写，稳定句子先显示。
- **流媒体播放采集**：HLS、MSE/blob、实时流或超过 20 分钟的媒体使用当前播放音轨采集（需 HTTPS/本地页面及支持 AudioWorklet 的浏览器）。请以 **1 倍速播放**，单次最多采集 20 分钟，点击**停止生成**整理结果；改变进度或倍速会结束本次识别，导出文件标记为 `partial`。
- **受限媒体说明**：受 DRM 保护、无 CORS 授权或位于封闭 Shadow DOM 内的媒体无法读取音轨，流畅阅读不会绕过浏览器安全限制。

::: info B 站自动本地识别条件
在 B 站开启**打开视频就翻译**后，仅当页面可见、播放器就绪、平台明确返回空字幕列表且标题不含「中文字幕 / 中英字幕」等标记时，才自动启动本地识别；其他情况均可手动触发。
:::

## 外观调整、校时与字幕导出 {#调整显示和保存字幕}

- **外观即时预览**：在**视频字幕外观**调整字号、轮廓样式、颜色、宽度、位置、双语顺序或隐藏背景（设置页示例不发送任何请求）。
- **时间轴校准（±10 秒）**：音画字幕不同步时，在播放器菜单**字幕时间**每次提前或延后 **0.5 秒**（最多 `±10 秒`，支持一键重置）。校准会持久化并同步移动原文与译文，不改变下载文件的原始时间戳。
- **导出 SRT / WebVTT / Markdown**：点击菜单顶部下载图标，选择**原文 / 译文 / 双语**：
  - 译文或双语导出前会先显示待补译条数与时间跨度，可选择**补译并导出完整字幕**（确认后才计费请求）或**仅导出已有结果**（文件名带 `partial`）。
  - 双语 SRT 合并为单轨清晰时间轴，原文在上、译文在下，相同行自动去重。

<summary>X / B 站本地 Whisper 模型管理与本机 Qwen3 ASR 配置</summary>

### 浏览器内 Whisper 模型

1. 在**视频翻译设置 → 本地 AI 字幕**管理模型：推荐 **Small**（约 590 MB），也可选择轻量 **Tiny**（约 100 MB）或 **Base**（约 150 MB），均支持多语言与自动检测。
2. 首次下载需联网，中断重试会复用完整缓存；运行优先使用 GPU，失败自动回退 CPU。
3. 支持文件系统访问 API 的浏览器可开启**跨浏览器共享模型**，授权同一目录后模型写入 `FluentRead/whisper`，无需重复下载。
4. 在播放器菜单**字幕选项**中可切换模型或**重新识别此视频**（不影响其他视频缓存）。

### 本机 Qwen3 ASR（vLLM）

如果本机运行了支持 `Qwen/Qwen3-ASR-1.7B` 的 vLLM 服务（无需凭据的 `POST /v1/audio/transcriptions` 接口，参考 [vLLM 配方](https://github.com/vllm-project/recipes/blob/main/models/Qwen/Qwen3-ASR-1.7B.yaml)）：

```sh
vllm serve Qwen/Qwen3-ASR-1.7B --host 127.0.0.1 --port 8000
```

在**视频翻译设置 → 本地 AI 字幕 → 识别方式**选择**本机 Qwen3 ASR**，填入 `http://127.0.0.1:8000`（仅接受 `127.0.0.1` 或 `[::1]` 回环地址）并保存即可使用。

</details>

### 读音标注

在**视频字幕外观 → 读音标注**或 YouTube/X 菜单顶部图标开启（默认关闭，仅扩展版支持）。支持**日语罗马音、韩语罗马字、中文拼音**，以及**俄语、希腊语、阿拉伯语、印地语和泰语**拉丁转写。

- 读音紧跟原文，不改写下载字幕；首次遇到日语下载约 **17.8 MB** 词典、印地语约 **0.5 MB**，校验后离线缓存，字幕文字不发送到注音服务。

### 逐字高亮

在**视频字幕外观**开启**逐字高亮**（默认关闭）后，YouTube 与 X 的原文和译文会随播放进度逐字点亮（按句长与时长估算节奏）。

</details>

<details class="guide-details">
<summary>完整句学习面板与快捷键</summary>

### 完整句学习

在 YouTube、X、B 站、Udemy、edX、Coursera 及普通 HTML 媒体取得完整字幕后，点击菜单**开始完整句学习**即可逐句精听：

- **播放器快捷键**：`← / →` 切换上一句/下一句，`R` 循环当前来源片段，`Q` 切换片段结束暂停（输入框或菜单打开时自动让行）。
- **按需讲解与编辑**：点击**查看解释**才会调用划词 AI 讲解服务；点击**编辑**可修改译文或解释并固定当前句。
- **收藏回跳**：点击**收藏此句**存入[学习中心](/guide/vocabulary-book)，之后点击来源链接可直接跳回对应视频时间点。

</details>

## 常见问题

- **没有字幕出现**：先确认平台原生字幕已打开并加载完毕；无字幕视频请参考上方本地 AI 转写章节。
- **提示「未识别出可读字幕」**：检查视频是否有清晰人声、源语言是否正确，或将 Whisper 模型从 Tiny/Base 切换为 **Small**。
- **译文报错**：原字幕与时间轴均已保留，直接点击重试或切换字幕翻译服务即可，无需重新识别音频。
