# 视频与会议翻译

在 YouTube、X、哔哩哔哩（含普通视频、分 P 与可访问的番剧/PGC）、Udemy、edX、Coursera、Disney+、Netflix、Amazon Prime Video、TED、Vimeo 视频和 Google Meet、Teams、Zoom 网页会议中，对照阅读原字幕与译文。也支持普通网页及嵌入 frame 中的 HTML 音频、视频播放器，并可在设置中直接导入本地音视频文件进行离线 AI 转写与逐句学习。普通 HTML 媒体、X、B 站和本地音视频文件均可复用本机 Whisper 或本机 Qwen3 ASR 识别字幕。

## 普通网页音频与视频

网页中的 `<audio>` / `<video>` 出现后，流畅阅读会提供一个小图标；音频的字幕显示在原播放器下方。页面有多个媒体时，点击或播放要学习的媒体即可切换。原媒体的布局、声音和播放位置保持由网页控制；没有媒体时只保留轻量检测。

优先使用可读取的原生字幕轨。没有字幕时，点击图标选择 **生成 AI 字幕**，复用设置中的 Whisper 模型和翻译服务。转写在浏览器中完成；首次下载模型需要联网，翻译文字仍按所选翻译服务处理。不会自动开始采集音频。

- 可读取的短媒体先独立解码、逐窗识别；支持的格式取决于浏览器，包括常见的 MP3、M4A、WAV、OGG、MP4 和 WebM。
- HLS、MSE/blob、实时流或超过 20 分钟的媒体使用当前播放音轨。播放采集需要 HTTPS 或本地页面以及支持 AudioWorklet 的浏览器。请先开始 **1 倍速播放**；字幕陆续出现，选择 **停止生成** 会整理本次已采集的字幕。单次采集最多 20 分钟，处理积压达到一分钟时停止以保护性能。改变播放位置或倍速会结束本次识别，需要重新开始。
- 播放采集只覆盖本次听到的片段，导出文件标为 `partial`，也不会作为整片字幕缓存。清晰人声、设备性能和模型速度会影响识别质量与字幕延迟。

字幕菜单的完整句学习提供可滚动的原句、译文、单词查询和按时间回放；直播回放范围取决于网页播放器是否支持回看。下载区可选择 **SRT / WebVTT / Markdown**，再选择原文、译文或双语；补译前仍会显示待翻译范围并确认。

受 DRM 保护、浏览器不允许读取音轨、无 CORS 授权且无法捕获、封闭 Shadow DOM 中的媒体可能无法转写；不会绕过这些限制，也不会把空白结果当成成功。

## 已有字幕的视频

1. 在扩展菜单或设置中确认 **视频字幕翻译** 已开启，并打开视频原生字幕。
2. YouTube、X 的播放器中，点击全屏按钮附近的流畅阅读图标。
3. 选择 **双语 / 译文 / 原文**。其他支持平台也会在字幕附近提供显示切换。

字幕服务默认跟随网页翻译，可在 **视频翻译设置** 单独选择。播放器菜单选 **关闭** 会停止翻译并隐藏字幕，视频控制栏的图标仍会保留；再次点击图标，选择 **双语 / 译文 / 原文** 即可恢复，刷新页面后也能从图标重新开启。要一并隐藏图标，请在设置中心关闭 **视频字幕翻译**。

出现译文需要等待所选服务返回。刚打开视频或跳到未翻译的位置时可能稍有延迟；翻译失败可重试，原字幕和已读取的时间轴会保留，无需重新识别音频。

YouTube 的 **原文 / 双语 / 译文** 模式都使用流畅阅读的字幕样式，沿用外观设置。原文模式不请求翻译；有匹配的字幕时间轴时显示当前完整字幕，避免跟随原生字幕逐词出现。暂时没有时间轴时使用可读取的原生文本。

练习听力时，可从播放器菜单依次选择 **关闭 → 原文 → 双语 → 关闭**。切换时保留已完成的译文，再次打开双语无需重复翻译相同字幕。流畅阅读接管期间持续隐藏 YouTube 原生字幕，切句空档、跳转进度和字幕容器重建时也保持隐藏；在设置中心关闭 **视频字幕翻译** 后恢复平台的原生字幕。

如果希望不移动鼠标直接切换显示模式，可在 **视频翻译设置 → 通用 → 字幕显示模式快捷键** 中开启快捷键（默认 `Alt+M` / `Option+M`，支持预设与自定义组合键），并按习惯选择 **双语 ↔ 原文**、**循环切换（双语 → 译文 → 原文）** 或 **循环切换（含关闭）**。快捷键在输入框内会自动让行，不影响搜索和评论输入。

## B 站、Udemy 与 edX

播放器控制栏的 **流畅阅读图标** 紧邻原生字幕按钮，普通、网页全屏和浏览器全屏均跟随原生按钮对齐。菜单与 YouTube/X 共用分段显示按钮、读音和下载入口；选择 **双语 / 译文 / 原文**，或选择 **关闭**，之后仍可从图标重新开启。双语模式下显示顺序设置，单语时自动收起。**字幕选项** 中可校时和切换本站自动翻译。下载默认收起，点击标题栏的下载图标展开。字幕沿用外观和读音设置，背景随文字宽度收拢。原文模式不请求翻译；翻译失败在菜单中重试。

- **B 站**：普通视频、分 P、带 `bvid` 的列表页以及番剧/PGC（`/bangumi/play/ep...` 与 `/bangumi/play/ss...`）优先读取平台人工字幕，没有人工轨时使用平台 AI 字幕。平台字幕需要登录并与当前分 P/剧集绑定；番剧如受 DRM 保护或无公开可解码音轨，不会绕过 DRM 限制。
- **Netflix**：识别播放器容器（`.watch-video--player-view` / `.VideoContainer`）和定时字幕节点（`.player-timedtext-text-container` / `.player-timedtext`），自动接管原生字幕显示并在关闭、停用或路由切换时精确恢复；存在播放器控制栏时挂载隔离的流畅阅读快捷菜单。
- **Amazon Prime Video**：支持 `primevideo.com` 以及 `amazon.com` / `amazon.co.jp` / `amazon.co.uk` / `amazon.de` 下的 `/gp/video/` 与 `/detail/` 视频页，读取播放器字幕节点（`.atvwebplayersdk-captions-text` / `.f35bt6a`）并在控制栏挂载显示模式切换入口。
- **TED**：支持 `ted.com` 演讲视频的原生字幕节点、HTML5 `<track>` 字幕轨以及页面演讲稿活跃句读取，并在播放器控制栏提供双语/单语/关闭切换。
- **Vimeo**：支持 `vimeo.com` 与 `player.vimeo.com` 的原生字幕（`.vp-captions` / `.vp-telecine`）及 `<track>` 字幕轨，在控制栏安全锚点挂载模式切换入口。

## 本地音视频导入与离线转写

在 **视频翻译设置 → 本地 AI 字幕** 下方的 **本地音视频离线转写** 面板中，可以直接拖拽或选择本机音视频文件（支持 `.mp4`、`.webm`、`.mp3`、`.m4a`、`.wav`、`.ogg`、`.flac`，单文件上限 **200 MB**、时长上限 **20 分钟**）：

1. 音频在浏览器本机经 Web Audio API 解码并重采样为 16 kHz 单声道 PCM，音频不会离开当前设备。
2. 复用已下载的浏览器内 **Whisper** 模型或已配置的 **本机 Qwen3 ASR** 协议逐窗离线识别，随时可取消并自动通知后台停止推理。
3. 识别完成后通过流畅阅读已配置的翻译服务批量翻译字幕（已为目标语言的字幕自动跳过，部分失败可单独补译），并在内嵌播放器上同步展示 **双语 / 仅译文 / 仅原文 / 关闭** 字幕。
4. 内置 **逐句精听与循环** 面板：按句末标点与静音停顿自动切分句子，支持点击跳转、上一句/重播/下一句、**循环本句**与**句末暂停**。
5. 支持一键导出 **SRT / WebVTT / Markdown** 格式的双语、原文或译文字幕文件；清除文件、切换文件或离开页面时自动中止任务并释放临时对象 URL。
- **Udemy**：支持普通课程与 Udemy Business。从课程原始语言开始，优先讲师上传的字幕；不会把另一语言的机器译轨再次翻译。切到下一节后自动绑定新的播放器。
- **edX**：支持提供可读取字幕元数据的 HTML5 播放器。跟随原生菜单所选字幕语言；同一单元有多个视频时，跟随最后开始播放的那个，暂停后仍保留。嵌入式 YouTube 播放器暂不在此接入范围。

在 **视频翻译设置 → 通用** 为三个站点分别选择 **打开视频就翻译**，也可在播放器菜单更改。B 站和 edX 默认关闭；Udemy 保留此前默认开启的行为。当前视频的手动选择在切换媒体后重新按站点偏好决定。B 站没有字幕时可按下文生成本地 AI 字幕；其他站点的空字幕检查不会先显示已开启再退回关闭。

三个站点均按完整原文时间轴显示，尊重空档和截止时间。播放中最多预取接下来十秒内的有限字幕，暂停时不继续发起新的预取。菜单支持每次 **±0.5 秒** 的校时和重置，导出沿用原时间戳。

浏览器扩展取得完整字幕后，可从菜单进入**完整句学习**，逐句回放或收藏。下载区支持 **SRT、WebVTT、Markdown** 的原文、译文和双语导出。需要补译时，先显示范围和预计请求数，由用户确认。Udemy 和 edX 读取网站已有字幕。B 站也可在本地 AI 字幕生成后进入学习或导出。

### Coursera

在提供可读取 WebVTT 字幕的 Coursera 视频课时，打开播放器的 FluentRead 菜单，选择 **双语** 或 **仅原文**。完整字幕加载后可逐句回放、收藏或导出。课程访问仍由 Coursera 管理。

## B 站视频没有字幕时

普通视频与分 P 可在播放器的流畅阅读菜单 → 字幕选项中选择 **生成 AI 字幕**。先在 **视频翻译设置 → 本地 AI 字幕** 下载并选择 Whisper 模型，或选择已配置的本机 Qwen3 ASR。未下载所选模型时，菜单会提示进入设置。Whisper 运行时切换到备用精度时可能补齐对应文件。

开启 B 站的 **打开视频就翻译** 后，优先使用平台已有字幕。页面可见、播放器就绪、平台明确返回空字幕列表且标题没有“中文字幕”“中英字幕”等标记时，才自动开始本地识别。已标注字幕的视频仍可手动生成。平台字幕读取或解析失败时保留重试入口。**停止生成** 会取消识别，切换视频、分 P、模型或原语言也会取消旧任务。

支持最长 **20 分钟**、有可读取 AAC DASH 音轨的普通视频。音轨在本机解码。使用本机 Qwen3 ASR 时，音频发送到设置中的本机回环地址。双语或译文模式会将识别出的文字交给所选字幕翻译服务。识别时不改变视频进度。稳定字幕会先显示，完整成功后可导出原文 SRT。B 站 AI 字幕保留在当前页面，刷新后需重新生成。

## 会议字幕与人工字幕

会议支持网页客户端，Zoom 使用 `/wc/` 网页版。平台、主持人或账号必须允许字幕，桌面会议客户端不受浏览器扩展控制。

**视频翻译设置 → 通用** 中，两项默认开启：

- **会议平台自动开启双语字幕**：尝试开启 Google Meet、Teams、Zoom 提供的字幕。未成功时，请手动开启原生字幕；关闭翻译或隐藏流畅阅读字幕会恢复原生显示。
- **优先使用人工字幕**：YouTube、Udemy、Disney+ 有可读取的目标语言人工字幕时直接使用，缺失或不可读取的部分继续翻译原字幕。

流畅阅读不会开启会议录制或转录，也无法为平台未提供字幕的会议生成字幕。Udemy、Disney+ 的字幕可用性还取决于账号、地区和播放器限制。

## 调整显示和保存字幕

在 **视频字幕外观** 调整字号、轮廓样式、颜色和粗细，也可隐藏字幕背景；位置、宽度、双语顺序等设置同样支持即时预览。设置页示例不读取视频或发送请求。

字幕与声音不同步时，打开播放器菜单的 **字幕时间**（X 位于 **字幕选项** 中），每次提前或延后 **0.5 秒**，最多 **±10 秒**，可一键重置。调整会保存并用于之后的视频，同时移动原文与译文；不会修改视频进度或下载的时间戳。没有可用时间轴时无法校时。

在 YouTube/X 点击菜单顶部的 **下载字幕** 图标，选择 **原文 / 译文 / 双语**，下载 SRT。双语文件中，原文在第一行，译文在第二行。两行相同时只保留一行。双语导出使用单轨时间轴，后一条开始时结束与它重叠的前一条，同一时刻开始的字幕合为一条。

译文或双语下载会先显示待补译的数量与时间跨度：

- **补译并导出完整字幕**：确认后才请求缺失译文，实际用量按所选服务计算。
- **仅导出已有结果**：跳过未翻译条目，文件名带 `partial`，并提示跳过数量。

补译期间可关闭菜单或按 Esc 取消，已完成译文仍可复用。切换视频或翻译设置后需重新预览。X AI 字幕必须完整识别成功后才能导出。

## X 视频没有字幕时

桌面 Chrome、Edge 和 Firefox 扩展默认使用浏览器内 Whisper 识别 X 视频。

1. 打开 X 播放器的流畅阅读菜单，选择 **生成 AI 字幕**。
2. 使用浏览器内 Whisper 时，首次选择模型并确认下载。推荐 **Small**（约 590 MB），也可用较小的 **Tiny**（约 100 MB）或 **Base**（约 150 MB）。
3. 等待音频读取与识别，可随时停止。稳定的句子会先显示，完整识别成功后才缓存时间轴并开放导出。

Whisper 模型均支持多语言。原语言未知或对白切换语言时使用 **自动检测**，已知单一语言也可手动指定。浏览器内识别优先使用可用的 GPU，失败时改用 CPU。字幕文字按显示模式交给所选翻译服务，仅原文模式在本机显示识别结果。

目前支持最长 **20 分钟** 的单段视频，耗时取决于视频和设备。部分媒体格式或受限制的视频无法读取；可尝试打开帖子详情或刷新后重试。没有清晰人声、配乐干扰、口音和专业名词都可能影响结果。

换模型或重新识别当前视频，使用 **字幕选项 → 识别模型 / 重新识别此视频**。确认前保留当前字幕，取消不改变结果；下载或识别进行中先停止，才能换模型。重新识别无需清除其他视频缓存。

在 **视频翻译设置 → 本地 AI 字幕** 管理 Whisper 模型。首次下载需联网。失败后可重试，完整缓存文件会复用，只补齐缺失项。清理浏览器缓存后可能需要重新下载。识别失败会清除不完整预览，翻译失败则保留已识别原文。

支持文件系统访问 API 的浏览器还可启用 **跨浏览器共享模型**：在每个浏览器中选择同一文件夹并分别授权，模型写入该目录下的 `FluentRead/whisper` 子目录。已有模型可迁移到共享目录；断开授权不会删除共享文件。其他浏览器仍可使用各自的扩展缓存。

### 使用本机 Qwen3 ASR

若已安装支持该模型的 vLLM，可用以下命令启动本机服务。服务需用固定模型 `Qwen/Qwen3-ASR-1.7B` 提供无需凭据的 `POST /v1/audio/transcriptions` 接口。[vLLM 模型配置](https://github.com/vllm-project/recipes/blob/main/models/Qwen/Qwen3-ASR-1.7B.yaml)

```sh
vllm serve Qwen/Qwen3-ASR-1.7B --host 127.0.0.1 --port 8000
```

在 **视频翻译设置 → 本地 AI 字幕 → 识别方式** 选择 **本机 Qwen3 ASR**，填写 `http://127.0.0.1:8000` 并保存。地址仅接受 `127.0.0.1` 或 `[::1]`。服务启动后，在有可读取音轨的 X 视频中选择 **生成 AI 字幕**，扩展才向本机服务发送音频。

字幕时间按音频窗口估计。停止会取消扩展端请求，服务仍可能处理已收到的音频。服务报错后可重试，或在设置中手动切回 **浏览器内 Whisper**。

## 读音标注

浏览器扩展可在 **视频字幕外观 → 读音标注** 或 YouTube/X 菜单顶部图标开启读音，默认关闭，油猴版暂不支持。支持日语罗马音、韩语罗马字、中文拼音，以及俄语、希腊语、阿拉伯语、印地语和泰语的拉丁转写。

读音紧跟原文，仅译文或隐藏字幕时不显示；开启读音不会自动切换显示方式。逐句准备读音或原文无需标注时，菜单不会反复显示提示；真正失败时可在菜单就地重试。首次遇到日语需下载约 **17.8 MB** 词典，印地语约 **0.5 MB**，下载并校验后本机缓存，可离线复用。字幕不发送到注音服务，下载前原文和译文也能正常显示。

读音仅辅助阅读，多音字、人名和连音可能有误，请结合音频。不会改写原字幕或下载文件。

### 逐字高亮

在视频字幕外观开启 **逐字高亮**（默认关闭），YouTube、X 的原文和译文会随播放逐字点亮。节奏按整句时间和文字长度推算，可能与实际发音有差异。

## 完整句学习

在 YouTube、X、B 站、Udemy、edX 的字幕菜单点击 **开始完整句学习**，查看原句、上下文和整句译文。本地 AI 字幕可在识别完成后使用。缺标点或过长的字幕可能标为 **字幕片段**。

学习面板在本地按规则从已有字幕中拆分句子。断句保留原文和原字幕时间范围。多个句子来自同一条字幕时，可能共享回放范围。切换这些句子时，播放位置会保持在当前片段内。

- **上一句 / 下一句** 选中相邻句子。进入不同来源片段时，跳到该片段起点并保持当前播放状态。
- **重播来源片段** 从片段起点播放。**循环来源片段 / 片段结束暂停** 按原字幕的时间范围控制播放。若播放头在范围外，可点击重播。手动拖动进度会解除播放辅助，用户暂停与倍速设置会保留。
- **查看解释** 是可选操作，点击后才调用划词 AI 讲解服务；允许使用语境时参考相邻字幕。
- 点击 **编辑** 可改译文或解释，并固定当前句；切句保留本次面板草稿，**回到当前句** 恢复跟随。
- **收藏此句** 保存原句、确认的译文、解释、上下文与时间位置到学习中心，无需先讲解。翻译未完成时请等待或手动填写。

播放器内可用左右键换句、R 切换循环、Q 切换片段结束暂停；输入框内按键保持普通输入，字幕菜单打开时优先操作菜单。拖动标题可移动面板，标题栏样式按钮可调整布局和字号。关闭学习、关闭字幕或切换视频会停止播放辅助。

学习中心的来源可返回对应视频时间；X 定位需要扩展开启。来源被删除或限制访问时仍保留收藏文字。字幕校时和双语顺序不改变收藏或循环使用的原始时间。默认不含私密上下文的词书导出也不含视频地址与时间。

## 没有字幕或时间不准

先开启平台字幕并等待加载。X、B 站和普通 HTML 音视频在没有字幕时可尝试上述本地 AI 功能。

“未识别出可读字幕”是音频识别没有得到文字，可检查人声、原语言，或由 Tiny/Base 换 Small。翻译失败则直接重试或换翻译服务。重要信息请结合原字幕与音频核对。
