# 学习中心：收藏、理解与使用

收藏阅读中遇到的单词、短语和句子，结合原句理解用法，再通过造句和复习巩固。

<GuideVisual kind="learning" />

## 从阅读中收藏

1. 打开 **工具与学习 → 学习中心 → 单词与句子**，在 **管理收藏** 中开启收藏入口。
2. 在网页中选中文字，打开划词翻译卡片，点击收藏图标；AI 回答下的 **收藏原文** 也可保存表达。
3. 回到 **单词与句子**，点击句子的 **听读与理解**，或单词、短语的 **学习用法**。

收藏会保存选中文字、可用译文、上下文与来源。重复收藏可补充上下文，不会创建相同词条。搜索支持原文、译文、解释和上下文；类型与掌握状态筛选可帮助查找，**清除筛选** 返回全部收藏。

双语逐句高亮只用于对照原文和译文，不会因鼠标划过而弹出操作或启动朗读。需要听读、复制和收藏时，主动选中文字，使用划词卡片；它只保存所选文字，不会自动改选整段。无痕窗口不保存收藏。

## 四个栏目分别保存什么

| 栏目 | 内容 | 保存期限 |
| --- | --- | --- |
| 单词与句子 | 主动收藏的表达、译文和解释 | 直到主动删除 |
| 阅读材料 | 按文章、文档和视频整理原句、问答引用、笔记和阅读位置 | 直到主动清空；移除后可恢复 |
| 阅读记录 | 读懂、句法、用法和练习的问答，可继续追问 | 30 天 |
| 学习笔记 | 从回答保存的笔记，或手动添加的要点和学习偏好 | 直到主动删除 |

**收藏原文** 与 **保存学习笔记** 是两个操作。**回答时参考学习笔记** 默认关闭；在划词翻译的 AI 设置中开启后，相关笔记和偏好才随问题发送给所选 AI。关闭开关不会删除笔记，也不影响继续保存。

## 理解与实际使用

打开学习页不会调用 AI 或改变掌握状态。可先听原句，查看收藏时的参考内容；缺少有效原句时，页面会说明。

1. 点击 **理解这个表达**，查看含义、搭配和例句。没有原句时，只讲常见用法。
2. 在 **用自己的话说一句** 中写句子，点击 **看看用得是否自然**，核对含义与搭配。反馈不会自动标记掌握。
3. 需要留下解释时，使用 **添加简短解释** 手动记录，或在生成完成后点击 **保存这段解释**。停止或失败的生成不会自动保存。

AI 讲解沿用 **专项翻译 → 划词翻译 → AI 深入讲解** 的服务、模型和原文范围。只有主动操作才发送当前表达、造句及允许参考的上下文和笔记，不发送整本收藏或来源网址。关闭、切换词条或修改模型会取消旧请求，失败可重试。

译文与解释分别保存，解释可编辑或清空。条目菜单还提供复制、掌握状态和删除；有译文时可复制双语。朗读失败可重试。

## 回忆与巩固

点击 **复习 N 条**，先回忆，再显示答案，最后选择 **记得** 或 **忘了**。只有这次评分会更新复习计划，查看讲解不会提高掌握度。

每轮最多 20 条，先处理到期旧收藏，再加入最多 10 条新收藏，不受当前列表筛选影响。有有效原句时，回忆句中缺少的表达；没有原句时，回忆表达的含义和用法。

## 在新网页里再次遇见

在 **管理收藏** 中开启默认关闭的 **再次遇见收藏表达**。附近正文中的已收藏表达会出现点状下划线；点击表达或右下角 **再次遇见**，对照当前原句与收藏原句。

打开卡片只读取本地收藏。点击 **理解当前用法** 才会使用划词 AI 设置，发送当前表达和允许参考的本次原句，不发送旧收藏参考或来源网址；未允许原句时需先调整设置。失败可重试，停止后保留已生成文字。

**标记选项** 可暂停本次页面访问或关闭所有网页标记；在学习中心可重新开启。看到表达、打开卡片和查看讲解都不改变收藏次数、掌握度或复习计划。

此功能仅用于浏览器扩展的普通网页，不用于无痕窗口或油猴版。链接、编辑器、代码等内容不参与标记。旧浏览器无法绘制标记时，仍可从右下角查看附近表达。

## 围绕材料继续学习

收藏、阅读问答与学习笔记按来源汇入 **阅读材料**，同名但不同地址的文章分别保留。点击 **继续阅读** 返回原句、文档页或视频时间；无法确认原文位置时，按提示搜索原句。地址变化后，可在 **整理材料** 中更新来源。

文档页点击 **加入学习材料**，保存文件指纹和当前位置。原文件记录缺失时重新选择原文件；同名但内容不同的文件不能替代原件。

在 **整理材料** 中添加主题和个人笔记。问答与学习笔记引用原记录，删除原记录后不保留回答副本，问答仍只保留 30 天。

**移除** 可恢复，不删除原收藏和问答；**清空全部材料** 永久删除材料组织、阅读位置和材料个人笔记。材料只保存在本机，不进入默认配置同步，打开材料不调用 AI，无痕窗口不可用。

在材料管理中使用独立的 **导出材料备份 / 恢复材料备份**。私密 JSON 含来源、原句、主题和个人笔记，与收藏和配置备份分开，请妥善保存。

超过 20 MiB 的材料备份会在本机分片校验、暂存，再一次性恢复。当前暂存材料记录总量最多 256 MiB、单条最多 128 MiB；可用空间不足或备份结构超出限制时请保留原材料与备份。若取消或断线后结果尚未确认，可在当前页面检查结果，或结束未完成的恢复；关闭页面后无法继续查询该次结果，请先检查材料列表。放弃查询不代表恢复已经取消或本机暂存已删除。清空全部材料会同时删除尚未提交的暂存内容。

## 数据与迁移

收藏和复习记录保存在当前浏览器。关闭收藏入口或清除翻译缓存不会删除它们。

| 需要保留什么 | 使用哪个入口 |
| --- | --- |
| 当前筛选列表的原文、译文、简短解释与复习记录 | **管理收藏 → 导出当前列表**，不含上下文和来源网址 |
| 完整收藏，包括上下文和来源 | **备份与恢复** |
| 转到 Anki 学习 | **管理收藏** 中导出 Anki，可选择原句与来源，解释有独立列 |
| 材料组织、位置和个人笔记 | 材料管理中的独立备份 |

**导入收藏** 合并 JSON，不清空已有内容，并报告新增、更新和跳过的数量。解释按修改时间合并，旧文件不会覆盖新解释或恢复已清空的解释。
