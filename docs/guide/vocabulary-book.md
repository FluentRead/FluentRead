# 学习中心与词书

把阅读中遇到的好词好句沉淀下来：结合原句理解用法、造句练习、间隔复习，并在未来浏览新网页时自动标记「再次遇见」，形成完整的语言内化闭环。

如需离线词典、自定义查词接口或划词学习卡模板，请参见[词典与学习卡](/guide/dictionaries)。

## 第一步：从阅读中收藏 {#从阅读中收藏}

1. 打开**工具与学习 → 学习中心 → 单词与句子**，在**管理收藏**中开启收藏入口。
2. 在网页、PDF 或视频字幕中划词打开翻译卡片，点击收藏图标（AI 回答下方的**收藏原文**同样可收藏）。
3. 回到**单词与句子**，点击句子的**听读与理解**或单词/短语的**学习用法**开始精学。

- **自动去重与检索**：重复收藏会合并补充新上下文而非创建重复词条；支持按原文、译文、解释与上下文全文搜索，并可按类型和掌握状态筛选。
- **隐私边界**：无痕/隐私窗口不写入收藏与记录；双语逐句高亮仅用于视觉对照，不会因鼠标划过而自动收藏或弹窗。

## 第二步：结合语境理解、造句与复习 {#理解与实际使用}

打开学习页不会自动调用 AI 或改变掌握度：

1. **听读与理解**：先听原句发音；需要进一步解释时点击**理解这个表达**查看含义、搭配与例句。
2. **主动造句反馈**：在**用自己的话说一句**输入框中写句子，点击**看看用得是否自然**获取用法点评（点评不会自动把词条标为「已掌握」）。
3. **保存个人解释**：可手动**添加简短解释**，或在 AI 生成完成后点击**保存这段解释**。
4. **间隔回忆复习**：点击**复习 N 条**（每轮最多 20 条，优先到期旧词并补充最多 10 条新词）。先回忆再看答案，点击**记得**或**忘了**才会更新复习计划。

::: info AI 讲解隐私控制
学习页沿用**划词翻译 → AI 深入讲解**的服务与模型，仅在点击理解或造句检查时发送当前表达、造句及允许参考的上下文/笔记，绝不上传整本词书或来源网址。
:::

## 第三步：在新网页里「再次遇见」 {#在新网页里再次遇见}

在**管理收藏**开启默认关闭的**再次遇见收藏表达**后：

- 浏览其他网页时，正文中出现过的已收藏表达会以柔和点状下划线标出（跳过链接、代码与编辑区）。
- 点击该表达或右下角**再次遇见**面板，即可对照**当前原句**与**当初收藏的原句**（仅读取本机收藏，不自动调 AI；主动点击**理解当前用法**才调用 AI）。
- 看到或点击卡片都不会改变掌握度与复习计划；可在**标记选项**中临时暂停当前页或全局关闭。此功能适用于浏览器扩展的普通网页（不含无痕窗口与油猴版）。

## 第四步：围绕阅读材料持续深读 {#围绕材料继续学习}

收藏、问答与笔记会自动按来源归类到**阅读材料**（同标题不同网址分别保留），PDF 与本地文档也可通过**加入学习材料**保存文件指纹与当前阅读进度：

- 点击**继续阅读**直接跳回原文章句子、文档页码或视频时间点；在**整理材料**中可添加主题与个人笔记。
- **移除**可恢复且不影响原收藏；**清空全部材料**会永久删除材料组织、阅读位置与材料个人笔记。
- 阅读材料仅保存本机，不进入默认配置同步，可通过材料管理中的**导出/恢复材料备份**单独迁移（超过 20 MiB 的大备份自动分片校验暂存，单条上限 128 MiB）。

## 数据备份、导出与 Anki 迁移 {#数据与迁移}

关闭收藏开关或清理翻译缓存均**不会**删除你的收藏与复习记录：

| 迁移需求 | 对应入口与说明 |
| --- | --- |
| **导出当前筛选词表** | **管理收藏 → 导出当前列表**（含原文、译文、简短解释与复习记录，不含上下文与来源网址） |
| **导出到 Anki 制卡** | **管理收藏 → 导出 Anki**（可自主勾选是否附带原句上下文与来源，解释占独立列） |
| **迁移完整收藏（含上下文）** | [本地完整备份](/config/backup-sync#本地完整备份)（勾选**包含单词上下文**） |
| **迁移阅读材料与进度** | **阅读材料 → 导出/恢复材料备份**（独立私密 JSON） |

**导入收藏**采用安全合并模式，不清空已有词条，并按修改时间保留较新的解释，不会用旧备份覆盖新编辑的解释。
