# WebDAV 配置云备份

更新日期：2026 年 10 月 4 日。

Google Drive 和 WebDAV 都位于**设置 → 备份与恢复 → 配置云备份**。选择 WebDAV 后，配置文件保存在你指定的网盘、NAS 或服务器中，由你主动保存、恢复或合并。两种备份方式分别记录连接和比较基线，不会自动把 Google Drive 的文件转存到 WebDAV。

备份默认只同步普通设置，敏感连接需明确同意后才可纳入此次操作；不包含单词本、聊天记录和用量统计。用于访问备份服务器的 WebDAV 地址、用户名及应用密码始终只保存在当前设备，不进入这份备份。此功能需要浏览器扩展后台；油猴脚本请使用本地配置备份。

## 本次同步范围

默认同步语言、外观、快捷键、网站规则等普通设置，排除整个敏感连接配置，包括 API Key、配置中的 OAuth Token、鉴权信息、翻译服务选择与模型、服务地址、自定义请求体及 URL 中的鉴权参数；私密提示词和未知字段也不上传。恢复或合并普通设置时，本机密钥、翻译服务、地址和自定义连接保持不变。

需要迁移敏感连接时，打开**本次包含 API Key 等敏感信息**，阅读风险、勾选确认，再点击**同意，仅本次包含**。保存或合并会包含本机敏感信息，恢复只应用云端备份实际包含的内容；只有普通设置的备份仍会保留本机密钥与连接。完成、失败（包括生成预览失败）、取消、离开或重新打开设置、切换供应商或账号后，开关恢复关闭，需要重新同意。

当前扩展仍可读取旧完整 v1 备份，默认只应用其中的普通设置；单次同意后保存的完整敏感备份沿用原 v1，旧扩展仍可读。新普通备份采用 v2，旧扩展会安全拒绝，必须升级。升级前尚未确认的事务失效，需要重新预览。

旧完整备份不会因关闭开关或仅恢复普通设置而被修改。只有确认保存或合并普通设置后，才会从当前云端文件移除敏感信息；这不会删除旧文件或服务商保留的历史版本，请另行管理这些副本。

## 准备服务器连接

服务器需要支持 Basic 鉴权，以及 `PROPFIND`、`GET`、`MKCOL`、`PUT`。更新已有备份还需要强 ETag，并遵守 `If-Match`、`If-None-Match` 条件，避免覆盖其他设备的修改。扩展依次从下载响应头、文件的 [`DAV:getetag` 属性](https://datatracker.ietf.org/doc/html/rfc4918#section-15.6)、`HEAD` 响应头读取 ETag；后两种方式还会条件重读并核对密文，防止把旧内容与新版本配对。建议使用有效证书的 HTTPS 和独立应用密码。属性响应按 XML 命名空间和指定目录解析，支持默认或局部前缀、CDATA 和字符引用；不会把其他文件或错误属性的版本用于覆盖。

填写的是**已存在目录的 WebDAV 地址**，不是网站首页、分享链接或备份文件地址。地址中不要放用户名、密码或查询参数。

以 Nextcloud 为例，通常为：

```text
https://cloud.example.com/remote.php/dav/files/你的用户名/
```

可从 Nextcloud 文件设置中复制个人 WebDAV 地址，在个人设置的安全页面创建应用密码。具体入口以 [Nextcloud 官方指南](https://docs.nextcloud.com/server/latest/user_manual/en/files/access_webdav.html) 为准。其他网盘或 NAS 请使用其 WebDAV 设置中提供的目录地址；目录账号必须有读取、创建目录和写入文件权限。

坚果云的入口地址为 `https://dav.jianguoyun.com/dav/`，用户名填写坚果云账号邮箱，密码使用[第三方应用密码](https://help.jianguoyun.com/?p=2064)。无需预先创建 `FluentRead` 文件夹；首次同步会先检查云端是否已有备份，在你确认保存后才创建目录和文件。入口地址检查通过、但备份父目录尚未创建时返回的 409，会按首次备份处理；真正的入口地址或权限错误仍会阻止同步。

## 第一次保存

1. 进入**配置云备份**，选择 **WebDAV → 设置 WebDAV**。
2. 填写目录地址、用户名和应用密码。HTTP 地址需要额外确认未加密传输的风险；优先改用 HTTPS。
3. 点击**测试连接**。测试只检查目录能否访问，不会创建或修改文件，也不能保证账号具有写入权限。
4. 点击**测试并保存**，把连接保存在当前设备。这一步仍不会创建云端备份。
5. 核对本次范围，点击**立即与WebDAV同步**。首次使用且云端没有备份时，预览会提示保存本机配置；默认仅普通设置，确认后才创建文件。

备份固定保存在所填目录下的：

```text
FluentRead/fluentread-config.encrypted.json
```

预览有效期为 10 分钟。点击**取消**或离开设置会结束本次预览，不删除已有备份。没有后台自动同步或持续连接。

## 在其他设备恢复或合并

在另一设备重新填写同一个 WebDAV 目录和账号。读取云端后，选择**恢复云端配置**或**保存本机配置**，点击下一步检查影响，再确认。

普通模式恢复或合并只应用普通设置，保留本机密钥、翻译服务、地址与自定义连接；保存会按本次范围替换当前云端文件。本次已同意包含敏感信息时，保存或合并可以纳入全部敏感连接，恢复仍以云端备份实际内容为准。两端都有要保留的修改时，使用次要入口**逐项合并**，为冲突选择本机或云端。敏感模式的凭据、服务、模型和自定义连接隐藏内容并按整组处理。

确认前会重新检查本机配置和云端版本。期间任何一端发生变化时，需要重新生成预览；已有文件的更新还会使用 ETag 条件写入。成功后显示本次账号与同步时间。

同步按钮右侧统一显示当前账号、服务器地址和该连接的上次同步时间；通过「修改连接」更换账号或服务器。确认页直接列出变更的设置名称和本机、云端值；连接配置说明改动的类别，密钥、地址及自定义内容仍隐藏。合并时先列出需要确认的冲突，再列出自动保留的修改。配置一致时只更新同步记录，不重复上传。

若三种读取方式都没有提供强 ETag，仍会打开预览，展示差异和**恢复云端配置**。界面会提前说明本次只能恢复，直接进入确认页，不展示保存、合并或多余的操作选择步骤；不会等到你确认保存后才报告版本缺失。恢复仍会重新核对云端内容，不能绕过鉴权、损坏文件或版本冲突。

## 换账号、停止使用和删除

使用**修改连接**更换服务器、账号或密码。地址或用户名改变时必须重新输入密码；修改连接后，旧预览和比较基线不能用于新连接。连接信息不会在密码框中回显。

**清除连接设置**只移除本机 WebDAV 连接、应用密码与同步记录，保留本机配置和云端文件。要删除云端备份，请在网盘或服务器中删除上述文件；需要停止授权时，可在服务商页面撤销应用密码。卸载扩展也不会自动删除服务器文件。

## 文件保护与常见问题

上传前在本机使用 AES-GCM 加密，沿用 Google Drive 的固定公开应用口令，无需另输加密密码。**得到文件的人可以按公开口令解密**。第三方账号被盗、共享目录被他人访问或备份泄露时，备份中的 API Key 等敏感信息可能泄露。保护主要依赖服务器账号、目录权限、HTTPS 和设备安全；建议只同步普通设置，迁移密钥时保护账号与目录权限，避免分享备份文件。详见[隐私政策](./privacy)。

| 提示 | 处理方式 |
| --- | --- |
| 用户名或密码不正确 | 核对账号和应用密码，确认服务允许 Basic 鉴权 |
| 目录不存在或不是有效 WebDAV 目录 | 使用服务商提供的完整目录地址，并开启 WebDAV |
| 无法连接 | 检查网络、证书和最终目录地址；扩展不会携带密码跟随重定向 |
| 云端备份可以恢复，但缺少安全覆盖所需的版本信息 | 在预览中检查差异后恢复；保存和合并暂不可用。更新需要服务器提供强 ETag 并支持条件写入 |
| 云端备份已变化 | 重新生成预览，检查其他设备的修改 |
| 存储不足或文件过大 | 释放服务器空间，或使用本地备份；配置 JSON 上限 20 MiB，密文文件上限 32 MiB |

协议细节见 [WebDAV 标准 RFC 4918](https://www.rfc-editor.org/rfc/rfc4918)。不同服务的权限、证书和条件写入实现可能不同，连接测试通过后仍应完成一次实际保存与恢复来确认兼容性。
