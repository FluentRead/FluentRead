# WebDAV 配置云备份

Google Drive 和 WebDAV 都位于**设置 → 备份与恢复 → 配置云备份**。选择 WebDAV 后，配置文件保存在你指定的网盘、NAS 或服务器中，由你主动保存、恢复或合并。两种备份方式分别记录连接和比较基线，不会自动把 Google Drive 的文件转存到 WebDAV。

备份包含完整配置，包括 API Key、配置中的 OAuth Token、鉴权请求头、自定义请求体及 URL 中的鉴权参数；不包含单词本、聊天记录和用量统计。WebDAV 连接地址、用户名及应用密码只保存在当前设备，不进入这份备份。此功能需要浏览器扩展后台；油猴脚本请使用本地配置备份。

## 准备服务器连接

服务器需要支持 Basic 鉴权，以及 `PROPFIND`、`GET`、`MKCOL`、`PUT`。更新已有备份还需要服务器返回强 ETag，并遵守 `If-Match`、`If-None-Match` 条件，避免覆盖其他设备的修改。建议使用有效证书的 HTTPS 和独立应用密码。

填写的是**已存在目录的 WebDAV 地址**，不是网站首页、分享链接或备份文件地址。地址中不要放用户名、密码或查询参数。

以 Nextcloud 为例，通常为：

```text
https://cloud.example.com/remote.php/dav/files/你的用户名/
```

可从 Nextcloud 文件设置中复制个人 WebDAV 地址，在个人设置的安全页面创建应用密码。具体入口以 [Nextcloud 官方指南](https://docs.nextcloud.com/server/latest/user_manual/en/files/access_webdav.html) 为准。其他网盘或 NAS 请使用其 WebDAV 设置中提供的目录地址；目录账号必须有读取、创建目录和写入文件权限。

## 第一次保存

1. 进入**配置云备份**，选择 **WebDAV → 设置 WebDAV**。
2. 填写目录地址、用户名和应用密码。HTTP 地址需要额外确认未加密传输的风险；优先改用 HTTPS。
3. 点击**测试连接**。测试只检查目录能否访问，不会创建或修改文件，也不能保证账号具有写入权限。
4. 点击**测试并保存**，把连接保存在当前设备。这一步仍不会创建云端备份。
5. 点击**立即与WebDAV同步**。首次使用且云端没有备份时，预览会提示保存本机配置；确认后才创建文件。

备份固定保存在所填目录下的：

```text
FluentRead/fluentread-config.encrypted.json
```

预览有效期为 10 分钟。点击**取消**或离开设置会结束本次预览，不删除已有备份。没有后台自动同步或持续连接。

## 在其他设备恢复或合并

在另一设备重新填写同一个 WebDAV 目录和账号。读取云端后，选择**恢复云端配置**或**保存本机配置**，点击下一步检查影响，再确认。

恢复会替换本机配置及凭据；保存会替换已有云端配置。两端都有要保留的修改时，使用次要入口**逐项合并**，为冲突选择本机或云端。凭据和自定义连接会隐藏内容并按整组处理。

确认前会重新检查本机配置和云端版本。期间任何一端发生变化时，需要重新生成预览；已有文件的更新还会使用 ETag 条件写入。成功后显示本次账号与同步时间。

## 换账号、停止使用和删除

使用**修改连接**更换服务器、账号或密码。地址或用户名改变时必须重新输入密码；修改连接后，旧预览和比较基线不能用于新连接。连接信息不会在密码框中回显。

**清除连接设置**只移除本机 WebDAV 连接、应用密码与同步记录，保留本机配置和云端文件。要删除云端备份，请在网盘或服务器中删除上述文件；需要停止授权时，可在服务商页面撤销应用密码。卸载扩展也不会自动删除服务器文件。

## 文件保护与常见问题

上传前在本机使用 AES-GCM 加密，沿用 Google Drive 的固定公开应用口令，无需另输加密密码。**得到文件的人可以按公开口令解密**，因此保护主要依赖服务器账号、目录权限、HTTPS 和设备安全；请勿公开分享备份文件。详见[隐私政策](./privacy)。

| 提示 | 处理方式 |
| --- | --- |
| 用户名或密码不正确 | 核对账号和应用密码，确认服务允许 Basic 鉴权 |
| 目录不存在或不是有效 WebDAV 目录 | 使用服务商提供的完整目录地址，并开启 WebDAV |
| 无法连接 | 检查网络、证书和最终目录地址；扩展不会携带密码跟随重定向 |
| 没有安全更新所需的 ETag | 仍可恢复已有备份；保存修改需要支持强 ETag 和条件写入的服务器 |
| 云端备份已变化 | 重新生成预览，检查其他设备的修改 |
| 存储不足或文件过大 | 释放服务器空间，或使用本地备份；配置 JSON 上限 20 MiB，密文文件上限 32 MiB |

协议细节见 [WebDAV 标准 RFC 4918](https://www.rfc-editor.org/rfc/rfc4918)。不同服务的权限、证书和条件写入实现可能不同，连接测试通过后仍应完成一次实际保存与恢复来确认兼容性。
