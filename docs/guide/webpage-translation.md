# 全文与局部翻译

在原网页中逐段对照阅读原文与译文，或仅框选需要的段落与评论区进行翻译，随时可一键恢复原文。

<DocDiagram kind="webpage-modes" />

## 全文翻译 {#页面翻译}

1. 打开文章，点击浏览器工具栏中的流畅阅读图标（或按默认快捷键 `Alt+T` / `Option+T`）。
2. 确认**目标语言**和**翻译服务**，点击**翻译**。
3. 默认双语对照阅读：
   - 点击弹窗翻译卡片右下角的显示模式按钮，可在**双语 / 仅译文**间即时切换（无需重新请求）。
   - 点击**恢复**随时回到原文并结束本次翻译会话。
   - 在弹窗选择服务时按 `Esc` 返回服务概览，再按一次回到主界面。

### 实用细节

- **单站仅译文**：想只让某些网站隐藏原文，在**工具与学习 → 网站规则 → 网站偏好**勾选**仅显示译文**，其他网站继续沿用全局模式（详见[网站阅读范围](/config/site-adaptation)）。
- **一键切换易读字体（Aa）**：网页字体难读时，点击卡片右下角 **Aa** 切换为浏览器默认字体，再点恢复原字体。该偏好跨网页保存并立即生效；保存失败时可就地点击**重试**。
- **随滚随译与去重缓存**：默认随阅读位置逐步翻译（含新展开的评论和动态加载正文），也可在设置中改为整页处理。同页重复段落自动复用结果，开启翻译缓存后后续批次及重译亦可复用（语言、服务、上下文不同或 AI 多段依赖邻段时分别处理）。
- **智能跳过与格式保留**：已属目标语言或「不翻译的语言」的段落尽量保持原文，简繁差异仍可转换；正文带删除线的文字在双语译文中保留删除线。

## 学术论文一键阅读 {#阅读学术论文}

扩展版为常见学术论文站提供直达入口：

| 平台 | 入口按钮 | 打开方式 |
| --- | --- | --- |
| **arXiv（含 HTML 版）** | **双语翻译（流畅阅读）** | 在新标签打开官方 HTML 正文并从当前阅读位置开始翻译，原站目录、公式与引文保持可用 |
| **PubMed Central** | **双语翻译（流畅阅读）** | 直接在当前全文页开始双语翻译 |
| **Hugging Face Papers / ACL Anthology / CVF / NeurIPS / 仅 PDF 的 arXiv** | **PDF 阅读（流畅阅读）** | 直接在[文档翻译阅读器](/guide/document-translation)中打开原 PDF 文件 |

## 局部翻译 {#局部翻译}

当页面信息密集，只想翻译文章正文、GitHub README 或评论区时：

1. 点击菜单中**翻译**旁的**局部**（或在**设置 → 翻译设置 → 局部翻译**开启 `Alt+R` / `Option+R` 快捷键）。
2. 移动鼠标预览高亮区块，单击锁定；也可按住鼠标左键连续划过多个段落后松开锁定。
3. 使用工具条上的**扩大范围 / 缩小范围**或键盘 `↑ / ↓` 微调选区，再点击**翻译所选区域**或按 `Enter` 开始。

- **安全交互**：选择期间不会误点网页链接或按钮；鼠标移动时会等待落点稳定减少跳动，移入操作条不改变选区；按 `Esc`、右键或关闭按钮退出。
- **局部恢复与重试**：再次选中已翻译区域并确认**恢复原文**，即可只恢复该区域；含失败段落时可重新确认以重试。
- **翻译页眉/侧栏**：全文翻译默认跳过页眉、导航和侧栏；通过局部翻译主动选中时仍可翻译，其中界面文字自动仅显示译文以防撑乱布局。

### 记住常用区域 {#记住常用区域}

锁定区域后勾选**记住此区域**：

1. 选择生效范围：**当前目录** 或 **整个网站**。
2. 选择下次访问行为：**提醒我翻译**（默认）或 **自动翻译**。
3. 点击**翻译并记住**保存（多段划选可一并保存）。

在**局部翻译 → 记住的区域**中可管理最多 100 条规则，并可为规则指定独立翻译方案；若站点改版导致旧规则匹配不到内容，页面保持原样，删除旧规则重选即可。

## AI 智能上下文与术语 {#ai-上下文与用词}

在弹窗打开**翻译服务 → AI 智能上下文**并选用支持的 AI 服务后，新翻译会参考页面主题、当前章节、附近段落及前文定义，减少一词多义与指代误判。

- 默认关闭；开启后不会改写已有译文（需先恢复再重译），并会向所选服务发送额外页面文字。
- 短页面参考直接带入，省去额外摘要请求；长参考生成精简摘要并可随翻译缓存复用；相邻正文可搭配[AI 多段翻译](/config/translation-engines#ai-精翻与多段翻译)减少重复提示词。
- 需要严格锁定专有名词译法或保留原文时，请配合[术语库](/guide/glossary)（同时适用于机器翻译与 AI 翻译）。

## 翻译失败与断点恢复 {#翻译失败后继续阅读}

- **单段与批量重试**：失败段落可直接点击重试；开启**全文翻译进度面板**后，可点击**定位失败段落**或**重试失败项**，保留成功译文与当前阅读位置（尚未滚动到的段落不计为失败）。
- **冷却提示**：服务返回限流冷却时间时，提前点击重试会提示剩余等待秒数。
- **弹窗优先与安全取消**：若网页弹出遮挡正文的对话框，会先翻译弹窗，关闭后继续正文；恢复原文会立即取消挂起任务，站内路由切换阅读规则时会先恢复原文。
- 正文大面积漏译请检查[网站阅读范围](/config/site-adaptation)；图片/图表文字请使用[图片翻译](/guide/image-translation)或[圈选翻译](/guide/area-translation)。

### 个人校订

在**设置 → 翻译设置 → 阅读辅助**开启**个人校订**（默认关闭）。悬停在双语译文上点击**校订译文**或按 `Alt+Shift+E`，编辑后先**预览受影响句子**再**确认保存**。

- **作用域**：默认**仅当前网页**（含查询参数和片段区分）；需跨页面复用时创建项目并手动加入相关页面。仅原句、语言方向与章节标题完全一致时自动复用，冲突译法不自动采用。
- **限制与存储**：仅存本机，最多 1,000 条记录与 100 个项目，不进入术语库、配置备份或云同步；仅支持纯文本双语网页段落（不支持仅译文模式、受保护代码/公式、PDF、字幕与油猴版）。

</details>

### 页面悬浮球

**设置 → 常规 → 网页辅助 → 全文翻译悬浮球**默认关闭。开启后半透明贴边吸附，单击翻译整页、再点恢复，图标显示翻译中/已完成/需重试状态；按住可拖动到屏幕左右任意高度。

- 悬停、Tab 聚焦或轻点展开工具条，齿轮打开快捷面板，按 `Esc` 逐层返回。
- 桌面默认边距 `0 px`、弹出边距 `20 px` 时移开自动半隐藏；点击工具条 **×** 可选**隐藏至刷新**、**在此网站隐藏**（含子域名）或**在所有网站隐藏**。油猴版 **×** 直接隐藏至刷新。

### 右键翻译

右键普通位置可翻译整页，选中文字后右键可**翻译选中文本**，右键图片可翻译图片（需在设置开启对应入口）。若只想用右键划词，在**专项翻译 → 划词翻译 → 划词触发方式**选择**仅右键菜单**。

</details>

<details class="guide-details">
<summary>自动翻译、页面识别与段落处理微调</summary>

### 自动翻译与多语言 {#自动翻译与网站规则}

常用网站可在[网站阅读范围](/config/site-adaptation)开启自动翻译或禁用扩展。源语言可自动检测或显式指定；各翻译服务支持的语言对存在差异。

### 页面识别与兼容说明 {#更多翻译语言}

- 按钮、标签页与表单标签在双语模式下默认仅显示译文，避免挤乱排版；输入框内容、原始 XML/RSS/SVG、独立时间/数字计数及 GitHub 代码行保持原文。
- 扩展同时支持标准 Hugging Face Space 内嵌应用。
- 菜单或导航漏译时，可在**高级选项 → 页面识别**临时开启**识别全部节点**并恢复重译。

### 调整段落处理方式

在**高级选项**中可微调：
- **侧边栏翻译**：正文外额外处理导航与侧栏（保留页眉页脚）。
- **翻译段落最少字符数**：跳过零碎短文本以减少请求。
- **免滚动预翻译字符数**：默认 `0`，调大后提前翻译页面开头指定字数。
- **长段落自动换行**：在译文句末插入换行提升长段可读性。
- **双语上下顺序**：原文在上或译文在上，切换后立即复用已有译文调整。

</details>
