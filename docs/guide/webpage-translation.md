# 网页翻译

翻译整篇文章或选定区域，对照原文阅读，也可随时恢复。

<GuideVisual kind="webpage" />

## 页面翻译

1. 打开文章，点击浏览器工具栏中的流畅阅读图标。
2. 选择目标语言和翻译服务，点击 **翻译**。
3. 默认双语阅读。翻译卡片右下角的显示模式按钮可切换 **双语 / 仅译文**；点击 **恢复** 回到原文。

显示模式会保存，已有译文立即调整，无需重译。Google 翻译只支持双语；使用该服务前，请先切回双语。

只想让某些网站显示译文时，在 **工具与学习 → 网站规则 → 网站偏好** 为该网站勾选 **仅显示译文**。其他网站沿用全局模式，详见[网站阅读范围](/config/site-adaptation)。

正文中以删除标签标记的文字，双语译文会保留删除线。

字体难读时，点击卡片右下角 **Aa**，切换浏览器默认字体，再点恢复原有字体。这个选择会保存并应用到所有网页，已有和后续译文立即更新，刷新后仍保留。保存失败时，卡片内会显示提示，可点击 **重试**。

默认随阅读位置逐步翻译，新展开的评论和后来加载的正文也会继续处理。若需要一次处理整页，可在设置中调整翻译范围。恢复原文会结束本次翻译；换语言或服务后，可重新开始。

同页不同位置出现完全相同的段落时，相同翻译请求会共用结果；普通批次中的重复文本也只发送一份，再回填到各个位置。开启翻译缓存后，后续批次和恢复后重译还可复用已有译文。语言、服务或影响译文的上下文不同，以及 AI 多段翻译中依赖邻段的文本，会分别处理。

已属于目标语言或“不翻译的语言”的段落会尽量保留。译文与原文相同时也不显示重复内容；简繁有差异时仍可转换。语言判断可能有误，漏译时请检查源语言和网站规则。

## 阅读 arXiv 论文

在 arXiv 摘要页的论文访问区点击 **双语翻译（流畅阅读）**，打开对应版本的官方 HTML 正文。流畅阅读用你配置的语言和服务，从当前阅读位置开始翻译，原站目录、公式和引文仍可使用。

只有 PDF 的论文会显示 **PDF 阅读**，点击后在流畅阅读的[文档阅读器](/guide/document-translation)打开原文件。原站的 PDF 和 HTML 链接仍可直接使用。此入口适用于浏览器扩展。

## AI 上下文与用词

在扩展弹窗打开 **翻译服务 → AI 智能上下文**，开启上下文偏好，并选用已配置、支持该能力的 AI 服务。之后的新翻译会参考页面主题、当前章节、附近段落及可用的前文定义和已译内容，帮助模型判断一词多义与上下文中的指代。开启开关不会重写已有译文；需要重新应用时先恢复原文，再翻译。

这是有长度限制的参考，不能保证读到整篇文章或消除所有歧义；缺少证据时仍可能误译。该能力默认关闭，开启后会向所选服务发送额外页面文字，可能增加请求量与费用。普通机器翻译和部分专用翻译模型不支持它，弹窗会说明当前状态。

需要固定术语译法，或指定单词保留原文时，使用[术语库](/guide/glossary)。术语库可同时用于机器翻译与 AI 翻译。

## 局部翻译

只想读文章、README 或评论区的一部分时：

1. 点击 **翻译** 旁的 **局部**，移动鼠标预览高亮范围。
2. 单击锁定区域；用 **扩大范围 / 缩小范围** 或 **↑ / ↓** 调整。也可按住鼠标左键划过多个段落，松开锁定。
3. 点击 **翻译所选区域**，或按 **Enter** 确认。单击锁定本身不会开始翻译。

快速划过或折返也会保留途经区域。拖动时先显示范围，松手后统一检查可翻译内容。移动鼠标预览时，会等落点稍稳定后再换区，减少高亮框跳动；移到操作条不会改变选区。

**重新选择** 可重新点选；**Esc**、右键或关闭按钮退出。选择期间不会打开网页链接或触发按钮。选区锁定后可滚动核对内容。

再次选择已翻译区域并确认 **恢复原文**，会停止剩余任务并恢复这一部分；有失败段落时可重新确认翻译以重试。恢复整页也会恢复局部译文。暂停插件或离开页面会停止未完成任务。

局部翻译默认沿用网页服务、语言和显示方式。常用时可在 **设置 → 翻译设置 → 局部翻译** 开启 **Alt+R** 快捷键（Mac 为 Option+R）；独立方案见[快捷键](/guide/custom-hotkey)。

全文翻译通常保留页眉、导航和侧栏；主动选择这些区域仍可翻译，其中的界面文字直接显示译文，避免挤乱布局。

### 记住常用区域

锁定后勾选 **记住此区域**，选择 **当前目录 / 整个网站**，再选择下次 **提醒我翻译 / 自动翻译**，点击 **翻译并记住** 保存。默认只在当前目录提醒；未勾选时仅翻译本次。多段划选也可一起保存。

下次匹配到页面时，只处理记住的区域。提醒可在本次访问中关闭，没有找到对应区域时保持原样。网站结构改变后，可删除旧规则并重新选择。

在 **局部翻译 → 记住的区域** 管理、启停或删除规则，最多 100 条。可指定独立翻译方案；原方案缺失时，重新选择或改为 **跟随默认** 后才能继续。

## 翻译失败后继续阅读

弹窗的翻译按钮出现提示图标时，点击图标可查看原因和可用的恢复操作。

失败段落可直接重试。开启 **全文翻译进度面板** 后，还可点击 **定位失败段落** 或 **重试失败项**，只重试当前会话的失败内容，保留成功译文和阅读位置。未滚动到的段落不计为失败。

页面有遮挡正文的弹窗时，会先翻译弹窗，关闭后继续正文。恢复原文会同时取消后续任务，旧重试入口不会重新启动。站内跳转若切换了阅读规则，页面会先恢复原文，在新页面重新点击翻译即可。

正文漏译、只翻译了导航时，参阅[网站阅读范围](/config/site-adaptation)。图片或图表里无法选中的文字，使用[图片翻译](/guide/image-translation)或[圈选翻译](/guide/area-translation)。

### 个人校订

在 **设置 → 翻译设置 → 阅读辅助** 开启 **个人校订**（默认关闭）。在双语译文上停留，点击 **校订译文**，或按 **Alt+Shift+E**。修改后先 **预览受影响句子**，核对范围，再 **确认保存**。

默认 **仅当前网页**，地址不同（含查询参数和片段）分开保存。需要跨相关页面复用时，创建项目并主动将各页面加入。只有原句、源/目标语言和章节标题完全一致时才自动复用；相近句子只提供草稿参考，冲突译法不会自动采用。

编辑器可管理、修改、删除记录和撤销上次操作；已有后续修改的操作不能撤销。删除校订、退出项目或关闭功能后，恢复原服务译文；没有服务译文时先恢复原文，可再次翻译。关闭功能不会删除记录。

校订仅保存在本机，最多 1,000 条、100 个项目，不进入术语库、配置备份或云同步。仅支持可安全编辑为纯文本的网页双语段落；仅译文模式、含代码或公式等保护内容、PDF、字幕和油猴版暂不提供入口。

</details>

### 页面悬浮球

**设置 → 常规 → 网页辅助 → 全文翻译悬浮球** 默认关闭。开启后，悬停、键盘聚焦或触屏轻点展开；点击翻译按钮翻译整页，再次点击恢复。按住可拖动到两侧，位置会保存。

齿轮按钮打开当前网页的快捷面板；点击空白处或按 Esc 收起。**悬浮球进阶设置** 可调整始终显示或悬停展开、展开延迟、本体点击行为、大小、透明度、默认边距和弹出边距，以及不显示的网站。边距单位为 px，可设为负数；悬停模式下两种边距相同可避免横向移动。关闭悬浮球不影响 Alt+T 或右键菜单。

### 右键翻译

右键网页普通位置可翻译整页；选中文字后右键可 **翻译选中文本**；右键图片可翻译图片。相关入口需要在设置中开启。

只想通过右键划词，可在 **专项翻译 → 划词翻译 → 划词触发方式** 选择 **仅右键菜单**，并保持对应右键入口开启。选区失效时重新选择；失败后可在卡片重试。

</details>

## 自动翻译与网站规则

常读的网站可设置自动翻译，需要保持原样的网站可单独关闭。设置方法见[网站阅读范围](/config/site-adaptation)。

## 更多翻译语言

源语言可自动检测，也可明确指定。不同服务和模型支持的语言不同，出现在语言列表中不代表所有服务都支持；图片识别和视频识别还有各自的语言限制。

### 页面识别与兼容说明

按钮、标签页和表单标签等操作文字在双语模式下也只显示译文，避免挤乱布局；恢复时还原。输入框内容和会随表单提交的操作值保持原样。独立时间、数字、持续变化的计数通常不翻译，含这些信息的正常句子仍可翻译。

原始 XML、RSS、SVG 文件不注入译文；普通 HTML、XHTML 网页可翻译。GitHub 代码行保持原样，提交说明和评论可翻译。浏览器扩展也支持标准 Hugging Face Space 的内嵌应用；自定义域名或含点、下划线的特殊地址暂未覆盖。

菜单或导航漏译时，可开启 **设置 → 高级选项 → 页面识别 → 识别全部节点**，恢复后重译。范围扩大也会改变更多操作文字，不需要时关闭。

### 调整段落处理方式

在 **高级选项** 可调整：

- **侧边栏翻译**：正文之外也处理导航与侧栏，页眉页脚仍保留。
- **翻译段落最少字符数**：跳过短段落，减少零碎请求。
- **免滚动预翻译字符数**：默认 0；调大后提前处理页面开头的指定字符数，其余仍随阅读翻译。
- **长段落自动换行**：在译文句末换行。
- **双语上下顺序**：原文或译文在上，立即复用已有结果调整；其他选项在下次翻译生效。
