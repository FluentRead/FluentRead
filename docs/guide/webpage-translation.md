# 网页翻译

翻译整篇文章或选定区域，在原文下方查看译文，方便对照阅读，也可随时恢复原文。

译文与原文相同时，只保留原文，不再显示重复译文。比较时忽略首尾空白、换行和重复空格，保留实际文字、大小写、标点及简繁差异。这条规则也适用于划词、输入框、圈选、图片、视频字幕和文档；双语复制与导出同样避免重复。翻译中心用于对比不同服务的输出，即使译文与原文相同，也会保留显示和复制。

## 页面翻译

1. 打开想读的文章，点击浏览器工具栏中的 FluentRead 图标。
2. 选择目标语言与翻译服务，点击 **翻译当前网页**。
3. 默认双语对照阅读；想只看译文，切换 **仅译文**。点击 **恢复当前网页**，即可回到原文。

默认随阅读位置逐步翻译。如果需要一次处理整页，可以在设置中调整翻译范围。恢复原文后，可以换语言或服务再次翻译。

扩展面板等待页面操作时会显示加载状态，全文与局部按钮暂时不可重复点击。切换标签页、导航到新页面或暂停插件后，旧页面的回复不会改变新页面的按钮状态；在新页面重新点击所需操作即可。

已经属于目标语言的段落会保留原文。有明确中文语境的段落不会因为夹有浏览器名称、构建术语、参数、单位或仓库链接就重复翻译。中文技术句子中有代码或缩写证据时，小写术语与箭头、斜杠连接的处理链也会按中文语境判断。完整外语句子、需要解释的外语词和不确定的混合内容仍会翻译；简体与繁体中文之间的转换也会保留。

| 想做什么 | 使用哪项操作 |
| --- | --- |
| 对照原文核对意思 | 双语对照 |
| 只读译文 | 仅译文 |
| 只翻译文章或评论区的一部分 | 下方的局部翻译 |
| 回到原网页 | 恢复当前网页 |

### 页面悬浮球

**全文翻译悬浮球** 默认关闭。在 **设置 → 常规 → 网页辅助** 中开启后，快捷入口默认半隐藏在网页边缘；鼠标悬停、键盘聚焦或触屏轻点时展开，移开鼠标后重新收起，按 Escape 也可收起。鼠标点击留下的焦点不会阻止收起，键盘聚焦时则保留工具方便操作。点击即可翻译整页，再次点击恢复原文；翻译状态只显示在翻译按钮上，品牌图标保持原样。按住可以上下拖动，松手后自动停靠到离得更近的一侧，展开时与页面滚动条保持间距。拖动后的停靠侧和高度会自动保存，在其他网页和刷新后继续使用；窗口大小改变时，悬浮球会保持在可见区域内。已保存的开关和按钮显示方式继续生效。

也可以在设置页搜索“全文翻译悬浮球”，直接定位开关；搜索“悬浮球进阶设置”则会定位到显示方式、位置和网站名单等详细选项。

下方的 **悬浮球进阶设置** 可以进一步调整：

- **按钮显示方式**：翻译与设置按钮可以悬停时展开、始终显示，或完全隐藏只保留悬浮球本体。
- **展开延迟**：鼠标停留多久后展开按钮，默认立即展开；调大可以避免划过页面边缘时误展开。键盘聚焦始终立即展开。
- **点击行为**：点击悬浮球本体可以切换翻译、打开设置页，或设为仅拖动。无论选择哪一项，按住都可以拖动调整位置。
- **缩小悬浮球**：以更小的尺寸显示，减少对网页内容的遮挡。
- **显示设置入口**：关闭后悬浮球不再显示打开设置页的按钮。
- **收起时不透明度**：数值越小越透明；鼠标悬停、展开和拖动时始终完全清晰。
- **不显示悬浮球的网站**：按主域名添加，该网站及其子域不再显示悬浮球，快捷键、右键菜单和其他功能仍然可用。

关闭悬浮球不会影响全文翻译快捷键（默认 Alt+T）和右键菜单入口。

## 翻译失败后继续阅读

开启“全文翻译进度面板”后，面板会显示已完成与失败的段落数。队列结束但仍有失败时，摘要会保留：点击 **定位失败段落** 跳转到失败位置，点击 **重试失败项** 只重新处理当前会话的失败段落，保留成功译文和阅读位置。单个段落原有的重试入口仍可使用。

弹窗优先阅读期间，汇总操作只处理弹窗内的失败段落；正文失败等待关闭弹窗后再重试。恢复原文会取消当前会话；原面板及旧段落的重试操作不会启动新请求。离屏段落仍会在滚动到附近时翻译，未进入视口不计为失败。

## 局部翻译

只想读网页中的一部分时，例如 GitHub 项目的 README、文章正文或某个评论区，不必翻译整页。点击扩展菜单里 **翻译当前网页** 旁的 **局部** 按钮，网页进入选择模式：

- 移动鼠标预览，高亮框会标出当前范围；标签会显示段落、列表、表格、文章或区域等范围类型，以及可翻译内容的状态。
- 单击网页区域只锁定选择，不会立即翻译。锁定后，工具条提供 **扩大范围**、**缩小范围**、**重新选择**、**翻译所选区域**（已翻译时为 **恢复原文**）和关闭按钮。点击 **重新选择** 可回到悬停预览。
- 按 **↑** 扩大到外层区域，按 **↓** 缩小回来；锁定后也可以用工具条调整范围。焦点在工具条或其按钮上时，方向键仍可调整范围；用 **Tab** 聚焦按钮后，**Enter** 执行该按钮。
- 点击 **翻译所选区域**，或按 **Enter** 确认，只翻译当前范围。预览和锁定状态下都可以按 **Enter** 确认。视口内的段落先翻译，其余随后完成；显示方式、翻译服务和目标语言与全文翻译相同。
- 再次选择已经翻译的区域后，点击 **恢复原文** 或按 **Enter** 确认，才会恢复这块区域的原文；区域里有翻译失败的段落时，确认翻译会重试它们。
- 按 **Esc**、点击右键或点击工具条上的关闭按钮退出。选择期间点击网页不会打开链接或触发按钮。

经常使用时，可以在 **设置 → 翻译设置 → 局部翻译** 中开启快捷键（默认 **Alt+R**，Mac 为 Option+R），选择模式中再按一次即可退出。页眉、导航和侧栏在全文翻译中通常保持原文；主动选择这类区域时，其中的文字也会翻译，并像按钮、菜单等界面文字一样直接替换原文显示，避免撑乱版面。恢复全文翻译时，局部翻译的内容会一并恢复原文。

## 更多翻译语言

源语言和目标语言现在提供 52 个语言选项，包括简体中文、繁体中文、德语、葡萄牙语、意大利语、阿拉伯语、印地语、越南语、泰语、乌克兰语和斯瓦希里语等。输入框翻译与写作助手也使用同一份语言列表；源语言仍可选择自动检测。原有语言设置会保留。

选择语言后，使用支持该语言对的翻译服务。不同机器翻译服务、AI 模型和 Chrome 内置翻译的语言范围不同；语言出现在列表中不代表每项服务都支持。图片文字识别和视频语音识别仍取决于各自的识别语言包或模型。

DeepL 当前不支持卡纳达语和僧伽罗语，选择这些语言时会提示切换服务。谷歌、小牛的挪威语以及微软的塞尔维亚语会自动转换为对应接口的语言代码；无需手动修改。

### 右键翻译

选中文字后右键，选择“翻译选中文本”打开划词翻译。右键网页普通位置可翻译全文，翻译后同一入口变为“显示页面原文”；右键图片可翻译图片。菜单使用扩展图标和操作名称，不再显示品牌名称、目标语言或快捷键。每个场景优先显示一个操作，不再创建分组子菜单。全文翻译也可以从工具栏的扩展面板发起。

如果选中文字只是为了复制或阅读，不希望旁边出现划词入口，可在 **设置 → 专项翻译 → 划词翻译 → 划词触发方式** 选择 **仅右键菜单**。此时划词图标和小点都不显示；需要翻译时，选中文字后右键选择“翻译选中文本”。请保持右键菜单及该入口开启。翻译卡片的选区提示由其独立设置控制。

::: details 页面识别与兼容说明

打开扩展菜单，点击“翻译页面”。默认将原文与译文按段落排列，方便随时核对；原文保留标题、链接和正文结构不变。带链接、加粗、斜体或脚注标记的段落会整段作为一次翻译单元，译文以通顺的整段文本呈现，避免句子被行内格式拆成碎片后逐片翻译，机器翻译服务的这类段落也只发一次请求；含行内代码、公式或图片的段落仍按片段翻译，以便在译文中原样保留这些内容。阅读论文或 Codeforces 题面时，文字周围的常见公式也会尽量保留原来的显示。Codeforces 比赛卡片中的状态、名称和注册链接分别翻译，实时倒计时仅保留原站点的一份，秒数变化不会反复重建译文。

直接打开原始 XML、RSS 或 SVG 文件时，FluentRead 不会向文档注入翻译内容或样式，以保留浏览器原生的文件展示；正常 HTML 与 XHTML 网页仍可翻译。

全文翻译中，快速完成或命中缓存的段落直接显示译文；等待稍久的段落才显示加载图标，减少图标闪烁。GitHub 文件和对比页中的代码行保持原样，提交说明和代码审查评论仍可翻译。

“按阅读进度”会优先处理当前屏幕，再预翻译上下约 600 像素内的内容。连续滚动时暂停派发新段落，停顿约 220 毫秒后按当前位置继续；快速划过并离开附近范围的待翻译段落，会等到再次读到时再处理，已经发出的请求会继续完成。高级选项中的“免滚动预翻译字符数”默认是 0；需要提前翻译页面开头的一部分内容时，可以自行调大。

网页中的固定高度内容卡片会在译文溢出时自动增高，避免压住相邻内容。带行数截断的卡片摘要也会临时展开，让双语译文完整显示；恢复原文后还原原有高度与截断样式。独立滚动区域仍保留原来的滚动方式。

OpenRouter 的模型列表、供应商列表和模型详情页会保留模型名称原文，模型介绍继续翻译。

页面出现需要先处理的公告或模态弹窗时，全文翻译会优先处理当前弹窗，等你关闭后自动继续原页面。翻译途中出现公告也会暂停尚未完成的正文任务，保留已经显示的译文。开启翻译进度提示时，等待期间会显示“关闭弹窗后自动继续翻译”；点击“恢复原文”会同时取消自动续译。普通提示条和非阻塞面板不会让全文翻译一直等待。

开启翻译进度提示后，短暂的任务不会立刻弹出面板；面板显示后，会等任务持续空闲一小段时间再收起，避免快速翻译或滚动时反复闪烁。进行中与剩余数量仍实时更新。点击关闭会隐藏本次全文翻译的提示，恢复原文也会立即结束提示；下次全文翻译会重新按需显示。

将 FluentRead 固定到浏览器工具栏后，图标右下角会显示浏览器原生角标：蓝底省略号（…）表示正在翻译，绿底白色对勾（✓）表示当前已进入翻译的内容完成，橙底白色感叹号（!）表示有内容翻译失败，可以在页面中点击“重试”。默认随阅读位置翻译时，尚未滚动到的内容会稍后处理。恢复原文、关闭翻译或刷新页面后，图标恢复原样。

#### 按钮和操作文字只显示译文

按钮、标签页、表单标签和工具栏里的操作文字是界面控件，宽高由网站样式固定。双语模式下这类文字**只显示译文、替换原文**，不再叠加一行原文，避免按钮被撑高、文字溢出或整排工具栏错位。原生按钮、`role` 声明的控件、按钮样式的链接，以及用输入框实现的按钮都按同一规则处理。恢复原文会把按钮文字还原为原始内容。

正文段落、标题和折叠区域里的完整句子仍按所选的显示模式呈现，双语对照不受影响。

会随表单一起提交的按钮（带 `name` 的提交按钮）和输入框中的内容保持原文，避免翻译后网站收到无法识别的操作或改动你输入的文字。

#### 补充翻译菜单和动态界面

某些网站的菜单、按钮或导航文字没有被翻译时，可在 **设置 → 高级选项 → 页面识别** 中开启 **识别全部节点**。先恢复原文，再重新翻译。此选项会保存，也会处理翻译期间新展开的可见菜单。

识别范围更大时，页面里的操作文字也可能发生变化。不需要时关闭，下一次翻译恢复默认范围。图片、图表里无法选中的文字，请使用[图片翻译](/guide/image-translation)或[圈选翻译](/guide/area-translation)。

#### 时间、数字与持续变化的内容

独立的日期、时钟、时长（如 `12:34 PM`、`5 minutes`、`1小时2分3秒`）和纯数值保持原文，不发送翻译请求。包含这些信息的正常句子仍可翻译。网页用 `<time>` 或 `role="timer"` 标记的时间展示也保持原文。

翻译期间来源文字变化后，全文翻译会等它稳定约 1.8 秒，再处理最新内容，减少反复撤下和插入译文。短时间内连续只改变数字的短标签（如访问计数、进度）会保持原文；同一位置换成其他内容后可重新翻译。这些规则同样用于悬浮翻译；悬浮时遇到仍在变化的内容，待其稳定后再次触发即可。

#### 调整段落处理方式

**设置 → 高级选项** 还提供几项网页翻译的细节控制，修改后在下一次翻译生效：

- **侧边栏翻译**：正文范围下一并翻译侧边栏和导航区域，页眉页脚仍保持原文。
- **翻译段落最少字符数**：短于该长度的段落不再翻译，可以减少零碎短句带来的请求。这里的长度按字符计算，例如 `hello` 是 5 个字符。
- **免滚动预翻译字符数**：默认为 0，完全按视口触发。调大后，启动全文翻译时会提前翻译页面开头的这部分内容；为保持段落完整，最后一段可能略超出额度。其余内容仍按阅读进度翻译。已保存的自定义数值会保留。
- **长段落自动换行**：在长段落译文的每句话结束处插入换行，便于阅读。
- **译文在原文之前**：双语模式下把译文放在每段原文前面，默认排在原文之后。
