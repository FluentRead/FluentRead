# 写作助手

在 Gmail、GitHub、Outlook、X、Reddit、LinkedIn、Slack、Discord、Notion 的编辑器旁，以及任意常规网页的输入框中起草或完善内容。先检查结果，再插入编辑器，由你决定何时发送。

<GuideVisual kind="writing" />

## 开始前

打开**设置 → 写作助手**，开启功能并选择 AI 服务与模型。缺少连接信息时，先到[翻译服务](/config/translation-engines)中配置。输出语言、对照语言、篇幅、语气和通用呼出快捷键可在设置中保存，也可在写作时临时调整。

## 支持的网站与呼出方式

### 一等支持平台（原生操作行入口）

在以下平台打开回复或撰写编辑框时，写作入口会自动显示在原生发送/评论按钮旁，不遮挡页面内容：

- **邮件**：Gmail（`mail.google.com`）、Outlook（`outlook.live.com`、`outlook.office.com`、`outlook.office365.com`）
- **开发协作**：GitHub（新建 Issue、Issue/PR 回复）
- **社区与社交**：X（`x.com`、`twitter.com`）、Reddit（`reddit.com` / `old.reddit.com` / `sh.reddit.com`）、LinkedIn（`linkedin.com`）
- **团队消息与文档**：Slack（`app.slack.com`）、Discord（`discord.com`）、Notion（`notion.so`）

### 任意网页（通用快捷键按需呼出）

在任何其他常规 HTTP/HTTPS 网页中，写作助手**不会**自动向页面输入框注入悬浮按钮，避免视觉干扰。只需聚焦任意 `<textarea>`、普通文本输入框或 `contenteditable` 编辑区，按下快捷键（默认 `Alt+Shift+W`，可在**设置 → 写作助手**中修改或关闭），即可按需呼出写作助手并捕获当前草稿与周边上下文。

## 起草一条回复

1. 在一等支持网站点击原生按钮旁的写作入口，或在任意网页聚焦编辑框后按下写作快捷键。
2. 有草稿时，助手会帮你完善；没有草稿时，结合当前邮件、帖子、推文、频道消息或页面参考起草。新邮件没有参考内容时，先填写收件人、目的和要点。
3. 生成后核对人名、事实和语气，需要时补充要求再调整。
4. 点击**插入回复**放回当前编辑器，或**复制回复**后自行粘贴。
5. 在原网站检查并发送。写作助手不会自动发送邮件、消息或评论。

原编辑器在生成期间发生变化时，请先核对新内容，避免插入时覆盖。包含链接、附件、复杂格式或由页面富文本框架（如 Slate、ProseMirror、Lexical）托管的编辑器，会自动提供复制回退以保护原编辑器状态。

## 插入双语回复

选择正文语言和不同的对照语言，等待对应的译文完整生成。**插入回复**只插入正文；旁边菜单中的**插入双语回复**会依次插入正文和对照译文。

GitHub、Reddit、Discord 和 Notion 保留 Markdown 格式，其余平台与通用文本输入默认输出纯文本。

## 完善已有草稿

先在回复框写下内容，再打开写作助手，可按需要调整语言、长度和语气。修改参考内容后也可重新起草。

## 参考内容与停止生成

生成前检查**参考内容**中的草稿和可见的讨论、邮件或页面参考。可选学习记忆沿用已保存的开关，无痕窗口不读取。

点击停止、关闭面板或离开页面会停止当前生成，保留已生成的正文。点击面板外可暂时收起；重新打开同一编辑器旁的入口，可接着查看本次草稿和结果。编辑器已被修改、更换编辑器或跳转页面后，会重新读取当前内容。

草稿和参考内容只在本页会话中保留。

## 调整或关闭入口与快捷键

入口旁的菜单可关闭本次入口、在当前网站禁用，或关闭整个功能。在**设置 → 写作助手**中可恢复被禁用的网站、修改或关闭通用呼出快捷键，已保存的服务与风格偏好仍会保留。禁用某网站后，行内入口与快捷键均不会在该网站生效。

</details>

## 数据去向

主动生成或调整时，必要的参考文字、草稿、指令和允许使用的学习记忆会发送给所选 AI 服务。详见[隐私政策](/guide/privacy)。
