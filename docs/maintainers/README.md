# 产品文档维护

用户指南发布自 `docs/guide`、`docs/config` 及对应的 `docs/en`。实现记录、诊断日志和历史快照不进入官网导航、搜索或站点输出。

`product-reference/` 保留 2026-09-06 重写前的技术参考：服务协议与降级、网站规则字段、用量实现来源、翻译卡内核及固定上游提交和许可、历史外部隐私政策。它们是维护参考快照，路径和产品状态可能需要按当前实现重新核对。

其中 `deepseek-harness-20260906.md` 和 `model-usage-20260906.md` 保留来源及许可说明；发行包继续保留 `public/third-party-notices`，不得用宣传文案替代许可信息。

## 官网语言

- 简体中文根路径与 `/en/` 英文路径包含相同用户指南。
- 仅无语言前缀的首页根据 `navigator.languages` 按顺序匹配中文或英文；其他语言回退英文。
- 语言菜单的主动选择优先，保存在 `fluentread-site-language`。明确的 `/en/` 与文档深链接尊重原 URL。
- 页面加载前执行选择，避免先绘制中文再跳转。存储被禁用时仍可访问。
- 宣传素材在仓库根部 `marketing/`，不复制到站点。

图片采集、压缩、商店规格与验证命令见 `marketing/README.md`。
