# 有界空格恢复

彩色输入保留了原先丢失的绿蓝信息，但两个固定原批次中的 `CABIN 04` 退化为 `CABIN04`。原模型在两个字母数字之间已有约 0.43 的弱空格分数，胜出类别仍是 blank；原 SDK 不在这些 blank 帧恢复空格。对应源裁图确有显著空列，且该模型帧的位置严格落在空列内部。

新后处理借用原来已准入、已读取的 RGBA，在完全不透明且外周恒色的识别副本中筛选明显内部空隙。只有物理候选行才额外扫描原模型输出；要求字典、原读序、稳定宽度分批、Tensor 与原 Box 对象身份一致，原 SDK 去掉 ASCII 空格后的文字也必须与原模型发射完全一致。最后仅在相邻 ASCII 字母或数字之间补一个空格，保留原有空格、框、置信度、结果顺序和置信度过滤。未知形状、缩放、身份、字典或超额均保留原文，不根据词典、期望文字或置信度选择颜色。

接入使用锁定的 `ppu-paddle-ocr@6.6.0` 公开会话和独立实例的 Tensor facade。原检测、裁切、旋转、排序、补齐、batch、decoder、重试与模型输出不变。SDK 没有公开已计算的 argmax，因此获准行确有额外扫描成本；SDK 自身仍照常解码。原会话及其 GPU→CPU 回退成功后只观察一次，不额外运行模型。额外扫描计入原推理节流的计时，用于下一次推理前的间歇，末次不增加固定等待；这不代表整个 Worker 的 CPU 占用保证。显式关闭 SDK 空格恢复时也关闭此后处理。

页内共用原来的 2,000,000 像素准入；不新增 Canvas、读回或 RGBA 副本。额外元数据限制为 128 个投影裁图、4096 个墨迹区段和 2000 个完整输出时间步，跨瓦片、气泡和重试累计，换页才重置。固定类别数 18710，因此每页最多新增 37,418,000 次 argmax 比较，最坏 74,840,000 次浮点索引读取；它不是零 CPU。临时列数组、原 Box/字典引用、投影空隙、排序及字符记录也占用内存，不能把时间步数组大小当成进程总内存。原 RGBA 在原生推理前释放，run/page 收尾清元数据；真正异常保留同一首因，不冒充正常回退。

额外 argmax 只扫描原控制器与 SDK 有效前缀的并域；两种浮点求值顺序可能相差一帧，例如 `T=25,w=56,W=200` 分别得到 7 和 8，故取较大范围校验，同时保留原恢复边界。数组长度、比例坐标分母和页内完整时间步扣账均不变。两者共同不读取的 padding 不再检查有限值，这是明确的合同调整；有效范围的非法值仍沿用原回退。固定研究批次的十条 BGR 裁图均会进入捕获，扫描步从 985 减到 635，额外类别比较减少约 35.5%；这不是整页时延或整体 CPU 改善的测量。

冻结的 20 条真实模型输出在离线重放中全部与研究版 v2 一致，修复其中两个缺失空格；其余原先正确的结果保留。这些是已有模型输出的回放，没有新增模型前向。另以真实 SDK 预处理和 decoder、原生 Canvas、模拟 session 验证 batch 1/2/6、固定 batch、同宽反序与 Box 关联；产品接入、预算、未知输入、取消、SDK 吞错和异常释放有定向覆盖。四个相关源码的 statements/branches/functions/lines 均达到 100%。

[机器证据](./manga-recognition-whitespace-20261027-evidence.json)绑定最终源码、386 项定向测试、构建与接入、前缀范围的独立审查；工作区仍保留首次测试包装失败日志和修正后的完整通过结果。

后续单次运行原 BGR 构建的两张整页，完整复现两处空格错误。几何目标所在两个完整原批次共十二行、1782 个完整时间步；旁观计数为九次原识别和两次原检测，未新增重试。固定模型目录四项缓存命中、下载调用为零，测试浏览器与临时 profile 均已清理。这是旧构建的归因，未把它当作新后处理的整页验证，也不能用含观察成本的耗时证明提速。

为后续离线验证，又以相同 PNG 和公开 Canvas 路径进行了零模型复建：九批归一化 RGB 输入 SHA 与原运行全部相同，保存十二行共 1,469,568 字节 RGBA。只读取固定字典，没有加载模型、下载或真实推理；九次 session 调用均为明确标记的全 blank 假输出。该结果约束复建 RGB 输入，不能证明原运行 alpha 逐字节相同，也不是质量验收。

英文 `POSTCARD FROMTHE FERRY` 的缺口在两个模型字符间：blank 帧的最高弱空格约 0.426，但原 SDK 不在 blank 帧恢复；日文 `雨あがり の市場へ` 的多余空格由 SDK 在「の」字符帧以约 0.0014 的弱空格分数补入，属于另一条路径。两目标均来自主识别，原重试选择没有替换它们。它们的输入外周都不恒色，当前物理规则应当保留原文，不能声称已经修复这两张整页。诊断本身完整，但段落顺序仍有两项失败，Worker 仍有一项去重后的 warning（两份原始观测）。

物理间距无法证明作者语义：刻意拉开的代码与词间空格可能拥有相同图片和模型输出。本方法只采用已冻结的联合条件，不能保证所有文字都应插入空格，也不删除日文多余空格。段落归属、注音、Atlas 画面保护、透明像素和运行时 warning 等既有失败仍见[彩色输入报告](./manga-color-input-20261026.md)。当前候选继续保持草稿，不能称为整页验收完成或优于参考项目。
