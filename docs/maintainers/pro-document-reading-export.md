# 专业文档阅读与导出

文档入口沿用 PR #993 的导入、识别和导出工作流，解析模型版本为 18。本文记录专业文档链路的定位和导出契约；用户操作说明见[文档翻译](../guide/document-translation.md)。

## 原文和阅读顺序

PDF 解析优先采用未旋转内容坐标。对于 `/Rotate` 与原内容方向共同产生的横排页面，只在展示方向明显恢复更多横向文字时采用展示坐标，并用 `sourceRotation` 保留原页嵌入方向；仅修改旋转元数据的普通 PDF 继续使用原坐标。阅读器、图形裁剪和导出必须消费同一个坐标契约。

扫描页按图像矩形在页面内的并集面积判断，不重复累计重叠图片；覆盖至少半页且没有原生正文时进入 OCR，允许页面底部只有明确页码。正文配图、小图标和正文区域的数字不能据此触发 OCR。模型升级会重新解析旧快照，已识别文字与人工校订继续按既有身份规则恢复。东亚文字跨行连接按 Unicode 字符边界判断，补充平面的汉字之间不插入空格。

在线 PDF 的读取与取消信号竞争，失败与取消不等待底层流清理完成；清理的迟到结果仍被接收，读取锁立即释放。阅读器对每个新段落只读取一次包含取色边缘的局部像素快照，复用底色和字色算法；不常驻整页像素，已取色段落改译时不重新读取。

未参与翻译的作者、页眉页脚和公式块使用 `segmentIndex = -1`，原字符留在 `PdfDocumentBlock.source`。该编号是哨兵，不能当作唯一位置、编辑索引或原图关联片段。重排条目以独立块 ID 标识；搜索同时读取片段原文及保留块原文。

列表前缀保存在 `listMarker`，不发给翻译服务，重排文字保留其含义。公式与图形保留原像素。表格使用物理列界和合并行边界，先按所在栏安排整表，再按单元格行序阅读。碎横线先拼接，不能因为窄列不足整页宽度阈值而丢掉前几列。页底脚注只有同栏分隔线、小字和连续行等证据满足时才独立识别。

`findPdfContinuations` 只提示高置信的相邻页正文接续，提供可选的跨页上下文对照。它不拼接翻译片段、不删除跨页硬连字符、不改写原文，也不推断译意。多个相接页面可在同一对照窗口查阅。片段 ID 和人工校订始终独立。

## 校订与材料定位

材料持久化边界使用纯算法入口 `src/features/document-translation/material/public.ts`，不加载阅读器、解析器或翻译服务；文档组合根也可从 feature 的 `public.ts` 使用以下最小接口；本 feature 不维护学习中心或新的材料数据库。

- `createDocumentMaterialReference(materialId, document, index)` 创建本地引用。
- `resolveDocumentMaterialReference(reference, materialId, document)` 在重解析模型中解析；无法安全定位时返回 `undefined`。
- `documentSourceLocators(document)` 经 feature 主入口提取原生页/位置、章节、结构路径或字幕时间及精确原文。
- `normalizeDocumentMaterialReference(input, materialId)` 在持久化边界验证版本、文件身份、原文预算和 `locatorOccurrences`；原文、范围、位置与邻文逐字符保存，不能经过 NFC、trim 或截断。

`materialId` 使用 `documentHistoryId` 的 32 位十六进制内容摘要，不使用文件名或 URL。引用含原文，仅供本地使用，不能自动上传或写日志。重复原文必须有双向唯一的原生位置或邻文证据；明确跨页、结构范围冲突和歧义映射拒绝自动恢复。完全相同的已知同版本快照保留独立空槽；解析规则变化不按出现次序猜测。无法恢复的人工校订继续放入已有的“保留的旧校订”。

DOCX/EPUB 以 ZIP 内的原生段落或章节定位，展示用 `pathLabel` 不参与身份；仅结构化 JSON 使用其路径。

材料 `source.fingerprint` 和引用 `materialId` 都绑定 `task.historyId` / 历史记录 `id`；历史记录的 `fingerprint` 是翻译设置标识，材料记录自己的 `id` 是数据库键，均不能充当文件身份。`locatorOccurrences` 保存创建时同原文、范围及原生位置的候选数，不能在白名单清理中丢弃，否则删除一个重复出现位置后可能错误指向剩余位置。原文和每侧邻文各限 12,000 个 UTF-16 单元，范围限 2,048、位置限 512，总计限 36,000；拒绝或明确保持粗略位置，不截短精确引用。

PDF 阅读器公开 `captureMaterialLocation()`、`resolveMaterialSelection(range)` 和可等待的 `resumeLocation(segmentIndex)`，它们只使用当前模型索引。文件摘要与完整引用由 `DocumentApp` 组合根创建。工具栏保存与自动进度复用现有常驻页、视口和渲染宿主：原版原文/译文根据真实宿主矩形及旋转模型几何定位；重排根据实际段落节点定位。阅读线沿用当前页策略（距视口顶部至多 80 px），扫描最多五个常驻页、8,000 个候选。隐藏、尚未挂载、未渲染、原文标签失配、几何歧义或模型已切换时返回不可用，不能猜页首或覆盖旧精确位置。

恢复后只有可信的阅读操作才开启自动写回；阅读正文以及外置的 PDF 页码/上一页下一页工具组、目录容器都监听真实 pointer/keyboard 意图，程序恢复或合成事件不算用户阅读。

同页滚动由已有 `updateViewport` 发无载荷通知，组合根防抖结束后重新读取实际位置，不另存一套段落状态。原文与译文划词也通过组合根回调采集；显示引文可以是译文，`documentReference.locator.source` 始终来自完整原文模型。可选材料捕获失败不阻断原有阅读卡或词书收藏。

恢复先等待材料作者的异步 reader ref 和 `resumePage` 时序，再定位精确段落；最多尝试 12 帧并确认两次稳定可见落点，每次动画帧等待由 750 ms 定时器兜底，累计帧等待至多 9 秒；完全冻结标签页仍须等浏览器恢复 JavaScript 执行机会。超时保留原定位并显示重试提示，成功、取消和超时都清理帧及计时器。快速请求、文档替换、显示方式变化和卸载均取消旧恢复。可信的滚动或阅读导航可抢占正在执行的精确恢复，淘汰旧布局锚点，随后按用户当前视口记录进度；程序滚动不会抢占。无法解析的旧引用不属于正在执行的恢复，普通手势仍不能授权覆盖它。精确引用失配不能退回全局相同文本搜索；旧记录仅有页/章节时显示粗略恢复，没有有效位置时保留材料并引导用户更新位置。本地文件缺失时要求重新选择原文件，同名不同内容文件不接管原材料。

## PDF 导出

导出目录优先读取原 PDF 的内部章节书签（显式目的地、命名目的地及 GoTo），没有有效原生书签时采用阅读器相同的标题识别规则。目录树只写内部跳转，不复制外部动作；有唯一同页标题片段对应时使用当前译文，否则保留原题。落点绑定实际输出页引用和首个标题绘制位置，不能用源物理页码推算插入续页或重排后的页码；左右双语定位到译文侧。光栅回退沿用其行或分页绘制项定位。

文字换行与分页只忽略首尾全空白段，不改写原文、译文或校订存储；正文内部空行保持。纯空白条目不创建页面或段间距，短译文也不能因为末尾换行被判为原位放不下而追加全文续页。

换行的字宽缓存最多保留 512 个近期词或字素，长前缀不能永久占满缓存。超高图片按累计绘制高度计算源条带终点，避免非整数缩放累积误差创建近零高度的额外页；仅合并浮点尾差，真实超出部分仍续页，源图像几何完整保留。

原版页保留图像外观，并根据 Canvas 实际绘制的每行几何生成不可见 CID/ToUnicode 文字层。此层不用下载字体；必须保全 Unicode，不得覆盖图表或生成可见的缺字方框。源块只有实际绘制了有效译文行时才从原文文字层排除。

阅读器原版排版中，完整译文放不下时保留可读的一行预览，全文仍在全文弹窗；该预览不代表全文已经显示。导出时保留完整批注，并在对应原版页后添加完整可见续页。续页有源页、段落和页码标识，底部链接返回原版页。标准 PDF `PageLabels` 记录 `1`、`1 · 译文续页 1`、`2` 等关系，验收应检查原版页相对顺序及连续续页编号，不能再假设每个源页只有一个输出页。

可见文字优先嵌入校验过的开放字体。字体离线或缺字时，可由浏览器有界 Canvas 生成可见续页并附同样的 Unicode 文字层；一份导出只尝试一次失败字体下载。重排正文仍以固定字号自动分页，图像区域中的原文字形按实际裁剪几何投影到搜索层，不能只保留图片后宣称文本完整。光栅回退中有绘制文字的页必须给出有效文字元数据；阅读计划中的纯图页可完整保留，图中已有的原文字形仍投影到搜索层；不能用空白产物或缺字下载冒充成功。

取消必须停止迭代、释放画布及字体/文档租约并禁止下载半成品。重试保留译文与人工校订。生产组合根默认提供页面光栅、文字重排和光栅回退三个端口；外部旧端口继续兼容，未提供全文搜索元数据时不能计入新端口验收。

## 复核

只运行显式范围，使用 `scripts/testing/run-resource-safe.mjs`：

- `run-document-corpus-audit.cjs`：校验 manifest 来源及 SHA，检查指定真实页的字形、片段、顺序、跨页边界和内存样本。其通过不等于视觉或翻译通过。
- `run-pro-document-ui-test.cjs`：在第二屏后台临时 Edge 中用真实人工校订验证弹窗、键盘、复制事件、搜索、迁移、取消、下载、响应式及卸载；不模拟普通文档的供应商。
- `run-document-export-pages-test.cjs --extension-dir <生产扩展目录> --playwright-root <Node包目录> --artifacts-dir <证据目录>`：经文档页校订与实际导出按钮，检查带首尾空行的短译文、36 行重排及长译文续页；重开下载文件核对页数、全文与逐页渲染。仅使用受控 PDF 与人工校订，不代表反馈原文件或在线供应商验收。
- 同一脚本追加 `--outline-only --runtime-diagnostics-helper <扩展UI测试技能>/scripts/runtime-diagnostics.cjs`，只运行两页 PDF 的原生目录与识别标题回退，分别下载原版双语、原版译文和重排译文六个场景。重开产物检查层级、中文标题、译文侧落点及插页后的实际目标页，同时采集扩展页与后台错误和告警；不会调用翻译供应商。
- `run-pdf-performance-test.cjs --extension-dir <生产扩展目录> --label <构建标识> --artifacts-dir <证据目录>`：后台第二屏临时 Edge 中运行两页 24 段人工校订，记录首次及三次重复的阅读、翻页、原版双语和长文重排导出；原样包装 Canvas API 记录读回、像素与测量量，下载后独立检查页序、全文与逐页非空，并渲染首次及末次输出。保留构建指纹、原始样本与中位数；耗时包含调度与计数开销，不设墙钟通过阈值，首次和缓存复用样本分开解释，不代表供应商或复杂文档整体性能。
- `run-document-live-translation.cjs --inputs <明确文件>`：公开原页节选的实际免费服务翻译与下载，独立记录供应商成功、错误及未覆盖项。
- `run-pdf-export-benchmark.cjs --self-test-expectations`：离线检查页序与批注验收逻辑。Mock 压力模式仍要求至少 300 页，不用于普通公开文档的翻译质量验证。

必须重开最终 PDF 提取文字、渲染所选输出页并查看截图；不能以字符串测试替代视觉验收。公开语料的未选页、Firefox/Safari/移动真机、物理触控板和系统剪贴板往返须分别说明验证范围。

浏览器脚本应使用与 `--playwright-root` 配套的 Node 运行。随附文档工具依赖使用 Node 24；混用系统旧 Node 与新版 PDF.js 可能令独立验证器缺少 `DOMMatrix` 等运行时能力。
