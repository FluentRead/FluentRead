# 翻译卡

FluentRead 的翻译卡基于 DeepSeek Harness 内核开发，是一个贴着选区使用的阅读理解工具。它适合在网页阅读时快速弄清一句话的意思、句子结构和表达用法，也可以继续追问、朗读原文，或收藏单词和句子到学习中心。

## 开始使用

打开扩展设置，进入 **专项翻译 > 翻译卡**，开启功能并选择服务和模型。它会复用 FluentRead 已保存的翻译服务凭据；服务列表中的模型由对应服务支持，Claude 和 Gemini 使用各自的原生模型协议，其他接入按服务的兼容协议发送。

在网页中双击单词，或拖动选中一句话。选区旁直接显示你已启用的“读懂”“拆句”“用法”和“练习”，优先动作以主样式显示。点击对应动作后开始分析，也可以在卡片中切换动作。只完成选区不会自动调用模型。首次使用时如果没有可用服务、模型或凭据，卡片会提示你去设置页补全配置。

设置页提供可点击的例句卡片：切换动作就能看到相应的回答示例，示例不调用模型。服务和模型直接显示；动作偏好、上下文范围、解释深度和学习程度放在常驻的“更多设置”分组中，不需要展开。隐藏一个动作后，示例与网页工具条会同步隐藏它。

卡片原文旁的喇叭可朗读原文，再次点击停止；朗读复用现有语音服务和配置。单词、短语和句子都可主动收藏，即使模型尚未回答也能保存原文。收藏在“工具与学习 > 学习中心”的“收藏”栏目中长期保留，原有复习与导入导出继续可用。

## 阅读方式

- **读懂**：说明原意，并解释语气、指代或隐含含义。
- **拆句**：先给出句子主干，再说明从句、修饰关系和关键语法。
- **用法**：挑出值得学习的表达，说明搭配、语气和自然例句。
- **练习**：围绕当前内容生成一道小练习，帮助迁移使用。

双击通常只会选中一个单词。卡片提供“理解整句”时，点击它才会将分析对象扩展为这个单词所在的整句。上下文范围是独立设置：默认允许模型通过只读工具使用当前段落；选择“当前选区”则只发送选中文字。

普通模式下每条问答在本机保存 30 天。选区旁点击“记录”，或在翻译卡中点击“阅读记录”，即可查看原文摘要、动作、日期和轮次。选择一条后恢复原文与回答，展开“前面的问答”可阅读更早内容，也可以直接继续追问。打开或恢复记录不产生模型请求；“返回当前阅读”回到原卡片。“学习中心 > 阅读记录”显示同一份列表，点击记录可查看独立详情，支持删除和清空。

真实追问最多使用最近 4 轮有回答的问答，中断回答会明确标为未完成。首次点击读懂、拆句等动作时独立分析当前原文，不把旧回答当成继续聊天的指令；这些分析仍保存在同一条阅读记录里。同一原文、同一设置下切换回已完成的动作，会恢复该动作最近的回答与追问状态，不重复请求；点击动作旁的“重新生成”才重新分析。原文、上下文、模型或设置变化会使当前卡片缓存失效。

保留期限按每条问答的创建时间计算，继续会话不会延长旧问答的期限。扩展启动、定期清理和读取历史时会删除过期问答，空会话一并移除。

回答随模型正文增量实时显示，网络片段不一定恰好一个字。卡片固定在可视区域内，长回答在内部滚动，逐步生成和追问不会因正文高度改变而重新选择上下位置。回答及历史共用 Markdown 展示，支持标题、列表、强调、代码、引用和简单表格。卡片支持停止、重试和复制；停止或错误时已收到的正文会保留并标示状态。模型服务返回的用量会以“阅读理解”用途记录在本机模型用量中；用量记录只保存服务、模型、时间、结果和可用的 Token 数，不保存选中文本、段落、回答或 API Key。

## 可选的学习记忆

在 **专项翻译 > 翻译卡 > 学习记忆** 中开启。默认关闭；开启后，模型会参考你主动保存的学习偏好和与当前问题相关的要点。不会自动挖掘浏览历史、自动总结个人信息或让模型自行改写记忆，也不会为检索额外调用模型或 embedding 服务。

- 在回答下方点击 **记住要点**，保存原文和回答的摘要片段；可在学习中心继续编辑。
- 在 **学习中心 > 学习记忆** 中添加、搜索、编辑或删除“学习偏好”“学习要点”和“笔记”。
- 最多保存 200 条，每条最多 2000 个字符。回答最多参考 3 条，每条最多传入 700 个字符；最新的一条学习偏好优先，其余按词法相关度选择。
- 记忆保存在本机，直到主动删除。关闭开关会停止使用已有记忆，但保留管理能力；隐私窗口不读取或写入记忆。
- **阅读记录**保存每条问答 30 天；**收藏**与**学习记忆**长期保存。三者有不同用途与保留期限。现有备份支持学习收藏，学习记忆不包含在当前备份格式中。

启用后，召回内容会随当前问题发送给你选定的模型服务。回答下方会显示本次参考的记忆数量；无相关记忆时不附加学习要点。记忆读取失败会提示并继续分析原文，不影响普通阅读。

此功能采用社区项目 [Culeot/dsh-agent-memory](https://github.com/Culeot/dsh-agent-memory/tree/af709743fb267b536d11343bab43e9a54f96367c) `0.8.4` 的纯检索代码子集（固定提交 `af709743fb267b536d11343bab43e9a54f96367c`），属于浏览器适配，并非安装完整插件或 DeepSeek 官方内置记忆包。保留中英文分词、词法/BM25 评分、过期过滤与排序，数据管理改用 FluentRead 的 IndexedDB 和 Vue 界面；没有引入它的 Node 文件系统、Cordis 装载、React 界面、模型写入工具或自动沉淀钩子。完整 MIT 许可随扩展附带在 `third-party-notices/dsh-agent-memory-MIT.txt`。

## 数据范围

点击学习动作时，扩展会捕获选中文字；默认的“可参考本段”模式还会捕获并裁剪所在正文段落，交给后台的只读 `read_context` 工具。模型只能通过这个工具取得已捕获的段落，不能继续读取页面其他内容。“仅选中文字”模式不提供段落工具。整句候选在点击“理解整句”前留在页面本地。

翻译卡只在当前选区生命周期内工作。页面导航、选区变化、关闭卡片、切换设置或扩展卸载时，未完成请求会被取消，迟到的回答不会写回新的选区。后台重启后，中断的会话会标为已停止，并保留此前已保存的部分正文。隐私窗口不保存也不读取历史。

## 开发者边界

完整的模块取舍、代码位置及 Mermaid 架构图保存在仓库 `docs/reports/harness-embedding-map-20260905.md`。该地图以 PR #440 的已提交内核为核查基线，说明哪些规则来自上游、哪些由 FluentRead 实现；开发报告目录不发布到文档站点。

FluentRead 参考 DeepSeek Harness `dsh-v0.1.3-alpha.1`，固定 commit 为 [`d347e703908d0406b7a7ef80e3a0e594d86b2215`](https://github.com/deepseek-ai/deepseek-harness/tree/d347e703908d0406b7a7ef80e3a0e594d86b2215)。参考文件是 [`packages/core/session/src/surface.ts`](https://github.com/deepseek-ai/deepseek-harness/blob/d347e703908d0406b7a7ef80e3a0e594d86b2215/packages/core/session/src/surface.ts)，已审阅文件 SHA-256 为 `aa75a34df001b33d3b1e4dd5c24a0391d00bc457e0a83f25757d3358b12b684f`。

本地实现只采用 surface 的 append-only 投影子集：保留 surface 类型、append marker、连续序号校验、用户/助手/工具消息投影和只追加 ledger。它没有逐行复制完整上游，也没有实现 replacement 或 provenance rewrite；本地会话按问答在本机保存 30 天并支持删除/清空，循环是独立的有界实现，另行限制模型调用次数、工具调用次数、请求时限、重复工具 ID 和取消行为。

扩展不包含 DeepSeek Harness 的 CLI、桌面 Web UI、host/bridge、Cordis 插件加载器、文件系统、shell、子进程、沙箱、动态代码执行、远程插件或网页抓取能力。模型通过 FluentRead 的 AI SDK gateway 选择，支持兼容服务和原生 Anthropic/Google 服务，需要模型支持工具调用才能使用段落工具；不支持时可以选择“当前选区”模式。翻译卡通过 runtime stream port 增量显示模型正文。

上游 DeepSeek Harness 代码按 MIT License 发布，发行包在 `third-party-notices/deepseek-harness-MIT.txt` 中附带许可文本，版权与完整许可文本也见上游 [`LICENSE`](https://github.com/deepseek-ai/deepseek-harness/blob/d347e703908d0406b7a7ef80e3a0e594d86b2215/LICENSE)。FluentRead 的移植是独立的浏览器适配；上游来源、SHA 和许可应与本文件一起维护，不以本地易过期的构建 hash 代替固定提交和上游链接。
