# 模型用量

模型用量帮助你查看 FluentRead 调用了多少次模型、使用了多少 Token，以及哪些服务和模型使用得最多。页面不显示花费。

## 查看用量

在完整设置中打开 **模型用量**，选择 **今日、7 天或 30 天**。时间范围按当前设备的本地日期计算，7 天和 30 天都包含今天。服务与模型筛选同时作用于概览、趋势、构成和请求明细。

页面顶部保留四项指标：

| 指标 | 含义 |
| --- | --- |
| 总 Token | 当前筛选范围内，服务商已上报的 Token 总量。未上报的请求不会被推算为 0 Token。 |
| 请求数 | 实际发往模型服务的请求尝试次数，包含成功、失败、超时和取消。重试或一次操作中的多次模型调用会分别计数。 |
| 平均耗时 | 当前范围内全部请求的平均耗时，包含成功、失败、超时和取消。 |
| 缓存读取比率 | 在已上报可用缓存数据的请求中，读取缓存的输入 Token 占这些请求全部输入 Token 的比例。 |

这里的缓存由模型服务商提供。本机翻译缓存直接复用已有译文时，不会发起新的模型请求，也不计入这里的请求数或缓存读取比率。缓存信息未上报时，页面会保留未知状态，不把这些请求当成缓存未命中。

## 趋势与 Token 构成

趋势支持在 **Token** 和 **请求次数** 之间切换。今日按小时查看，7 天和 30 天按天查看；查看某个时间点的详情可以读取精确数值。Token 趋势展示已上报用量，请求次数则包括没有上报 Token 的请求。

Token 构成使用互不重叠的分类，避免把缓存重复加到输入中：

| 构成 | 统计方式 |
| --- | --- |
| 未读取缓存的输入 | 对缓存状态已知的请求，用输入 Token 减去读取缓存的 Token。 |
| 读取缓存 | 服务商明确上报的缓存读取 Token。 |
| 缓存状态未知的输入 | 已上报输入 Token，但未上报可用缓存读取数据的请求输入。 |
| 输出 | 已上报的输出 Token。 |
| 未分类 | 已上报总 Token 超过可分类输入与输出时，保留无法归入这些分类的差额。 |

例如，一个请求上报输入 1,000 Token，其中缓存读取 600 Token，输出 200 Token；构成会显示未读取缓存的输入 400、读取缓存 600、输出 200，总计 1,200 Token。缓存状态未知的请求会单独归类，不会用它们拉低缓存读取比率。

缓存写入和推理 Token 如有上报，可在请求明细中查看；它们可能已经包含在输入或输出中，不会再作为额外用量加入总数。服务商未上报 Token 或返回异常用量时，页面明确区分这些状态，不根据文本长度生成估算值。

## 找到常用模型和请求

服务与模型排行展示各组合的已上报用量与请求数。点击某一行可以直接筛选对应服务和模型，再查看它的趋势、构成和明细。

请求明细按需展开，保留时间、服务、模型、用途、结果、耗时和已上报的 Token 数据。用途包括 **翻译、摘要、连接测试、阅读理解**；请求结果包括成功、失败、超时和取消。一次阅读理解或其他操作可能产生多次模型调用，因此请求数不等同于点击次数。

## 记录范围与数据管理

模型用量保存在当前浏览器的扩展私有存储中，最多保留最近 **1,000 条请求记录**。达到上限后，较早记录会被移除；因此即使选择 30 天，也可能只覆盖最近保留下来的部分请求。导入记录后同样遵守这一上限。

这些数字只代表本机保留的 FluentRead 调用记录，不代表服务商账号总用量、剩余额度或套餐限制，也不包含其他设备和应用的请求。请求已经发生但服务商未提供用量时，只能统计请求本身，无法据此确认 Token 消耗。

用量记录仅保存服务与模型标识、时间、用途、请求结果、耗时和可用的数值指标，不保存网页正文、原文、译文、阅读理解回答或 API Key。导出和导入统一在 **备份与恢复** 中管理，也可以单独清空用量记录；清空只作用于模型用量，不会删除翻译缓存、设置或单词本。

## 开源参考与实现选择

本页面结合以下开源项目的信息组织与统计思路，在 FluentRead 的 Vue、TypeScript 和现有界面样式中独立实现：

| 项目 | 借鉴内容 | 许可证与引入决策 |
| --- | --- | --- |
| [dsh-context](https://github.com/bowenliang123/dsh-context) | 概览、Token 构成、逐请求趋势与按需展开详情，让数字的来源容易理解。 | [Apache-2.0](https://github.com/bowenliang123/dsh-context/blob/main/LICENSE)。参考产品设计；不引入其 DeepSeek Harness、React 插件及上下文浏览器。 |
| [ccusage](https://github.com/ccusage/ccusage) | 本地用量、日期聚合、模型分组和紧凑展示；其 `--no-cost` 也支持隐藏费用。 | [MIT](https://github.com/ccusage/ccusage/blob/main/apps/ccusage/LICENSE)。参考统计与展示方式；不引入面向本地命令行日志的解析器或 CLI。 |
| [Langfuse](https://langfuse.com/docs/observability/features/token-and-cost-tracking) | 以提供商上报值为依据，保持输入、输出与缓存分类互不重叠，区分缺失数据。 | [核心代码为 MIT](https://github.com/langfuse/langfuse/blob/main/LICENSE)，企业目录另有许可。参考计量语义；不复制企业代码，不接入远程追踪平台。 |
| [Helicone](https://docs.helicone.ai/features/advanced-usage/custom-properties) | 请求属性筛选、按模型查看用量与性能、从汇总进入请求详情。 | [Apache-2.0](https://github.com/Helicone/helicone/blob/main/LICENSE)。参考信息组织；不接入其代理、日志服务或远程分析平台。 |

图表由 Vue 管理 DOM 绘制，沿用 FluentRead 的主题、圆角、文字层级和交互方式，无需新增图表依赖。以上属于产品设计与统计方法参考，没有复制这些项目的实现代码，也不会向它们传输使用记录。
