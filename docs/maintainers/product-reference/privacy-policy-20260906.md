感谢您使用流畅阅读浏览器插件（以下简称“我们”或“流畅阅读”）。我们致力于保护您的隐私和个人数据，并遵守适用的隐私法规。

本隐私权政策旨在向您说明我们收集哪些个人数据，以及如何使用、共享和保护这些数据。

## 1. 收集的个人数据

在使用流畅阅读插件时，我们可能会收集以下类型的个人数据：

- **用户活动：** 当您使用流畅阅读插件时，我们可能会收集和存储您的用户活动，如点击、鼠标指针位置或击键操作记录。
- **设备信息：** 我们可能会收集与您的设备相关的信息，如设备类型、操作系统版本和唯一设备标识符。
- **日志信息：** 当您与流畅阅读插件互动时，我们的服务器会自动记录某些信息，包括您的浏览器类型、访问日期和时间、页面浏览次数等。

### 单词本 Beta 数据处理说明

单词本 Beta 默认关闭。开启后，只有在您主动点击划词卡片中的收藏星标时，扩展才会在当前浏览器的扩展专属 IndexedDB 中保存以下学习数据：

- 您收藏的单个英文单词、当时已经显示的译义、音标和词性；
- 最多约 500 个字符的纯文本阅读上下文、页面标题，以及移除查询参数和片段后的来源地址；
- 收藏次数、掌握状态、下次复习时间和精简复习记录。

点击收藏时，扩展会读取选区附近的 DOM 纯文本并截取最多约 500 个字符作为阅读上下文；它不保存 DOM 结构、Cookie 或整页正文，也不使用浏览器同步存储。您选中的文字、附近上下文、页面标题、网址路径本身可能包含姓名、账号或其他敏感信息，请在收藏和导出前自行确认。划词卡的译文仍由您选择的翻译服务处理；单词学习卡还可能把被选中的单个英文单词发送给多个公开词典提供方进行顺序降级查询。上述翻译和查词发生在卡片生成阶段，点击收藏不会额外发起一次请求，和是否保存到本地词库是两件独立的操作。无痕或隐私窗口不提供持久收藏入口。

## 2. 数据使用

我们收集的个人数据将用于以下目的：

- **提供服务：** 我们使用收集的文件数据来执行流畅阅读插件的功能，帮助您对文件进行操作和管理。
- **改进插件：** 我们可能会使用收集的日志信息来分析用户行为，并不断改进和优化流畅阅读插件的功能和性能。
- **安全保障：** 我们可能使用设备信息等数据来确保流畅阅读插件的安全性和完整性。
- **单词学习：** 单词本数据仅用于显示您收藏的词条、生成本地复习队列、更新掌握程度，以及执行您主动发起的导入、导出或删除操作。

关闭单词本 Beta 只会隐藏网页收藏入口，不会删除已有学习数据。数据会保留到您在单词本中删除或清空、清除浏览器的扩展数据，或卸载扩展为止。您可以随时导出 FluentRead JSON 或 Anki TSV；导出默认不包含阅读上下文、页面标题和来源地址，只有主动勾选后才会包含这些字段。

## 3. 数据共享

我们不会向任何第三方出售、出租或共享您的个人数据，除非获得您的明确同意或法律允许。但在以下情况下，我们可能会与第三方共享数据：

- **服务提供商：** 我们可能与第三方合作伙伴共享数据，以提供流畅阅读插件所需的服务和功能。
- **法律要求：** 如果有合理理由认为需要披露您的个人数据，以遵守适用的法律、法规、法律程序或政府请求，我们可能会披露相关信息。

保存后的本地词库、阅读上下文和复习记录不会因为收藏或复习功能而另行上传、出售或共享给第三方；卡片生成阶段对所选单词的翻译和公开词典查询以前述说明为准。您主动导出的文件由您自行选择保存位置和后续用途。

## 4. 数据保护

我们采取合理的安全措施，保护您的个人数据免受未经授权的访问、使用或泄露。然而，您理解互联网上的数据传输存在风险，我们无法完全保证数据的安全。

单词本学习数据由浏览器的扩展隔离机制保护。请注意，能够访问您本地浏览器配置或导出文件的人仍可能读取这些内容；卸载扩展或清除扩展数据前，如需保留词库，请先导出备份。

## 5. 隐私权政策的更新

我们可能会根据业务需求和法律法规的变化，不时更新本隐私权政策。更新后的隐私权政策将在生效前通过适当方式通知您。
