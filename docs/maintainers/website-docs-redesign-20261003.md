# 官网与文档重构：实现与验证

首页先解释网页双语阅读，再展示划词、句法、字幕与文件能力，最后提供服务选择、第一次使用与常见问题。文档首页位于 `/docs/` 与 `/en/docs/`，按用户任务组织 16 个入口；旧 `/guide/` 与功能概览的已有锚点保留。

## 展示方式

- `SiteHome.vue` 共用中英文布局，文案独立切换。
- `TranslationDemo.vue` 使用 Vue 状态和 CSS 展示双语、仅译文、恢复原文、划词结果、AI 学习动作、字幕与输入框翻译。它使用固定示例，不读取访客输入，不调用提供商。
- `GrammarDemo.vue` 使用“Every language offers a new way to see the world.”展示句子拆解。原文、句中作用、词性始终可见；点击与左右方向键切换解释，结果区域支持屏幕阅读器播报。
- 翻译出现动画有限次播放，重播由用户触发；减少动态效果偏好会关闭动画。
- 不再把全部功能详情堆在一页。网页、悬浮、输入框、句法、分享、写作、外观与备份都有独立的中英文指南。详细兼容说明保留在可展开内容中。
- 最新 main 的逐句高亮自定义 CSS 与保存样式说明移入外观指南，图片翻译更新也保留。随后合入 WebDAV 云备份，完整保留其指南与隐私说明，并连接到新的备份入口。

## 图片与体积

六张真实扩展界面截自独立生产 Chrome MV3 构建，版本 0.0.35，源码基线见 `marketing/site-ui-manifest.json`。使用临时浏览器配置，通过 focus-safe helper 在第二块屏幕打开可见但不抢焦点的窗口；未使用个人配置或服务凭据。

PNG 原图保存在 `marketing/source/site-ui/`，网页使用 `docs/public/screenshots/ui/` 的无损 WebP。两者解码后的像素完全一致。六张合计由 1,529,902 字节降到 544,854 字节，减少约 64.4%；网页图为 67,118–116,314 字节。图片明确宽高、按需加载，可点击查看完整尺寸。首页关键说明通过文字与交互呈现。

## 验证范围

- `pnpm compile` 通过。
- `pnpm docs:typecheck` 对官网配置和 Vue 组件独立检查，通过。
- `pnpm docs:build` 通过；移开 `.wxt` 后也成功构建。根配置引用 `.wxt/tsconfig.json` 的现有警告不阻止网站构建。
- `pnpm docs:check` 检查 75 个静态页面、3,810 个内部链接、708 个锚点及 90 次图片引用；包括 canonical、语言对应链接、旧链接、图片尺寸和内部材料不发布。
- 独立无头 Edge 检查所有公开内容页面在 1440px 与 390px 的加载和布局；首页进一步检查 320/768/1024px，覆盖中英文、主题、搜索、手机目录、手动切换语言、减少动态效果，以及上述演示交互。没有页面或控制台错误。WebDAV 合入后追加检查中英文文档入口、备份、隐私和 WebDAV 共 8 个路径的桌面与手机布局，也没有错误。文档主按钮的文字对比度也有断言。
- 没有修改扩展业务代码；不把网站演示和截图捕获当成真实提供商翻译或扩展全量回归。

证据位于 `docs/reports/website-docs-redesign-20261003/`。这些材料不会进入公开网站。

## 后续维护

GitHub Pages 工作流在构建后运行官网类型和链接检查；仅 main 成功后部署。官方域名保持 `https://read.thinkstu.com`。合并、Pages 部署和线上内容核对分别记录，PR 构建不会发布。

界面截图可在生产扩展构建后通过 `scripts/capture-docs-ui.cjs --runtime <Playwright 与 sharp 所在目录> --helper <focus-safe-browser.cjs>` 更新；脚本保留原图并核对无损像素。
