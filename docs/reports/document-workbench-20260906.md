# 文档翻译工作台：产品设计与验证

本次把文档翻译从纵向堆叠的表单改为阅读工作台：左侧管理文件、设置和任务状态，右侧阅读、校订和下载。顶部仅保留品牌、界面语言和设置入口。窄屏下可以收起设置。

## 产品流程

1. **导入并预览**：一次打开一个文件，解析后展示原文、文件大小与可翻译片段。尚无译文时，阅读方式明确显示原文。
2. **确认并翻译**：选择语言、服务、已保存模型及术语。任务固定语言、模型和术语选择，逐段保存返回的译文。
3. **暂停或恢复**：中断后保留已完成片段，继续只补译缺失项。取消后的迟到结果没有提交权；更改语言、服务、模型或术语后，必须显式重新开始，避免混合结果。
4. **阅读与校订**：阅读视图不再铺满输入框。校订支持整份文档搜索、未翻译筛选、直接跳页与逐段编辑，取消原有前 80 段限制。切换视图保留搜索和页码。PDF 支持适合宽度和实际放大，文本阅读器跟随深色主题。
5. **下载**：独立选择双语或仅译文。下载会保留格式；部分完成时明确说明缺失处保留原文，确认后才生成。完成后下载是主要操作，重新翻译是次要操作。
6. **保护结果**：重新翻译或更换尚未下载的文档前确认；刷新或关闭页面通过浏览器 beforeunload 提醒。下载生成与旧文件的异步回调同样校验归属。

## 实现边界

复用 Vue/WXT、现有 Config 字段级保存、翻译客户端、格式解析器和导出服务。没有新增依赖、修改版本号或复制参考项目代码。本地 read-frog 和 kiss-translator 只做只读检索，没有找到可以直接复用的独立文档工作台；本次按 FluentRead 架构实现。

文件在本地解析，待译文字会发送到所选服务。文档和校订结果只保留在当前页面，暂不支持关闭后的任务恢复。原有 10 MB 单文件限制、扫描 PDF 无 OCR、PDF 译页为图像的边界保持明确；不能把 PDF 译页描述为可复制的文字层。
