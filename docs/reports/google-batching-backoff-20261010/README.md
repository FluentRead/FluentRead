# Google 合批与限流退避验证

Google 匿名网页接口的请求现共享启动节奏与限流恢复状态。收集窗口为 120 毫秒，每批最多 32 段，字符预算为 10,000 个 HTML 转义字符（含包装）；满批立即发送，超长单段独立处理。所有入口最多两路在途，启动间隔至少 200 毫秒。429 暂停整个队列，优先遵循 `Retry-After`，没有有效提示时使用有界指数退避，恢复先发一个探测。

受控时钟测试中，20 个间隔 30 毫秒到达的段落合为 5 次 HTTP。生产扩展的临时 Edge 专项中，12 个间隔 25 毫秒到达的请求在一次 429 后全部成功，共 4 次 HTTP（含被限流的首次请求）。另覆盖 503 回退、取消排队调用者，以及 Control 悬浮与 Alt+T 全文的翻译、恢复、再次翻译。浏览器使用第二屏后台正常窗口，未成为前台应用，成功后关闭窗口并清理临时配置。

这些结果使用受控 Google 响应，证明请求调度和交互；没有量化真实 Google 在线额度、持续阅读成功率或译文质量。借鉴来源、复现命令和证据范围见[测试说明](../../testing.md#谷歌合批请求节奏与限流恢复)。

## Userscript 体积

以独立源码快照构建主线 `f3f6016e89aaa9db91a387c7f28504f72aa36dc1`，与候选使用同一份冻结锁文件依赖、Node 20.11.1、Vite 5.4.19。两份构建都未修改依赖或版本号。

| 产物 | 字节数 |
| --- | ---: |
| 主线基线 | 1,975,252 |
| Google 优化后 | 1,977,788 |
| 增量 | 2,536（0.1284%） |

`scripts/verify-userscript-build.mjs` 的体积预算从 1,976,000 调整至 1,979,000 字节，增加 3 KB；其余协议、固定资源、重复注入、平台边界和兼容性断言保持执行。基线原预算验证通过；候选超出原预算 1,788 字节，此增量来自共享 Google 调度实现。

复现时分别准备主线提交和候选提交的独立检出目录，使用同一冻结锁文件依赖，然后在各自目录执行：

```bash
pnpm exec wxt prepare
pnpm build:userscript
node -e "console.log(require('node:fs').statSync('.output/userscript/fluent-read.user.js').size)"
node scripts/verify-userscript-build.mjs
```
