# Google 翻译动态优先级、快速换线与批量优化

核对日期：2026-10-05（Asia/Shanghai）。基础为 `origin/main`，提交 `f94225c333c8d17c69de06574860ea202c674c94`。

## 发现与实现

原适配器先尝试两个网页 RPC，再尝试 `translate_a/single`，每个入口最多等待 8 秒。只对 RPC 的 XSRF 拒绝冷却，其他故障可能在后续段落反复出现；客户端还可能按全局配置重跑整条回退链。全文富文本槽没有使用 Google 原生批量能力。

保留四条入口：`translateHtml`、`translate_a/t`、主 RPC 和英国区域 RPC。初始权重分别为 1.2、1、0.8、0.7，随后复用免费翻译池的纯性能策略，按近期成功率平方、响应耗时和在途数量动态排序。变慢立即降级，变快平滑恢复；老观测逐渐回到初始权重。每 10 批实际请求优先探索观察最少的可用入口，平手时选择更久未使用的入口，不额外发送后台请求，不绕过冷却窗口。冷却到期先给入口一次受控恢复机会，避免历史低分使它永远得不到重试。

明确失败立即继续；单入口最多 2 秒，整批共用 8 秒。谷歌与免费聚合一样免除外层重复重试。常规故障从 30 秒开始指数冷却，最多 5 分钟；403、429、XSRF 拒绝冷却 5 分钟。到期只允许一个恢复探测。400、413、415、422 等请求特有错误不会淘汰健康入口；取消也不计作故障。较早的在途成功不能覆盖后来观察到的失败。动态状态只保存在当前执行环境内存中，不保存原文；扩展后台重启后重新学习。

同语言请求在 10 毫秒窗口内合批，每包最多 32 条、通常不超过 4,000 个转义后的字符；超长单条保留为独立请求，不在适配层拆分语言上下文。回退入口也支持多条，RPC 按编号还原乱序响应。数量、类型、非空译文和编号必须有效，否则整批换线，不把错误结果填入其他段落。HTML 入口转义纯文本，用 `pre` 保留换行，并只解码一次实体。一个调用者取消不影响共用请求的其他调用者；全部离开后才终止网络。

## 接口实测与清理

对三句公开合成英文分别请求，检查实际中文译文，而不只检查 HTTP 200。

| 入口 | 三次结果 | 处理 |
| --- | --- | --- |
| 主网页 RPC | 3/3 成功，约 1.09–2.95 秒 | 保留并参与动态排序 |
| 英国区域 RPC | 3/3 成功，约 1.43–2.61 秒 | 保留并参与动态排序 |
| `translate_a/single` | 0/3，均 HTTP 429 | 移除候选与解析代码 |
| `translateHtml` | 3/3 成功，约 1.13–1.69 秒 | 初始优先并参与动态排序，实测多条、换行和字面 HTML |
| `translate_a/t` | 3/3 成功 | 保留并参与动态排序，实测两条数组 |

零成功是本轮网络环境的观测，不代表 `single` 在全球永久失效。保留入口也不保证所有地区、语言或以后的时间都可用。2 秒等待是快速换线的取舍：慢于阈值的可用入口也会暂时跳过。

## 验证

定向覆盖 Google 批量与安全错误、取消所有权、冷却恢复、乱序/缺槽、总预算、客户端单条/批量/视频不重复重试，以及全文语言跳过、会话缓存、动态文本、标题和可见性调度。动态排序测试覆盖成功但变慢的入口降级、更快备用上升、在途分流与负载释放、每十批探索且无额外流量、探索跳过限流冷却。供应商/模块边界与文件头检查通过；测试审计、类型检查、Chrome/Firefox/userscript 构建、userscript verifier 和文档构建通过。未运行全量回归。

userscript 初次构建被基础分支已有的语言资源缺失阻断；只在任务 worktree 临时生成后完成验证，不把无关资源纳入补丁。Firefox 只做构建验证，未验证真实 Firefox 请求。

补充动态排序后，重新执行的 147 项定向测试、812 项架构边界与文件头检查通过，Google 最终 27 项测试通过；测试审计、类型检查与三端构建也重新通过。

真实生产扩展在临时 Edge 配置中通过 DOM 断言验证悬浮 `[1,0,1]`、全文 `[6,0,6]`、原文恢复、相邻段落不受悬浮操作影响及 URL 不变。服务为 `google`，英文到简体中文；6 段首次全文约 294 毫秒，再次约 1,157 毫秒。网络记录包括 6 条合为一次的真实 `translateHtml` 请求。

注入当前首选接口 HTTP 503 后，备用请求约 0.4 毫秒内发出；第一段取得真实备用译文约 923 毫秒，下一段跳过故障接口，约 194 毫秒完成。无响应的单入口 2 秒与四入口总预算由确定性测试覆盖。这些时间仅说明本机网络与合成短文本的结果，不是对大网页、国内直连或 Chrome 自带翻译的速度保证。

另在全新临时配置中，对生产扩展注入合成译文与可控延迟。前四批延迟分别设置为 1,400、100、1,800、100 毫秒，观察到 HTML → LIST → LIST → HTML：较慢的首选失去优先级，备用变慢后再次转向评分更高的入口。30 批仅产生 30 次网络调用；第 10 批探索主 RPC，第 20 批探索英国 RPC，四条线路均被观察。这是浏览器中的路由行为验证，合成响应不计作服务商真实成功率。

浏览器保护证据：`launchMode=macos-background-cdp`、`focusPolicy=launchservices-no-foreground`、`windowPlacement.mode=background-visible-no-focus`、`browserFrontmost=false`，正常尺寸窗口完整位于第二屏；未连接用户日常配置。临时浏览器和配置已清理。
