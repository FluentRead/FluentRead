# Harness 阅读学习实现报告（Mermaid 版）

本次最初从 `main` 提交 `4d1d9e5` 开发，合并前已同步到 `73f4c6d`，工作分支为 `codex/harness-reading-core-20260905`。在同一分支完成阅读学习入口、真实流式回答和最近 30 天会话。本文记录实现范围与验证证据，发布状态以 GitHub PR 为准。

当前完成的是“选区阅读学习”与 Harness 的连接。原有全文翻译、悬浮翻译尚未统一迁入 Harness，因此它目前承担阅读学习的内核，而不是全插件所有功能的统一调度内核。

## 已实现的功能

| 能力 | 已实现行为 |
| --- | --- |
| 阅读入口 | 默认关闭；开启后与原有划词翻译共用入口和卡片，选中本身不调用模型，点击“理解”才发起请求。 |
| 直接恢复 | 选区旁点击“最近”直接查看历史，不触发新分析；恢复后可以继续提问。 |
| 理解整句 | 保留网页原生双击选词与拖选；识别到整句候选时，允许用户显式扩展分析对象。 |
| 四个学习动作 | 读懂：解释原意、语气和指代；拆句：解释主干、从句和语法；用法：说明搭配和例句；练习：围绕内容生成一道小练习。 |
| 连续学习 | 在同一卡片追问或提交练习答案，请求保留最多四轮近期问答；普通模式按问答在本机保存 30 天，历史可折叠查看、恢复、删除或清空。 |
| 结果操作 | 停止、失败重试、复制；符合条件的英文单词可显式加入现有单词本，隐私窗口不提供收藏。 |

| 服务与模型 | 复用已有凭据；可以跟随默认服务及其模型，也能独立选择服务、选择或输入模型名。支持兼容协议与 Claude、Gemini 原生协议。 |
| 设置与引导 | 工具与学习下新增 DeepSeek Harness；提供不联网的例句演示，详细偏好折叠展示并持久保存。 |
| 生命周期 | 停止、关闭、换选区、页面导航或相关设置变化时取消请求；旧回答不能覆盖新选区。 |
| 现有能力连接 | 接入原划词卡、服务配置、单词本、模型用量和配置同步。修复嵌套配置共享导致设置变更未保存的问题。 |

## 产品定位

FluentRead 的阅读学习应当围绕用户正在读的文字展开：先读懂，遇到难点再拆句、学表达，最后通过一道小练习确认自己能用出来。学习入口和原有划词翻译共用一张卡片，保留网页原生的双击与拖选行为。

选中文字出现轻量入口。明确点击“理解”后，后台才调用模型；点击“最近”可直接恢复已有会话，不会额外发起分析。需要更多解释时在当前卡片追问。切换选区或关闭卡片会取消请求，普通窗口已保存的问答仍可在最近 30 天内恢复。单词收藏是显式操作，复用现有单词本；模型请求复用服务凭据与模型用量记录。

## 内核与开源来源

固定上游版本为 DeepSeek Harness `dsh-v0.1.3-alpha.1`，提交 `d347e703908d0406b7a7ef80e3a0e594d86b2215`。实际移植的是会话 surface 的只追加事件投影子集；模型／工具循环是适配浏览器的独立有界实现，并非完整上游包。

内核负责把用户消息、模型消息、授权段落工具和追问历史串成一致的会话。FluentRead 的服务层负责模型协议、配置快照、错误与用量，内容层负责选区与卡片。单次请求有模型调用、工具调用、并发与总时限限制，并按 tab/frame/document 归属取消。

```mermaid
flowchart TD
    A["阅读卡<br/>选中文字、动作、问题、近期问答"] --> B["后台请求管理<br/>配置快照、请求归属、并发与取消"]
    S["现有服务配置与凭据"] --> B
    B --> C["Harness 会话事件记录<br/>采用上游只追加投影子集"]
    C --> D["FluentRead 有界循环<br/>模型调用、工具结果、下一步请求"]
    D --> E["AI SDK 模型接入层"]
    E <--> F["用户选择的模型<br/>兼容服务 / Claude / Gemini"]
    E --> G{"模型返回"}
    G -->|"工具调用"| H["校验工具名、参数与调用次数"]
    H --> I["read_context<br/>只返回本次已捕获的段落"]
    I --> C
    G -->|"正文增量"| J["检查请求仍有效<br/>通过流式端口发送正文"]
    J --> K["阅读卡实时显示<br/>停止或失败时保留部分回答"]
    B <--> P["本机会话仓库<br/>恢复近期问答、保存流式检查点"]
    P --> Q["逐条问答保留30天<br/>读取时、启动时及定时清理"]
    E -.-> U["现有模型用量记录<br/>不保存选区或回答正文"]
    K -->|"用户主动收藏"| V["现有单词本"]
    X["关闭、停止、换选区或导航"] -.-> B
```

当前只实现 `read_context` 一个模型可调用工具；“当前选区”模式不提供它。单词本写入由用户点击触发，不是模型自主调用的工具。循环默认最多进行 4 次模型调用、2 次工具调用，40 秒超时；不会让模型无限运行。

本次复用 AI SDK，新增固定版本的 Anthropic、Google 适配器，使 Claude、Gemini 及已支持的兼容服务保持各自协议。DeepSeek Harness MIT 与新增适配器 Apache 2.0 声明随扩展包分发。

更多来源与范围见[使用指南](../guide/deepseek-harness.md)。

## 当前边界

- 全文翻译、悬浮翻译等现有链路尚未迁入 Harness；本次完成的是阅读学习链路及其与现有能力的连接。
- 四个学习动作由模型生成解释和练习，不是独立语法解析器或确定性的学习评测系统。
- 正文通过 runtime stream port 逐字增量显示；停止或错误时保留已收到的部分正文并标示状态。
- 本机会话按每条问答保存 30 天，支持历史折叠查看、恢复继续提问、删除和清空；恢复不会自动请求模型，模型只取最近四轮上下文。
- 会话持久化由 FluentRead 的 IndexedDB 仓库实现；没有移植完整上游运行时的 replacement、provenance rewrite、持久化 session 子系统、CLI、桌面界面、插件加载器或文件／shell 执行能力。
- 模型选择以对应服务实际支持为准；模型不支持工具调用时，可使用“当前选区”模式。

## 流式回答与最近 30 天会话

正文在模型仍生成时逐步显示，来自真实的模型流式响应。工具参数和模型内部推理不会进入阅读卡。用户停止、关闭或切换选区后，旧请求立即失效，已收到的部分回答保留下来，并标记为中断或失败。

普通窗口的选区、已授权段落、问题、回答和状态保存在扩展自己的 IndexedDB 中。每条问答自创建起保留 30 天；继续追问不会延长旧问答的保存期限。流式过程约每 500 毫秒保存一次检查点，结束时立即保存最终状态；后台重启后可恢复最后一次已保存的部分回答。隐私窗口不保存，也不能读取普通窗口会话。

选区旁的“最近”直接打开历史，恢复时不请求模型。恢复后主动追问才将最近四轮非空问答作为模型上下文，中断回答会明确标注为未完成。设置页的“最近会话（30天）”默认折叠，支持查看、删除和清空。列表分页读取；删除或清空后，正在运行的旧请求不能把会话重新写回来。

```mermaid
sequenceDiagram
    actor U as 用户
    participant C as 阅读卡
    participant H as Harness 会话编排
    participant M as 所选模型
    participant S as 本机会话仓库
    U->>C: 点击理解或提交追问
    C->>H: 当前动作和会话标识
    opt 恢复已有会话
        H->>S: 读取未过期问答
        S-->>H: 原文、授权段落和近期历史
    end
    H->>S: 保存本轮问题和生成状态
    H->>M: 发起模型请求
    loop 正文增量到达
        M-->>H: 正文片段
        H-->>C: 流式更新正文
        H->>S: 定期保存部分回答
    end
    alt 正常完成
        H->>S: 保存完整回答
    else 用户停止或关闭卡片
        C->>H: 取消当前请求
        H->>S: 保存部分回答和中断状态
    else 模型或网络错误
        M-->>H: 请求失败
        H->>S: 保存部分回答和失败状态
    end
    U->>C: 再次点击最近并恢复
    C->>S: 通过后台读取会话
    S-->>C: 显示历史，不调用模型
    Note over S: 启动、读取与定时清理超过30天的问答
```
