# Safari 广播权限风险修复验证（2026-10-16）

四处后台广播已改为向实际运行内容脚本的页面发送通知。专项验证通过 161 个测试，七个受影响模块的语句、分支、函数和行覆盖率均为 100%；Safari 原生行为仍待验收。

## 风险与变更

所审查的 [WebKit 公开 tabs 实现](https://github.com/WebKit/WebKit/blob/main/Source/WebKit/UIProcess/Extensions/Cocoa/API/WebExtensionContextAPITabsCocoa.mm)中，`tabsQuery` 汇集匹配标签的网址，再调用 `requestPermissionToAccessURLs`。因此，后台广播使用 `tabs.query({})` 存在扩大网站授权请求范围的风险；同份源码的 `tabsSendMessage` 未调用该授权钩子。这是公开 `main` 源码证据，不能代表已安装的 iOS 26.2 二进制，也没有证明此前 H5 权限提示的调用来源。

配置及阅读模型失效、翻译缓存清理、词书变化、个人校订变化四条后台路径共用接收者策略。Safari 从可信配置读取消息登记实际内容脚本标签，只在 `storage.session` 保存整数标签 ID，不保存网址、正文或凭据；不按顶层网址筛除 iframe 或临时授权页面。会话存储跨后台唤醒保留，浏览器会话结束后清空；标签关闭和迟到登记均有独立回归。Chrome、Firefox 保留原标签查询行为。

Safari 设置页的功能状态广播也已停止全标签查询，继续通过原有配置保存和内容脚本订阅同步变化；Chrome、Firefox 保留即时广播。实际 SFC 生命周期测试验证了正常编辑、配置回读和卸载后的回调。没有新增权限、开发者签名或发布操作，也未修改或复制参考仓库实现。

## 验收边界

这些测试使用注入端口，不代表实际 Safari 的会话存储、后台挂起与唤醒、临时授权或 iframe 投递已经验收。持续会话存储失败时，未落盘的新接收者与待补发意图仅保留在当前后台内存；若后台随后被销毁，不能保证恢复这些状态。实现不会回退到全标签枚举来绕过该故障。

仍需对新产物执行 Safari 原生验收，并分别记录站点权限、服务域权限及实际变化同步。现有结果不能替代 iPhone／iPad 真机测试，也不改变 Safari 开发预览的交付边界。
