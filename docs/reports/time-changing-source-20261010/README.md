# 时间展示与持续变化文本专项验证

2026-10-10。主分支已有独立时间过滤和高频原文防抖。本次扩充专项案例，确认此前未覆盖的繁体时长、带点缩写、时区及拆分行内节点确实会进入翻译来源；修改前新增矩阵共 124 个案例，96 通过、28 失败，见 [复现记录](./baseline-tests.txt)。本次补修这些问题，并处理整段 DOM 替换丢失变化历史、较慢持续更新穿过固定等待窗口的情况。

## 当前行为

| 页面内容 | 处理 |
| --- | --- |
| 独立时钟、日期和日期与时钟组合 | 保留原文，包括全角、AM/PM、上午/下午、UTC/GMT 与常见时区 |
| 独立秒、分钟、小时及组合时长 | 保留原文，包括繁体 `5 分鐘後`、缩写 `2 min.`、`1 hr. 2 min. 3 sec.` |
| 拆成多个行内节点的展示值 | 合并识别整个展示值，原节点保留；不将 `minutes`、`PM` 等碎片送给翻译服务 |
| 含时间的正常句子、单独单位词和普通 aria-live 消息 | 仍可翻译，如 `The task takes 8 minutes`、`minutes` |
| 连续仅数值变化的短计数标签 | 识别后保持原文；标签语义变成正文后恢复 |
| 连续变化的普通正文 | 暂停请求，停止变化后只翻译最新来源 |

展示值扫描最多访问 32 个节点、128 个字符，只合并行内内容，不跨段落拼接；隐藏、禁译、代码等后代遵守当前保护选项。共享的原始 DOM 保护缓存避免重复样式读取，原文槽例外与追加 `notranslate` 均有用例。翻译、恢复和重新翻译保留本地展示值及宿主节点。

普通正文从第二次真实变化估计更新间隔，安静窗口为近期最大间隔的 1.5 倍，限制为 **1.8–10 秒**；峰值观察期为 10 秒。每 250 毫秒更新仍使用 1.8 秒窗口，每 2.2 秒更新识别后约等待 3.3 秒。识别前可发生请求；连续更新识别后不新增请求，稳定后有限恢复。大于观察期的更新按普通内容变化处理。

同一活父级、同结构与语义槽的替换节点可以继承已断连候选历史。已有兄弟节点的弱集合防止删除前段后，原本存在的相邻段落误继承计数禁译。交接记录使用弱引用及纯历史快照，最多每父级 64 槽、父级 64 个直属节点、来源 8192 字符，有效期 10 秒；超出范围按新候选处理。恢复和停止会话取消定时器，路由重置清理历史。

## 浏览器证据

浏览器执行使用生产 Chrome MV3 扩展、真实隔离 Edge 和本地确定性 Microsoft 传输。第一轮已执行 54 个双语案例，但随后创建测试页时触发焦点保护，测试中止，见 [中断报告](./browser-interrupted.json)。中断运行不计为完整通过。

最终运行复用单个临时宿主页，并启用原生 macOS 激活事件监控；不连接日常浏览器配置。**113 个场景全部通过**，见 [完整浏览器报告](./browser-report.json)：

- 42 种独立展示值 × 双语/仅译文两种模式，共 **84 次执行**，均无 provider 翻译项、无译文节点，保留原节点；更新、恢复后显示最新值。
- **24 个生命周期场景**，覆盖数字标签、普通正文、完整 owner 节点替换、稳定后只处理最新来源、待执行窗口取消、翻译中恢复、再次翻译与旧请求失效。每 250 毫秒持续变化时不新增请求。
- 旧结果审计观察实际译文：仅译文模式读取宿主 `aria-label`，避免 closed ShadowRoot 的宿主 `textContent` 仅包含原文；同时断言观测到最新译文，旧来源从未提交。
- 每 2.2 秒变化的普通正文，两种模式均在识别前出现一次请求，识别后连续更新 **零新增请求**；稳定后各请求一次，旧结果未写入 DOM。
- **5 个悬浮场景**，包括正常正文翻译—恢复—再次翻译 `[1, 0, 1]` 及四种时间/时长排除。

运行方式为 `macos-background-cdp`，焦点策略 `launchservices-no-foreground`，第二屏正常可见窗口 `background-visible-no-focus`（1280 × 900）；原生监控记录一次“提醒事项”激活，无测试浏览器激活。启动时 `browserFrontmost=false`，结束前再次确认测试浏览器在后台，`focusViolation=null`，`errors=[]`。截图：[双语模式](./bilingual-settled.png)、[仅译文模式](./single-settled.png)。

证据边界：本地夹具验证候选、请求、DOM 和生命周期，不代表在线供应商翻译质量、Firefox 运行时或商店版本已发布。

可复现入口：`scripts/testing/run-changing-source-test.cjs`，传入 `--extension-dir .output/chrome-mv3`、`--playwright-root <工作区 Node 包目录>`、`--artifacts-dir <证据目录>`。后台焦点保护失败时停止，不切换到前台测试模式。
