# 写作助手

写作助手帮助你根据当前讨论起草回复，完善已有草稿，再按要求调整表达。功能默认开启，自动在 Gmail 邮件编辑器，以及 GitHub 的 Issue、Pull Request 回复区显示入口。其他网站、GitHub 仓库首页和列表页不显示入口。

完整设置的「工具与学习 → 写作助手」只有一个功能总开关，另提供写作偏好，以及 AI 服务、模型和服务连接配置。输出语言独立选择；「回答风格」直接显示长度、风格、语气和「您的角色」四组选项，点击选项即可保存，与写作卡片使用同一份持久化设置。设置页调整影响后续生成，不会请求 AI 或改写当前版本。写作服务可以与网页翻译分别选择；微软、谷歌等机器翻译服务不能用于写作。不另设网页入口开关、写作快捷键或写作专用网站禁用名单。插件总开关与全局网站禁用规则仍然有效；升级时保留用户明确关闭写作助手的选择。

网页入口和卡片使用 FluentRead 品牌图标，完整设置的侧栏沿用普通功能图标。Popup 不提供独立写作入口。卡片贴着当前回复入口展开，滚动和调整窗口时跟随定位；打开时根据空间选择展开方向，保持在屏幕内。卡片高度与本次展开方向固定，草稿、参考内容、回答风格与语言选择在同一区域切换，长内容在卡片内滚动。右上角的设置按钮沿用线性图标风格。

点击「写作助手」后，已有草稿会自动进入完善流程；空草稿有当前讨论时自动起草回复；新邮件没有参考内容时，先在底部写下要点，再点击「生成」。未选择支持写作的 AI 服务时，卡片提供「设置写作服务」入口；缺少模型或连接配置时按提示完成设置。卡片右上角也可打开写作设置。

输出语言默认「跟随目标语言」，使用你在 FluentRead 中设置的翻译目标语言；卡片显示实际输出语言。点击语言入口，可以搜索并选择其他语言，也可以恢复跟随目标语言。语言选择会保存；已有正文时，切换到不同选项会按新语言改写当前正文。旧版的自动语言偏好迁移为跟随目标语言，已选定的具体语言继续保留。

默认回复长度为「简短」，语气为「自然」，风格与角色为「自动」。点击下方「回答风格」，集中选择长度、风格、语气和「您的角色」；语气与角色支持预设和自定义。选择过程中不会请求 AI。确认「应用并改写」后，保存这些偏好并根据当前正文发起一次改写；尚无正文时，有可用参考或要点则「应用并起草」，没有内容则只「应用」偏好。点击「取消」或「返回草稿」放弃本次未应用的选择。设置页也提供同样的预设和自定义输入；设置页自定义内容留空时，语气回到「自然」、角色回到「自动」（不指定回复身份）。角色仅用于调整表达立场，不能代替事实或授权，也不应让 AI 编造承诺。

明确选择开发者或维护者身份并回复反馈时，回复应先简短感谢反馈或贡献，再回应具体问题，必要时表达继续排查或协助支持的意愿，避免空洞的客服套话。不能据此声称已经复现或修复，也不应承诺完成日期。其他角色与自动身份不套用开发者口吻。

「参考内容」展示当前编辑器对应的信息和原草稿。GitHub 包含当前项目、Issue/PR 编号和可见标题，普通回复结合原帖与最近讨论；PR 行内回复使用当前评审线程，不混入其他线程。可见状态与发起人也会作为辅助信息。Gmail 使用当前邮件会话或撰写窗口中的可见主题与邮件正文。标题单独保留预算，参考信息总计最多 12,000 字符；有后续讨论时，原帖最多占 4,000 字符，余量优先保留最近回复。不读取隐藏内容、侧栏或其他页面，也不访问帖子中的链接。

原有草稿最多 12,000 字符且只读。「项目与讨论」可删改，核对后点击「重新起草」，从原有草稿与更新后的参考信息重新生成；直接返回草稿会放弃尚未应用的参考修改。正文默认以 Markdown 预览呈现，点击「编辑正文」切换到原文编辑，完成后返回预览。预览支持标题、段落、列表、引用、代码和简单表格，以及粗体、斜体与行内代码；HTML 按字面文本显示，链接和图片不会被执行或加载。这是有限的 Markdown 子集，不保证完整 GitHub Markdown 排版。

生成后可以复制、重新生成，或在底部输入改进要求。改写以当前正文为基础，包含你对正文的手工修改。调整期间保留上一稿，成功后显示新版本；失败或停止时仍可继续使用已有草稿。卡片保留本页会话最近五个版本，同一编辑器和原草稿未变化时，关闭再打开会恢复当前结果。

点击「插入回复」只填写原编辑框，随后收起卡片并返回回复框，发送仍由你自己完成。GitHub 插入和复制保留 Markdown 原文；Gmail 插入和复制使用可读纯文本，去掉标题、强调等显示语法，保留段落、列表、代码、表格文本和链接地址。如果原草稿已改变、编辑器已关闭或页面已经切换，则保留网页原内容并提示手动复制。原草稿含链接、图片等复杂格式时，主操作为「复制回复」，保留原有格式。

「停止」、关闭卡片、离开页面或停用功能都会取消当前请求；迟到的结果不能覆盖新内容。草稿与参考内容只在本页会话中保留，开始起草或调整时发送给所选 AI 服务；自动显示入口本身不会调用 AI。模型用量中将这些调用归类为「写作助手」。写作助手不会自动发送邮件或提交评论。

MiniMax 模型列表新增 `MiniMax-M3` 与 `MiniMax-M3.1`，网页翻译和写作助手共用这份目录，已有默认模型保持不变。
