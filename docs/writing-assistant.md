# 写作助手

写作助手帮助你根据当前讨论起草回复，完善已有草稿，再按要求调整表达。功能默认开启，自动在 Gmail 邮件编辑器，以及 GitHub 的 Issue、Pull Request 回复区显示入口。其他网站、GitHub 仓库首页和列表页不显示入口。

完整设置的「工具与学习 → 写作助手」只有一个功能总开关，另提供 AI 服务、模型和服务连接配置。写作服务可以与网页翻译分别选择；微软、谷歌等机器翻译服务不能用于写作。语言、篇幅和语气在卡片中按本次需要调整，不另设网页入口开关、写作快捷键或写作专用网站禁用名单。插件总开关与全局网站禁用规则仍然有效；升级时保留用户明确关闭写作助手的选择。

网页入口和卡片使用 FluentRead 品牌图标，完整设置的侧栏沿用普通功能图标。Popup 不提供独立写作入口。卡片贴着当前回复入口展开，滚动和调整窗口时跟随定位；打开时根据空间选择展开方向，保持在屏幕内。卡片高度与本次展开方向固定，生成和查看参考内容只更新内部内容区域。

点击「写作助手」后，已有草稿会自动进入完善流程；空草稿有当前讨论时自动起草回复；新邮件没有参考内容时，先在底部写下要点，再点击「生成」。未选择支持写作的 AI 服务时，卡片提供「设置写作服务」入口；缺少模型或连接配置时按提示完成设置。卡片右上角也可打开写作设置。

「参考内容」展示当前编辑器对应的讨论和原草稿。原有草稿只读，当前讨论可在重新生成前删改；生成后的正文可直接编辑。参考内容最多 12,000 字符，原草稿最多 12,000 字符；不读取隐藏内容、侧栏或其他页面。输出语言默认自动跟随讨论或草稿；缺少这些内容时跟随回复要点的语言。

生成后可以直接编辑正文、复制、重新生成，或在底部输入改进要求。更改语言、篇幅或语气会调整当前正文，包含你对正文的手工修改。调整期间保留上一稿，成功后显示新版本；失败或停止时仍可继续使用已有草稿。卡片保留本页会话最近的版本，同一编辑器和原草稿未变化时，关闭再打开会恢复当前结果。

点击「插入回复」只填写原编辑框，随后收起卡片并返回回复框，发送仍由你自己完成。如果原草稿已改变、编辑器已关闭或页面已经切换，则保留网页原内容并提示手动复制。原草稿含链接、图片等复杂格式时，主操作为「复制回复」，保留原有格式。

「停止」、关闭卡片、离开页面或停用功能都会取消当前请求；迟到的结果不能覆盖新内容。草稿与参考内容只在本页会话中保留，开始起草或调整时发送给所选 AI 服务；自动显示入口本身不会调用 AI。模型用量中将这些调用归类为「写作助手」。写作助手不会自动发送邮件或提交评论。

MiniMax 模型列表新增 `MiniMax-M3` 与 `MiniMax-M3.1`，网页翻译和写作助手共用这份目录，已有默认模型保持不变。
