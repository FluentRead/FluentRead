# 写作助手

写作助手帮助你根据当前讨论起草回复，再按要求改进表达。网页入口仅出现在 Gmail，以及 GitHub 的 Issue、Pull Request 回复页面。其他网站、GitHub 仓库首页和列表页不显示入口，也不会响应写作快捷键。

在完整设置的「工具与学习 → 写作助手」中启用功能，选择已配置的 AI 服务和模型。写作服务可独立于网页翻译；微软、谷歌等机器翻译服务不能用于写作。默认关闭功能，启用后在回复框的发送或评论按钮旁显示「写作助手」。

入口和卡片均使用 FluentRead 品牌图标。卡片贴着当前回复入口展开，滚动和调整窗口时跟随定位；打开时根据空间选择展开方向，保持在屏幕内。卡片高度与本次展开方向固定，生成与展开参考内容只更新内部滚动区域。

点击入口旁的「⋮」可以直接进入写作助手设置，也可以选择「本次关闭」（刷新或下次访问恢复）、「在当前网站停用」或「永久停用写作助手」。后两项会保存到设置，可随时重新开启。

点击入口或使用 Alt+W（macOS 显示为 Option+W）打开回复卡片。可以先写下回复要点，也可以直接根据讨论生成草稿。「查看参考内容」展示本次参考的正文和原草稿，支持删改。参考内容最多 12,000 字符，原草稿最多 12,000 字符，不读取隐藏内容、侧栏或其他页面。

生成后可以直接编辑正文、复制、重新生成，或在底部输入改进要求。语言和语气可以在生成前调整。点击「插入回复」只填写原编辑框，发送仍由你自己完成。如果原草稿已改变、编辑器已关闭或页面已经切换，则保留新内容并提示手动复制。含链接、附件等复杂富文本的原草稿使用复制回退，避免破坏格式。

「停止生成」、关闭卡片、离开页面或停用功能都会取消当前请求；迟到的结果不能覆盖新内容。草稿与参考内容只在本页会话中保留，点击生成时才发送给所选 AI 服务。模型用量中将这些调用归类为「写作助手」。

设置中可以关闭网页按钮、修改或清除快捷键、选择默认语言及语气，也可以按域名禁用写作助手。网站规则包含子域；插件总开关与全局网站禁用规则同样有效。

MiniMax 模型列表新增 `MiniMax-M3` 与 `MiniMax-M3.1`，网页翻译和写作助手共用这份目录，已有默认模型保持不变。
