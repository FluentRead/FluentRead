# FluentRead 宣传与商店素材

中文和英文的文案、界面截图及宣传图分别制作。两版均重点介绍 GPL-3.0 开源与 DeepSeek Harness 会话内核的浏览器适配。

这一目录独立于 README 和官网，供 Chrome 商店填写、社区发布及产品介绍使用。中英文版本分别放置，上传时选择对应语言。

## 直接拿来用

| 文件或目录 | 用途 |
| --- | --- |
| `chrome-web-store/zh-CN/` | 中文名称、短介绍、详细介绍与 5 张商店截图 |
| `chrome-web-store/en/` | 对应的英文介绍与 5 张商店截图 |
| `chrome-web-store/promo/` | 440×280 小宣传图与 1400×560 横幅，各含中英文备选 |
| `chrome-web-store/icon-128.png` | 128×128 商店图标 |
| `copy/` | 一句话、简短介绍与社区发布文案 |
| `source/` | 2x 高清原图、自有示例文章、译文与采集记录 |
| `asset-manifest.json` | 每张成品的尺寸、格式、体积与来源 |

详细介绍是 UTF-8 纯文本，可整段复制。短介绍单独存放且不超过 132 字符；它对应扩展的摘要，不会在本次内容改写中自动修改扩展 manifest。提交商店时请检查待发布包中的名称和摘要是否一致。

## 图片怎么选？

截图依次展示双语阅读、AI 翻译卡、划词翻译、文档翻译和服务选择。商店截图为 **1280×800、无透明通道 PNG**，高分辨率原图保留为 2560×1600。源语言均设为 **自动检测**；语言本身仍可手动选择。

宣传图用于品牌展示，与截图分开。Chrome 的宣传位不按语言自动区分，从中英文备选里选择一组上传即可。

官网使用同源无损 WebP，并提供高清查看链接；首页主图按屏幕宽度选择 1280 或 2560 像素版本。不要再次把网页图放大截图充当原图。

## 内容与来源

所有产品界面来自本项目生产扩展在临时 Edge 配置中的真实渲染。演示文章由本项目素材脚本编写，不包含用户内容；译文与翻译卡讲解由预先审校的本地示例服务返回，分别经过扩展的真实翻译流程和 Harness 会话、段落工具流程。它们用于展示交互和排版，不是外部服务质量或真实站点兼容性测试。

网页正文中 `Field Notes` 等演示导航保持原文；文档示例只含完整的文章正文，避免无意义地重复菜单。没有修改扩展界面来伪造成功状态。截图中的界面设置属于本次临时配置。

图标来自仓库 `public/icon`，文案、示例文章与成品按项目 GPL-3.0 分发。第三方商标归各自所有。

## 重新生成

在本 worktree 构建扩展后，运行 `scripts/capture-product-assets.cjs`，用 `--runtime` 指定含 Playwright 的 Node 包目录，用 `--helper` 指定 focus-safe-browser.cjs。默认采集中文；英文另加 `--locale en --output marketing/source/screenshots-en`。脚本只创建临时浏览器配置，采集后关闭本次实例。

随后运行 `scripts/build-product-assets.cjs --runtime <Node 包目录>` 生成官网与商店图片。`scripts/verify-product-site.cjs` 检查站点语言、链接、图片、桌面与窄屏表现。运行 `node scripts/package-product-kit.cjs --output <输出目录>` 可生成独立的中英文 ZIP，各自附带商店资料、宣传图、社区文案、2x 原图和示例来源。所有中间产物和截图原图都有明确来源，便于以后更新。

## 商店规格依据

尺寸与用途核对于 2026-09-06，依据 [Chrome 官方图片指南](https://developer.chrome.com/docs/webstore/images) 与[商店资料说明](https://developer.chrome.com/docs/webstore/cws-dashboard-listing)。商店截图采用推荐的 1280×800；每种语言提供 5 张。宣传小图为 440×280，横幅为 1400×560，图标为 128×128。

这些材料面向当前源码的能力。实际提交时请使用已包含对应功能的发布包，并在商店后台核对版本、隐私链接和数据披露。此目录不代表已经提交、审核通过或发布。
