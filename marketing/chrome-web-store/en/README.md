# English release materials

- `title.txt`: store title.
- `short-description.txt`: short store summary.
- `description.txt`: complete, ready-to-copy store description.
- `screenshots/`: five English-interface screenshots, 1280×800 PNG.
- [English promotional images](../promo/): use the two files beginning with `en-`.
- [English community copy](../../copy/en.md): short introduction and community post.
- [High-resolution originals](../../source/screenshots-en/): actual 2x captures for larger displays.

Both the copy and images emphasize GPL-3.0 open source and the reading card’s browser adaptation of the DeepSeek Harness session core. Screenshots use automatic source-language detection; manual selection is also available.

Images come from the real extension. The sample article, translations, and AI explanations are supplied by a local demonstration service to show the interface and reading flow. They are not benchmarks of an online model’s translation quality. Match the materials to the version you are releasing.
