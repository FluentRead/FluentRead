# 中文发布材料

- `title.txt`：商店名称。
- `short-description.txt`：一句话摘要。
- `description.txt`：可以直接复制的完整商店介绍。
- `screenshots/`：5 张中文界面的商店截图，1280×800 PNG。
- [中文宣传图](../promo/)：选择文件名以 `zh-CN-` 开头的两张图。
- [中文社区文案](../../copy/zh-CN.md)：短介绍与社区发布版本。
- [高清原图](../../source/screenshots/)：保留实际两倍像素，用于更大尺寸展示。

介绍重点为 GPL-3.0 开源，以及翻译卡对 DeepSeek Harness 会话内核的浏览器适配。截图里的源语言为自动检测，用户仍可手动选择。

图片来自真实扩展界面；示例文章、译文与 AI 讲解由本地素材服务提供，用于展示交互和排版。不要把它们用于宣称某个线上模型的翻译质量。上传前以实际发布版本为准。
